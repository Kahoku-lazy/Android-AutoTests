# ARCH 章结构细则

> 主 skill 的渐进披露。写稿时优先打开 **ARCH-01** 对照，本文件作速查。

---

## 类型 A / B 章序

**类型 A（无自有表，如仪表盘）**

```
文头 → 简述 → 能获取什么 → 关联文档
1. 概览（定位 + 四图 + 同步表 + 偏差表）
3. 后端（跳过 §2）
4. API
5. 边界
6. 设计要点
变更记录
```

**类型 B（有表，或需显式「无表+依赖他表」）**

```
…至 §4 同 A…
5. 数据模型（ER / 状态机 / 无自有表说明）
6. 边界（含 api.__all__ + 跨模块）
7. 设计要点
变更记录
```

瞬态模块（如设备检查器）可选类型 B 短节说明生命周期，勿过度装饰 ER。

## 文头模板

```markdown
# ARCH-{序号} — {中文名} ({English Name})

> **版本**：vX.Y · **日期**：YYYY-MM-DD · **关联模块**：`apps/{name}/` · 前端 `frontend/src/modules/{name}/`
```

关联必须链 `ARCH-00` 对应小节 + `PRD-{同号}-…`，并写 **契约以 PRD §5 为准**。

## 四图 checklist

| 图 | 必须表达 |
|----|----------|
| 全景 | 用户 → 网关 → 后端 → 下游（DB/设备/他 App） |
| 包图 | import 方向；实线合法 / 虚线特殊；图下防火墙 ASCII |
| 数据流 | 源 → 处理层 → 字段或前端**角色** |
| API 关系 | 端点 → 角色；未消费标 ❌；附同步方式表 |

着色尽量对齐 ARCH-01 分层色。

**前端命名**

| ✅ | ❌ |
|----|-----|
| 统计卡片、截图栏、候选面板、设备选择区 | ScreenshotView、XPathCandidatePanel、index.vue、props |

## 各章粒度

| 章 | 写 | 不写 |
|----|----|------|
| §1.1 | 1–3 句定位 + 模块性质 | 用户故事、验收 |
| §3 | 真实目录；核心类型/函数名；可选实测 SQL/ms | 逐步业务验收 |
| §4 | 信封说明；端点表（消费列）；1 个 JSON 骨架 | 完整字段表、错误文案大全 |
| §5 模型 | ER 关键列；状态机；或「无自有表」+ 依赖表生命周期 | 复制 models 全文 |
| 边界 | 规则表；防火墙；`__all__`（可空）；跨模块方向/用途 | — |
| 要点 | 5–8 条**决策** | 功能复读 |

信封非 `{status,data}`：章首登记原因 + 前端是否已适配。

## ARCH-01 vs ARCH-03（反例速查）

| 项 | 要求 |
|----|------|
| 跳过 §2 | 必须 |
| 四图 | 必须 |
| 前端抽象角色 | 必须（ARCH-03 写了 Vue 名 → 错误） |
| 同步方式表 | 必须 |
| 契约偏差表 | 有则写 |
| 性能数字 | 有实测才写 |
| API 详字段 | 一律指 PRD |
