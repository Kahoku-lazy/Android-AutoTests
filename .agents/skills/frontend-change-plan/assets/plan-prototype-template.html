子页面的硬约束

Do

  • L2+ 页头必有「返回」或波浪面包屑
  • 同模块三级共用同一模块色硬阴影
  • Hub 用 SketchCard；工作台用分栏；叶子用纸（表/Excel/详情）
  • AI 四子项侧栏切换，深链页独立全屏 + 回退
  • 画布 / 表体 / Excel 禁止旋转

Don't

  • 不要每层再包一层 el-card
  • 不要用浏览器原生 history 当唯一导航（要页内可见回退）
  • 不要在侧栏再复制一套模块内 Tab 顶栏（AI 例外：侧栏已是子项）
  • 不要三级页各写一套私有皮肤
  • 不要改路由深度或拆合业务

建议落地顺序

P0共享件：SketchTable / SketchCard(Hub) / 面包屑条 / DialogForm
P0设备管理（已有原型）→ 报告列表接同一张表纸
P1元素定位 + 用例管理「Hub→台→叶」成对落地（同一导航模版）
P1AI 四子项壳 + 任务/智能体详情回退
P2页面流列表 + 画布外框；检查器分栏纸；仪表盘钉板收尾

子页面最容易翻车的是「人找不到上一层」。 下面三种导航模版覆盖本平台全部深度。

三种导航模版

① 面包屑条

Hub → 工作台 → 叶子。元素/用例/页面流用。

  • 页头下方一条
  • 祖先可点，当前项黄马克笔
  • 可选左侧「← 返回」芯片

② 侧栏子项

AI 助手四子路由。侧栏即导航，页内不再叠顶 Tab。

  • WorkbenchHeader 随路由换标题
  • 深链（任务/Skill）跳出四子项，用面包屑回

③ 列表行进入

报告 run/task、AI 任务卡。行点击进详情。

  • 详情顶：返回列表 + 标题
  • 不新开浏览器 Tab
