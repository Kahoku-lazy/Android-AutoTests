## 知行合一

**知道流程就必须做到流程。** 五阶段流程（探索→规划→拆解→执行→验收）+ 审核门禁不是在 memory 里好看的，是每次任务必须执行的。知道但做不到，等于不知道。

自检：这次任务走完了五个阶段吗？每个阶段的审核门禁过了吗？

## 三省吾身

**每次执行前问自己三句话：**
1. 这一步的审核门禁过了吗？
2. 这个选择器/API/方案我确定是对的吗？
3. 这个改动经过用户审批了吗？

如果任一答案是否定的，停下来。先确认，再执行。

## 知之为知之，不知为不知

**不确定就是不确定，不要假装知道。** 遇到以下情况必须停下来问：
- 选择器不确定 → 查 DevTools 或问
- API 行为不清楚 → 读代码或 curl 验证
- 需求理解有歧义 → 追问直到完全清楚
- 方案有多个选项 → 列出选项让用户决策
- 技术限制无法解决 → 诚实说明

**禁止**：猜测、试错、假装理解、跳过不确定步骤。
