## 7. 需要处理的问题

### 🔴 Blocker（影响核心功能）

1. **Redis 服务未启动**
   - 影响: Channels WebSocket、实时任务推送、AI 对话流式输出
   - Django 启动时会尝试连接 `redis://localhost:6379/0`，失败后降级到 `InMemoryChannelLayer`
   - **修复**: 启动 Redis 服务
     ```bash
     # 方式1: 如果已装 Redis
     redis-server --daemonize yes
     # 方式2: 用 Docker
     docker run -d --name redis -p 6379:6379 redis:7
     ```

2. **AgentScope 服务未启动**
   - 影响: AI 助手对话功能（`/ai-assistant/chat/:id`）无法流式响应
   - AgentScope 2.0 库已装（2.0.3），但端口 8000 未监听
   - **修复**: 启动 AgentScope 服务
     ```bash
     cd D:\Kahoku\Android-AutoTests
     C:\Users\zhiyan\.workbuddy\binaries\python\versions\3.13.12\python.exe run_agentscope.py
     ```

3. **ADB 无设备连接**
   - 影响: 设备管理、元素定位、用例执行等核心测试功能不可用
   - 后端 API 在无设备时会返回错误（但服务本身正常）
   - **修复**: 连接 Android 设备并开启 USB 调试
     ```bash
     adb devices   # 确认设备出现
     ```

### 🟡 Suggestion（建议优化）

4. **app.db 已达 446.69 MB**
   - 长期运行需压缩或迁移
   - **修复**:
     ```bash
     # 方式1: SQLite VACUUM 压缩
     python -c "import sqlite3; sqlite3.connect('data/app.db').execute('VACUUM')"
     # 方式2: 迁移至 MySQL（项目已预留配置）
     set DB_ENGINE=mysql && set DB_NAME=android_autotests && ...
     ```

5. **mysqlclient 未安装**
   - 仅在切换到 MySQL 时需要
   - 当前 SQLite 模式不影响运行
   - **修复**（如需 MySQL）:
     ```bash
     pip install mysqlclient --target "C:\Users\zhiyan\AppData\Roaming\Python\Python313\site-packages"
     ```

6. **DJANGO_DEBUG=True**
   - 生产环境应设为 False
   - **修复**: 设置环境变量 `DJANGO_DEBUG=False`
