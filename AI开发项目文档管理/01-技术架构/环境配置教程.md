## 2. 前置条件

- **Windows 10/11 64-bit**（生产推荐）
- macOS / Linux 理论支持，但本教程以 Windows 为准

### 必备工具

| 工具 | 用途 | 安装方式 |
|------|------|----------|
| [scoop](https://scoop.sh) | Windows 包管理器 | 见下方 |
| Git | 代码版本控制 | `scoop install git` |

打开 **PowerShell**（普通用户，不需要管理员），执行：

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
Invoke-RestMethod -Uri https://get.scoop.sh | Invoke-Expression
```

验证：

```powershell

```

## 第三步：安装 MySQL 数据库

### 3.1 安装 MySQL 8.4 LTS

```bash
scoop install mysql-lts
```

安装路径：`C:\Users\<你的用户名>\scoop\apps\mysql-lts\current\`

### 3.2 启动 MySQL

```bash
# 前台启动（关闭终端即停止）
mysqld --console

# 或后台启动（推荐）
start /B mysqld --console
```

### 3.3 设置 root 密码

首次安装后 root 密码为空。打开新的终端窗口：

```bash
mysql -u root -e "ALTER USER 'root'@'localhost' IDENTIFIED BY 'autotests2026'; FLUSH PRIVILEGES;"
```

### 3.4 创建数据库

```bash
mysql -u root -pautotests2026 -e "CREATE DATABASE android_autotests CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
```

### 3.5 验证

```bash
mysql -u root -pautotests2026 -e "SHOW DATABASES;" | grep android_autotests
# 应输出: android_autotests
```

> **回退方案**：如不想用 MySQL，可跳过本步，系统默认使用 SQLite（`data/app.db`）。

## 常见问题排查

### Q1: `pip install` 报权限错误

**原因**：尝试安装到系统目录

**解决**：使用 `--target` 参数安装到用户目录：

```bash
pip install <包名> --target "%APPDATA%\Python\Python313\site-packages"
```

---

### Q2: Django 启动报 `MySQLdb.OperationalError: (1071, 'Specified key was too long')`

**原因**：MySQL utf8mb4 索引上限 3072 字节，某字段组合索引超限

**解决**：已修复。如仍遇到，检查 model 的 `UniqueConstraint` 字段总长度：

```python
# 每个字段字节数 = max_length × 4 (utf8mb4)
# 例：page(BigAutoField=8) + resource_id(500×4=2000) + bounds(200×4=800) = 2808 < 3072 ✓
```

---

### Q3: `GBK codec can't encode character`

**原因**：Windows 默认用 GBK 编码，处理 emoji 时失败

**解决**：设置环境变量 `PYTHONUTF8=1`

```bash
set PYTHONUTF8=1
```

或使用 `run.py` 启动（已自动设置）。

---

### Q4: AgentScope 启动失败，报 Redis 连接错误

**原因**：Redis 未启动

**解决**：

```bash
redis-cli ping
# 如非 PONG，则启动 Redis
redis-server --port 6379
```

---

### Q5: 前端页面加载卡顿（首屏 > 3 秒）

**原因**：可能下载了中文字体（3.4MB）

**解决**：已在 `vite.config.js` 中配置 `stripChineseFonts` 插件。如仍卡顿，检查 `frontend/dist/assets/` 下是否有 `.woff2` 中文字体文件。

---

### Q6: Django Admin 页面无样式

**原因**：静态文件未收集或 `STATIC_URL` 配置错误

**解决**：

```bash
python manage.py collectstatic --noinput
```

检查 `config/settings.py` 中：

```python
STATIC_URL = '/static/'  # 不能是 None
STATIC_ROOT = BASE_DIR / 'staticfiles'
```

---

### Q7: WebSocket 连接失败

**原因**：Redis 未启动或 Channels 配置错误

**解决**：

1. 确认 Redis 运行：`redis-cli ping` → `PONG`
2. 检查 `config/settings.py` 中 `CHANNEL_LAYERS` 配置
3. 查看日志：`logs/backend.log`

---

### Q8: ADB 设备列表为空

**原因**：USB 调试未开启或驱动未安装

**解决**：

1. 手机：设置 → 开发者选项 → 开启 USB 调试
2. 手机：用 USB 线连接后，弹窗点击「允许调试」
3. 电脑：安装 [Google USB Driver](https://developer.android.com/studio/run/win-usb)
4. 重试：`adb devices`

---

### Q9: `port_in_use` 检测不准

**原因**：Windows 上 `socket.bind()` 对 `0.0.0.0` 绑定的端口可能不抛异常

**解决**：已修复。`run.py` 改用 `connect_ex()` 探测。

---

### Q10: 如何从 MySQL 回退到 SQLite

**解决**：不设置 `DB_ENGINE` 环境变量，直接启动即可：

```bash
daphne -p 8765 -b 0.0.0.0 config.asgi:application
```

默认使用 `data/app.db`。如需指定：

```bash
set DB_ENGINE=sqlite
```

## 生产部署建议

1. **安全**
   - `DJANGO_DEBUG=False`
   - 修改 `DJANGO_SECRET_KEY` 为随机字符串
   - MySQL root 密码改为强密码
   - `ALLOWED_HOSTS` 限制为实际域名
   - 配置 HTTPS

2. **性能**
   - MySQL 配置 `innodb_buffer_pool_size` 为物理内存的 50-70%
   - Redis 配置 `maxmemory` 和淘汰策略
   - 前端使用 `npm run build` 构建后由 Nginx 托管
   - Daphne 配置多 worker

3. **持久化**
   - MySQL 注册为 Windows 服务：`mysqld --install MySQL --defaults-file="..."`
   - Redis 注册为 Windows 服务或用 `--daemonize yes`
   - 配置日志轮转

4. **备份**
   - MySQL 定时备份：`mysqldump -u root -p android_autotests > backup_$(date).sql`
   - Redis 持久化：配置 `appendonly yes`
   - 上传文件目录 `data/` 定期备份
