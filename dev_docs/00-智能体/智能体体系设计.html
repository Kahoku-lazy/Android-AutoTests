三档强度判定（Phase 0 规则引擎）

🪶 Lite

  • 1 文件 ≤50 行 / 修 Bug / 文案 / 注解
  • 阶段：探索→方案→编码→Review
  • 审查：终端打印
  • 无 HTML 报告

🛡️ Standard

  • 2–3 文件 / 50–200 行 / 单模块
  • 阶段：…→Review→测试
  • 审查：quality-gate 齿轮 1+2
  • 输出 HTML 报告

🏛️ Strict

  • 新模块 / 跨模块 / API / >200 行
  • 阶段：…→测试→架构审查
  • 审查：四齿轮全开
  • HTML ×2（质量+架构）

模块边界防火墙（三道）

🛡️ 防火墙 #1

service.py 互不 import
  • ✅ 跨 App import Model
  • ✅ 跨 App import api.py
  • ❌ 跨 App import service

🛡️ 防火墙 #2

读放开，写收敛
  • ✅ 跨 App SELECT 直接 ORM
  • ❌ 跨 App INSERT/UPDATE/DELETE 必须走 api

🛡️ 防火墙 #3

外部访问只走 API
  • Vue → HTTP → Django API → ORM
  • AgentScope → Tool → ORM/API（同进程）
  • Admin → ORM → DB
