# 智能体体系 · 结构总览

> 源文件位于仓库根的 `CLAUDE.md`、`AGENTS.md`、`.claude/`、`.agents/`。  
> **本文件只做结构整理与索引，不修改上述目录。**

---

## 1. 总览关系

```
仓库根
├── CLAUDE.md              ← 调度入口：Agent 路由 · 铁律 · Rules/Skills 索引
├── AGENTS.md              ← 项目真相：架构 · 模块边界 · API/DB · 启动
├── .claude/               ← Claude Code 专用（只读引用）
│   ├── agents/            ← 6 个角色 Agent
│   ├── skills/            ← 10 个项目 Skill
│   ├── rules/             ← 15 条领域规则（always 引用）
│   ├── hooks/             ← 会话钩子
│   └── memory/            ← 项目记忆
└── .agents/               ← 扩展 Skill 包（只读引用）
    └── skills/            ← 7 个通用 Skill
```

| 文档 | 职责边界 |
|------|----------|
| `CLAUDE.md` | **怎么调度 Agent**：路由表、身份、验证铁律、原则、规则/Skill 索引 |
| `AGENTS.md` | **项目是什么**：启动、架构图、目录、防火墙、表与 API、配置注意 |
| `.claude/agents/*` | 各角色 system prompt + 工具权限 |
| `.claude/skills/*` | 可触发的专项工作流（auto-dev、PRD、质量关卡等） |
| `.claude/rules/*` | 编码/安全/前后端等硬约束 |
| `.agents/skills/*` | 跨项目通用能力（教程、Skill 锻造、浏览器测试等） |

## 2. Agent 路由（摘自 CLAUDE.md）

| Agent | 触发场景 | 定义文件 |
|-------|---------|----------|
| `prd-writer` | 写 PRD、改需求、需求评审 | [`.claude/agents/prd-writer.md`](../../.claude/agents/prd-writer.md) |
| `architect` | 架构设计、依赖分析、方案评估 | [`.claude/agents/architect.md`](../../.claude/agents/architect.md) |
| `developer` | 做功能、改代码、修 Bug、重构 | [`.claude/agents/developer.md`](../../.claude/agents/developer.md) |
| `reviewer` | 代码审查、质量/安全检查 | [`.claude/agents/reviewer.md`](../../.claude/agents/reviewer.md) |
| `tester` | 测试、验证、验收 | [`.claude/agents/tester.md`](../../.claude/agents/tester.md) |
| `test-automator` | 三层自动化脚本（DB/API/UI） | [`.claude/agents/test-automator.md`](../../.claude/agents/test-automator.md) |

**调度优先级**：需求 → `prd-writer` 同步 PRD → 复杂改动走 `architect` → 日常开发 `developer` → 交付前 `reviewer` + `tester`。
