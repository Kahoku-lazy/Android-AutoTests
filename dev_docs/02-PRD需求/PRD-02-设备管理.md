# PRD-02 — 设备管理 (Device Pool)

> 关联需求大纲：[`需求大纲.md`](./需求大纲.md) §5.1
> 版本：v4.1 · 日期：2026-07-17

---

## 1. 功能定位

设备管理是平台的设备基础设施。用户在此发现、连接、锁定、释放 Android 设备。

---

## 2. 功能需求与验收标准

### 2.1 设备扫描与发现

#### F-01-01 ADB 扫描

**需求**：点击「扫描设备」，扫描 ADB 已连接设备并注册入库。

**验收**：
- [ ] 点击扫描按钮后，按钮显示 loading 状态
- [ ] USB 连接的设备自动出现在设备列表中，状态为 ONLINE
- [ ] 已注册的设备再次扫描时更新在线状态，不重复创建
- [ ] 扫描超时 15 秒，提示「扫描超时，请检查 ADB 服务是否运行」
- [ ] 无 ADB 服务时提示「未检测到 ADB 服务，请确认已安装 Android SDK Platform Tools」

**测试方案**：
```
场景1: USB 设备扫描
  前置：一台 Android 设备通过 USB 连接，开启 USB 调试
  操作：点击「扫描设备」
  期望：设备列表出现该设备，显示型号、序列号、状态=ONLINE

场景2: 无设备扫描
  前置：没有连接任何设备，ADB 服务正常
  操作：点击「扫描设备」
  期望：设备列表保持为空，无错误提示

场景3: 重复扫描
  前置：设备A 已在列表中(ONLINE)
  操作：再次点击「扫描设备」
  期望：设备A 状态不变，不出现重复条目
```

---

#### F-01-02 WiFi 局域网连接

**需求**：支持通过 IP:Port 连接局域网内的 Android 设备。

**验收**：
- [ ] 点击「WiFi 连接」→ 弹出输入框：IP 地址（必填）+ 端口（默认 5555）
- [ ] 输入合法 IP 和端口 → 点击连接 → 连接成功设备出现在列表
- [ ] IP 格式非法时提示「请输入正确的 IP 地址」
- [ ] 端口超出范围(1024-65535)时提示「端口范围 1024-65535」
- [ ] 连接超时 10 秒，提示「连接超时：无法访问 {IP}:{Port}，请检查设备和网络」
- [ ] 目标设备未开启 ADB over WiFi 时提示「连接失败：设备拒绝连接，请在设备上开启 ADB 网络调试」

**测试方案**：
```
场景1: 正常 WiFi 连接
  前置：设备已开启 ADB over WiFi(adb tcpip 5555)
  操作：输入设备 IP → 点击连接
  期望：设备出现在列表，连接方式显示 WiFi 图标

场景2: IP 不可达
  前置：输入一个不存在的局域网 IP
  操作：点击连接
  期望：10 秒后提示「连接超时：无法访问 192.168.1.999:5555」

场景3: 端口未开
  前置：设备 IP 可达但 5555 端口未开启 ADB
  操作：点击连接
  期望：提示「连接失败：设备拒绝连接」
```

### 2.2 设备状态管理

#### F-02-01 设备卡片展示

**需求**：每台设备以卡片形式展示完整信息和状态。

**验收**：
- [ ] 卡片展示：设备名称/型号、序列号、分辨率、Android 版本、连接方式图标
- [ ] ONLINE 状态：绿色边框 + 🟢 标签
- [ ] BUSY 状态：黄色边框 + 🟡 标签 + 「被 XX 锁定，剩余 X 分钟」
- [ ] OFFLINE 状态：红色边框 + 🔴 标签 + 「最后在线：X 分钟前」
- [ ] 30 秒自动刷新在线状态，离线设备及时标记

**测试方案**：
```
场景1: 状态切换 ONLINE→BUSY
  前置：设备A 为 ONLINE
  操作：锁定设备A
  期望：卡片变黄色，显示 🟡 BUSY + 锁定者信息 + 倒计时

场景2: 状态切换 BUSY→ONLINE
  前置：设备A 为 BUSY
  操作：释放设备A
  期望：卡片变绿色，显示 🟢 ONLINE

场景3: 设备离线
  前置：设备A 为 ONLINE
  操作：断开设备 USB 连接 → 等待 30 秒
  期望：卡片变红色，显示 🔴 OFFLINE + 最后在线时间
```

---

#### F-02-02 设备锁定

**需求**：一键锁定设备，基于 JWT 登录用户自动绑定，无需弹窗输入。仅锁定者可解锁。

**验收**：
- [ ] 点击「锁定」→ 状态立即变为 BUSY，按钮变为红色「解除锁定」
- [ ] 锁定基于 JWT 当前登录用户，无需手动输入用户 ID
- [ ] 已锁定设备仅锁定者可点击「解除锁定」释放
- [ ] 他人锁定的设备 → 按钮禁用，显示「已锁定」
- [ ] 锁定超时 3600 秒自动释放，锁记录标记为 expired

**测试方案**：
```
场景1: 一键锁定
  前置：当前用户 admin 登录，设备A 为 ONLINE
  操作：点击「锁定」
  期望：设备绑定到 admin，按钮变红「解除锁定」；其他用户看到「已锁定」

场景2: 仅锁定者可解锁
  前置：设备A 被 admin 锁定
  操作：tester 点击「解除锁定」（已禁用不可点击）
  期望：tester 无法解锁；admin 点击可解锁

场景3: 锁定冲突
  前置：设备A 已被 tester 锁定
  操作：admin 查看设备A
  期望：锁定按钮禁用显示「已锁定」，锁定状态列显示 tester
```

---

#### F-02-03 设备释放

**需求**：手动释放自己锁定的设备。

**验收**：
- [ ] 点击「释放」→ 设备状态立即恢复 ONLINE
- [ ] 释放后如有排队用户，自动分配给队首
- [ ] 释放后锁记录标记为 released
- [ ] 非锁定者不显示「释放」按钮

**测试方案**：
```
场景1: 手动释放
  前置：设备A 被当前用户锁定
  操作：点击「释放」
  期望：设备恢复 ONLINE；锁记录标记 released

场景2: 释放 + 自动分配
  前置：设备A 被用户A 锁定，用户B 排队等待设备A
  操作：用户A 释放设备A
  期望：设备A 自动分配给用户B，状态保持 BUSY
```

---

#### F-02-04 强制断开

**需求**：管理员可强制断开异常设备，清除其锁和排队。

**验收**：
- [ ] 点击「断开」→ 二次确认弹窗「断开后将删除设备记录，清除锁和排队，确定？」
- [ ] 确认后设备从列表移除，关联的锁和排队记录清空
- [ ] 强制断开 BUSY 设备时弹窗：「将强制释放 XX 的锁，确定？」
- [ ] 取消 → 不做任何操作

**测试方案**：
```
场景1: 断开 ONLINE 设备
  前置：设备A 为 ONLINE
  操作：点击「断开」→ 确认
  期望：设备从列表移除

场景2: 强制断开 BUSY 设备
  前置：设备A 被用户B 锁定(BUSY)
  操作：管理员点击「断开」→ 确认
  期望：设备移除；用户B 的锁记录标记 released；用户B 收到提示
```

#### F-02-05 锁定状态列

**需求**：设备列表新增「锁定状态」列，显示设备是否被用户锁定。

**验收**：
- [ ] 已锁定设备显示蓝底标签「锁定者用户名」
- [ ] 未锁定设备显示绿底标签「共用」
- [ ] 锁定状态随设备列表自动刷新

#### F-02-06 操作按钮样式

**需求**：操作列按钮使用动森主题配色，区分锁定和占用操作。

**验收**：
- [ ] 「锁定」按钮：紫色（未锁定）→ 自动变红色（已锁定）
- [ ] 「解除占用」按钮：黄色，仅已占用设备可点击

### 2.3 排队调度

#### F-03-01 加入排队

**需求**：设备忙碌时用户可加入等待队列，设备释放后 FIFO 自动分配。

**验收**：
- [ ] BUSY 设备（别人锁定）→ 按钮为「加入排队」
- [ ] 点击加入 → 提示「已加入等待队列，当前位置 #N」
- [ ] 排队面板展示队列列表：位置、用户、等待时间
- [ ] 设备释放后自动分配给队首用户

**测试方案**：
```
场景1: 正常排队
  前置：设备A 被用户B 锁定
  操作：用户C 点击「加入排队」
  期望：提示「已加入等待队列，当前位置 #1」；排队面板出现用户C

场景2: FIFO 分配
  前置：用户C(#1)、用户D(#2) 排队设备A
  操作：用户B 释放设备A
  期望：设备A 分配给用户C(#1)；用户D 变为 #1
```

---

#### F-03-02 取消排队

**需求**：用户可取消自己的排队。

**验收**：
- [ ] 排队面板中 → 点击「取消排队」
- [ ] 确认弹窗「确定取消排队？」
- [ ] 确认后从队列移除，后面用户位置前移
- [ ] 排队超时 30 分钟自动取消，提示「排队等待超时，已自动取消」

**测试方案**：
```
场景1: 取消排队
  前置：用户C 排队位置 #2
  操作：点击「取消排队」→ 确认
  期望：从队列移除；原 #3 变为 #2

场景2: 排队中设备被断开
  前置：用户C 排队设备A
  操作：管理员断开设备A
  期望：用户C 排队自动取消，提示「排队目标设备已移除」
```

## 3. 数据表单约束

| 操作 | 约束 | 违规提示 |
|------|------|------|
| WiFi 连接 IP | 合法 IPv4 地址 | 「请输入正确的 IP 地址」 |

| 设备序列号 | 全局唯一 | 重复扫描不创建新记录 |

| 心跳间隔 | 30s 前端上报，60s 后端巡检 | — |
