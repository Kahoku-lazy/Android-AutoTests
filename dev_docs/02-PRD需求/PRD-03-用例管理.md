# PRD-03 — 用例管理 (Case Manager)

> 关联需求大纲：[`需求大纲.md`](./需求大纲.md) §5.3
> 版本：v5.0 · 日期：2026-07-16

## 1. 功能定位

用例管理是测试资产管理中枢。用户在此创建、组织、编排测试用例。

---

## 2. 功能需求与验收标准

### 2.1 目录管理

#### F-01-01 目录树展示

**需求**：左侧两级目录树展示所有用例目录，根级显示未分类用例。

**验收**：
- [ ] 目录以树形结构展示，支持展开/折叠
- [ ] 每个目录节点显示用例计数，如「登录模块(3)」
- [ ] 未分配目录的用例显示在根级「(未分类)」区域
- [ ] 点击目录节点 → 右侧面板过滤显示该目录下的用例
- [ ] 点击根级目录 → 右侧面板显示所有用例

**测试方案**：
```
场景1: 目录树展示
  前置：创建目录"登录模块"下有3条用例，根级有1条未分类用例
  操作：打开用例管理页
  期望：左侧树显示「登录模块(3)」和「(未分类)(1)」
```

---

#### F-01-02 目录操作

**需求**：右键菜单 + 拖拽移动 + 批量选择移动。

**验收**：
- [ ] 右键目录 → 菜单：新建子目录 / 新建用例 / 重命名 / 删除 / 移动到...
- [ ] 右键「新建子目录」→ 输入名称 → 回车保存，同级不可重名
- [ ] 同级重名时提示「同级目录名不能重复」
- [ ] 长按目录 500ms 激活拖拽模式，拖到目标目录松手
- [ ] 拖拽到自己内部时目标变红，禁止 drop
- [ ] 点击「选择」→ 勾选 → 「移动到...」→ 选择目标 → 批量移动
- [ ] 删除非空目录时弹窗「目录下有 N 条用例，删除目录将同时删除这些用例，确定？」

**测试方案**：
```
场景1: 拖拽移动
  前置：目录A 和 目录B 平级
  操作：长按目录A 500ms → 拖到目录B 上方 → 松手 → 确认弹窗点确定
  期望：目录A 成为目录B 的子目录

场景2: 拖到自己内部
  前置：目录A 是根级
  操作：长按目录A → 拖到目录A 的子目录C 上
  期望：目标变红，禁止 drop
```

---

### 2.2 用例编辑

#### F-02-01 用例 CRUD

**需求**：创建、编辑、删除、启用/禁用测试用例。

**验收**：
- [ ] 新建用例：输入 ID(全局唯一)、标题(同目录唯一)、优先级(P0/P1/P2/P3)
- [ ] ID 重复时提示「用例 ID 已存在，请使用其他 ID」
- [ ] 同目录标题重复时提示「该目录下已存在同名用例」
- [ ] 编辑用例：修改后保存，未保存离开时弹窗「有未保存的修改，离开后数据将会丢失，确定离开吗？」
- [ ] 禁用用例后，该用例不出现在执行引擎的用例选择列表中
- [ ] 删除用例：确认弹窗「删除后将无法恢复，确定？」

**测试方案**：
```
场景1: ID 冲突
  前置：已有用例 ID="TC-login-001"
  操作：新建用例，ID 填 "TC-login-001"→ 保存
  期望：提示「用例 ID 已存在，请使用其他 ID」

场景2: 未保存离开
  前置：正在编辑用例，修改了标题但未保存
  操作：点击侧边栏导航到其他页面
  期望：弹窗「有未保存的修改...」；点「取消」留在编辑页；点「确定」离开
```

---

#### F-02-02 右侧面板三态

**需求**：右侧面板根据选中状态切换列表态/详情态/编辑态。

**验收**：
- [ ] 未选中任何用例 → 列表态：显示用例卡片或表格
- [ ] 点击用例 → 详情态：右侧面板展示步骤内容（不跳转编辑页）
- [ ] 点击「编辑」→ 编辑态：全屏编辑页，含步骤编排器
- [ ] 详情态点击「返回列表」→ 回到列表态

**测试方案**：
```
场景1: 列表→详情→返回
  前置：目录"登录模块"下有3条用例
  操作：点击用例A → 右侧显示步骤详情 → 点击「返回列表」
  期望：回到列表态，显示3条用例
```

### 2.3 步骤编排

#### F-03-01 步骤编排器

**需求**：17 种步骤类型以分类按钮选择，拖拽排序。

**验收**：
- [ ] 步骤类型按 6 类分组展示：点击/手势/等待/验证/控制/工具
- [ ] 点击步骤类型 → 新增步骤到列表末尾
- [ ] 拖拽步骤调整顺序，松手后即时生效
- [ ] 每个步骤可独立删除（确认弹窗）
- [ ] 步骤至少 1 个，删除最后一个时提示「请至少保留 1 个步骤」
- [ ] swipe/drag 步骤显示额外字段：方向(direction) + 距离(distance)

**测试方案**：
```
场景1: 拖拽排序
  前置：3 个步骤：click → wait → verify_text
  操作：拖拽 verify_text 到 click 前面
  期望：顺序变为：verify_text → click → wait

场景2: 新增手势步骤
  前置：步骤列表为空
  操作：点击手势类 → 选择 swipe
  期望：新增步骤，显示 XPath + direction(up/down/left/right) + distance 字段
```

---

#### F-03-02 元素选取器

**需求**：步骤编辑器内嵌元素搜索面板，从已保存元素中搜索选取 XPath。

**验收**：
- [ ] 点击步骤的「选取元素」→ 弹出搜索面板
- [ ] 按页面筛选 → 按别名/文本搜索 → 显示匹配的元素列表
- [ ] 点击选中元素 → XPath 自动填入步骤字段 → 关闭面板
- [ ] 搜索无结果时显示「未找到匹配元素」
- [ ] 同一元素可被多个步骤引用

**测试方案**：
```
场景1: 搜索选取
  前置：元素库中有"登录按钮"(别名) 属于"登录页"
  操作：步骤编辑器中点击「选取元素」→ 搜索"登录"→ 点击结果
  期望：XPath 自动填入，面板关闭，步骤显示 XPath 表达式
```

### 2.4 YAML 导入导出

#### F-04-01 导出

**需求**：勾选用例导出为 YAML 文件。

**验收**：
- [ ] 勾选 1 条或多条用例 → 点击「导出 YAML」→ 生成下载
- [ ] 导出内容包含：用例 ID、标题、步骤 JSON、优先级、包名
- [ ] 无勾选时按钮禁用，提示「请先选择要导出的用例」
- [ ] 导出文件名格式：`export_{timestamp}.yaml`

**测试方案**：
```
场景1: 多选导出
  前置：目录下 5 条用例
  操作：勾选 3 条 → 点击「导出 YAML」
  期望：下载文件包含 3 条用例的完整数据
```

---

#### F-04-02 导入

**需求**：从 YAML 文件批量导入用例。

**验收**：
- [ ] 选择 YAML 文件 → 预览内容（用例数、用例标题列表）
- [ ] 选择目标目录 → 确认导入
- [ ] 单次最多 500 条，超出提示「单次最多导入 500 条，当前 N 条」
- [ ] YAML 格式错误时提示「文件格式不正确，请检查 YAML 语法」并指明错误行
- [ ] 导入时 ID 冲突 → 提示「用例 ID XX 已存在」，提供「跳过」或「覆盖」选项

**测试方案**：
```
场景1: 正常导入
  前置：准备一个含 3 条用例的合法 YAML 文件
  操作：选择文件 → 预览确认 → 选择目标目录 → 导入
  期望：3 条用例出现在目标目录下

场景2: 格式错误
  前置：准备一个 YAML 语法错误的文件
  操作：选择文件
  期望：提示「文件格式不正确」并指明第几行有问题
```

## 3. 数据表单约束

| 操作 | 约束 | 违规提示 |
|------|------|------|
| 用例 ID | 全局唯一，CharField PK | 「用例 ID 已存在」 |
| 用例标题 | 同目录唯一 | 「该目录下已存在同名用例」 |
| 步骤数量 | 最少 1 个 | 「请至少添加 1 个测试步骤」 |
| YAML 导入 | 最多 500 条/次 | 「单次最多导入 500 条」 |
| 目录深度 | 最多 2 级 | 「仅支持两级目录」 |
