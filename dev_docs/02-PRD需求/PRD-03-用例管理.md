# PRD-03 — 用例管理 (Case Manager)

> 关联需求大纲：`[需求大纲.md](./需求大纲.md)` §5.3

## 1. 功能定位

用例管理是测试资产管理中枢。用户在此创建、组织、编排测试用例。

---

## 2. 功能需求与验收标准

### 2.1 目录管理

#### F-01-01 目录树展示

**需求**：左侧两级目录树展示所有用例目录，根级显示未分类用例。

**验收**：

- [ ] 目录以树形结构展示，支持展开/折叠
- [ ] 每个目录节点显示用例计数，如「登录模块(3)」
- [ ] 未分配目录的用例显示在根级「(未分类)」区域
- [ ] 点击目录节点 → 右侧面板过滤显示该目录下的用例
- [ ] 点击根级目录 → 右侧面板显示所有用例

**测试方案**：

```
场景1: 目录树展示
  前置：创建目录"登录模块"下有3条用例，根级有1条未分类用例
  操作：打开用例管理页
  期望：左侧树显示「登录模块(3)」和「(未分类)(1)」
```

---

#### F-01-02 目录操作

**需求**：右键菜单 + 拖拽移动 + 批量选择移动。

**验收**：

- [ ] 右键目录 → 菜单：新建子目录 / 新建用例 / 重命名 / 删除 / 移动到...
- [ ] 右键「新建子目录」→ 输入名称 → 回车保存，同级不可重名
- [ ] 同级重名时提示「同级目录名不能重复」
- [ ] 长按目录 500ms 激活拖拽模式，拖到目标目录松手
- [ ] 拖拽到自己内部时目标变红，禁止 drop
- [ ] 点击「选择」→ 勾选 → 「移动到...」→ 选择目标 → 批量移动
- [ ] 删除非空目录时弹窗「目录下有 N 条用例，删除目录将同时删除这些用例，确定？」

**测试方案**：

```
场景1: 拖拽移动
  前置：目录A 和 目录B 平级
  操作：长按目录A 500ms → 拖到目录B 上方 → 松手 → 确认弹窗点确定
  期望：目录A 成为目录B 的子目录

场景2: 拖到自己内部
  前置：目录A 是根级
  操作：长按目录A → 拖到目录A 的子目录C 上
  期望：目标变红，禁止 drop
```

### 2.2 用例编辑



#### F-02-01 用例 CRUD

**需求**：创建、编辑、删除、启用/禁用测试用例。

**验收**：

- [ ] 新建用例：输入 ID(全局唯一)、标题(同目录唯一)、优先级(P0/P1/P2/P3)
- [ ] ID 重复时提示「用例 ID 已存在，请使用其他 ID」
- [ ] 同目录标题重复时提示「该目录下已存在同名用例」
- [ ] 编辑用例：修改后保存，未保存离开时弹窗「有未保存的修改，离开后数据将会丢失，确定离开吗？」
- [ ] 禁用用例后，该用例不出现在执行引擎的用例选择列表中
- [ ] 删除用例：确认弹窗「删除后将无法恢复，确定？」

**测试方案**：

```
场景1: ID 冲突
  前置：已有用例 ID="TC-login-001"
  操作：新建用例，ID 填 "TC-login-001"→ 保存
  期望：提示「用例 ID 已存在，请使用其他 ID」

场景2: 未保存离开
  前置：正在编辑用例，修改了标题但未保存
  操作：点击侧边栏导航到其他页面
  期望：弹窗「有未保存的修改...」；点「取消」留在编辑页；点「确定」离开
```

---



#### F-02-02 右侧面板三态

**需求**：右侧面板根据选中状态切换列表态/详情态/编辑态。

**验收**：

- [ ] 未选中任何用例 → 列表态：显示用例卡片或表格
- [ ] 点击用例 → 详情态：右侧面板展示步骤内容（不跳转编辑页）
- [ ] 点击「编辑」→ 编辑态：全屏编辑页，含步骤编排器
- [ ] 详情态点击「返回列表」→ 回到列表态

**测试方案**：

```
场景1: 列表→详情→返回
  前置：目录"登录模块"下有3条用例
  操作：点击用例A → 右侧显示步骤详情 → 点击「返回列表」
  期望：回到列表态，显示3条用例
```

### 2.3 步骤编排



#### F-03-01 步骤编排器

**需求**：17 种步骤类型以分类按钮选择，拖拽排序。

**验收**：

- [ ] 步骤类型按 6 类分组展示：点击/手势/等待/验证/控制/工具
- [ ] 点击步骤类型 → 新增步骤到列表末尾
- [ ] 拖拽步骤调整顺序，松手后即时生效
- [ ] 每个步骤可独立删除（确认弹窗）
- [ ] 步骤至少 1 个，删除最后一个时提示「请至少保留 1 个步骤」
- [ ] swipe/drag 步骤显示额外字段：方向(direction) + 距离(distance)

**测试方案**：

```
场景1: 拖拽排序
  前置：3 个步骤：click → wait → verify_text
  操作：拖拽 verify_text 到 click 前面
  期望：顺序变为：verify_text → click → wait

场景2: 新增手势步骤
  前置：步骤列表为空
  操作：点击手势类 → 选择 swipe
  期望：新增步骤，显示 XPath + direction(up/down/left/right) + distance 字段
```

---



#### F-03-02 元素选取器

**需求**：步骤编辑器内嵌元素搜索面板，从已保存元素中搜索选取 XPath。

**验收**：

- [ ] 点击步骤的「选取元素」→ 弹出搜索面板
- [ ] 按页面筛选 → 按别名/文本搜索 → 显示匹配的元素列表
- [ ] 点击选中元素 → XPath 自动填入步骤字段 → 关闭面板
- [ ] 搜索无结果时显示「未找到匹配元素」
- [ ] 同一元素可被多个步骤引用

**测试方案**：

```
场景1: 搜索选取
  前置：元素库中有"登录按钮"(别名) 属于"登录页"
  操作：步骤编辑器中点击「选取元素」→ 搜索"登录"→ 点击结果
  期望：XPath 自动填入，面板关闭，步骤显示 XPath 表达式
```

### 2.4 协作编辑



#### F-05-01 创建人/修改人追踪

**需求**：用例自动记录创建人和最后修改人。

**验收**：

- [ ] 新建用例时自动记录创建人为当前登录用户
- [ ] 修改用例时自动更新修改人为当前登录用户
- [ ] 用例卡片显示「创建: XX」和「修改: XX」元信息



#### F-05-02 编辑锁

**需求**：同一时间只允许一人编辑。第二人打开时自动进入只读模式。

**验收**：

- [ ] 打开用例编辑页 → 自动获取编辑锁
- [ ] 他人打开同一用例 → 页面顶部显示黄色横幅「用例正被 XX 编辑中，当前为只读模式」
- [ ] 只读模式下保存按钮禁用、步骤编辑器不可操作
- [ ] 关闭编辑页 → 自动释放编辑锁
- [ ] 锁超时 30 分钟自动释放



#### F-05-03 强制编辑

**需求**：用例创建者可强制踢出当前编辑者，夺回编辑权。

**验收**：

- [ ] 只读横幅中，创建者可见「强制编辑」按钮
- [ ] 点击强制编辑 → 踢出当前编辑者 → 自己进入编辑模式
- [ ] 非创建者不可见强制编辑按钮



#### F-05-04 持久锁

**需求**：创建者可将用例锁定，锁定后任何人（包括创建者之外的其他人）不可编辑。

**验收**：

- [ ] 创建者可锁定用例 → 他人打开时只读
- [ ] 仅创建者可解除锁定
- [ ] 锁定用例卡片显示 🔒 图标
- [ ] 卡片操作区显示 🔓/🔒 切换按钮（仅创建者可见）



#### F-05-05 卡片编辑状态

**需求**：当有人正在编辑用例时，卡片实时显示编辑状态，阻止他人进入。

**验收**：

- [ ] 用户打开编辑页 → 卡片显示 "✏️ {用户} 正在编辑" 标签
- [ ] 编辑状态下他人卡片编辑按钮禁用
- [ ] 用户关闭编辑页 → 状态清除 → 他人可编辑



#### F-05-06 用例可见性控制

**需求**：创建者可设置用例的可见范围（公开/隐藏/指定用户）。

**验收**：

- [ ] 编辑页（创建者可见）→ 可见性下拉：所有人可见 / 仅创建者 / 指定用户
- [ ] 「仅创建者」→ 其他用户列表不可见
- [ ] 「指定用户」→ 出现用户输入框（逗号分隔）→ 仅被指定用户可见
- [ ] 「所有人可见」（默认）→ 全员可见
- [ ] 非公开用例卡片显示 👁️‍🗨️ 图标

### 2.5 权限管理



#### F-06-01 用例编辑权限

**需求**：创建者可设置用例的编辑权限级别：所有人可编辑 / 所有人只读 / 指定用户可编辑。

**验收**：

- [ ] 编辑页「权限管理」区域（仅创建者可见）：下拉选择 edit / readonly / restricted
- [ ] `edit`（默认）：所有可见用户均可进入编辑页
- [ ] `readonly`：其他用户打开时只读模式，保存按钮禁用，banner "此用例为只读模式"
- [ ] `restricted` → 显示编辑者输入框（逗号分隔用户名），仅指定用户可编辑
- [ ] 权限变更即时生效，无需刷新

**测试方案**：

```
场景1: 设为只读
  前置：admin 创建用例，permission=readonly
  操作：tester 打开用例
  期望：只读模式，banner "此用例为只读模式"，保存按钮禁用

场景2: 指定编辑者
  前置：admin 设置 permission=restricted, permitted_editors=["tester"]
  操作：user3 打开用例 → tester 打开用例
  期望：user3 只读；tester 可正常编辑
```

**权限矩阵**：


| permission   | 创建者  | 其他用户                        | 编辑锁      |
| ------------ | ---- | --------------------------- | -------- |
| `edit`       | 全部权限 | 可编辑                         | 需要获取     |
| `readonly`   | 全部权限 | 仅可查看                        | —        |
| `restricted` | 全部权限 | permitted_editors 中可编辑，其余只读 | 指定用户需要获取 |

### 2.6 目录权限



#### F-07-01 目录创建与删除权限

**需求**：目录创建者可控制他人在该目录下的创建和删除权限。默认他人不可删除。

**验收**：

- [ ] 目录右键菜单（创建者可见）→「权限设置」面板
- [ ] 「允许他人创建子目录/用例」开关（默认开启）
- [ ] 关闭后，其他用户在该目录下右键无「新建子目录」「新建用例」
- [ ] 默认仅创建者可删除目录；非创建者右键无「删除」选项
- [ ] 创建者可在权限设置中开启「允许他人删除」
- [ ] 删除含子目录或用例的目录时仍需二次确认

**测试方案**：

```
场景1: 删除保护
  前置：admin 创建目录"登录模块"
  操作：tester 右键"登录模块"
  期望：无"删除"选项

场景2: 创建限制
  前置：admin 关闭"登录模块"的 allow_create
  操作：tester 右键"登录模块"
  期望：无"新建子目录"和"新建用例"选项
```

### 2.7 数据同步



#### F-08-01 卡片/列表/编辑页数据同步

**需求**：用例在任意位置修改后，卡片、列表、编辑页保持信息一致。

**验收**：

- [ ] 编辑页保存 → 返回列表 → 卡片信息（标题/修改人/时间）已更新
- [ ] 卡片锁定/解锁 → 列表即时刷新
- [ ] 他人编辑状态变化 → 卡片「正在编辑」标签即时更新
- [ ] 列表 30s 自动刷新 + 手动刷新按钮
- [ ] 编辑锁释放 → 卡片清除「正在编辑」标签

**测试方案**：

```
场景1: 标题同步
  前置：admin 打开用例A，标题为"旧标题"
  操作：保存为"新标题" → 返回列表
  期望：用例A 卡片标题更新为"新标题"，修改人更新为 admin

场景2: 锁定同步
  前置：admin 在卡片点击 🔓 锁定用例A
  操作：tester 查看同一列表页
  期望：用例A 卡片显示 🔒，编辑按钮禁用（30s 内自动刷新）
```

### 2.8 YAML 导入导出



#### F-04-01 导出

**需求**：勾选用例导出为 YAML 文件。

**验收**：

- [ ] 勾选 1 条或多条用例 → 点击「导出 YAML」→ 生成下载
- [ ] 导出内容包含：用例 ID、标题、步骤 JSON、优先级、包名
- [ ] 无勾选时按钮禁用，提示「请先选择要导出的用例」
- [ ] 导出文件名格式：`export_{timestamp}.yaml`

**测试方案**：

```
场景1: 多选导出
  前置：目录下 5 条用例
  操作：勾选 3 条 → 点击「导出 YAML」
  期望：下载文件包含 3 条用例的完整数据
```

---



#### F-04-02 导入

**需求**：从 YAML 文件批量导入用例。

**验收**：

- [ ] 选择 YAML 文件 → 预览内容（用例数、用例标题列表）
- [ ] 选择目标目录 → 确认导入
- [ ] 单次最多 500 条，超出提示「单次最多导入 500 条，当前 N 条」
- [ ] YAML 格式错误时提示「文件格式不正确，请检查 YAML 语法」并指明错误行
- [ ] 导入时 ID 冲突 → 提示「用例 ID XX 已存在」，提供「跳过」或「覆盖」选项

**测试方案**：

```
场景1: 正常导入
  前置：准备一个含 3 条用例的合法 YAML 文件
  操作：选择文件 → 预览确认 → 选择目标目录 → 导入
  期望：3 条用例出现在目标目录下

场景2: 格式错误
  前置：准备一个 YAML 语法错误的文件
  操作：选择文件
  期望：提示「文件格式不正确」并指明第几行有问题
```

## 3. 数据表单约束


| 操作      | 约束                              | 违规提示             |
| ------- | ------------------------------- | ---------------- |
| 用例 ID   | 全局唯一，CharField PK               | 「用例 ID 已存在」      |

| 用例可见性   | public/hidden/restricted        | 不可见用例不出现在列表中     |
| 编辑锁超时   | 30 分钟                           | 自动释放             |
