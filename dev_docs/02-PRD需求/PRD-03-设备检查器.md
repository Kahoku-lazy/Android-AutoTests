## 1. 功能定位

设备检查器是平台的**实时元素获取工具**，主要用于**实时获取 Android 手机页面元素**：通过 dump 方式获取当前页面所有元素的 XML 层级信息，解析出各元素的属性（坐标 bounds / 文本 text / resource-id / 可点击性 clickable 等），返回给页面元素面板，并据此生成唯一定位 xpath。

**核心模块功能（按三模块）**：


| 模块       | 功能编号                        | 核心职责                              |
| -------- | --------------------------- | --------------------------------- |
| ① 工具栏    | F-01-01 / F-01-02 / F-01-03 | 设备连接 / 刷新屏幕 / Dump UI             |
| ② 屏幕显示区域 | F-02-01                     | 实时截图流与元素选取                          |
| ③ 页面元素   | F-03-01 ~ F-03-04           | 坐标检测 / 元素列表与筛选 / 元素缩略图 / 批量保存       |


设备检查器是**瞬态服务（无持久化数据表）**：区别于设备管理的设备注册表、元素定位的元素资产仓库，截图帧、UI 树、XPath 只在会话内流转。

## 2. 功能详细规格

> 本章按页面四个功能区域分层。每模块依次说明：**设计目的 → 功能需求 → 组件与边界 → 验收方式**。
> 模块 ↔ 功能编号映射见 §1（F-xx-xx 用于 §5 API、§8 非目标交叉引用）。


### 2.1 模块一：工具栏

**核心功能**

- **设备连接**：从设备管理（device-pool）的设备列表选择已注册设备，以观察（observe）模式建立会话连接 / 断开，采集设备元信息（本模块不直接连接设备，底层连接由设备管理完成）
- **刷新屏幕**：立即抓取一帧最新截图并重新 Dump UI 层级
- **Dump UI**：抓取当前页面完整 UI 树（含可交互元素判定）

**功能需求**

**F-01-01 设备连接**

**功能实现逻辑**：本模块**不直接连接设备**，设备的底层连接由设备管理模块完成。用户在检查器下拉框选择设备管理模块中**已注册的设备**，以观察（observe）模式建立会话连接并采集设备元信息；断开时释放会话占用。

**详细功能点**：

- **设备可选范围**：下拉框展示设备管理模块（PRD-02）中已注册且可用的设备（状态 `ONLINE` / `BUSY`）；执行引擎占用中的设备不展示，避免干扰执行任务。
- **连接成功**：用户选择设备后点击「连接」，以观察（observe）模式建立会话。连接成功后，该设备在设备管理模块中显示「使用中」（BUSY）；信息栏展示品牌 / 型号 / 分辨率 / 连接类型 + 绿点「已连接」，连接按钮变「已连接」（绿底），断开按钮红色可点。
- **断开**：用户点击「断开」释放观察会话，设备在设备管理模块中恢复「在线」（ONLINE）；离开页面时自动断开。
- **职责与边界**：本模块只负责**选择设备并建立 / 释放观察会话**，不负责设备的连接初始化；设备连接 / 注册 / 扫描 / 锁定 / 释放 / 删除均由设备管理模块（PRD-02）承担。
- **数据交互**：设备列表与元信息**从设备管理模块读取**；连接 / 断开会**改变设备在设备管理模块中的占用状态**（BUSY / ONLINE）。
- **跨模块引用**：依赖设备管理模块（PRD-02）提供设备列表与占用状态；本模块不自行注册设备、不自行建立底层连接。

**验收方式**：

- 执行引擎占用中的设备不出现于下拉框
- 连接后设备信息栏展示完整元信息；连接按钮「已连接」绿底、断开按钮红色可点
- 断开后设备在设备管理模块中恢复「在线」；离开页面后观察会话被释放

**F-01-02 刷新屏幕**

**功能实现逻辑**：用户点击「刷新屏幕」，立即抓取一帧最新截图，并重新获取当前页面元素层级；刷新期间按钮进入加载态，完成后恢复。

**详细功能点**：

- **前置条件**：已连接设备且设备在线（未连接或设备离线时不执行，提示用户）。
- **抓取最新截图**：立即获取一帧最新画面，替换当前显示。
- **重新 Dump**：重新获取当前页面元素层级，同步更新页面元素面板的数据。
- **加载态**：刷新期间按钮进入 loading，完成后恢复可点。

**验收方式**：

- 点击「刷新屏幕」后截图刷新，且元素清单同步更新
- 刷新期间按钮显示加载态，完成后恢复

**F-01-03 Dump UI**

**功能实现逻辑**：抓取当前页面完整 UI 树，判定可交互元素，并保留最近 3 张页面截图作为视觉参考；结果喂给「页面元素」面板（全量清单）。

**详细功能点**：

- **抓取完整 UI 树**：获取当前页面所有元素及其属性。
- **可交互元素判定**：`clickable` / `text` / `resource_id` / `content_desc` 四者任一非空即视为可交互。
- **截图保留**：保留最近 3 张页面截图作为视觉参考。
- **结果分发**：全量元素清单喂给「页面元素」面板。

**验收方式**：

- Dump 后全量元素数与「页面元素」列表一致
- 可交互元素数与可交互列表一致
- 页面截图保留最近 3 张

### 2.2 模块二：屏幕显示区域

**设计目的**

屏幕显示区域是检查器的**实时画面中枢**。用户在手机边框内看到设备当前画面，画面叠加元素边界框；点击 / 悬停画面即可选取对应元素，在页面元素列表中定位。

**功能需求**

**F-02-01 实时截图流**

**功能实现逻辑**：用户连接设备后，屏幕显示区域展示设备实时画面（用户动作）。系统持续推送设备实时画面（约 2fps），并在画面上叠加元素边界框；推送不可用时自动降级为按需拉取快照（功能响应）。实现「实时查看设备画面并选取元素」的需求。

**详细功能点**：

- **实时画面推送**：持续推送设备画面（约每 500ms 一帧），叠加元素边界框。
- **元素边界框叠加与选取**：可交互元素叠加边界框（默认蓝 / hover 橙 / 选中红三色，见 §3.3）；悬停命中元素高亮，点击（或右键）命中后，在页面元素列表中定位对应元素。

**消息类型**：


| type               | 触发       | 前端处理                |
| ------------------ | -------- | ------------------- |
| `screenshot`       | 约每 500ms | 更新手机画面（base64 JPEG） |
| `device_changed`   | 设备切换     | 更新 serial / 分辨率     |
| `no_device`        | 无当前设备    | 显示「未选择设备」占位         |
| `screenshot_error` | 截图异常     | 显示错误提示              |


**降级链路**：

```
WS 连接成功 → 停止 HTTP 轮询，仅走 WS 推送
WS 断开 / 失败 → 重启 HTTP 轮询（REST 快照），3s 后重连 WS
```

**职责与边界**：本功能只负责画面展示与元素选取；UI 树抓取（F-01-03）与元素列表展示（F-03-02）不在本功能范围。

**验收方式**

- 连接后首帧 2s 内渲染（REST 快照兜底），之后 2fps 持续刷新
- WS 断开后自动降级 REST 轮询，3s 后重连
- 元素边界框随 hover / 选中变色（蓝 / 橙 / 红三色，见 §3.3）
- 点击画面命中元素后，页面元素列表中定位到对应元素

### 2.3 模块三：页面元素

**设计目的**

页面元素区域用于**抓取页面所有元素，展示元素的 resource-id / text / 坐标信息 / 唯一定位 xpath，并将有坐标的区域截图出来**（元素缩略图）。用户在此查看 Dump 后的去重元素清单，通过筛选 / 搜索缩小范围，勾选后批量保存到元素管理。

**功能需求**

**F-03-01 坐标检测（去重）**

**功能实现逻辑**：用户在 Dump 后、元素展示到页面前，系统先对元素做坐标检测去重（用户动作）。系统检测各元素坐标截图区域的重合度与大小：两个坐标的截图区域重合度 ≥95% 且截图大小一致时，判定为坐标一致，只保留一个；否则判定为不一致，全部保留（功能响应）。实现「元素展示前去除重复坐标元素」的需求。

**详细功能点**：

- **重合度检测**：检测两个坐标截图区域的重合度。
- **大小一致性**：检测两个坐标截图区域的大小是否一致。
- **判定规则**：重合度 ≥95% 且大小一致 → 坐标一致；否则不一致。
- **去重策略**：一致的坐标只保留一个，不一致的坐标都保留；去重后的元素才展示到页面。

**职责与边界**：本功能只做坐标去重判定；元素资产 CRUD 由元素定位模块（PRD-04）承担，本模块不落库。

**验收方式**：

- 两个截图区域重合度 ≥95% 且大小一致的坐标判定为一致，只保留一个展示
- 重合度 <95% 或大小不一致的坐标判定为不一致，全部展示

**F-03-02 元素列表与筛选**

**功能实现逻辑**：用户 Dump 后查看去重后的元素清单（用户动作）。系统展示元素列表，每行含 resource-id / text / 坐标信息 / 唯一定位 xpath / 缩略图，支持按类型筛选与文本搜索（功能响应）。实现「浏览与筛选页面元素」的需求。

**详细功能点**：

- **列表字段**：每行展示 resource-id / text / 坐标信息（bounds）/ 唯一定位 xpath / 缩略图。
- **唯一定位**：每个元素生成一条唯一定位 xpath，按 ID（resource-id）→ Text 顺序，优先取匹配数 = 1 的候选。
- **筛选**：全部 / 可点击 / 有文本 / 有 Resource ID / 可点击+文本 / 可点击无文本 / 输入框 / 可滚动。
- **搜索**：匹配 text / resource_id / content_desc / class_name。

**职责与边界**：本功能负责列表展示、筛选与唯一定位展示；元素数据由 Dump（F-01-03）抓取提供，候选 XPath 生成由后端完成。

**验收方式**：

- 元素列表与坐标检测去重后的元素一致；每个元素展示 resource-id / text / 坐标 / 唯一定位 xpath
- 筛选 / 搜索后列表正确缩小

**F-03-03 元素缩略图（坐标区域截图）**

**功能实现逻辑**：用户查看元素缩略图（用户动作）。系统对每个有坐标的元素，从 Dump 时抓取的截图按其 bounds 裁剪出 48px 缩略图，点击放大到 240px 浮层展示详情（功能响应）。实现「可视化查看元素区域截图」的需求。

**详细功能点**：

- **缩略图裁剪**：对有坐标（width > 0）的元素，按其 bounds 裁剪 48px 缩略图。
- **放大详情**：点击缩略图放大到 240px 浮层，展示 Class / Text / ID / Desc / Bounds / Clickable 详情。

**职责与边界**：本功能只做缩略图裁剪与展示；截图来源由 Dump（F-01-03）提供。

**验收方式**：

- 有坐标元素均渲染 48px 缩略图（区域与 bounds 一致）；点击放大到 240px 且详情字段完整

**F-03-04 批量保存到元素管理**

**功能实现逻辑**：用户勾选元素后批量保存到元素管理（用户动作）。系统按所选定位策略为每个勾选元素匹配 XPath，写入元素定位模块，返回 saved / updated / skipped 计数（功能响应）。实现「批量持久化元素」的需求。

**详细功能点**：

- **弹窗字段**：目标页面（下拉）+ 定位策略（8 种）。
- **策略匹配**：每个勾选元素按所选策略匹配 XPath（优先 count=1），匹配不到跳过。
- **结果反馈**：返回 saved / updated / skipped 计数，并刷新元素管理表格。

**职责与边界**：本功能只发起批量保存；元素资产 CRUD 由元素定位模块（PRD-04）承担，本模块不落库。

**验收方式**：

- 批量保存后元素出现在元素定位对应页面；返回 saved / updated / skipped 计数可感知；成功后刷新元素管理表格

**边界状态（场景）**

**① 工具栏**


| 场景              | 行为                                                    |
| --------------- | ----------------------------------------------------- |
| 无可用设备           | 下拉框为空，提示「未连接设备 — 选择设备后点击连接」                           |
| 未连接             | 断开按钮灰色不可点；刷新屏幕 / Dump 按钮禁用；连接按钮选中设备后可点                |
| 连接成功            | 连接按钮变「已连接」（绿底），断开按钮红色可点；信息栏显示品牌/型号/分辨率/连接类型 + 绿点「已连接」 |
| 连接失败            | Toast「连接设备失败」                                         |
| 设备记录消失（离线即删）    | 轮询发现设备不在列表后提示「设备 {serial} 已离线」，并清除连接状态                |
| 未连接时点刷新 / Dump  | 提示「请先选择设备并点击"连接"」，不发送请求                               |
| 设备离线时点刷新 / Dump | 提示「设备 {serial} 已离线」                                   |
| 离开页面            | `onUnmounted` 自动调用 `disconnect-observe` 断开            |


**② 屏幕显示区域**


| 场景        | 行为                             |
| --------- | ------------------------------ |
| 未连接设备     | 播放「设备未连接~」待机动画（圆环扩散）           |
| 已连接无首帧    | 显示「正在连接截图流…」占位                 |
| 无当前设备（后端） | 显示「未选择设备，请在上方选择或连接设备」          |
| 截图失败      | 显示「截图流连接失败，3 秒后重试」+ 降级 REST 轮询 |


**③ 页面元素**


| 场景           | 行为                              |
| ------------ | ------------------------------- |
| 未 Dump / 无元素 | 元素面板空态「Dump UI 后显示页面元素」         |
| Dump 请求失败    | Toast 错误提示，面板保持上次结果或空态          |
| 批量未勾选        | 提示「请先勾选要保存的元素」                  |
| 批量无匹配策略      | 提示「N 个元素缺少「strategy」定位策略」       |
| 批量保存成功       | Toast「已保存 N 个元素（N 个已更新，N 个跳过…）」 |
| 无坐标元素        | 缩略图占位图标（不裁剪）                    |
| 批量刷新         | 「刷新元素」按钮重新 Dump + 重新抓取缩略图       |

## 4. 后端功能逻辑

### 4.1 设备可用性（对齐 PRD-02）

设备状态以 PRD-02 为准：仅 `ONLINE` / `BUSY`；设备离线或断开后**删除记录**，不存在 `OFFLINE` / `DISCONNECTED` 墓碑。

**设备初始化归设备管理**：设备连接（adb/u2）与信息采集由 device-pool 在连接/注册时完成；本模块**不二次初始化**，仅在操作前做可用性检查。

所有检查器操作前统一校验：


| 检查项                    | 不通过 → 错误码 | 消息                       |
| ---------------------- | --------- | ------------------------ |
| serial 为空              | 409       | 未选择设备，请先连接设备             |
| Device 不存在（含离线已删）      | 409       | 设备未注册                    |
| status == BUSY 且执行引擎占用 | 409       | 设备正被执行引擎占用（{进程}），请等待执行完毕 |


> 执行引擎占用前缀：`runner-` / `ai_agent` / `task-` / `run-`。检查器自身 observe 占用**不阻断**操作。
>
> ⚠️ 偏差：`GET /inspector/device-info` 未走统一校验，采用软查询（设备不存在时返回部分信息，非 409），与「统一校验」口径不一致（已登记）。
>
> 「刷新屏幕」为**前端组合动作**（`GET /inspector/screenshot` 快照 + `POST /inspector/dump`），无独立后端端点。

### 4.2 截图流口径

- 进程内单路广播：已连接的 WS 客户端共享同一截图循环
- 帧间隔默认 0.5s（2fps）；JPEG quality 50，max_width 720
- 新客户端接入时先推送最近缓存帧，缩短首屏等待
- 发送失败的客户端自动剔除，不阻断其余客户端

### 4.3 无持久化（瞬态）

本模块无数据表。Dump 产生的页面截图仅保留最近 3 张；UI 树 / XPath 只出现在响应中。元素持久化由 element-locator（PRD-04）承担。

### 4.4 降级规则


| 场景           | 行为                                              |
| ------------ | ----------------------------------------------- |
| WS 不可用 / 断开  | 前端 REST 轮询 `/api/inspector/screenshot`，并定时重连 WS |
| 截图采集失败       | 下行 `screenshot_error`；前端提示并重试                   |
| 设备记录已删除      | 操作类接口 409「设备未注册」；前端清除连接态                        |
| adb / 设备瞬时失败 | 动作/Dump 返回失败 message，不写库                        |

## 5. API 接口功能

鉴权：全部 HTTP 端点需 JWT Bearer；WebSocket 经 query string `token`。JSON 字段 snake_case。

> ⚠️ **信封差异**：本模块成功响应字段**平铺**（`{status, serial, elements, ...}`），未包裹 `data`（与平台统一信封 `{status, data}` 不同）。原因：后端裸 `JsonResponse`（非 DRF 信封渲染器）。前端已按平铺读取，已登记。后续若 DRF 化，须同步改前端解包并追加契约变更行。

### 5.1 端点总览


| #   | 方法   | 端点                           | 功能                                    | 前端消费 |
| --- | ---- | ---------------------------- | ------------------------------------- | ---- |
| 1   | POST | `/api/inspector/dump`        | Dump UI + XPath（F-01-03 / F-03-02） | ✅    |
| 2   | GET  | `/api/inspector/device-info` | 当前设备信息 + 占用状态（F-01-01）                | ✅    |
| 3   | GET  | `/api/inspector/screenshot`  | 单帧 JPEG 快照（F-02-01 降级 / F-03-03 缩略图）  | ✅    |
| 4   | WS   | `/ws/screenshot?token=`      | 截图流 2fps（F-02-01）                     | ✅    |
| 5   | POST | `/api/inspector/ocr`         | OCR 文字识别（cnocr）→ 文字/坐标/置信度/缩略图        | ✅    |


> 另消费 device-pool（契约见 PRD-02）：`GET /api/devices/`、`POST /api/devices/{serial}`（observe）、`POST /api/devices/{serial}/activate`、`POST /api/devices/{serial}/disconnect-observe`。

### 5.2 端点 1 — Dump UI

**接口地址**：`POST /api/inspector/dump`

**请求**：无 body。

**响应字段**（平铺）：


| 字段                 | 类型      | 说明                |
| ------------------ | ------- | ----------------- |
| `status`           | boolean | true              |
| `serial`           | string  | 当前设备 serial       |
| `package`          | string  | 当前前台包名            |
| `activity`         | string  | 当前 Activity       |
| `element_count`    | number  | 节点总数              |
| `actionable_count` | number  | 可交互元素数            |
| `elements`         | array   | 全量节点              |
| `actionable`       | array   | 可交互元素（含 `xpaths`） |


**节点字段**：`class_name` / `resource_id` / `text` / `content_desc` / `index` / `clickable` / `scrollable` / `bounds` / `x` / `y` / `width` / `height`；actionable 另含 `xpaths[]`（`type` / `xpath` / `count` / 可选 `note`）。

**响应示例**：

```json
{
  "status": true,
  "serial": "emulator-5554",
  "package": "com.example.app",
  "activity": ".MainActivity",
  "element_count": 128,
  "actionable_count": 23,
  "elements": [
    {
      "class_name": "android.widget.Button",
      "resource_id": "com.example:id/login_btn",
      "text": "登录",
      "content_desc": "",
      "index": "0",
      "clickable": true,
      "scrollable": false,
      "bounds": "[0,100][1080,220]",
      "x": 0,
      "y": 100,
      "width": 1080,
      "height": 120
    }
  ],
  "actionable": [
    {
      "class_name": "android.widget.Button",
      "resource_id": "com.example:id/login_btn",
      "text": "登录",
      "clickable": true,
      "x": 0,
      "y": 100,
      "width": 1080,
      "height": 120,
      "xpaths": [
        {
          "type": "resource-id",
          "xpath": "//android.widget.Button[@resource-id='com.example:id/login_btn']",
          "count": 1
        }
      ]
    }
  ]
}
```

**错误**：未选设备 / 未注册 / 执行引擎占用 → 409（见 §4.1）。

### 5.3 端点 2 — 当前设备信息

**接口地址**：`GET /api/inspector/device-info`

**响应字段**：


| 字段                           | 类型      | 说明            |
| ---------------------------- | ------- | ------------- |
| `serial` / `model` / `brand` | string  | 设备标识（DB 缓存优先） |
| `screen_w` / `screen_h`      | number  | 分辨率           |
| `connection_type`            | string  | USB / WIFI    |
| `package`                    | string  | 当前前台包名        |
| `occupied`                   | boolean | 是否被占用         |
| `occupied_by`                | string  | 占用进程（未占用为空）   |


### 5.4 端点 3 — 截图快照

**接口地址**：`GET /api/inspector/screenshot`

**响应字段**：


| 字段                      | 类型     | 说明                                    |
| ----------------------- | ------ | ------------------------------------- |
| `image`                 | string | base64 JPEG（quality 50，max_width 720） |
| `format`                | string | `jpeg`                                |
| `serial`                | string | 当前设备 serial                           |
| `screen_w` / `screen_h` | number | 分辨率                                   |


**错误**：未选设备 / 设备不可用 → 409（§4.1）。

### 5.5 WebSocket — 截图流

**接口地址**：`WS /ws/screenshot?token={JWT}`

**鉴权**：query `token`；校验失败直接 close。

**下行消息**：


| type               | 字段                               | 说明                 |
| ------------------ | -------------------------------- | ------------------ |
| `screenshot`       | `image`, `format`                | 截图帧                |
| `device_changed`   | `serial`, `screen_w`, `screen_h` | 设备切换               |
| `no_device`        | `message`                        | 无当前设备              |
| `screenshot_error` | `message`                        | 截图异常（文案截断约 200 字符） |


### 5.6 端点 5 — OCR 文字识别

**接口地址**：`POST /api/inspector/ocr`

**请求**：无 body。

**响应字段**（平铺）：


| 字段                      | 类型     | 说明               |
| ----------------------- | ------ | ---------------- |
| `status`                | boolean | true             |
| `serial`                | string  | 当前设备 serial       |
| `screen_w` / `screen_h` | number  | 分辨率（设备物理像素）       |
| `count`                 | number  | 识别文字条数           |
| `texts`                 | array   | 文字区域列表（见下）       |


**texts[] 字段**：`text` / `confidence`（0~1）/ `x` / `y` / `width` / `height`（设备物理像素，与 dump 元素一致）/ `thumbnail`（base64 JPEG）/ `thumbnail_format`。

**错误**：未选设备 / 未注册 / 执行引擎占用 → 409（见 §4.1）；模型加载 / 识别异常 → 500「OCR 识别失败，请稍后重试」。

### 5.7 契约变更


| 版本   | 变更                                                                                                               |
| ---- | ---------------------------------------------------------------------------------------------------------------- |
| v1.0 | 初始契约：3 HTTP + 1 WS；响应平铺非 `{status, data}`；状态可用性口径含历史 OFFLINE 分支                                                  |
