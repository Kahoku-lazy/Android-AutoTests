# PRD-07 — 仪表盘 (Dashboard)

> 关联需求大纲：[`需求大纲.md`](./需求大纲.md) §5.8

## 1. 功能定位

仪表盘是首页聚合层。用户登录后一眼看到平台全局状态和快捷入口。

---

## 2. 功能需求与验收标准

### 2.1 全局概览

#### F-01-01 KPI 统计卡片

**需求**：6 个卡片展示平台核心数据。

**验收**：
- [ ] 卡片：设备在线 · 用例总数 · 元素总数 · 执行次数 · 智能体数 · 报告数
- [ ] 所有数据来自 API，不硬编码
- [ ] 点击卡片 → 跳转到对应模块
- [ ] 全 0 数据时卡片正常显示 0，不报错不白屏
- [ ] API 加载失败时显示「数据加载失败」+ 重试按钮

**测试方案**：
```
场景1: 正常加载
  前置：平台有 3 台在线设备、42 条用例
  操作：登录进入仪表盘
  期望：6 张卡片分别显示 3/42/...，数字正确

场景2: 空数据
  前置：全新平台，无任何数据
  操作：登录进入仪表盘
  期望：6 张卡片全显示 0，页面结构正常

场景3: API 失败
  前置：模拟 API 返回 500
  操作：刷新页面
  期望：显示「数据加载失败」；点击重试后重新请求
```

---

#### F-01-02 执行趋势图

**需求**：近 12 天执行成功/失败趋势 + 新建用例折线。

**验收**：
- [ ] 柱状图：绿色=成功执行，红色=失败执行
- [ ] 折线图：蓝色=新建用例数
- [ ] 无执行数据时显示「暂无执行数据」
- [ ] 少于 2 天数据时仍正常渲染

**测试方案**：
```
场景1: 有数据
  前置：最近 12 天有执行记录
  操作：查看仪表盘趋势图区域
  期望：柱状图+折线图正常渲染；hover 显示具体数值
```

---

### 2.2 导航与活动

#### F-02-01 快捷入口

**需求**：5 个快捷按钮一键跳转各业务模块。

**验收**：
- [ ] 按钮：新建用例 → /case-manager
- [ ] 按钮：执行测试 → /test-runner
- [ ] 按钮：元素截图 → /elements
- [ ] 按钮：AI 对话 → /ai-assistant
- [ ] 按钮：查看报告 → /report-generator
- [ ] 点击后正确跳转，无 404

**测试方案**：
```
场景1: 快捷跳转
  操作：依次点击 5 个快捷按钮
  期望：每个按钮跳转到正确页面，无报错
```

---

#### F-02-02 活动时间线

**需求**：跨模块最近事件流。

**验收**：
- [ ] 展示最近操作：设备连接、用例创建、执行完成等
- [ ] 每条显示时间 + 操作描述
- [ ] 无活动时显示「暂无最近活动」
- [ ] 最多展示 20 条

**测试方案**：
```
场景1: 有活动
  前置：最近有设备连接、用例创建操作
  操作：查看活动时间线
  期望：按时间倒序展示最近操作
```
