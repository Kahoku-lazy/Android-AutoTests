## 1. 功能定位

平台小助手是 AI 助手的**智能体看板 + 任务下发入口**：展示平台唯一智能体的两条能力线路（控制设备 / 平台任务），并**创建 / 分配**任务给智能体执行。

**核心职责**：

- **小助手看板**：展示平台唯一智能体的两条线路卡片（控制设备 / 平台任务），显示各线路的规划 / 执行 / 校验模型配置，超管可跳转智能体设置详情页。
- **智能体设置详情页**：配置智能体基本信息、循环次数与各线路的模型配置。
- **任务卡片列表**：新建任务（下发到指定线路）并查看任务卡片与执行状态。

## 2. 业务功能

### 2.1 平台小助手（F-01-01）

#### 2.1.1 平台小助手功能简介（F-01-01-01）

**平台小助手页面简介**：平台小助手页面有两个模块，第一个模块为小助手看板，第二个模块为任务卡片列表。小助手看板展示平台唯一智能体的两条线路卡片（控制设备 / 平台任务）；任务卡片列表可 **新建任务**并将任务**分配**给智能体去执行。

#### 2.1.2  平台小助手页面 UI布局（F-01-01-02）

页面为纵向流式布局，自上而下由「顶部页头 + 两个区块」组成：区块 1 为小助手看板（两条线路卡片），区块 2 为任务卡片列表（含新建任务弹窗）。两区块内卡片均为自适应网格（`repeat(auto-fill, minmax(280px, 1fr))`，间距 16px）。

**看板卡片（`AgentRouteCard`）**：固定渲染 2 条线路——控制设备（📱）/ 平台任务（🧭），数据取自平台唯一智能体的 `route_configs`。每条卡片展示图标、线路名、小标签（控制设备 / 平台任务），以及三行模型配置：规划模型（`planner`）/ 执行模型（`executor`）/ 校验模型（`verifier`）的 `model_name`（未配置显示「未配置」），并含「校验」按键（点击校验模型通断）；右下角「配置」按钮仅超管（`isSuperuser`）可见，点击跳转智能体设置详情页并定位到对应线路配置。

**新建任务弹窗（`el-dialog`，宽 640px，`label-width` 120px）**：

| 表单项 | 必填 | 控件 | 字段 |
| --- | --- | --- | --- |
| 任务目标 | 是 | 文本域（2 行） | `goal` |
| 任务要求 | 否 | 文本域（2 行） | `requirements` |
| 任务附件文件 | 否 | 单行输入 | `attachment` |
| 智能体 | 是 | 下拉（控制设备 / 平台任务） | `route` |
| 设备 | 否 | 可搜索下拉（留空走第一台在线设备） | `device_serial` |
| 报告文件名 | 否 | 单行输入 | `report_name` |
| 任务校验清单 | 否 | 文本域（2 行） | `checklist` |

底部按钮：`取消` / `提交`（任务目标为空时禁用）。

**任务卡片**：每张卡片显示任务标题、状态徽标（六态：待执行 / 执行中 / 成功 / 失败 / 取消 / 暂停）、目标文本、线路标签、设备序列号、创建时间，以及可选的结果摘要；当前仅展示、无操作按钮。

**组件**：`index.vue` + `AgentRouteCard` / `TaskBoard` + `useAgentBoard` / `useTaskPublish` / `useTaskList`。

**边界状态**：

| 场景 | 行为 |
| --- | --- |
| 智能体列表加载失败 | 看板区展示错误态，可点击重试 |
| 无智能体 | 看板区展示空态「还没有智能体 · 请联系管理员配置智能体」 |
| 任务目标为空 | 「提交」按钮禁用 |
| 任务列表加载失败 | 任务区展示错误态，可点击重试 |
| 任务列表为空 | 展示空态「还没有任务 · 点击『新建任务』创建」 |
| 非超管 | 看板卡片「配置」按钮隐藏 |

**验收标准**：

- 看板固定渲染「控制设备 / 平台任务」两条线路卡片，规划 / 执行 / 校验模型显示与 `route_configs` 一致
- 新建任务弹窗字段齐全，任务目标、智能体必填校验生效
- 任务卡片状态徽标与后端 `status` 六态一致


#### 2.1.3  平台小助手页面详细功能（F-01-01-03）

**详细功能说明**：以下描述了平台小助手页面的功能。

1. 小助手看板：固定渲染两条线路卡片——控制设备（📱）/ 平台任务（🧭），数据取自平台唯一智能体的 `route_configs`。每条卡片展示基本信息、小标签显示是控制手机或平台任务，显示规划模型 / 执行模型 / 校验模型三类模型的具体模型名称；「校验按键」点击后校验模型通断，超管（`isSuperuser`）点击「配置」跳转到智能体设置详情页。

2. 智能体设置详情页：点击看板卡片「配置」跳转（`/ai-assistant/agent/{id}`）。详情页自上而下展示：基本信息（名称 / 头像 / 标签 / 描述）、循环次数（max_loops，1–10）、模型配置（规划模型、执行模型、校验模型），底部「校验按键」，点击后校验（模型服务 / 模型名 / API Key / API 地址）测试模型通断，底部为「保存」按键。

3. 智能体健康状态：后端每 30 分钟自动检测一次智能体连通性（`GET /ai/agents/health`）；当前看板不再以「已连接 / 连接断开」图标展示检测结果。

4. 任务列表页：显示「新建任务」按键与用户创建的所有任务卡片。

5. 新建任务卡片：点击「新建任务」弹出弹窗，填写任务目标（必选）、任务要求（可选）、任务附件文件（可选）、智能体（必选，控制设备 / 平台任务）、设备（可选，留空走第一台在线设备）、报告文件名（可选）、任务校验清单（可选）。

6. 任务卡片显示：每张卡片显示任务标题、执行状态徽标、目标文本、线路标签、设备序列号、创建时间，以及可选的结果摘要；当前仅展示，无「查看详情 / 取消 / 暂停 / 删除」等操作按键，也无执行进度展示。

7. 任务卡片执行状态：执行状态分为待执行、执行中、任务成功、任务失败、任务取消、任务暂停。

**验收标准**：

- 小助手看板固定渲染「控制设备 / 平台任务」两条线路卡片，规划 / 执行 / 校验模型显示正确无错乱
- 智能体健康状态每隔 30min 自动检测一次
- 无智能体时展示空态引导

**组件**：`AgentDetail.vue` + `AgentBasicInfo` / `AgentRouteConfig` / `ModelConfigField` / `AgentFormFooter`。

**边界状态**：

| --- | --- |

## 5. API 接口功能

鉴权：全部端点需要 JWT Bearer。响应统一 `{status, data}` / `{status, message}`，JSON 字段 snake_case。

### 5.1 智能体相关端点

| #  | 方法   | 端点                       | 功能             | 前端消费 |
| --- | ---- | ------------------------ | -------------- | ---- |
| 1  | GET  | `/ai/agents`             | 智能体列表（看板）      | ✅   |
| 2  | POST | `/ai/agents/create`      | 创建智能体（F-01-02）  | ✅   |
| 3  | GET  | `/ai/agents/{id}`        | 智能体详情（含脱敏 Key）  | ✅   |
| 4  | POST | `/ai/agents/{id}/update` | 更新智能体          | ✅   |
| 5  | POST | `/ai/agents/{id}/delete` | 删除智能体          | ✅   |
| 6  | POST | `/ai/models/detect`      | 检测可用模型（F-01-04） | ✅   |
| 7  | POST | `/ai/agents/{id}/test`   | 连接测试（F-01-04）   | ✅   |
| 8  | GET  | `/ai/agents/{id}/models` | 缓存的可用模型        | ❌   |
| 9  | GET  | `/ai/agents/health`      | 全部智能体健康检查      | ✅   |

> 完整端点总览见父 PRD [`PRD-08-AI助手`](./PRD-08-AI助手.md) §5.1；一次性 Key 查看（`reveal-key`）见父 PRD §2.3 API Key 安全。

### 5.2 智能体详情（端点 3）

**接口地址**：`GET /api/ai/agents/{id}`

**响应** `agent` **字段**（核心）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` / `name` / `avatar` / `tags` / `description` | — | 基本信息 |
| `model_provider` / `model_name` / `vision_model_name` / `strong_model_name` / `strong_enabled` / `base_url` | string / boolean | 模型配置（三类模型 + 强模型开关） |
| `api_key` | string | **脱敏值**（`mask_key`） |
| `system_prompt` | string | 系统提示词 |
| `temperature` / `max_tokens` | number | 采样参数 |
| `max_iters` / `parallel_tool_calls` | — | ReAct 参数 |
| `enable_knowledge_base` / `enable_workspace_tools` / `enable_business_tools` / `enable_mcp_tools` / `enable_skills` | boolean | 能力开关 |
| `generate_kwargs` | string | JSON 字符串 |
| `skills_config` / `knowledge_sources` | object | 逐工具 / 逐文档开关 |
| `compression_*` | — | 压缩 |
| `status` | string | active 等 |
| `is_connected` / `last_checked_at` / `available_models` | — | 健康状态 |
| `tools[]` | array | 每项含 `id/name/tool_type/config_json/enabled` |
