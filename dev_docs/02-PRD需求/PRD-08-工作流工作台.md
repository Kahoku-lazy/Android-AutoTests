# PRD-08 — 工作流工作台 (Workflow)

> 关联需求大纲：[`需求大纲.md`](./需求大纲.md) §5.7
> 版本：v3.0 · 日期：2026-07-16

---

## 1. 功能定位

可视化编排工具。用户通过 Blockly 积木和 VueFlow 创建测试，降低编码门槛。

---

## 2. 功能需求与验收标准

### 2.1 工作流目录

#### F-01-01 目录与文档管理

**需求**：左侧目录树管理 Blockly 积木文档和 VueFlow 页面流文档。

**验收**：
- [ ] 目录树支持新建/重命名/移动/删除文件夹
- [ ] 新建文档：选择类型 blockly_test_case 或 page_flow
- [ ] 文档 ID 自动生成（DOC-xxx 格式）
- [ ] 重命名：行内编辑，回车保存
- [ ] 删除文档：确认弹窗「删除后将无法恢复，确定？」
- [ ] 文档支持拖拽移动到不同目录

**测试方案**：
```
场景1: 新建积木文档
  前置：目录"A"已存在
  操作：右键"A" → 新建文档 → 类型选 blockly_test_case → 输入标题 → 确定
  期望：右侧编辑器打开空白 Blockly 工作区

场景2: 新建页面流文档
  前置：同上
  操作：新建文档 → 类型选 page_flow
  期望：右侧编辑器打开 VueFlow 画布
```

---

### 2.2 Blockly 积木编辑器

#### F-02-01 积木编排

**需求**：从工具箱拖入积木块到工作区，编排测试步骤。

**验收**：
- [ ] 工具箱按分类展示积木：点击/等待/验证/控制/工具
- [ ] 从工具箱拖入积木块到工作区，可拖拽排序
- [ ] 积木块删除：拖回工具箱或右键删除
- [ ] 本地草稿自动保存（localStorage），刷新不丢失
- [ ] 手工清除草稿后工作区为空，显示引导提示

**测试方案**：
```
场景1: 拖拽编排
  操作：拖入 click 积木 → 拖入 wait 积木 → 拖入 verify_text 积木
  期望：3 个积木按顺序排列在工作区

场景2: 草稿恢复
  前置：工作区有 2 个积木，已自动保存
  操作：刷新页面
  期望：工作区恢复 2 个积木，状态栏显示「已存本地草稿」
```

---

#### F-02-02 同步到用例库

**需求**：积木块一键转为可执行用例，同步到用例管理模块。

**验收**：
- [ ] 工具栏「同步到用例库」按钮
- [ ] 同步前检查：积木块至少 1 个，否则提示「请至少添加 1 个积木块」
- [ ] 同步成功提示「已同步到用例库」
- [ ] 同步失败提示具体原因
- [ ] 同步后在用例管理页可看到新创建的用例

**测试方案**：
```
场景1: 正常同步
  前置：工作区有 3 个积木块（click → wait → verify_text）
  操作：点击「同步到用例库」
  期望：提示「已同步到用例库」；切换到用例管理页看到新用例，含 3 个步骤
```

---

#### F-02-03 从用例库导入

**需求**：从用例管理模块导入已有用例，转为积木块。

**验收**：
- [ ] 左侧「+ 导入用例」按钮 → 弹出用例多选列表
- [ ] 选中用例 → 确认 → 积木块加载到工作区
- [ ] 不支持的步骤类型（swipe/drag）自动跳过并提示
- [ ] 导入后工作区原有积木被替换（非合并）

**测试方案**：
```
场景1: 导入用例
  前置：用例管理中有"登录冒烟"(5 个步骤)
  操作：点击「导入用例」→ 选择"登录冒烟"→ 确认
  期望：工作区出现 5 个积木块，对应原用例的 5 个步骤

场景2: 部分跳过
  前置：用例含 swipe 步骤
  操作：导入该用例
  期望：提示「swipe 步骤已跳过(不支持)」；其他步骤正常导入
```

### 2.3 VueFlow 页面流

#### F-03-01 页面流编辑

**需求**：可视化画出 App 页面节点和跳转连线。

**验收**：
- [ ] 画布支持拖入页面节点
- [ ] 节点展示页面名称、包名、Activity
- [ ] 节点间连线表示跳转关系，标注触发元素
- [ ] 右键节点：编辑/删除/查看关联元素
- [ ] 保存后数据持久化到服务器
- [ ] 重命名文档（标题失焦/改名）不得覆盖或清空已保存的 nodes/links
- [ ] 再次打开文档须从服务端拉取最新 config，不得用过期内存缓存覆盖显示

**测试方案**：
```
场景1: 创建页面流
  操作：拖入"登录页"节点 → 拖入"首页"节点 → 连线 → 标注触发元素"登录按钮"
  期望：连线显示"登录按钮"标签；保存后刷新页面仍存在

场景2: 改名不洗图
  前置：页面流已保存含 ≥2 个节点
  操作：修改标题后失焦 → 刷新页面再打开
  期望：节点与连线仍在；库中 config_json.nodes 长度不变

场景3: 多标签打开最新
  前置：标签 A 保存了新图；标签 B 此前打开过旧缓存
  操作：标签 B 关闭后重新打开同一文档
  期望：显示标签 A 保存的最新图，而非空图/旧图
```
