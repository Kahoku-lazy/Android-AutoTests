# PRD-设备管理

> 文档类型：产品需求文档（PRD）
> 模块：设备管理（device-pool）
> 视角：产品功能表单与设计（不含技术实现细节）
> 更新日期：2026-09-03

---

## 一、产品背景与定位

设备管理是自动化测试平台的**设备接入中心**：负责 Android 设备的发现、接入、状态管理、锁定与占用，为「执行测试、设备检查、AI 助手」等下游功能提供可用的设备资源。

## 二、功能表单（功能清单）

| 序号 | 功能 | 功能描述（做什么） | 关键业务规则 | 使用者 |
|------|------|------------------|-------------|--------|
| F01 | 设备扫描/发现 | 扫描并发现当前接入平台的设备（USB 或无线） | USB 自动识别；无线设备需先建立连接 | 所有用户 |
| F02 | 设备列表 | 展示当前可见设备及其状态、型号、分辨率、连接方式 | 状态仅「在线 / 使用中」两态；离线即从列表消失 | 所有用户 |
| F03 | 设备连接 | 连接一台设备，使其可用 | 使用中的设备不可连接；无线连接失败给出提示 | 所有用户 |
| F04 | 设备切换（激活） | 切换「当前正在操作」的设备 | 使用中的设备不可切换 | 所有用户 |
| F05 | 设备锁定/公开 | 锁定设备（仅自己可见）或公开给所有人 | 仅无线设备可锁定；USB 设备恒公开 | 所有用户 |
| F06 | 设备释放 | 释放被占用的设备，恢复在线 | 正在执行用例的设备不可释放 | 操作者 |
| F07 | 设备断开/删除 | 断开并移除无线设备 | 使用中的设备不可删除；USB 无删除入口 | 操作者 |
| F08 | 设备占用 | 检查器观察设备时，设备标记「使用中」 | 记录占用者；占用超时自动回收 | 系统/用户 |
| F09 | 心跳同步 | 定时同步设备在线状态（30 秒周期） | 离线设备自动移除；超时占用自动释放 | 系统 |
| F10 | 可见性控制 | 控制「谁能看到哪台设备」 | 管理员全局可见；USB 公开；无线按锁定规则 | 系统 |

## 三、产品设计

### 3.1 设备状态设计（两态）

```
在线（可用） ⇄ 使用中（占用）
     ↓（离线）
   从列表移除（不留「离线」记录）
```

- **在线**：设备空闲可用，可连接、切换、锁定。
- **使用中**：正被占用（检查器观察 / 执行用例），不可连接、切换、删除。
- **离线**：拔线/断网后，由心跳发现并**直接从列表移除**（不保留「离线」僵尸记录）。

### 3.2 设备可见性规则

| 设备类型 | 可见规则 |
|---------|---------|
| USB 设备 | 恒公开，所有用户可见 |
| 无线设备（未锁定） | 公开，所有用户可见 |
| 无线设备（已锁定） | 仅锁定者与配置者可见 |
| 管理员 | 无视锁定，全局可见 |

### 3.3 核心业务流程

**① 设备接入流程**

```
连接设备 → 识别有线/无线 → 确认设备唯一身份 → 登记 → 采集型号/分辨率 → 展示在列表
```

**② 设备占用/释放流程**

```
检查器打开设备 → 设备变「使用中」→ 检查器关闭 → 设备恢复「在线」
```

**③ 设备断线处理流程**

```
设备断线 → 心跳发现 → 判断状态
   ├─ 空闲（在线）→ 从列表移除
   └─ 使用中 → 保护执行中的任务，不误删；执行结束/超时后再清理
```

### 3.4 业务规则汇总（边界与约束）

| 规则 | 说明 |
|------|------|
| 状态封闭性 | 设备只有「在线 / 使用中」两态，不存在第三种 |
| 离线即删 | 不保留「离线」历史记录 |
| 执行保护 | 正在执行用例的设备不可释放、不可误删 |
| 锁定边界 | 仅无线设备可锁定；USB 天生公开 |
| 超时兜底 | 占用后异常退出（关页/崩溃），超时自动回收，设备不永久卡「使用中」 |

## 四、产品视角小结

设备管理模块从产品上就是一句话：**「管好设备的接入、状态、归属与生命周期」**——

- **接入**：扫得到、连得上（F01/F03）
- **状态**：在线/使用中两态清晰、离线不残留（F02/F08/F09）
- **归属**：锁定/可见性控制设备给谁用（F05/F10）
- **生命周期**：占用→释放→断开全闭环，异常有兜底（F04/F06/F07/F09）
