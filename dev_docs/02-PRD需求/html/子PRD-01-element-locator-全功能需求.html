🎯 第一部分：业务视角

1 功能定位

元素定位是平台的 UI 发现与定位中心：实时截图流、Dump UI 树、8 种 XPath 策略、页面/元素资产库，并向用例工程与 AI 供给测试点。

一句话：连上设备后，在浏览器里像 UI Inspector 一样选元素、复制 XPath、存进资产库。

2 用户故事

3 解决的痛点

没有本模块之前

  • 手写 XPath 易错
  • 无可视化只能盯真机
  • 元素散落无资产库
  • 用例与定位脱节

有了本模块之后

  • 所见即所得选元素
  • 8 策略自动生成
  • 页面/元素可复用
  • 测试点直供用例与 AI

5 功能详细规格

F-01 实时截图流 P0

项规格
WSws/screenshot · JWT query · ~2fps
首帧并行 GET /api/elements/screenshot
消息screenshot / device_changed / no_device / screenshot_error
叠加蓝普通 / 橙悬停 / 红选中；可点击或有 text/rid 才画

F-02 Dump + 8 种 XPath P0

POST /api/elements/dump → u2 dump_hierarchy → 16 属性 → 最多 8 候选，按匹配 count 升序。过滤器：all/clickable/text/rid/clickable_text/clickable_no_text/input/scrollable。

F-03 设备手势 P0

action参数
click / longclickx, y
swipex,y,direction,distance
inputx,y,text,clear_first

现网 action 枚举含 click/longclick/swipe/input（drag 若前端传需与后端对齐）。

F-04 页面/元素资产 P0

表 el_pages / el_elements。页面 label 唯一；元素 UNIQUE(page, resource_id, bounds) upsert。支持 clear 全清。

F-05 元素管理页 P0

路由 /element-mgr + Tab 内嵌。页面 CRUD、批量删、测试点 Switch、筛选 Tab。

F-06 页面跳转流 P1

API：GET/POST /api/elements/flows、DELETE /flows/{id}。表 el_page_flows。GAP 前端尚无跳转流可视化 UI（api.js 已封装）。

F-07 跨模块供给 P0

→ case-manager：EventBus add-step-to-case、is_test_point、YAML 导出读 Element。
→ AI：get_test_points / search_elements / fetch_page_elements。
→ dashboard：元素/页面统计。

F-08 观察模式连接 P1

前端 apiConnectObserve / DisconnectObserve；依赖 device-pool 当前设备与 activate。

6 模块边界

element-locator
  ├─ 读/写 本模块 el_* 表
  ├─ 读 device_pool.Device；调 device_pool.api.ensure_device / device
  ├─ 禁止他 App 写 el_*（须走本模块 api）
  └─ 对外 api.py：get_test_points, gen_xpath_candidates, simple_yaml_dump…
  • 无设备时 Dump/截图须友好错误，禁止裸异常堆栈到前端
  • WS 必须 JWT；截图流断连自动重连
  • 前端业务数据只从 API 来

8 REST / WS 端点（现网）

方法路径说明
POST/api/elements/dumpDump UI
POST/api/elements/action手势 click/longclick/swipe/input
GET/api/elements/device-info当前设备信息
GET/api/elements/screenshot首帧 JPEG
GET/POST/PUT/DELETE/api/elements/pages*页面 CRUD + clear
GET/POST/PUT/api/elements/pages|items*元素列表/增改
GET/POST/DELETE/api/elements/flows*跳转流
WS/ws/screenshot截图流

方向规则

级联删页面 CASCADE 元素与相关 flows

11 状态机

截图流: connecting → connected ↘ no_device / error → (3s) 重连 Dump: idle → dumping → ready | error 设备观察: disconnected ↔ observing (依赖 device-pool current)

14 Agent 专属提示词（编码时粘贴）

你在改「元素定位」模块。
红线：1) 不破坏 /ws/screenshot JWT 与 2fps 广播 2) XPath 候选必须按 count 升序
3) 跨模块写设备必须 device_pool.api 4) 响应 {ok,data|error}
路径：apps/element_locator/{views,api,service,consumers,stream}.py
前端：frontend/src/modules/element-locator/
验证：浏览器打开 /elements → Dump → 保存元素 → /element-mgr 可见。
