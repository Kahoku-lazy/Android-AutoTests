工作流可视化方案

VUE FLOW · COMFYUI 风格节点图 · 页面跳转 + 测试执行轨迹 · 四阶段实施

将 ComfyUI 风格的节点/连线工作流可视化 引入 Android-AutoTests 平台， 实现两个核心能力：① App 页面跳转关系图（页面=节点，点击元素=连线，弹窗=标记）； ② UI 自动化测试步骤执行轨迹（步骤=节点，实时高亮 pass/fail/running 状态）。

设计原则：ComfyUI 选型理由 — 节点图天然适合表达「实体 + 关系」的场景。 页面跳转是「Page → click Element → Page」，测试步骤是「Step₁ → Step₂ → … → Stepₙ」。 两者本质都是 DAG（有向无环图），节点编辑器的交互范式完美匹配。
两个核心需求
REQ 1
页面跳转工作流
将 App 页面之间的跳转关系画成节点图：
· 页面 = 节点（含截图缩略图、元素数量）
· 点击元素 = 连线（标注触发动作）
· 弹窗标记 = 连线上的 ⚠ badge
· 从页面列表 → 一键打开工作流视图
REQ 2
测试执行轨迹
用例步骤执行过程画成可实时更新的节点链：
· 每个步骤 = 一个节点（含类型图标 + 描述）
· WS 实时推送 → 节点状态流转
· pending → running(脉冲动画) → pass(绿)/fail(红)
· 点击节点查看步骤详情

Vue Flow
@vue-flow/core		 ComfyUI 同类技术（React Flow 的 Vue 3 版）；原生支持拖拽节点、自定义节点、小地图、缩放；~50KB gzip 需新增 4 个 npm 依赖 ✅ 推荐
ECharts Graph 已安装，无需新依赖 节点交互弱（force layout 不稳定），不适合做编辑器风格的可视化 ❌
Mermaid 已安装，文字→流程图快 纯静态 SVG，不支持交互、高亮、实时动画 ❌
纯 Canvas/SVG 完全自主可控 开发量巨大，重复造轮子 ❌
