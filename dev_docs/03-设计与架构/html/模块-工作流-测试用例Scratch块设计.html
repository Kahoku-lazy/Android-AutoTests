测试用例 Scratch 块设计 — 垂直流容器化块组件

VUE 3 + TYPESCRIPT + PINIA · TREE-STRUCTURED BLOCKS · RECURSIVE RENDERING

本方案将测试用例画布从「节点 + 连线」的图模型重构为 Scratch 可视化编程风格的树形容器块模型。 分支和循环不再是独立的小菱形节点，而是真正的 C 形容器，在视觉上包裹住内部的子步骤。 整体布局从水平流改为垂直堆叠，块之间通过凹口咬合连接，支持任意层级嵌套。

设计参考：Scratch 可视化编程语言中的「如果...否则」「重复...次」块。 核心设计理念：块 = 语义单元，容器 = 作用域包裹，嵌套 = 控制流层级。
设计动机 — 为什么从图模型切换到树模型
维度旧：节点 + 连线新：Scratch 容器块
分支表达小菱形节点 + PASS/FAIL 两根连线IF 块 C 形包裹 pass/fail 子序列
循环表达小圆节点 + BODY/EXIT 两根连线REPEAT 块 C 形包裹循环体
嵌套连线交叉混乱，难以追踪直观缩进，层级一目了然
布局水平从左到右，换行复杂垂直从上到下，自然滚动
数据模型扁平 nodes[] + connections[]树形 rootBlocks[]，递归嵌套
用户心智需要理解端口 + 连线概念和 Scratch 一致，拖块即编程

组件职责技术
TestCaseCanvas.vue垂直滚动 SVG 画布，渲染顶层 BlockSequenceSVG + viewBox 动态高度
BlockSequence.vue递归渲染 Block[] 序列，计算垂直偏移递归组件 + getBlockOffset()
ScratchBlock.vue统一块入口 — 根据 kind 分发到 StepFace/BranchFace/LoopFacedefineComponent + h() 渲染函数
blockLayout.ts共享高度计算：getStepHeight / getBlockHeight / getSeqHeight / notchPathComposable 纯函数
StepPropsPanel.vue属性编辑面板 — 根据选中块的 kind 显示不同表单Vue 3 + watch
为什么用 h() 渲染函数？容器块需要动态计算子块高度来绘制 C 形外壳。 渲染函数可以精确控制 SVG 元素的创建顺序和属性，比模板更适合递归几何计算。
交互设计
操作行为
点击块选中块 → 右侧属性面板显示对应编辑表单
添加步骤点击左侧面板 / 工具栏按钮 → 在选中块之后插入新步骤块
添加分支/循环工具栏按钮 → 在选中块之后插入空容器，可向容器内添加子步骤
包装为 IF选中步骤块 → 右侧面板「包装为 IF 分支」→ 步骤移入 THEN 区
展开子块 (Unwrap)选中容器 → 「展开子块」→ 子块提升到父级序列，删除容器
折叠/展开点击容器头部 ▼/▶ → 切换折叠态，折叠时只显示头部 + 统计数据
删除选中块 → 右侧面板「删除」 / 键盘 Delete → 递归删除容器及所有子块
执行模拟「▶ 执行」→ 递归展平所有块 → 逐步骤推进状态动画
