# 命名统一标准

> Android-AutoTests 项目命名唯一权威来源。所有 PRD、架构文档、代码以此为准。
> 版本：v2.0 · 日期：2026-07-01

---

## 一、统一原则

| 原则 | 规则 | 示例 |
|------|------|------|
| **文档目录名** | `kebab-case` | `element-locator/`, `device-pool/` |
| **Python 包名** | `snake_case` | `element_locator/`, `device_pool/` |
| **Django Model 类名** | `PascalCase` | `Element`, `TestDefinition` |
| **数据库表名** | `{前缀}_{snake_case 复数}` | `el_elements`, `dp_devices` |
| **数据库字段名** | `snake_case` | `page_id`, `created_at` |
| **REST API URL** | `/api/{domain}/*`，kebab-case 资源名 | `/api/elements/pages`, `/api/ai/agents` |
| **URL 路径参数** | `snake_case` | `/{page_id}`, `/{run_id}` |
| **WebSocket 路径** | `/ws/` 前缀 | `/ws/screenshot`, `/ws/test-run/{run_id}` |
| **JSON 字段名** | `snake_case` | `{"page_id": 1, "element_count": 5}` |
| **JSON 顶层包装** | `ok` + `data` 或 `error` | `{"ok": true, "data": {...}}` |
| **前端 JS 变量** | `camelCase` | `testDefinitions`, `lastDump` |
| **前端文件名** | `kebab-case` | `api-client.js`, `event-bus.js` |
| **Vue 组件文件** | `PascalCase.vue` | `ChatView.vue`, `AgentDetail.vue` |
| **Vue 路由路径** | `kebab-case` | `/ai-assistant/chat/:agentId` |
| **WebSocket type** | `snake_case` | `"screenshot"`, `"case_started"` |
| **Git 分支** | `斜杠 + kebab-case` | `feat/element-export`, `fix/ws-reconnect` |

### element-locator — `/api/elements/*`

12 端点：元素 CRUD + XPath 生成 + 页面管理 + 跳转关系

### device-pool — `/api/devices/*`

12 端点：设备 CRUD + 锁定/释放/排队 + 心跳 + 切换

### case-manager — `/api/cases/*`

5 端点：用例 CRUD + YAML 导出

### test-runner — `/api/runner/*`

5 端点：测试执行 + 结果查询 + 停止 + 历史

### report-generator — `/api/reports/*`

3 端点：报告保存 + 模板 + 内容查看

### WebSocket

| 路径 | 说明 |
|------|------|
| `/ws/screenshot` | 2fps 截图流 |
| `/ws/test-run/{run_id}` | 执行进度（6 种消息类型） |

## 四、WebSocket 消息规范

### WS-1: 实时截图流 — `/ws/screenshot`

| 方向 | 消息格式 | 频率 |
|------|---------|:--:|
| S→C | `{"type":"screenshot", "image":"<base64>", "ts":"<ISO8601>"}` | 2fps |

### WS-2: 测试执行进度 — `/ws/test-run/{run_id}`

| type | 触发时机 | 关键字段 |
|------|---------|---------|
| `case_started` | 开始执行用例 | `run_id, case_id, case_title, loop_count` |
| `iteration_result` | 每轮迭代完成 | `run_id, case_id, iteration, result, duration_ms` |
| `case_finished` | 用例全部迭代完成 | `run_id, case_id, pass, fail, rate` |
| `run_finished` | 全部执行完毕 | `run_id, summary, csv_path, log_path` |
| `log` | 步骤执行日志 | `run_id, message` |
| `device_error` | 设备连接失败 | `run_id, error` |

## 六、JSON 核心实体字段

### Device
```
serial, name, model, screen_w, screen_h, sdk, status, locked_by, locked_at
```

### Element
```
id, page_id, class_name, text_val, content_desc, resource_id, bounds,
xpath, xpath_candidates, clickable, enabled, is_test_point, created_at
```

### TestStep（14 种类型）
```
type, xpath, xpath2, timeout, expected_text, index, description
```

### TestCaseDef
```
id, title, category, description, steps, steps_data, enabled, package_name
```

### TestResult
```
case_id, case_title, iteration, result, duration_ms, detail
```

### JWT Payload
```
sub, iat, exp, type
```

## 七、前端文件结构

```
frontend/src/modules/{domain}/
├── index.vue              ← 模块主页面
├── routes.js              ← Vue Router 路由定义
├── api.js                 ← 本模块 HTTP 请求（可选）
├── store.js               ← Pinia store（可选）
├── composables/           ← 组合式函数（可选）
└── components/            ← 模块内子组件（可选）
    └── {name}.vue

frontend/src/shared/
├── api-client.js          ← Axios 实例 + JWT 拦截器
├── event-bus.js           ← mitt 事件总线
├── components/
│   └── AppSidebar.vue     ← 全局侧边栏
└── icons/
    └── index.js           ← 24 个自定义 SVG 图标

frontend/src/views/
└── LoginView.vue          ← 平台统一登录页
```

### 跨 App 调用规则（三道防火墙）

```python
# ✅ 允许 — 跨 App import Model（只读）
from apps.device_pool.models import Device
device = Device.objects.get(serial="RF8N21MSW7A")

# ✅ 允许 — 跨 App import api.py（复杂写操作）
from apps.device_pool.api import acquire_device

# ❌ 禁止 — 跨 App import service / 内部实现
from apps.device_pool.service import allocate_device

# ❌ 禁止 — 跨 App 直接 ORM 写操作
Device.objects.update(status="ONLINE")  # 在其他 App 代码里
```
