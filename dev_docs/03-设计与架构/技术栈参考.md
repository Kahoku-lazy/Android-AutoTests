## 一、技术选型

| 层 | 技术 | 版本/说明 |
|---|------|------|
| **前端** | Vue 3 + Vite | SPA，`:5173` HMR 开发 |

## 二、命名统一标准

### 2.1 统一原则

| 原则 | 规则 | 示例 |
|------|------|------|
| 文档目录名 | `kebab-case` | `element-locator/`, `device-pool/` |
| Python 包名 | `snake_case` | `element_locator/`, `device_pool/` |
| Django Model 类名 | `PascalCase` | `Element`, `TestDefinition` |
| 数据库表名 | `{前缀}_{snake_case 复数}` | `el_elements`, `dp_devices` |
| 数据库字段名 | `snake_case` | `page_id`, `created_at` |
| REST API URL | `/api/{domain}/*`，kebab-case | `/api/elements/pages`, `/api/ai/agents` |
| URL 路径参数 | `snake_case` | `/{page_id}`, `/{run_id}` |
| WebSocket 路径 | `/ws/` 前缀 | `/ws/screenshot`, `/ws/test-run/{run_id}` |
| JSON 字段名 | `snake_case` | `{"page_id": 1, "element_count": 5}` |
| JSON 顶层包装 | `ok` + `data` 或 `error` | `{"ok": true, "data": {...}}` |
| 前端 JS 变量 | `camelCase` | `testDefinitions`, `lastDump` |
| 前端文件名 | `kebab-case` | `api-client.js`, `event-bus.js` |
| Vue 组件文件 | `PascalCase.vue` | `ChatView.vue`, `AgentDetail.vue` |
| Vue 路由路径 | `kebab-case` | `/ai-assistant/chat/:agentId` |
| WebSocket type | `snake_case` | `"screenshot"`, `"case_started"` |
| Git 分支 | `斜杠 + kebab-case` | `feat/element-export`, `fix/ws-reconnect` |

### 2.4 WebSocket 消息规范

**截图流** — `/ws/screenshot`：
| 方向 | 消息格式 | 频率 |
|------|---------|:--:|
| S→C | `{"type":"screenshot", "image":"<base64>", "ts":"<ISO8601>"}` | 2fps |

**执行进度** — `/ws/runner`：
| type | 触发时机 | 关键字段 |
|------|---------|---------|
| `step_result` | 每步完成 | `run_id, case_id, step_type, passed, duration_ms` |
| `step_log` | 步骤日志 | `run_id, message` |
| `iteration_complete` | 迭代完成 | `run_id, case_id, iteration, pass, fail` |
| `run_complete` | 全部完成 | `run_id, summary, csv_path, log_path` |
| `run_error` | 异常 | `run_id, error` |
| `progress` | 进度更新 | `run_id, completed, total` |

### 2.5 跨 App 调用规则（三道防火墙）

```python
# ✅ 允许 — 跨 App import Model（只读查询）
from apps.device_pool.models import Device
device = Device.objects.get(serial="RF8N21MSW7A")

# ✅ 允许 — 跨 App import api.py（复杂写操作）
from apps.device_pool.api import acquire_device

# ❌ 禁止 — 跨 App import service / 内部实现
from apps.device_pool.service import allocate_device

# ❌ 禁止 — 跨 App 直接 ORM 写操作
Device.objects.update(status="ONLINE")  # 在其他 App 代码里
```

### 3.4 CSS 注意事项

1. **类名 BEM 双下划线**：`animal-tabs__list`（非单下划线），手写 CSS 需与源码一致
2. **Card 无 body 层**：样式直接写在挂载类上（如 `.table-card`），不要用 `.animal-card-body`
3. **嵌套 Tabs 滚动边界**：外层管纵向滚动（`overflow-y: auto`），内层表格只管横向（`overflow-x: auto`）
4. **flex 高度链**：`doc-body` → `tabs-panel` → `animal-tabs__content` → `animal-tabs__inner` 需完整

## 四、AI 一键提示词 — animal-island-ui 页面生成

> 给普通用户使用的 self-contained 提示词。复制到 Cursor / Claude / ChatGPT 等任意 AI 编程工具发送即可。
> 最后同步：v0.9.5 / 2026-06-02

### 使用说明

1. 复制下方提示词到 AI 编程工具
2. AI 会反问你想做什么页面（如「个人博客」、「商品列表」、「FAQ 页面」）
3. 回答后 AI 输出一个 **self-contained `index.html`**，保存后双击即可在浏览器预览
4. 不需要 npm、不需要打包工具、不需要任何安装

### 提示词正文

````markdown
You are a senior React engineer. Generate a **single self-contained `index.html` file** that the user can save to disk and double-click to preview in a browser. It must PERFECTLY match the visual style of the npm package "animal-island-ui" (an Animal Crossing-inspired component library, v0.9.5).

## OUTPUT REQUIREMENTS

- **DELIVER A SINGLE SELF-CONTAINED `index.html` FILE** — NO build step, NO npm install, NO bundler.
- The HTML must use these CDN scripts inside `<head>`:
  - React 18: `<script crossorigin src="https://unpkg.com/react@18/umd/react.production.min.js"></script>`
  - ReactDOM 18: `<script crossorigin src="https://unpkg.com/react-dom@18/umd/react-dom.production.min.js"></script>`
  - Babel Standalone: `<script src="https://unpkg.com/@babel/standalone/babel.min.js"></script>`
  - animal-island-ui CSS: `<link rel="stylesheet" href="https://unpkg.com/animal-island-ui@0.9.5/dist/index.css">`

## DESIGN SYSTEM (CRITICAL)

### Colors
- Primary/Accent: `#f7cd67` (warm yellow) — buttons, active tabs, highlights
- Background: `#fff9e6` (warm cream) — page background
- Card background: `#fffef9` (warm white) — cards
- Text primary: `#3a7a10` (leaf green) — headings, labels
- Text secondary: `#6b5b3e` (warm brown) — body text
- Border: `#d4c8a0` (warm beige) — borders, dividers

### Typography
- Font: system-ui, -apple-system, sans-serif
- Headings: bold, `#3a7a10`
- Body: `#6b5b3e`, 14-16px

### Components Style
- Cards: rounded corners (12px), warm white bg, warm beige border, subtle shadow
- Buttons: rounded (20px), warm yellow bg (`#f7cd67`), leaf green text, hover darkens
- Tabs: pill-shaped, active tab yellow bg
- Inputs: rounded (8px), warm beige border, focus yellow ring

### Icons
Use emoji as icons — NO icon libraries.

## PROCESS
1. Ask the user: "What kind of page do you want me to build?"
2. After they answer, generate the complete `index.html`
3. Wrap ALL React code in a single `<script type="text/babel">` tag

## CONSTRAINTS
- Only use React 18 CDN + Babel standalone + animal-island-ui CSS — NO other libraries
- Output ONLY the `index.html` file, no other files
- Make it responsive and production-quality
````

### 技术说明

- **真实数据源**：`src/styles/variables.less` + 各组件 `*.module.less`
- **冲突处理**：本提示词与源码冲突时，**以源码为准**
- **像素级还原**：项目内直接 `npm i animal-island-ui` + `import` 真实组件
