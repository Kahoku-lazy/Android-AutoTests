## 一、技术选型

| 层 | 技术 | 版本/说明 |
|---|------|------|
| **前端** | Vue 3 + Vite | SPA，`:5173` HMR 开发 |
| | Element Plus | 基础 UI 组件库 |
| | Pinia | 状态管理（新模块默认不用；现存 store 仅 3 个：workflow `wf-workflow`/`wf-library` + device-inspector `device-inspector`，均模块内使用） |
| | Vue Router | SPA 路由，JWT beforeEach 守卫 |
| | VueFlow | 工作流工作台页面流编排（Blockly 已于 PRD-09 v5.2 下线） |
| **后端** | Django 4.x + Daphne | ASGI HTTP + WebSocket，`:8766` |
| | Airtest + uiautomator2 | Airtest: 设备操作（截图/手势/App/Shell）；u2: UI 层级 dump + XPath 定位 |
| | SQLite / MySQL | 环境变量 `DB_ENGINE` 一键切换 |
| **AI** | AgentScope | ReAct 推理引擎，Django 进程内运行（in-process，无独立端口） |
| | ChromaDB | 向量知识库（RAG，数据在 `data/chromadb/`） |
| | Redis | Channels 消息总线（WS group_send），`:6379` |
| **认证** | JWT | Django 签发与验证（AgentScope 同进程共享密钥） |
| **加密** | Fernet (cryptography) | API Key 对称加密存储 |

## 二、命名统一标准

### 2.1 统一原则

| 原则 | 规则 | 示例 |
|------|------|------|
| 文档目录名 | `kebab-case` | `element-locator/`, `device-pool/` |
| Python 包名 | `snake_case` | `element_locator/`, `device_pool/` |
| Django Model 类名 | `PascalCase` | `Element`, `TestDefinition` |
| 数据库表名 | `{前缀}_{snake_case 复数}` | `el_elements`, `dp_devices` |
| 数据库字段名 | `snake_case` | `page_id`, `created_at` |
| REST API URL | `/api/{domain}/*`，kebab-case | `/api/elements/pages`, `/api/ai/agents` |
| URL 路径参数 | `snake_case` | `/{page_id}`, `/{run_id}` |
| WebSocket 路径 | `/ws/` 前缀 | `/ws/test-run/{run_id}`, `/ws/case-editing/{case_id}` |
| JSON 字段名 | `snake_case` | `{"page_id": 1, "element_count": 5}` |
| JSON 顶层包装 | `status` + `data` / `message` | `{"status": true, "data": {...}}` / `{"status": false, "message": "..."}` |
| 前端 JS 变量 | `camelCase` | `testDefinitions`, `lastDump` |
| 前端文件名 | `kebab-case` | `api-client.ts`, `event-bus.ts` |
| Vue 组件文件 | `PascalCase.vue` | `ChatView.vue`, `AgentDetail.vue` |
| Vue 路由路径 | `kebab-case` | `/ai-assistant/chat/:agentId` |
| WebSocket type | `snake_case` | `"case_updated"`, `"case_started"` |
| Git 分支 | `斜杠 + kebab-case` | `feat/element-export`, `fix/ws-reconnect` |

### 2.4 WebSocket 消息规范

> WS 中央路由在 `gateway/routing.py`，当前共 **2 个端点**。

**执行进度** — `/ws/test-run/{run_id}`：
| type | 触发时机 | 关键字段 |
|------|---------|---------|
| `run_started` | 任务开始 | `run_id` |
| `case_started` | 用例开始 | `run_id, case_id` |
| `step_started` | 步骤开始 | `run_id, step_index` |
| `step_result` | 每步完成 | `run_id, case_id, step_type, passed, duration_ms` |
| `iteration_result` | 迭代完成 | `run_id, case_id, iteration, pass, fail` |
| `case_finished` | 用例结束 | `run_id, case_id` |
| `run_finished` | 全部完成 | `run_id, summary, log_path` |
| `log` | 步骤日志 | `run_id, message` |
| `device_error` | 设备异常 | `run_id, message` |
| `heartbeat` | 心跳 | `run_id` |

**协作编辑** — `/ws/case-editing/{case_id}`：
| 方向 | 消息格式 | 说明 |
|------|---------|------|
| S→C | `{"type":"case_updated","case_id":"..."}` | 用例变更广播（keep-alive，服务端 group_send 推送） |

> 截图流 WS（`/ws/screenshot`）已于 2026-08-19 随设备检查器快照化（PRD-03 v1.7）移除，快照获取改走 HTTP `/api/inspector/capture`。

### 2.5 跨 App 调用规则（三道防火墙）

```python
# ✅ 允许 — 跨 App import Model（只读查询）
from apps.device_pool.models import Device
device = Device.objects.get(serial="RF8N21MSW7A")

# ✅ 允许 — 跨 App import api.py（复杂写操作）
from apps.device_pool.api import acquire_device

# ❌ 禁止 — 跨 App import service / 内部实现
from apps.device_pool.service import allocate_device

# ❌ 禁止 — 跨 App 直接 ORM 写操作
Device.objects.update(status="ONLINE")  # 在其他 App 代码里
```

### 2.7 前端文件结构

```
frontend/src/modules/{domain}/
├── index.vue              ← 模块主页面
├── routes.ts              ← Vue Router 路由
├── api.ts                 ← HTTP 请求封装（djangoClient → /api/... DRF）
├── composables/           ← 逻辑编排（流程 / 校验，禁止组件内 fetch/axios）
└── components/            ← 模块内子组件
    └── {Name}.vue

frontend/src/shared/
├── api-client.ts              ← Axios 实例（JWT 拦截器分离在 api-auth-interceptors.ts）
├── event-bus.ts               ← mitt 事件总线
├── ws-url.ts                  ← WebSocket 地址构造（经 Vite 代理）
├── api/ · auth/               ← 认证 API 与 token 存储
└── components/
    ├── AppSidebar.vue         ← 全局侧边栏
    └── patterns/              ← 共享展示组件（ErrorState / EmptyState / ConfirmButton …）
```

> 前端分层红线（展示不碰网 / 流程不做校验等）见 `frontend/AGENTS.md` 与 `.agents/skills/android-autotests-rules/references/frontend.md`。
