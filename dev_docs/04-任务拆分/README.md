## 每个阶段的文件约定

| 文件 | 用途 | 维护时机 |
|------|------|---------|
| `任务清单.md` | 当前迭代任务 + 历史迭代记录 | 每次迭代开始/结束时更新 |
| `负责执行的智能体.md` | 该阶段 Agent 的角色设定（system prompt 可直接复用） | 角色职责变化时更新 |
| `执行方案与计划.md` | 具体执行方案、任务拆解、时间安排 | 每次任务规划时更新 |
| `验收与校对.md` | Gate 门禁验收结果、校对发现的问题 | 每次阶段验收时更新 |

## 阶段门禁流程

```
立项 ──Gate 0──► 架构 ──Gate 1──► PRD ──Gate 2──► 开发 ──Gate 3──► 测试 ──Gate 4──► 发布
  │                │                │                │                │                │
  └─ 验收与校对    └─ 验收与校对    └─ 验收与校对    └─ 验收与校对    └─ 验收与校对    └─ 验收与校对
```

每个阶段的 `验收与校对.md` 记录该 Gate 的通过/驳回/修改意见。
