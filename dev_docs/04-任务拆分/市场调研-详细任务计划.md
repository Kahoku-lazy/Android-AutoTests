## 二、持续调研任务

### 竞品跟踪

| 竞品 | 频率 | 关注点 |
|------|:--:|------|
| **TestHub** | 每月 | APP 自动化模块演进、AI 集成方式变化、功能矩阵更新 |
| **Appium** | 每季 | 新版本特性、社区插件、可视化工具生态 |
| **Airtest** | 每季 | 控件定位能力增强、游戏测试以外的新场景 |
| **商业测试云** | 每季 | 私有部署方案、定价变化、数据安全合规 |

产出：更新 `竞品调研与价值评估.html` 中功能对比矩阵和竞品档案。

### 用户验证

| 任务 | 产出 |
|------|------|
| 收集 Android 测试工程师反馈 | 更新用户画像、调整需求优先级 |
| 验证「XPath 优于图像识别」假设 | 补充量化对比数据到灵感分析.html |
| 监控「单平台聚焦」市场信号 | 决定是否需要扩展 iOS / Web |
