## 五、新增模块时的 4 文件注册清单

```
1. config/settings.py      → INSTALLED_APPS 加 1 行
2. config/urls.py          → include('apps.{name}.urls')
3. frontend/src/router.js  → import 模块路由
4. frontend/src/shared/components/AppSidebar.vue → navItems 加菜单项
```
