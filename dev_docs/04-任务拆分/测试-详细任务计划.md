## 二、分层测试覆盖矩阵

### 模块 × 测试层

| 模块 | L1 DB | L2 API | L3 UI | L4 白盒 | L5 安全 |
|------|:--:|:--:|:--:|:--:|:--:|
| **device_pool** | 3 表 | 12 端点 | 设备卡片/锁定/排队 | pool.py 单例 | 锁定权限 |
| **element_locator** | 3 表 | 12 端点 | 截图流/点击/XPath | XPath 8 策略 | WS 鉴权 |
| **case_manager** | 2 表 | 5 端点 | 用例编辑器/目录树 | YAML 导出 | 用例所有权 |
| **test_runner** | 3 表 | 5 端点 | 任务卡片/实时进度 | 状态机/恢复 | 运行权限 |
| **report_generator** | 2 表 | 3 端点 | 报告列表/详情 | CSV/HTML 生成 | 报告所有权 |
| **ai_assistant** | 6 表 | 18 端点 | 智能体/对话/SSE | AgentScope Tool | API Key 脱敏 |
| **dashboard** | — | 1 端点 | KPI/图表/导航 | 跨模块聚合 | 只读验证 |
| **platform（横切）** | — | — | 路由守卫/JWT | 中间件 | JWT/黑名单 |

### L2 API 测试 — 端点状态码矩阵

每个端点至少验证：

| 状态码 | 场景 |
|:--:|------|
| 200 | 正常请求 |
| 400 | 无效 JSON / 缺少必填参数 |
| 401 | 无 token / token 过期 |
| 404 | 资源不存在 |
| 409 | 状态冲突（如设备已锁定） |

### L3 UI 测试 — 页面验证矩阵

每个页面至少验证：

| 检查项 | 说明 |
|--------|------|
| 加载 | 页面正常渲染，无白屏 |
| 组件 | 关键组件在 DOM 中可见 |
| 交互 | 点击/输入/切换正常响应 |
| 数据正确 | 显示数据与 API 返回一致 |
| 空态 | 无数据时显示空状态提示 |
| 错误态 | API 失败时显示错误提示（ElMessage.error） |

## 三、安全测试清单

| 检查项 | 验证方式 |
|--------|---------|
| JWT 无 token 返回 401 | `curl` 不带 Authorization header |
| WebSocket 无 token 拒绝连接 | 不带 query string token |
| API 响应 `api_key` 脱敏 | `grep "api_key"` 响应 → 应为 `sk-***xxxx` |
| 日志无敏感字段 | `grep "password\|api_key\|token" logs/` → 应为空 |
| 跨用户数据隔离 | 用户 A 无法查看用户 B 的设备/用例/报告 |
| 写操作 catch 有 ElMessage.error | `grep "catch.*_" frontend/src/modules/` → 写操作必须报错 |
| 前端无硬编码数据 | `grep -rn 'ref(\[{.*id:' frontend/src/modules/` → 应为空 |
| `.env` 在 `.gitignore` 中 | `grep ".env" .gitignore` → 应存在 |

## 四、回归测试范围

改 A 模块时，至少验证以下关联模块：

| 改动的模块 | 必须回归检查 |
|-----------|------------|
| `device_pool` | element_locator（设备连接） · test_runner（设备锁定） |
| `element_locator` | case_manager（XPath 引用） |
| `case_manager` | test_runner（用例执行） |
| `test_runner` | report_generator（报告生成） · device_pool（设备释放） |
| `ai_assistant` | 全部 6 个 App（Tool 调用） |
| `report_generator` | test_runner（执行→报告链路） |
| `config/settings.py` | 全部模块 |
| `gateway/middleware.py` | 全部 API（JWT 鉴权） |
| `shared/auth/jwt_auth.py` | 全部 API + AgentScope |

## 五、环境降级对照表

| 组件不可用 | 降级方式 | 记录要求 |
