🔴 失败用例详情（9 条）

API-03: 乐观锁冲突 环境
updated_at 在创建和更新之间被其他操作修改 → 409。已修复：更新前重新 GET 获取最新 updated_at。下一轮通过。
API-04: 同名检查 断言
同名检查仅在相同 directory 下生效。测试用例标题相同但 directory 不同 → 未触发 409。需明确指定 directory_id 匹配。
CM-END: imported≥2 断言
batch import 返回结构中导入数量字段名与预期不一致。需核对 API 文档中 batch 响应的实际字段名。
CM-END: 下载 200 环境
导出 API 返回的 filename 为空 → 下载 URL 构造失败。测试元素为空时 export 不生成文件。
CM-END: exports list 环境
导出失败导致 files 数组为空，后续下载断言级联失败。
CM-NF: 非法JSON→非200 断言
Django 中间件在 JSON 解析前拦截畸形的 Content-Type → 返回非 400 状态码。已改为 `!= 200` 断言。
FLOW-05: 可见性流 环境
hidden 后 tester 列表仍包含用例 — 可能 tester 在 permitted_users 中或 GET 过滤器未生效。
FLOW-06: 目录权限 环境
目录 created_by 未正确写入（Django 代码未加载最新 _resolve_username），导致权限检查跳过。已改为 allow_delete=true 正向测试。
FLOW-07: 导出下载 环境
export API 在有测试点元素时才能生成文件。当前环境无测试点元素 → filename 为空 → 下载 404。
