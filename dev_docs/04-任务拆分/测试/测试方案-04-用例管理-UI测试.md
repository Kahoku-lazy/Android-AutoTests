### Playwright 断言速查

| 断言类型 | 代码示例 | 适用场景 |
|------|------|------|
| 元素可见 | `await expect(el).toBeVisible()` | 菜单项出现、卡片渲染 |
| 元素隐藏 | `await expect(el).toBeHidden()` | 权限菜单不出现 |
| 元素禁用 | `await expect(btn).toBeDisabled()` | 保存/编辑按钮灰显 |
| 元素启用 | `await expect(btn).toBeEnabled()` | 编辑按钮可点击 |
| 文本包含 | `await expect(el).toContainText('xx')` | 卡片标签、banner |
| 文本精确 | `await expect(el).toHaveText('xx')` | 标题更新后验证 |
| CSS 类 | `await expect(el).toHaveClass(/class/')` | 锁定状态变化 |
| 数量 | `await expect(locator).toHaveCount(n)` | 菜单项数量 |
| URL | `await expect(page).toHaveURL(/cases/)` | 路由跳转 |
| 等待 | `await page.waitForTimeout(35000)` | 30s 自动刷新 |

### 通用选择器策略

```js
// 登录
await page.fill('input[placeholder="账号"]', 'admin')
await page.fill('input[placeholder="密码"]', 'admin123')
await page.click('button:has-text("开始使用")')

// 导航到用例管理
await page.click('.sidebar-menu__item:has-text("测试用例")')

// 右键菜单
await page.click('.el-tree-node__content:has-text("UI测试目录")', { button: 'right' })

// 卡片
const card = page.locator('.case-card:has-text("UI测试用例")')
const editBtn = card.locator('button:has-text("编辑")')
await expect(editBtn).toBeDisabled()

// 锁定按钮
const lockBtn = card.locator('button:has-text("🔓")')

// 编辑锁 banner
const banner = page.locator('.edit-lock-banner')
await expect(banner).toContainText('正被 admin 编辑中')

// 权限面板
const permSection = page.locator('text=权限与可见性')
await expect(permSection).toBeVisible()

// 步骤编辑器
const stepDropdown = page.locator('[placeholder="选择步骤类型"]')
// 或
const dragHandle = page.locator('.step-item').first().locator('.drag-handle')
```
