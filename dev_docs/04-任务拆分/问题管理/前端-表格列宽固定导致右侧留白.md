# 多页面表格列宽固定导致右侧留白

> 状态：✅ 已修复 · 日期：2026-07-13 · 模块：前端
> 影响页面：报告列表页 · 元素管理页 · 用例管理页

---

## 问题原因

三个页面的表格列宽问题**根因相同**——列宽使用固定像素值，表格未设 `width: 100%` 撑满容器：

| 页面 | 列宽情况 | 容器宽度 | 表格布局 | 额外问题 |
|------|---------|:--:|---------|---------|
| **报告列表** | 固定像素合计 ~1180px | ~600px | `width: max-content` + `table-layout: auto` | — |
| **元素管理** | 固定像素合计 ~760px | ~214px（Tabs 区域被筛选栏挤压） | 同上 | 容器 `overflow: auto` + `max-height: 100%`，表格被限制内部滚动 |
| **用例管理** | 混用 `%` + `72px` / `148px`，标题列 `width: auto` | 侧栏占宽后表格未强制铺满 | 同上 | 标题列 `width: auto` 导致列宽不可控 |

**叠加效应**：固定列宽 → 表格宽度超出容器 → 右侧留白。容器链未设 `width: 100%` → 表格按内容收缩 → 留白加剧。

---

## 修复内容

三个页面采用**统一修复方案**（与报告列表一致）：

| 层面 | 修复 |
|------|------|
| 列宽定义 | 从固定像素改为百分比（合计 100%），由 columns 配置驱动 |
| 表格铺满 | `table-layout: fixed` + `width: 100%` |
| 容器链拉满 | Tabs → Card → animal-table-wrapper → table 全部 `width: 100%` |
| 字号统一 | 表头 18px、正文 14px（三个页面统一） |
| 长文本 | `text-overflow: ellipsis`，避免撑破列宽 |
| 筛选区 | 元素管理筛选 Tabs 与计数横排结构调整，Tabs 不再被挤压 |

## 现在的效果

- 三个页面的表格均铺满内容区宽度，随窗口大小自适应
- 右侧无留白
- 筛选 Tabs 区域不再被挤压
- 长文本自动省略，不破坏列宽比例
- 字号统一：表头 18px、正文 14px
