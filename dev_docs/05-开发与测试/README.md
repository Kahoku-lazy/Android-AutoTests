# 05-开发与测试

> **按平台功能模块建子目录**（不再平铺前缀）。每模块固定三份核心 HTML：
>
> 1. **编程工作流.html** — 需求分析 → 改动评估 → 编码 → Review
> 2. **代码质量分析.html** — 现网结构/依赖盘点（非占位）
> 3. **质量与验收手册.html** — Review · 质量流程 · 报错诊断 · AC 验收
>
> 测试方案 HTML **暂缓**；既有 `测试方案-*.md` 留在对应模块目录。平台横切进 `平台级/`。
