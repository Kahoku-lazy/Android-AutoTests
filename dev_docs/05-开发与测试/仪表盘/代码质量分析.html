1. 修防火墙破口 P0

test_runner.api 新增活跃运行快照；dashboard 改调 api；删 runner 私有 import。

2. 修 URL include P0 · 5min

压缩日序列与 _recent_tasks 查询次数；抽 applyStatsPayload；失败 ElMessage。
