## 一、数据契约层（`test_device_contracts.py`）

#### 用例名称：`test_device_status_values`
- **业务功能**：设备状态枚举（设备只有「在线 / 使用中」两态）
- **测试目的**：验证只有两种状态、取值正确，且对外展示仍是文字（不因内部用枚举破坏前端契约）
- **测试方法与步骤**：直接断言枚举各成员的 `value`、str 语义、成员集合
- **断言逻辑**：
  - `DeviceStatus.ONLINE.value == "ONLINE"`
  - `DeviceStatus.BUSY.value == "BUSY"`
  - `DeviceStatus.ONLINE == "ONLINE"`
  - `{e.value for e in DeviceStatus} == {"ONLINE", "BUSY"}`

#### 用例名称：`test_connection_type_values`
- **业务功能**：连接方式枚举（设备只有「USB / 无线」两种接入）
- **测试目的**：验证只有两种取值、不会出现第三种
- **测试方法与步骤**：直接断言枚举各成员的 `value` 与成员集合
- **断言逻辑**：
  - `ConnectionType.USB.value == "USB"`
  - `ConnectionType.WIFI.value == "WIFI"`
  - `{e.value for e in ConnectionType} == {"USB", "WIFI"}`

#### 用例名称：`test_device_info_defaults`
- **业务功能**：设备数据契约默认值
- **测试目的**：验证默认构造时各字段默认值正确、防误改
- **测试方法与步骤**：实例化 `DeviceInfo()`，逐字段断言默认值
- **断言逻辑**：
  - `info.serial == ""`、`info.connection_type is ConnectionType.USB`、`info.status is DeviceStatus.ONLINE`
  - `info.screen_w == 0`、`info.screen_h == 0`
  - `info.locked_at is None`、`info.occupied_at is None`、`info.last_seen is None`、`info.created_at is None`

#### 用例名称：`test_device_info_fields_match_model`
- **业务功能**：数据契约字段与数据库表对齐
- **测试目的**：验证契约字段与表字段一一对应、顺序一致（防漂移）
- **测试方法与步骤**：用 `fields(DeviceInfo)` 取契约字段、`Device._meta.fields` 取模型字段（排除主键 id），断言两列表相等
- **断言逻辑**：
  - `[f.name for f in fields(DeviceInfo)] == [f.name for f in Device._meta.fields if f.name != "id"]`

## 二、设备探测层（`test_device_detector.py`）

#### 用例名称：`test_is_wireless`
- **业务功能**：判断设备有线/无线
- **测试目的**：验证「IP 或 mDNS 前缀 → 无线；纯串号 → USB」识别规则
- **测试方法与步骤**：实例化探测器，依次传入 IP:port、mDNS 名、纯串号三个地址，断言返回值
- **断言逻辑**：
  - `is_wireless("192.168.1.5:5555") is True`
  - `is_wireless("adb-ABC123-_adb-tls-connect._tcp") is True`
  - `is_wireless("RF8N21MSW7A") is False`

#### 用例名称：`test_resolve_serial_usb`
- **业务功能**：USB 设备序列号解析
- **测试目的**：验证 USB 直接用地址当序列号、连接地址为空
- **测试方法与步骤**：调用 `resolve_serial("RF8N21MSW7A")`，断言返回元组
- **断言逻辑**：
  - `resolve_serial("RF8N21MSW7A") == ("RF8N21MSW7A", "")`

#### 用例名称：`test_resolve_serial_mdns_when_getprop_empty`
- **业务功能**：无线 mDNS 设备序列号解析
- **测试目的**：验证取不到真实序列号时从 mDNS 名称拆出内嵌序列号（避免身份漂移）
- **测试方法与步骤**：① mock `fetch_serial_no` 返回空串；② 调用 `resolve_serial("adb-ABC123-xyz._adb")`；③ 断言拆出的 serial 与 addr
- **断言逻辑**：
  - `serial == "ABC123"`
  - `addr == "adb-ABC123-xyz._adb"`

#### 用例名称：`test_adb_device_serials_parses_device_lines`
- **业务功能**：扫描在线设备（解析 `adb devices`）
- **测试目的**：验证只取 `device` 状态、跳过 `offline`/未授权
- **测试方法与步骤**：① mock `subprocess.run` 返回含 device/offline 两行的 stdout；② 调用 `adb_device_serials()`；③ 断言地址集合
- **断言逻辑**：
  - `serials == {"RF8N21MSW7A", "192.168.1.5:5555"}`

#### 用例名称：`test_adb_device_serials_returns_empty_on_error`
- **业务功能**：扫描容错（adb 不可用）
- **测试目的**：验证 adb 失败时返回空集、不抛错崩溃
- **测试方法与步骤**：① mock `subprocess.run` 抛异常；② 调用 `adb_device_serials()`；③ 断言返回空集
- **断言逻辑**：
  - `adb_device_serials() == set()`

#### 用例名称：`test_detect_returns_contract_list`
- **业务功能**：汇总设备清单（组装数据契约）
- **测试目的**：验证每台设备被正确归类 USB/无线、并带上正确连接地址
- **测试方法与步骤**：① mock `adb_device_serials` 返回 `{USB串号, IP:port}`、mock `resolve_serial`；② 调用 `detect()`；③ 按 serial 分组断言类型与地址
- **断言逻辑**：
  - `set(by_serial) == {"RF8N21MSW7A", "192.168.1.5:5555"}`
  - `by_serial["RF8N21MSW7A"].connection_type is ConnectionType.USB`、`.connection_addr == ""`
  - `by_serial["192.168.1.5:5555"].connection_type is ConnectionType.WIFI`、`.connection_addr == "192.168.1.5:5555"`

#### 用例名称：`test_connect_wireless_success`
- **业务功能**：连接设备（无线成功）
- **测试目的**：验证无线 IP:port 的 adb connect + u2 探活均成功时不抛错
- **测试方法与步骤**：① mock `subprocess.run` 返回「connected」；② mock `probe_u2`；③ 调 `connect("192.168.1.5:5555")`；④ 断言不抛错
- **断言逻辑**：
  - `detector.connect("192.168.1.5:5555")` 正常返回（不抛异常）

#### 用例名称：`test_connect_wireless_adb_fail`
- **业务功能**：连接设备（adb connect 失败）
- **测试目的**：验证无线 adb connect 输出无 connected/already 时抛 504
- **测试方法与步骤**：① mock `subprocess.run` 返回「failed to connect」；② 调 `connect` 期望抛 `DeviceError`；③ 断言 status_code
- **断言逻辑**：
  - `pytest.raises(DeviceError)`
  - `e.value.status_code == 504`

#### 用例名称：`test_connect_atx_agent_not_running`
- **业务功能**：连接设备（ATX Agent 未运行）
- **测试目的**：验证 u2 探活报 atx-agent/offline 时抛 502
- **测试方法与步骤**：① mock `subprocess.run` 返回「connected」；② mock `probe_u2` 抛 `EngineConnectError("atx-agent...") `；③ 调 `connect` 期望抛 `DeviceError`；④ 断言 status_code
- **断言逻辑**：
  - `pytest.raises(DeviceError)`
  - `e.value.status_code == 502`

#### 用例名称：`test_connect_usb_skips_adb_connect`
- **业务功能**：连接设备（USB 跳过 adb connect）
- **测试目的**：验证 USB 设备不触发 adb connect、直接 u2 探活
- **测试方法与步骤**：① mock `probe_u2` 与 `subprocess.run`；② 调 `connect("RF8N21MSW7A")`；③ 断言 `subprocess.run` 未被调用
- **断言逻辑**：
  - `mock_run.assert_not_called()`

## 三、单元测试运行方式

> 运行指令： `python -m pytest tests/graybox/unit -v`

| 场景 | 命令 |
|------|------|
| 全部单元测试 | `python -m pytest tests/graybox/unit -v` |
| 业务模块筛选 | `python -m pytest -m "unit and device_pool"` |
| 单文件运行 | `python -m pytest tests/graybox/unit/test_device_contracts.py -v` |
