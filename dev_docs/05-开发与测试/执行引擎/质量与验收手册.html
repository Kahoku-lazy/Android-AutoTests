③ 报错诊断

通用项见 平台级/报错诊断手册.md

任务卡在 RUNNING

原因：状态机未收尾 / 回调丢失

处理：查 state_machine + callbacks

WS 无进度

原因：Channels/Redis / 鉴权

处理：查 /ws/test-run/{id}

设备执行失败

原因：u2 断连 / recovery

处理：查 u2_recovery / device_connect
