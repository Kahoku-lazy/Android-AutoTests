# 模块测试方案 — 端到端全链路

> 关联：`02-PRD需求/实际需求文档.md` · 版本：v1.0 · 日期：2026-07-01

---

## 1. 前置条件

- Django :8765 运行
- AgentScope :8000 运行（Redis 可用）
- Vite :5173 运行
- Android 设备通过 ADB 连接
- 已有 admin/admin123 账号
- 已有至少 1 个智能体（含 14 工具）

---

## 2. E2E 用例

### E2E-01：完整手动测试闭环

| 步骤 | 操作 | 预期 |
|:--:|------|------|
| 1 | 访问 localhost:5173 | 跳转 /login |
| 2 | 登录 admin/admin123 | 跳转 /dashboard |
| 3 | 导航到设备管理 | 列表显示已连接设备 |
| 4 | 导航到元素定位 | 截图实时刷新 |
| 5 | 点击"抓取 UI" | 元素列表加载 |
| 6 | 点击某元素 → 标记为测试点 | 标签更新 |
| 7 | 导航到测试用例 → 新建 | 填写表单 |
| 8 | 添加步骤（从元素选择 XPath）| 步骤列表正确 |
| 9 | 保存用例 | 列表刷新 |
| 10 | 导航到执行引擎 → 选择用例+设备 | 执行启动 |
| 11 | 观察 WebSocket 进度 | 实时推送步骤结果 |
| 12 | 完成后查看报告 | 通过率/失败详情正确 |

### E2E-02：AI 智能生成用例闭环

| 步骤 | 操作 | 预期 |
|:--:|------|------|
| 1 | 登录 → 导航 AI 助手 | 智能体列表 |
| 2 | 选择一个智能体 → 新建对话 | 输入框就绪 |
| 3 | 输入 "查看在线设备" | SSE 流式返回设备列表 |
| 4 | 输入 "搜索元素登录按钮" | 调用 search_elements → 返回 XPath |
| 5 | 输入 "创建冒烟用例 test-e2e-001" | 调用 save_test_case |
| 6 | 导航到测试用例模块 | test-e2e-001 出现在列表 |
| 7 | 回到 AI 对话，输入 "在设备 X 跑 test-e2e-001 循环 1 轮" | 锁定→执行→返回结果 |
| 8 | 导航到测试报告 | 报告记录存在 |

### E2E-03：无设备降级

| 步骤 | 操作 | 预期 |
|:--:|------|------|
| 1 | 断开 ADB（adb disconnect） | — |
| 2 | 访问元素定位 | 提示"请连接设备"，不崩溃 |
| 3 | 访问执行引擎 | 设备列表为空 |
| 4 | 访问 AI 助手 → 对话 | 仍可搜索元素（返回空）和创建用例（无 XPath） |
| 5 | 重连 ADB → 刷新元素定位 | 截图恢复 |

### E2E-04：AgentScope 不可用降级

| 步骤 | 操作 | 预期 |
|:--:|------|------|
| 1 | 停止 Redis | AgentScope :8000 不可用 |
| 2 | AI 对话发送消息 | 自动降级到 Django /send |
| 3 | 回复正确显示 | 阻塞模式，非流式但内容完整 |
| 4 | 消息审计 | AIMessage 表有记录 |

### E2E-05：JWT 全链路

| 步骤 | 操作 | 预期 |
|:--:|------|------|
| 1 | 登录 → 获取 token | localStorage 有 access_token |
| 2 | F5 刷新页面 | 保持登录状态 |
| 3 | 等待 58 分钟（或手动改 exp） | token 自动刷新 |
| 4 | 点击退出 | token 清除 |
| 5 | 用旧 token curl API | 401 |

### E2E-06：多模块交叉验证

| 步骤 | 操作 | 预期 |
|:--:|------|------|
| 1 | 设备管理 → 锁定设备 X | 状态 BUSY |
| 2 | 同一设备在元素定位 | 仍可截图（读操作不冲突） |
| 3 | 执行引擎选设备 X | 提示设备被占用 |
| 4 | 设备管理 → 释放设备 X | 状态 ONLINE |
| 5 | 执行引擎重试 | 正常执行 |

### E2E-07：Agent Team 编队

| 步骤 | 操作 | 预期 |
|:--:|------|------|
| 1 | AI 对话输入 "给登录页生成完整用例并跑一轮" | 复杂任务触发编队 |
| 2 | 观察 AgentScope 日志 | element-inspector → case-writer → device-operator → test-executor 依次 spawn |
| 3 | Leader 汇总回复 | 包含完整执行摘要 |
| 4 | 导航到用例模块 | 新用例存在 |
| 5 | 导航到报告 | 执行报告存在 |
