# Android-AutoTests 平台测试方案

> 基于实际代码 · 版本：v2.0 · 日期：2026-07-01

---

## 一、测试策略总览

### 1.1 测试金字塔

```
         ┌──────┐
         │ E2E  │  全链路：登录 → AI对话 → 生成用例 → 执行 → 报告
         │  8条 │  需要：ADB + Android 设备 + Redis
         ├──────┤
         │ 集成  │  模块间 API 调用链：device→element→case→runner→report
         │ 12条 │  需要：Django + SQLite
         ├──────┤
         │ API  │  每个端点独立验证：请求→响应→数据库状态
         │ 37条 │  需要：Django（无需设备）
         └──────┘
```

### 1.2 测试环境

| 环境 | 用途 | 依赖 |
|------|------|------|
| **纯后端** | API 测试、JWT 测试 | Django + SQLite |
| **后端+Redis** | AgentScope Tool 测试、SSE 测试 | Django + Redis + AgentScope |
| **后端+设备** | 截图流、元素 dump、执行引擎 | Django + ADB + Android |
| **全栈** | 前端 E2E、用户故事验证 | Django + Redis + AgentScope + Vite + 设备 |

### 1.3 严重度定义

| 级别 | 定义 | 示例 |
|:--:|------|------|
| P0 | 核心链路阻断，无绕过方案 | 登录失败、用例保存报 500、AI 对话无响应 |
| P1 | 重要功能异常，有绕过方案 | XPath 策略少了一种、报告缺少某列 |
| P2 | 边缘场景或体验问题 | 动森主题颜色偏差、空列表提示文案不友好 |

## 四、快速验证清单

上线前必过的 6 条：

```bash
# 1. JWT 认证链路
curl -X POST localhost:8765/api/ai/auth/login \
  -d '{"username":"admin","password":"admin123"}'  # → 200 + access_token

# 2. AI 智能体 CRUD
curl localhost:8765/api/ai/agents  # → 200 + agents 数组

# 3. 元素 dump（需设备）
curl -X POST localhost:8765/api/elements/dump  # → 200 + page_id

# 4. 用例创建
curl -X POST localhost:8765/api/ai/agents/1/conversations/create \
  -d '{"title":"test"}'  # → 200 + id

# 5. 执行测试（需设备+用例）
curl -X POST localhost:8765/api/runner/run \
  -d '{"case_ids":["xxx"],"serial":"RF8N21MSW7A","loop_count":1}'  # → 200 + run_id

# 6. 前端可访问
curl localhost:5173  # → 200 (HTML)
```
