## 1. 需求（用户口径原文归纳）

| # | 规则 |
|---|------|
| 1 | 共享层 = **主 token**：所有颜色、所有字号、字体规格的唯一出处；另含「通用组件库配色」一档 |
| 2 | 子模块各有**一份 token**：按**使用场景**命名（标签用色 / 背景用色 / 表格用色…），值只能来自主 token |
| 3 | 数据链单向：主 token 提供**基础元素**（颜色 / 字体 / 字号），模块 token **组合**这些元素设计样式 |
| 4 | 主 token 内**同值不得重复出现**；**以颜色命名**，不设计场景、不设计使用模块 |
| 5 | 层间「输送管道」要规范：介质不限（样式表 / SVG 属性 / 模板 style / prop / JS 字符串），但**出处受边界约束** |
| 6 | 模块边界 = `modules/` 下 8 个目录 **+ `views/` 也算一个独立模块**；`shared/` 是通用层 |

## 2. 词表分层：每份 token 的边界与职责

### 2.1 总表

| 层 | 文件 | 职责（只放什么） | 命名 | 硬禁止 |
|----|------|------------------|------|--------|
| **T0** 主 token·颜色 | `shared/styles/tokens.css` → `:root` | **全部字面量色值的唯一登记处** | `--color-<色相>[-<档位>]`（如 `--color-red-500`）· 惯用名 `--color-paper` / `--color-ink` | 场景名 · 模块名 · 同值重复 |
| **T0** 主 token·排版 | 同上 | 字体族 + 字号刻度（6 档） | `--font-<族>` · `--font-size-<档>` | 新增第 7 档 · 场景名 · 同值重复 |
| **T0** 主 token·基础量 | 同上 | 间距 / 圆角 / 阴影 / 动效 / 布局尺寸 | `--space-*` `--radius-*` `--shadow-*` `--duration-*` `--ease` `--size-*` | 场景名 · 同值重复 |
| **T0** 主 token·通用组件配色 | 同上 | `shared/components/**` 与 L1 外壳的场景配色；EP `--el-*` 覆盖 | `--comp-<组件>-<场景>`（待定 §8-1） | 引用任何 T1 · 字面量以外的新值 |
| **T1** 模块 token | `modules/{name}/tokens.css` ×8 · `views/tokens.css` ×1 | 本模块**场景 → 原子**的映射表 | `--{mod}-<场景>[-<部位>]` 如 `--ai-tag-bg` | 任何字面量 · 引用别的模块 · 被 T0 引用 |
| **T1** 组件级载体 | 组件自身根类（`<style scoped>` 内） | 只被**单个组件**消费的场景别名 | 同上，可省模块前缀 | 字面量（值必须 `var(T0)`） |
| **T2** 消费 | `.vue` scoped 块 · `*.style.css` · 模板 `style` · SVG 属性 · prop · JS 字符串 | 引用 T1（模块内）或 T0（shared 内） | — | 裸字面量色值 · 跨模块借 T1 |

### 2.2 T0 与 T1 的分界（一句话）
=> **T0 存「值 + 颜色名」，T1 存「用途 + 场景名」。** 每个色值在 T0 只出现一次；T1 只写 `var(--color-…)`，把用途讲清楚。两者一一按需对应，不要求每个原子都有场景别名。

### 2.3 T1 的两级粒度（保留上一轮成果）

| 消费范围 | 落点 | 现存量 |
|----------|------|--------|
| 同模块 ≥2 个组件消费 | `modules/{m}/tokens.css` | `.ai-workbench` 42 条 · `.case-workbench` 2 条 · workflow `--ac-*` 30 条 |
| 只被 1 个组件消费 | 该组件自身根类载体 | ~148 行 / 40 个 `.vue`（上一轮 `land-module-color-registry` 建立的形态） |

## 3. 数据链（单向，不可逆行）

```text
[T0 主 token]  shared/styles/tokens.css
   ├ 颜色原子        --color-*                 ← 全部字面量色值的唯一登记处
   ├ 排版原子        --font-* / --font-size-*  ← 字体族 + 6 档字号
   ├ 基础量原子      --space/radius/shadow/duration/size-*
   ├ 通用组件配色    --comp-<组件>-<场景>       ← shared/components/** + L1 外壳 + EP --el-*
   └ 外壳骨架        --shell-*（待定 §8-4）
            │
            │  T1 只能 var(T0)；T0 绝不引用 T1（单向）
            ▼
[T1 模块 token]  modules/{8}/tokens.css · views/tokens.css · 组件根类载体
   场景命名：--{mod}-tag-bg / --{mod}-table-header-bg / --{mod}-drawer-*
   作用域：模块页面根类；Teleport 目标则声明在被传送元素自身根类
            │
            ▼
[T2 消费]  <style scoped> ─┐
           外部 *.style.css ├── 只引用该模块 T1；若调用点在 shared/** 则引用 T0
           SVG 元素属性     │
           模板 style/prop  │
           JS 字符串 / .ts ─┘
```

### 3.1 溯源判定树（开发与审查都用这一棵）

```text
这处外观值由谁消费？
├─ 在 shared/**（通用组件 / L1 外壳） ───────> T0：颜色原子 或 --comp-*
├─ 在 modules/{m}/** 或 views/**（模块内） ─> T1 的 --{m}-*
│      └─ T1 无对应场景？ ──> 先在 T1 加一条（组合 T0），不得直接引用 T0 的组件名/场景名
├─ 该元素 Teleport 到 body ────────────────> T1 声明在被传送元素自身根类；无则退用 T0 原子
├─ canvas / ECharts（不解析 CSS 变量） ────> 模块图表色表集中声明，注释标注对应 T0 原子名
└─ 组件私有一次性注入（父传 --x） ─────────> 保留在组件根类，值必须溯源自 T0/T1
```

## 4. 作用域表（每份 token 的生效范围）

| 文件 / 载体 | CSS 选择器 | 生效范围 | Teleport 安全性 |
|-------------|-----------|----------|----------------|
| T0 颜色/排版/基础量 | `:root` | 全站 | 安全 |
| T0 通用组件配色 | `:root`（或 `.wb-shell`，待定 §8-1） | 全站 | 安全 |
| `modules/{m}/tokens.css` | `.{m}-workbench` 等模块页面根类 | 该模块页面 DOM 子树 | 原地渲染安全；Teleport 到 body **不安全** → 需元素自身根类 |
| `views/tokens.css` | views 页面根类 | views 页面 | 同上 |
| 组件级载体 | 组件根类 | 组件子树 | 组件内 Teleport 时需移到元素自身根类 |

**实测依据**：EP 2.7 `el-dialog` 渲染为 `Teleport({ disabled: appendToBody !== true })`，本仓 `append-to-body` 命中 0 → 弹层**原地渲染**，故模块根类作用域可达（上一轮 `land-module-color-registry` 已验证）；改落点后需复验该前提仍成立。

## 9. 风险与未核验项

1. **T0 颜色原子会膨胀到约 100 条**：所有色值都必须进 T0，其中约 66 个是单模块专用（实测跨模块的只有 2 个）。
2. **近邻色命名需要判定**（真实例子，必须给出可区分色名）：`#e85f5f`(app-error) / `#f87171`(app-live) / `#ff6b6b`(app-marker-red) / `#c43f3f`(ai-status-danger-text)；`#6bcb77` / `#4caf50`(ai-status-green-border) / `#2a7a2a`(ai-status-green-text)；`#f7c948`(本期主色) / `#f5cda0`(wb-btn--sunset hover)。
3. **零视觉变化**：本方案只搬值与改名，不改任何色值/字号；上一轮已按同口径执行。
4. **未核验**：`vite build` / `vitest` 被沙箱拦（spawn EPERM），浏览器核验未做；模块 token 作用域变更后的 Teleport 前提需在改动时复验。
