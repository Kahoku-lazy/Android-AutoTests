# 设计方案 — 测试框架三层划分

> 目标：把测试按「真实执行形态」拆分为三层，各自独立执行，互不混装。保留 `tests/arch` 架构契约测试。
> 变更范围：删除 `tests/` 下除 `arch/` 外的全部旧测试文件，重建 pytest 骨架。

## 一、三层划分

| 层 | 目录 | 内涵 | 执行形态 | 依赖 |
|---|---|---|---|---|
| 接口测试 | `tests/api/` | 黑盒 HTTP 端点 + 鉴权 | 对运行中的后端发真实 HTTP | 后端 live server + 环境变量凭据 |
| 灰盒测试 | `tests/graybox/` | 单元 + 集成 | 进程内直调代码/ORM | Django 配置（SQLite :memory:） |
| 黑盒测试 | `tests/e2e/` | 端到端完整链路 | Playwright 真实浏览器 | 前后端 live + pytest-playwright |
| 架构契约 | `tests/arch/` | 跨模块不变量 | 读源码断言结构 | 无 |

## 二、目录结构

```
tests/
├── conftest.py              # 全局共享 fixture（base_url）
├── api/                     # ① 接口测试（黑盒 HTTP）
│   ├── conftest.py          #   api_session / admin_creds / auth_token / auth_headers
│   └── test_auth_login.py   #   示例
├── graybox/                 # ② 灰盒测试
│   ├── unit/                #    单元（纯逻辑，零 I/O 零 DB）
│   └── integration/         #    集成（django_db + 多模块协作）
├── e2e/                     # ③ 黑盒测试（端到端）
│   ├── conftest.py          #   frontend_url / e2e_services / 失败截图
│   ├── selectors.py         #   data-testid 常量
│   └── test_example_e2e.py  #   示例
└── arch/                    # ④ 架构契约（保留）
    └── test_channels.py
```

## 三、marker 与分开执行

主 marker：`api` / `unit` / `integration` / `e2e` / `arch`（定义见 `pytest.ini`）。

```bash
# ① 接口测试
pytest tests/api
# ② 灰盒（单元 + 集成）
pytest tests/graybox/unit tests/graybox/integration
# ③ 黑盒（端到端）
pytest tests/e2e
# ④ 架构契约
pytest tests/arch

# 或用 marker 过滤（跨目录）
pytest -m api
pytest -m 'unit or integration'
pytest -m e2e
pytest -m arch
```

## 四、关键约定

1. **文件命名**：所有测试文件以 `test_` 开头（`tests/AGENTS.md` 铁律）。
2. **凭据不硬编码**：admin 密码走 `TEST_ADMIN_PASSWORD` 环境变量；未设置则相关用例 skip（`android-autotests-rules` 安全铁律）。
3. **端点常量集中**：各层 conftest.py 顶部集中定义 URL 常量，测试内不散写字符串。
4. **E2E 选择器走 data-testid**：`tests/e2e/selectors.py` 与前端 DOM 一一对应，禁止裸 CSS/文案选择器。
5. **报告输出**：Allure 结果用 `--alluredir=temps/allure-results`（临时产物入 `temps/`，不污染 `tests/`）。
6. **django_db 边界**：集成测试使用 `config.test_settings`（SQLite :memory:）；含 MySQL 专属 RunSQL 的 App（test_runner/0017、ai_assistant/0021）需 mock 或显式跳过。

## 五、环境变量清单

| 变量 | 默认 | 说明 |
|---|---|---|
| `TEST_BASE_URL` | `http://localhost:8766` | 后端根地址 |
| `TEST_FRONTEND_URL` | `http://localhost:5173` | 前端根地址 |
| `TEST_ADMIN_USERNAME` | `admin` | 登录用户名 |
| `TEST_ADMIN_PASSWORD` | 无（必填） | 登录密码 |
