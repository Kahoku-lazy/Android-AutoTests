## 🔴 P0：竞态条件

### 1. 队列任务丢失 ✅
**位置**：`views.py` — `_start_next_queued()`

`is_device_busy()` 与 `mark_device_busy()` 非原子；`dp_acquire` 失败时 dequeued 任务未回队。

**修复**：每设备 `asyncio.Lock` 保护 check→dequeue→mark_busy；acquire 失败 `_enqueue_front` 回队。

### 2. TaskCard 状态并发覆盖 ✅
**位置**：`state_machine.py` — `_save_transition()`

**修复**：`select_for_update()` 重取 TaskCard / TestRunRecord 后再写。

### 3. `_run_client_task` 并发删读 ✅
**位置**：`views.py` — `finalize()` vs `list_active()`

**修复**：`client_tid` 在 `_execute_tests` 入口快照；映射在 finalize/mark_failed 后清理；移除 `list_active` 激进清理。

### 4. `_preflight_runs` 注册晚于协程启动 ✅
**位置**：`views.py` — `start_test_run`

**修复**：先登记 `_preflight_runs` 再 `_spawn_bg`。

### 5. ~~`_bg_sync` 闭包变量捕获~~ ❌ 误判（已关闭）
`delayed_execute` 已用默认参数绑定 `serial`/`client_task_id`/`pkg`，当前代码无此缺陷。

### 6. 并发恢复无互斥 ✅
**位置**：`recovery_helpers.py`

**修复**：`threading.Lock` 保护 `recover_stale_running_taskcards`。

### 7. 成功路径队列不前进 ✅（复查补充）
**位置**：`views.py` — `_execute_tests`

`543` 在设备仍 busy 时调度 → `_start_next_queued` 空跑；`finally` 因 `run_completed=True` 不再调度。

**修复**：移除过早调度；在 `finally` 释放设备后无条件 `_schedule_next_queued`。

## 🟢 P3：设计缺陷（部分修复 / 记录保留）

### 16. DB 写入在设备释放之后 — 保留设计权衡
设备释放在 `finally`；DB 写入在 try 内。已通过 #7 修复保证队列在释放后推进。

### 17. `status` / `running` 双源字段 — 保留
前端/API 已派生 `running` from `status`；`recover_orphans` 处理漂移。

### 18. `started_at` / `finished_at` 是 CharField — 保留
需迁移才能改 DateTimeField，本次不改动表结构。

### 19. 状态机缺少 `running→queued` / `done→idle` — 保留
产品层通过新建任务卡片重新执行。

### 20. 恢复不重建 `_active_runs` — 保留
重启后 running 任务由 `recover_orphans` 标 interrupted，符合预期。

### 21. `_device_queue` 恢复无去重 ✅
**位置**：`apps.py`

**修复**：入队前检查 `client_task_id` 去重（对齐 `list_active`）。

### 22. `TestResult` 表 0 行数据 ✅
**根因**：`runner.py` 只写 `state.all_results`，未填充 `run_model.case_results`；`persist()` 遍历空列表。

**修复**：每轮迭代 append `TestResult` 到 `run_model.case_results`。

### 23. `AllowedHostsOriginValidator` 未使用 ✅
**位置**：`asgi.py`

**修复**：WebSocket 路由包裹 Origin 校验。

### 24. `case_items` 无 TaskCard 时被丢弃 — 保留
无 TaskCard 场景仅写 `TestRunRecord.summary`（含聚合数据）。

### 25. `api.py:persist_results` 死代码 + FK 错误 ✅
**修复**：改为接收 `TestRunRecord` 实例；修正 FK 赋值。

### 26. 跨线程访问 `state.is_running` / `log_lines` — 保留
当前 CPython + 单写者模式可接受；无 GIL Python 需另行加固。
