5格式转换（Copilot → Cursor）

源格式（PM-Project）

--- name: "gate_review" tools: [read, search, web, edit, execute, todo, agent] agents: [] ---

目标格式（.agents/）

--- name: gate-review description: Stage-Gate 评审门 Agent... tools: Read, Write, Edit, Grep, Glob, WebFetch, Skill, Task skills: - gate-review project_root: "{PROJECT_ROOT}" # 指向你指定的目录 ---
转换项处理方式
tools 映射read→Read · search→Grep/Glob · web→WebSearch/WebFetch · agent→Task
路径引用所有 .github/skills/ → .agents/skills/；所有 projects/prd-{name}/ → dev_docs/projects/prd-{name}/
Copilot MCPtavily-mcp → WebSearch；飞书 MCP → 标注可选
agents 数组内嵌子 Agent 调度 → 改为 Task 工具调用说明
命名下划线 → 连字符（gate_review → gate-review）
