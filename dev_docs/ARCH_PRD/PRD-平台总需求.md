## 一、项目定位

### 1.1 一句话定位

> 面向测试工程师的 **AI Agent 平台**：前端展示、后端通道与记账、**`engines/` 承载全部可执行能力**。一个 Agent **角色** = **Model + Harness**（工具 / 技能 / 知识 / 记忆与上下文 / 提示词）；用户可配置角色并下发任务。
> **当前主场景**：把用例写成文档，交给 SOP 双角色（执行 + 验收）跑完，结果回到任务事件时间线与测试报告——这是首个落地场景，**不是**平台能力上限。

### 1.2 功能介绍

1. 输入需求文档，让 Agent 输出功能测试点与 UI 自动化测试步骤。
2. 让 Agent 具备执行能力：控制手机、读取设备串口日志等，模拟「人」执行测试任务。
3. 平台目标态：一切皆插件；在 Harness 上扩展工具/技能/知识，自由组合 Model 创建新角色（清单见 `GUIDE-创建Agent清单.md`）。

### 1.3 北极星与范围标签

| 标签 | 含义 |
|------|------|
| **本期** | 当前应对用户交付、验收的能力 |
| **目标态** | 架构已指向、实现可渐进；不因「非本期」而把逻辑写进 View |

- 北极星文档：根 `AGENTS.md`「平台架构定位」、`ARCH-平台架构设计.md` §2。
- 新增 Agent：必须遵循 `GUIDE-创建Agent清单.md`。

### 1.4 产品边界

**✅ 本期范围**

1. Android 8.0+ UI 自动化；USB + WiFi ADB 接入。
2. JWT 认证（登录 / 注册 / 刷新 / 登出 / 当前身份），复用 Django 内置用户表。
3. 文档式用例：项目、目录、文件、用例、步骤五层；支持移动、批量删除、导入导出。
4. AI 任务：按智能体下发、指定设备与用例、重跑、取消；同一设备串行、不同设备并行。
5. AI 执行内核：AgentScope SOP 双角色（`executor` + `verifier`），模型支持 DeepSeek 与阿里百炼。
6. 验收证据：设备截图 + 串口日志关键词命中（动作后 5 秒窗口，动作前 30 秒基线）。
7. 观测：四组运行日志、任务事件时间线、测试报告、仪表盘趋势与模型费用。
8. 知识库助手：与 AI 助手并列的问答入口，**支持语音（Omni 实时）与文字（DeepSeek Flash）两种方式**，对话实时显示并写入本地日志；**本期产品面**以问答与平台说明为主，**不对用户开放**完整 RAG 文档库运营（上传/解析/引用范围配置）；引擎侧 engines/agents/rag 可按目标态演进，与产品开关分离。

**❌ 非本期**

1. iOS 设备；Web / API 自动化（相关能力已退役）。
2. 设备云租用、跨团队多租户隔离。
3. OAuth / SSO 等第三方身份源。
4. AI 自主修复失败用例、自主生成完整用例集。
5. 分布式执行集群、跨机调度。
6. **本期**不对用户提供 RAG 知识库运营能力（文档上传 / 解析 / 向量检索 / 引用范围配置）；不阻碍 engines 内 Harness 检索能力按目标态建设（须遵守 engines AGENTS）。

## 二、目标用户

### 2.1 用户画像

| 角色 | 核心诉求 | 使用频率 |
|------|---------|:--:|
| **测试工程师**（主要） | 快速建用例、一键跑回归、失败能定位到具体步骤与证据 | 每日 |
| **QA 负责人**（次要） | 任务执行结果、通过率趋势、设备占用情况、AI 花费 | 每周 |
| **产品经理**（次要） | 一键跑冒烟用例、看报告结论 | 每周 |

### 2.2 用户核心旅程

```
登录 → 仪表盘总览 → 设备管理接入/占用设备 → 用例管理建用例
   → AI 助手下发任务（选智能体 / 设备 / 用例 / 附件）
   → 任务详情看事件时间线与判决 → 测试报告看汇总 → 串口日志复核证据
```

## 五、非功能约束

| 类别 | 约束 |
|------|------|
| 并发 | 单机；同一设备同一时刻至多一条执行任务，不同设备可并行 |
| 实时性 | 无 WebSocket / SSE；任务进度与列表靠 HTTP 轮询。唯一例外：知识库助手走 `/ws/knowledge-assistant/?mode=voice|text`，该通道只承载语音音频、转写、打断、播放进度与文字提问，不承载平台写操作 |
| 安全 | 全部 `/api/` 走 JWT；公开面仅登录/注册/刷新、Admin、静态资源、API 文档；AI 智能体写操作仅超管 |
| 契约 | 响应信封 `{status, data}`；错误 `{status, message}` + HTTP 状态码；JSON snake_case；`/api/` 尾斜杠 |
| 数据 | 表前缀 `acc_ ai_ cm_ dp_ rg_ sl_ task_ wf_`；SQLite（开发）/ MySQL（生产）；JWT 吊销记录落库（`acc_token_revocations`），平台无外部 KV 依赖 |
| 可观测 | 后端 / 智能体 / 设备 / 串口四组日志；任务事件与费用可回看 |
| 质量 | 本地 `python run.py check` 与 CI 同一批门禁（23 项）；后端测试以 pytest 分层维护；接口契约基线由 drf-spectacular 生成并纳入门禁 |

## 六、术语

| 术语 | 含义 |
|------|------|
| SOP | AgentScope 的步骤化执行单元：每步含「执行描述 + 验收标准」 |
| executor / verifier | AI 执行角色 / AI 验收角色，一次运行内成对出现 |
| 任务 | 一次下发（智能体 + 设备 + 用例 + 附件），落 `task_tasks` |
| 用例 / 步骤 | 文档式测试资产，步骤只含「操作 / 预期」两段文本 |
| 证据窗口 | 动作后 5 秒内截取串口日志命中；动作前 30 秒作基线 |
| 任务事件 | 模型调用、工具调用、内容块、判决等结构化记录，落 `task_events` |
| 知识库助手 | 与 AI 助手并列的语音/文字问答入口；对话落 `logs/knowledge_assistant/YYYY-MM-DD.jsonl`；本期不对用户开放 RAG 运营能力 |
