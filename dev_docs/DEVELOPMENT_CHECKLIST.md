## 快速自检（日常使用）

小改动不需要走全部 6 组。日常开发完成后跑这个：

```
[ ] 级别判定：这是 🔴大 / 🟡增量 / 🟢修补 / ⚪重构？
[ ] PRD 相关：行为/文案/校验规则一致？（组1）
[ ] ARCH 相关：文件位置正确？路径更新？（组2/5）
[ ] 脚本通过：gen_arch_stats.py --check-md && --check-boundaries（组3/5）
[ ] 命名正确：URL前缀/表前缀/JSON格式？（组4）
```
