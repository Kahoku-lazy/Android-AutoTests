## 2. 一次实施中的改判（重要）

原推荐「改显示名算运行内容 → 回草稿」。实施前发现三条冲突：既有规格「只修改显示名 MUST 保持已发布」及其两个场景、用例 `test_runtime_edit_returns_to_draft_display_name_does_not`、以及**名片即发布体，回草稿等于从所有非作者列表消失**（改错别字即下线）。

采取等效方案：版本里 `run_name` 留痕、解析时用当前显示名覆盖。代价是历史任务重跑时报告角色名跟随当前名片名。详见 change 的 `design.md` D1。

## 3. 口径澄清（实施中发现的文档与实现不一致）

goal / team 任务「不记版本」≠「读实时配置」：`resolve_sop_workflow` 先取最新 `AssistantRelease`，没有版本才回落实时配置。所以这两类是**跟随最新发布**，正好挡住未发布草稿泄漏进运行。spec delta、proposal、design、模块文档、架构图均已按此改正。
