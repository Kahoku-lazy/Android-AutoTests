# 前端功能统计 — Android-AutoTests

> 统计时间：2026-10-25 · 基线：`Kahoku` 主干 · 口径：`frontend/src/`（不含 `node_modules/`、`dist/`、`tests/`）
> 功能点口径：**用户可见的一级能力**（一个页面区块、一个操作、一个弹窗计 1 点）；纯视觉样式、设计令牌、路由重定向不计。
> 代码事实来源：`frontend/src/router.ts`、各模块 `routes.ts`、`shared/components/sidebarNavConfig.ts`、模块视图与组件。

---

## 一、结论

1. **前端是「8 个业务模块 + 1 个全局壳」的单页应用**：8 个模块共 **14 个可导航页面**（13 个业务页 + 登录页），另有 404 兜底页。
2. 按上述口径共 **55 个功能点**；若把全局壳的 4 项（侧栏、登出、鉴权、404）也算入，为 **59 个**。
3. 规模：`src/` **192 个文件 / 29,654 行**（94 `.ts` + 72 `.vue` + 26 `.css`）；其中 8 个模块 **123 文件 / 20,912 行**，`shared/` **50 文件 / 6,867 行**。
4. **体量最大的是页面流**（20 文件 / 5,451 行），其次是任务清单（23 文件 / 3,514 行）、用例管理（17 文件 / 3,389 行）；**功能点最多的是设备管理（9）与用例管理（8）**。
5. **有 2 个功能点仅超级管理员可见**：串口监听开关、AI 助手「配置」入口。
6. 发现 **5 处文档与实现漂移 / 未接线代码**（见第七节），其中 2 处是页面副标题写了不存在的功能。
