# 字符与 Emoji 速查表

> 用途：统一平台文档、日志、UI 中常见符号与 emoji 的写法、码点和编码认知。
>
> 生成日期：2026-10-21
>
> 说明：UTF-8 是编码方式，emoji 是 Unicode 字符。本文按“用途”分类，不追求穷举全部 Unicode emoji。

---

## 1. 先分清三个概念

| 概念 | 说明 |
|---|---|
| Unicode | 字符集，给每个字符分配唯一码点，例如 `U+2705` |
| UTF-8 | Unicode 的一种变长编码，把码点编码成 1–4 个字节 |
| Emoji | Unicode 中带“表情/图形”语义的一类字符，常由多个码点组合 |

例如：

```text
✅  = U+2705
📝  = U+1F4DD
⚠️  = U+26A0 U+FE0F
👨‍💻 = U+1F468 U+200D U+1F4BB
```

## 2. 状态与判断

| 字符 | 名称 | 码点 | CSS `color` 能否改色 |
|---|---|---|---|
| ✅ | 白色勾号按钮 | `U+2705` | 通常不能，彩色 emoji |
| ✔️ | 重勾号 + emoji 变体 | `U+2714 U+FE0F` | 通常不能 |
| ✔ | 重勾号（文本） | `U+2714` | 可以 |
| ❌ | 叉号 | `U+274C` | 通常不能 |
| ✖️ | 粗乘号 + emoji 变体 | `U+2716 U+FE0F` | 通常不能 |
| ✖ | 粗乘号（文本） | `U+2716` | 可以 |
| ❎ | 叉号按钮 | `U+274E` | 通常不能 |
| ⚠️ | 警告 + emoji 变体 | `U+26A0 U+FE0F` | 通常不能 |
| ⚠ | 警告（文本） | `U+26A0` | 可以 |
| 🚨 | 警车灯 | `U+1F6A8` | 通常不能 |
| ℹ️ | 信息 + emoji 变体 | `U+2139 U+FE0F` | 通常不能 |
| ❗ | 红色感叹号 | `U+2757` | 通常不能 |
| ❓ | 红色问号 | `U+2753` | 通常不能 |
| ⛔ | 禁止通行 | `U+26D4` | 通常不能 |
| 🚫 | 禁止标志 | `U+1F6AB` | 通常不能 |

### 文本呈现与 emoji 呈现

```text
✔   U+2714          文本呈现，可用 CSS color
✔️  U+2714 U+FE0F   emoji 呈现，颜色由字体决定
```

`U+FE0F` 叫 **emoji variation selector-16**，作用是“尽量按彩色 emoji 呈现”。

## 10. UTF-8 字节示例

| 字符 | Unicode | UTF-8 字节 |
|---|---|---|
| `✅` | `U+2705` | `E2 9C 85` |
| `❌` | `U+274C` | `E2 9D 8C` |
| `⚠️` | `U+26A0 U+FE0F` | `E2 9A A0 EF B8 8F` |
| `✔️` | `U+2714 U+FE0F` | `E2 9C 94 EF B8 8F` |
| `📝` | `U+1F4DD` | `F0 9F 93 9D` |
| `🔴` | `U+1F534` | `F0 9F 94 B4` |
| `🟢` | `U+1F7E2` | `F0 9F 9F A2` |
| `🚀` | `U+1F680` | `F0 9F 9A 80` |
| `→` | `U+2192` | `E2 86 92` |
| `★` | `U+2605` | `E2 98 85` |
| `─` | `U+2500` | `E2 94 80` |

规律：

- ASCII：1 字节
- 拉丁扩展、希腊、西里尔等：2 字节
- 大部分符号、Dingbats、CJK：3 字节
- 大多数彩色 emoji：4 字节
- 带 `U+FE0F` 的字符会多 3 字节
- 带 ZWJ 的组合 emoji 可能更长

## 11. `✔️` 能不能变色

### 结论

可以，但要看它按“文字”还是“彩色 emoji”渲染。

```text
✔   U+2714          普通文字，可用 CSS color
✔️  U+2714 U+FE0F   彩色 emoji，颜色由字体决定
```

### 方案 A：去掉 `FE0F`，用文本字符

```html
<span class="check">✔</span>
```

```css
.check {
  color: #16a34a;
  font-family: "Segoe UI Symbol", "Arial Unicode MS", sans-serif;
}
```

### 方案 B：`font-variant-emoji: text`

```css
.check {
  font-variant-emoji: text;
  color: #16a34a;
}
```

新版 Chromium 可用，旧浏览器需实测。

### 方案 C：SVG（推荐）

```html
<svg class="check-icon" viewBox="0 0 16 16" width="1em" height="1em"
     fill="none" stroke="currentColor" stroke-width="2"
     stroke-linecap="round" stroke-linejoin="round">
  <path d="M2.5 8.5l3.5 3.5 7-8" />
</svg>
```

```css
.check-icon {
  color: #16a34a;
}
```

### 方案 D：滤镜（只能整体调色）

```css
.check {
  filter: hue-rotate(120deg) saturate(2);
}
```

常用滤镜：

```css
filter: grayscale(1);              /* 去色 */
filter: sepia(1);                  /* 复古黄 */
filter: hue-rotate(120deg);        /* 色相旋转 */
filter: brightness(0) invert(1);   /* 变白，适合深色背景 */
```

## 12. 使用建议

| 场景 | 建议 |
|---|---|
| 前端 UI / 文档 | 可以保留 emoji，视觉表达更直观 |
| 后端日志 / CI 输出 | 优先用 `[OK]`、`[FAIL]`、`[WARN]`、`[INFO]`，避免控制台编码导致乱码 |
| JSON | Python 用 `json.dumps(..., ensure_ascii=False)` 才会保留原字符；默认会转成 `\uXXXX` |
| Windows 控制台 | 设置 `PYTHONUTF8=1` 或 `chcp 65001` |
| CSV / Excel | 建议 UTF-8 BOM，或避免 emoji |
| 文件名 / 路径 | 不建议使用 emoji，跨平台和压缩工具容易出问题 |
| 代码标识符 | 禁止用 emoji 作为变量名/函数名 |

### 容易踩的坑

1. `⚠` 和 `⚠️` 看起来几乎一样，但码点不同；字符串比较、去重、断言时不能混用。
2. `✔` 和 `✔️` 同理；一个是文本呈现，一个是 emoji 呈现。
3. 同一个 emoji 在不同系统上的显示颜色可能不同，不能把 emoji 当作严格的状态色。
4. 组合 emoji 的字符串长度不等于“看起来的字符数”，不要用 `len()` 当字数统计。
5. 终端乱码通常只是显示编码问题，不代表文件内容损坏；用 UTF-8 编辑器确认。

## 13. 快速选择

```text
需要彩色状态图标？
  ├─ 是 → 用 emoji 或 SVG
  └─ 否 → 用 ASCII 标记 / SVG

需要精确品牌色？
  ├─ 是 → SVG + currentColor
  └─ 否 → ✔（无 FE0F）+ CSS color
         或 filter: hue-rotate(...)

需要跨平台一致？
  ├─ 是 → SVG
  └─ 否 → emoji 可以接受

需要写入日志/CSV/文件名？
  ├─ 日志 → [OK] / [FAIL] / [WARN]
  ├─ CSV → UTF-8 BOM 或避免 emoji
  └─ 文件名 → 不要用 emoji
```
