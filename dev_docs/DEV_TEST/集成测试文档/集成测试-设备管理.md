## 一、设备接入与登记（`test_device_registry.py`）

#### 用例名称：`test_register_new_usb_device`
- **业务功能**：新设备接入登记（注册 + 自动采集型号/分辨率）
- **测试目的**：验证设备入库、状态在线、型号/分辨率自动采集、记下接入人
- **测试方法与步骤**：① mock 探测器返回序列号/判 USB/返回采集信息；② 调 `registry.register_device`；③ 断言返回值与库中记录
- **断言逻辑**：
  - `created is True`、`dev.connection_type == "USB"`、`dev.status == "ONLINE"`、`dev.added_by == "1"`
  - `dev.model == "SM-G973F"`、`dev.brand == "samsung"`、`dev.screen_w == 1080`
  - `Device.objects.filter(serial="RF8N21MSW7A").count() == 1`

#### 用例名称：`test_register_existing_device_not_created`
- **业务功能**：重复扫描幂等
- **测试目的**：验证不产生重复设备、不重复采集
- **测试方法与步骤**：① 库里先造一条同 serial 设备；② mock 探测器；③ 调 `register_device`；④ 断言非新建、库仍一条、未采集
- **断言逻辑**：
  - `created is False`
  - `Device.objects.filter(serial="RF8N21MSW7A").count() == 1`
  - `detector.get_info.assert_not_called()`

#### 用例名称：`test_register_wireless_resolve_failure_raises`
- **业务功能**：无线设备身份缺失
- **测试目的**：验证拿不到真实序列号时不登记、返回「无法解析序列号」
- **测试方法与步骤**：① mock 探测器返回 `("", 地址)`；② 调 `register_device` 期望抛 `DeviceError`；③ 断言库为空
- **断言逻辑**：
  - `pytest.raises(DeviceError)`
  - `Device.objects.count() == 0`

## 二、设备状态流转（`test_device_state_machine.py`）

#### 用例名称：`test_update_status_removes_offline_device`
- **业务功能**：设备断开被移除（离线清理）
- **测试目的**：验证离线设备被清理、不留「离线」僵尸记录
- **测试方法与步骤**：① 造一条 ONLINE 设备；② mock adb 列表为空（模拟拔线）；③ 调 `update_device_status`；④ 断言移除计数与库记录
- **断言逻辑**：
  - `removed == 1`
  - `not Device.objects.filter(serial="OLD123").exists()`

#### 用例名称：`test_update_status_protects_busy_device`
- **业务功能**：使用中的设备断线不误删（执行保护）
- **测试目的**：验证系统保护进行中任务、不误删设备
- **测试方法与步骤**：① 造 BUSY 设备 + 有效进程锁；② mock adb 列表为空；③ 调 `update_device_status`；④ 断言未移除、设备保留
- **断言逻辑**：
  - `removed == 0`
  - `Device.objects.filter(serial="BUSY123").exists()`

#### 用例名称：`test_lock_wifi_and_unlock`
- **业务功能**：无线设备锁定/公开
- **测试目的**：验证锁定记录锁定者、公开清空锁定
- **测试方法与步骤**：① 造 WIFI 设备；② `set_device_lock(True)` 断言锁定；③ `set_device_lock(False)` 断言公开
- **断言逻辑**：
  - `result == {"serial": "WIFI1", "locked": True}`、refresh 后 `dev.locked_by == "1"`
  - `DeviceLock.objects.filter(device=dev, lock_type="user", status="active").exists()`
  - 解锁后 `dev.locked_by == ""`

#### 用例名称：`test_lock_usb_rejected`
- **业务功能**：USB 设备不支持锁定
- **测试目的**：验证 USB 设备锁定被拒绝
- **测试方法与步骤**：① 造 USB 设备；② `set_device_lock(True)` 期望抛 `DeviceError`
- **断言逻辑**：
  - `pytest.raises(DeviceError)`

#### 用例名称：`test_occupy_and_release_observe`
- **业务功能**：设备占用与释放（在线 ⇄ 使用中）
- **测试目的**：验证状态在「在线 ⇄ 使用中」正确流转
- **测试方法与步骤**：① 造 ONLINE 设备；② `occupy_observe` 断言 BUSY；③ `release_observe` 断言 ONLINE
- **断言逻辑**：
  - occupy 后 `dev.status == "BUSY"`、`dev.occupied_by == "user1"`
  - release 后 `dev.status == "ONLINE"`、`dev.occupied_by == ""`

#### 用例名称：`test_release_occupy_protects_runner`
- **业务功能**：执行引擎占用保护
- **测试目的**：验证执行中的设备不可手动强制释放
- **测试方法与步骤**：① 造 BUSY 设备（`occupied_by="runner-1"`）；② `release_occupy` 期望抛 `DeviceError`
- **断言逻辑**：
  - `pytest.raises(DeviceError)`

#### 用例名称：`test_heartbeat_recycles_expired_observe`
- **业务功能**：超时占用自动回收（防泄漏兜底）
- **测试目的**：验证系统自动回收超时占用、设备恢复在线
- **测试方法与步骤**：① 造 BUSY 设备 + 过期 observe 锁（`timeout_seconds=0`）；② mock 设备仍在 adb；③ 调 `heartbeat_sync`；④ 断言恢复在线、计数正确
- **断言逻辑**：
  - refresh 后 `dev.status == "ONLINE"`、`dev.occupied_by == ""`
  - `result["total"] == 1`

## 三、设备锁定与可见性（`test_device_serializer.py`）

#### 用例名称：`test_usb_device_visible_to_all`
- **业务功能**：USB 设备恒公开
- **测试目的**：验证 USB 设备所有用户可见
- **测试方法与步骤**：① 造 USB 设备；② `is_device_visible(任意用户)`；③ 断言 True
- **断言逻辑**：
  - `is_device_visible(dev, "999", set()) is True`

#### 用例名称：`test_wifi_device_locked_visible_only_owner`
- **业务功能**：无线锁定仅锁定者可见
- **测试目的**：验证锁定后仅锁定者可见、他人不可见
- **测试方法与步骤**：① 造 WIFI 设备（`locked_by="1"`）；② 分别以锁定者/他人断言可见性
- **断言逻辑**：
  - `is_device_visible(dev, "1", set()) is True`
  - `is_device_visible(dev, "2", set()) is False`

#### 用例名称：`test_wifi_device_unlocked_visible_to_all`
- **业务功能**：无线未锁定公开
- **测试目的**：验证未锁定无线设备公开可见
- **测试方法与步骤**：① 造未锁定 WIFI 设备；② 断言任意用户可见
- **断言逻辑**：
  - `is_device_visible(dev, "2", set()) is True`

#### 用例名称：`test_admin_sees_all`
- **业务功能**：管理员全局可见
- **测试目的**：验证管理员无视锁定、全局可见
- **测试方法与步骤**：① 造 WIFI 设备（`locked_by="1"`）；② 以管理员（`999` ∈ 管理员集合）断言可见
- **断言逻辑**：
  - `is_device_visible(dev, "999", {"999"}) is True`

#### 用例名称：`test_device_to_dict_fields`
- **业务功能**：列表序列化
- **测试目的**：验证序列号/分辨率/状态/是否当前设备等字段正确
- **测试方法与步骤**：① 造 USB 设备 `DEV1`（1080x2400，ONLINE）；② `device_to_dict(dev, "DEV1")`；③ 断言各字段
- **断言逻辑**：
  - `d["serial"] == "DEV1"`、`d["screen"] == "1080x2400"`、`d["status"] == "ONLINE"`、`d["connection_type"] == "USB"`
  - `d["is_current"] is True`、`d["remaining"] == 0`
