## 一、需求原子拆解

| ID | 需求原子 | 类型 | 用户可感知 | 物理依赖 |
|:--:|------|:--:|:--:|:--:|
| REQ-FW-019a | 每天制冰时间（累计制冰时长） | 数据展示 | ✅(APP图表) | 无 |
| REQ-FW-019b | 冰块预估重量（时间换算）+ kg/lb 单位 | 数据换算 | ✅(APP) | 无 |
| REQ-FW-019c | 图表时间颗粒度：当天Day/近30天(天)/近一年(月) | 数据聚合 | ✅(APP) | 无 |
| REQ-FW-019d | 满冰停止时间不计入累计时长 | 数据规则 | ✅(APP) | 无 |

## 二、复杂度与方案

- **复杂度**：L2（4因子，数据展示类，无物理依赖）
- **方法组合**：CRUD数据法(图表数据+颗粒度) + 边界值(30天边界/12月边界) + 等价类(kg↔lb)
- **优先级**：P1(用户可见数据展示) / P2(近一年月颗粒度为低频视图)

## 三、校验策略

制冰图表是纯数据展示功能，核心验证点：
1. 颗粒度切换时数据连续性
2. 满冰停止时间排除规则
3. 重量换算公式正确性（1轮=9颗×约10g=90g，kg↔lb换算精度）
