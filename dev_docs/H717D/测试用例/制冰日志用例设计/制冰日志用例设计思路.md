# H717D — 制冰日志用例设计思路 V1.0

> **设计日期**：2026-07-23
> **需求来源**：7.1 固件需求 §20 制冰日志
> **方法论**：测试用例设计方法论 V2.0 · CRUD数据法+边界值+协议测试
> **用例总数**：3 条（P1:3）

## 一、需求原子拆解

| ID | 需求原子 | 类型 | 用户可感知 | 物理依赖 |
|:--:|------|:--:|:--:|:--:|
| REQ-FW-020a | 展示日期时间和冰块制作模式/清洁/缺水/除霜事件 | 数据展示 | ✅(APP) | 无 |
| REQ-FW-020b | 记录事件不记录时长 | 数据规则 | ✅ | 无 |
| REQ-FW-020c | 联网同步更新；离线仅存最近10条 | 数据存储+同步 | ✅(APP) | WiFi |

## 二、复杂度与方案

- **复杂度**：L2（数据展示+离线存储+联网同步）
- **方法组合**：CRUD数据法(日志CRUD) + 边界值(10条FIFO上限) + 协议测试(联网补推)
- **优先级**：P1(用户可查看的日志功能)

## 三、校验策略

- 事件类型覆盖：制冰开始/清洁/缺水/除霜
- 离线FIFO：触发12个事件→确认只保留最近10条
- 联网补推：离线日志恢复联网后自动同步
