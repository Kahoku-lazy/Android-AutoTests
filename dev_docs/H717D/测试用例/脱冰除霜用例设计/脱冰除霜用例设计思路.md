## 二、复杂度与方案

- **复杂度**：L2（硬件闭环+数据联动+互斥规则）
- **方法组合**：场景流(脱冰→轮次联动) + CRUD(轮次数据验证) + 判定表(除霜×预约互斥) + 错误推测(取消的轮次不计)
- **优先级**：P1（脱冰=制冰核心流程的收尾环节）

## 三、校验策略

- 冷媒/热气物理过程不可软件测 → 通过效果间接验证(脱冰触发信号)
