📖 使用指南

MD 文档在线查看器

在 index.html 文档索引中点击 .md 文件卡片，即可在浏览器中查看渲染后的 Markdown 内容——无需离开页面，无需安装任何工具。

1启动方式

MD 查看器需要通过 HTTP 服务器访问 index.html（浏览器安全策略限制 file:// 协议下 fetch 请求）。任选以下一种方式：

方式 A：Python 内置服务器（推荐，最简单）

A

在 dev_docs 目录下启动 HTTP 服务

# 必须在项目根目录启动（测试报告路径需访问上级 tests/ 目录）
cd /Users/aeron/Desktop/workspace/Android-AutoTests

# 仅本机访问
python3 -m http.server 9999

# 局域网访问（绑定所有网络接口）
python3 -m http.server 9999 --bind 0.0.0.0

本机打开 http://localhost:9999/dev_docs/index.html，局域网设备访问 http://<本机IP>:9999/dev_docs/index.html。

💡 必须在项目根目录启动——测试报告存放在项目根 tests/ 下，路径使用 ../tests/ 相对引用。从 dev_docs/ 启动会导致 404。

方式 B：使用项目自带的 Vite 开发服务器

B

在项目根目录启动（需要 dev_docs 在 Vite 的静态服务范围内）

# 在项目根目录
cd /Users/aeron/Desktop/workspace/Android-AutoTests
python run.py start

# 浏览器打开
open http://localhost:5173/dev_docs/index.html

2操作说明

①

打开 index.html → 选择阶段 → 找到 MD 文档卡片

左侧导航点击任意阶段（如「PRD 需求」或「设计与架构」），右侧内容区中带有 MD 绿色标签的卡片即为 Markdown 文档。

②

点击卡片 → 弹出全屏查看器

点击 MD 文档卡片，页面会弹出全屏遮罩层，自动加载并渲染文档内容。顶部栏显示文件路径和 Markdown 渲染 标识。

③

关闭查看器 — 三种方式

① 点击右上角 ✕ 按钮 　 ② 点击遮罩背景区域 　 ③ 按键盘 Esc 键

3查看器功能

📝

Markdown 渲染

标题、列表、表格、引用块、代码块——完整 GFM 语法支持

🧜

Mermaid 图表

自动识别并渲染流程图、时序图、ER 图，每张图有「mermaid」标签

💻

代码高亮

深色背景代码块，左上角显示语言标签（python/bash/json/mermaid）

📄

不修改源文件

浏览器端实时渲染 .md 原始文件，不影响本地文档内容

⌨️

键盘操作

Esc 关闭 　 点击遮罩关闭 　 滚动阅读

📱

响应式布局

桌面端最大 960px 居中；移动端全宽，触摸滚动

4Mermaid 标签说明

文档中的 ```mermaid 代码块会被渲染为可交互的 SVG 图表。每张图表左上角有一个 🧜 mermaid 标签，用于：

  • 区分格式：一眼识别这是 Mermaid 代码渲染的图表，而非静态图片
  • 来源追溯：知道原始文档中有 ```mermaid 代码块
  • 不混淆：与 HTML 内嵌的 ECharts / 静态 PNG 图区分开来

示例：在 02-PRD需求/实际需求文档.md 中包含多张 Mermaid 架构图，点击查看时每张图都会自动渲染并标注「🧜 mermaid」。

6常见问题

Q：直接双击 index.html 打开，点击 MD 卡片没反应？

A：浏览器安全策略禁止 file:// 协议下 fetch 请求。请在项目根目录执行 python3 -m http.server 9999，然后访问 http://localhost:9999/dev_docs/index.html。

Q：Mermaid 图显示空白或报错？

A：检查网络——Mermaid 库从 CDN 加载（v10.x，与项目 MD 文档语法兼容）。确认能访问 cdn.jsdelivr.net。Mermaid 11.x 解析器对 graph TB 等旧语法不兼容，已选定 v10 版本。

Q：能同时打开多篇 MD 文档吗？

A：当前版本同一时间只能打开一篇。关闭当前查看器后才能打开下一篇。

Q：查看器能打印或导出 PDF 吗？

A：可以。打开 MD 查看器后按 Cmd+P（Windows: Ctrl+P）使用浏览器打印功能，选择「另存为 PDF」即可。

Q：HTML 格式的文档怎么查看？

A：HTML 文档卡片点击后直接在浏览器中打开。MD 查看器只拦截 .md 结尾的链接。带 HTML 蓝色标签的卡片不受影响。
