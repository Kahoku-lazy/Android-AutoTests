# 代码库入门指南：Android-AutoTests

> 由 `codebase-onboarding` skill 生成 · 2 分钟快速浏览版。权威细节以 `dev_docs/` 与代码为准。

## 概述

**Android-AutoTests** 是一个 **AI 驱动的 Android UI 自动化测试平台**，面向 Android 测试工程师，将元素定位、用例编排、执行调度、报告输出整合为**自然语言驱动的全流程闭环**。前后端分离：Vue SPA（:5173）+ Django 纯 API（:8766），AI 引擎（AgentScope 2.0）运行在 Django 进程内。

## 架构

```
Vue 前端 :5173 ──HTTP/WS──→ Django(daphne) :8766 ──ORM──→ MySQL/SQLite
        │                       │
        │                       ├── Channels(WS) ──→ Redis channel layer
        │                       └── AgentScope(进程内) ──→ 17 平台 Tool + ChromaDB RAG
        └── Vite proxy(/api /ws /media) ──→ 后端唯一出口
Django ──engines.android(airtest_u2)──→ Android 设备(uiautomator2/ADB)
```

- **单体 Django + 独立 Vue SPA**（非微服务）；3 个运行服务：Redis / backend / frontend。
- **11 个 Django App**（`apps/`）＝业务模块；`gateway/`、`shared/`、`engines/`、`models/`、`algorithms/` 为框架层。
- **API 风格**：REST（DRF），统一响应信封 `{status, data}`；WebSocket 仅 2 个消费点（执行进度 / 用例编辑锁）；SSE 已移除。

## 关键入口点

- **后端入口**：`manage.py`（Django 管理）· `run.py`（平台启停管理器）· `run_daphne.py`（daphne 热重载）· `config/asgi.py`（HTTP+WS 协议路由）
- **路由真相源**：`config/urls.py`（每 App 一次 include）· `gateway/routing.py`（WS 路由，禁新增消费点）
- **鉴权**：`gateway/middleware.py`（JWT 校验，`request.user_id`）· `shared/auth/jwt_auth.py`
- **响应信封**：`shared/renderers.py`（`EnvelopeJSONRenderer`）
- **设备引擎插槽**：`engines/registry.py`（L1c 可替换）· `engines/android/airtest_u2.py`
- **前端入口**：`frontend/src/main.ts` · `frontend/src/router.ts` · `frontend/vite.config.js`

## 请求生命周期（REST）

1. 前端 `.vue`（纯展示）→ composable/流程层 → 模块 `api.ts` → `djangoClient`（axios，baseURL `/api`）
2. Vite 代理 `/api` → daphne :8766
3. `gateway.normalize_slash`（尾斜杠规范化，防 301 丢 Authorization 头）
4. `gateway.middleware.JWTAuthenticationMiddleware`（校验 Bearer token → `request.user_id`）
5. DRF View/ViewSet（`views.py`/api 模块）
6. `shared.renderers.EnvelopeJSONRenderer` 包裹 `{status: true, data}`（错误 `{status: false, message}`）
7. Django ORM → MySQL/SQLite；跨模块写表走唯一写库收敛点（防火墙约束）
