### 1.1 路由表（对齐 `routes.ts`）

| path | name | 组件 | meta.title |
| --- | --- | --- | --- |

### 1.2 子页
- **线路看板** `/ai-assistant/agents`：AgentRouteCard 网格（Agent-01 设备执行 / Agent-02 用例编写）。
- **编辑/新建** `/ai-assistant/agent/:id`：面包屑 + 基本信息表单（名称/标签/描述；职责与工作流只读）+ 保存。

---

## 2. 目标与范围

### 2.1 做什么

- 展示平台智能体线路看板（身份、职责、配置入口）。
- 超级管理员可点「配置」进入编辑页，保存名称/标签/描述。
- 空态提示联系管理员；错误态可重试加载。

### 2.2 不做什么（本页 / 本期不纳入）

- 不在本页改模型/线路 `route_configs`（后台维护）。
- 不提供聊天对话窗（知识库助手另页）。
- 不改 `/ai/agents/*` 契约。

---

## 3. 用户与场景

| 角色 | 场景 | 期望 |
| --- | --- | --- |
| 任意用户 | 打开 AI 助手 | 看到平台小助手卡片网格 |
| 超级管理员 | 点配置 | 进入编辑页并可保存 |
| 普通用户 | 看卡片 | 无配置按钮 |
| 空库 | 无智能体 | EmptyState「还没有智能体」 |

---

## 4. 信息架构与页面布局

### 4.1 线路看板
1. 侧栏壳 + WorkbenchHeader「平台小助手」。
2. `route-card-grid`：DoodleNote 卡片（头像 + 名称 + 职责 + 可选配置按钮）。

### 4.2 详情页
1. WorkbenchCrumbs 返回列表。
2. AgentBasicInfo 表单 + AgentFormFooter 保存。

> 交付形态为**桌面 Web**；窄屏仅为适应性说明，不做手机壳。

---

## 5. 视觉规范引用

- 模块强调色：`var(--c-ai)`（侧栏 active 书签条与主区点缀同源）
- 纸面底 `--paper` / 墨色 `--ink` / 硬色偏移阴影 `3~4px 3~4px 0`
- 页头：`WorkbenchHeader`（图标渐变见模块常量）

---

## 6. 组件与交互

| 组件 / 区域 | 说明 |
| --- | --- |
| AgentRouteCard | 312px 便签卡；胶带强调色 `--c-case` |
| AgentBasicInfo | 名称/头像只读说明/标签/描述/职责只读/工作流只读 |
| WbLoader / EmptyState / ErrorState | 加载与空错态 |

### 6.1 主流程

1. **进入**：`/ai-assistant` → redirect agents → listAgents
2. **配置**：管理员 editAgent → `/ai-assistant/agent/:id`
3. **保存**：saveAgent → 成功回列表
