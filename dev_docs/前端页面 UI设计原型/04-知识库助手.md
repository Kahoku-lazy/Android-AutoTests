## 2. 目标与范围

### 2.1 做什么

- 语音问答 / ASR+DeepSeek+TTS 双路线。
- 左 VoiceConsole（路线、麦克风、圆形按键、状态、打断）+ 右 TranscriptPanel。
- 就绪状态检测；会话 WS；本地日志路径展示。

### 2.2 不做什么

- 不改 WS 协议与模型配置契约。
- 不做知识库文档管理后台（本页是对话助手）。

## 3. 用户与场景

| 角色 | 场景 | 期望 |
| --- | --- | --- |
| 测试同学 | 点开始对话 | 进入聆听并可打断 |
| 运维 | 服务未就绪 | ErrorState + 原因 + 重试 |
| pipeline 路线 | 文本提问 | 显示 composer 发送 |

## 4. 信息架构与页面布局

### 4.1 双栏
- 左：路线 select / 麦克风 / orb 按键 / 状态 / meta（模式·模型·日志）
- 右：对话记录 +（pipeline）文本输入

> 交付形态为**桌面 Web**；不做手机壳。

## 5. 视觉规范

- 模块色：`var(--c-element)`（值参考 `var(--c-element)`）
- 纸面 `--paper` / 墨色 `--ink` / 硬阴影偏移

## 6. 组件与交互

| 组件 / 区域 | 说明 |
| --- | --- |
| VoiceConsole | 圆形语音键 + 开始/结束/打断 |
| TranscriptPanel | 消息列表 + 空态 |
| useVoiceSession | 音频/WS 编排（原型 Mock） |

### 6.1 主流程

1. **读状态**：GET /knowledge-assistant/status/
2. **开始**：选路线 → start WS → listening
3. **打断**：speaking 时 interrupt
4. **结束**：stop 释放麦与 WS

## 7. 状态

| 状态 | 表现 |
| --- | --- |
| idle | 未开始 |
| connecting/listening/thinking/speaking | 状态条文案 |
| error | 会话出错 |
| !ready | 不可用原因 |
