## 2. 目标与范围

### 2.1 做什么

- 扫描/刷新设备；筛选全部/在线/使用中。
- 表格/卡片双视图；锁定/释放/断开；局域网 Wi‑Fi 连接对话框。
- 心跳轮询 30s。

### 2.2 不做什么

- 不在本页做远控投屏。
- 不改设备 API 契约。

## 3. 用户与场景

| 角色 | 场景 | 期望 |
| --- | --- | --- |
| 测试 | 插 USB 后刷新 | 看到 ONLINE |
| 同学 | 锁定设备 | 可见性显示锁定者 |
| 管理员 | 局域网连接 | 输入 IP:port |

## 4. 信息架构与页面布局

WorkbenchHeader + 工具栏（FilterTabs / 表格|卡片 / 局域网 / 刷新）+ AppTable 或分组 DeviceCard + DisconnectDialog / NetworkConnectDialog。

> 交付形态为**桌面 Web**；不做手机壳。

## 5. 视觉规范

- 模块色：`var(--c-device)`（值参考 `var(--c-device)`）
- 纸面 `--paper` / 墨色 `--ink` / 硬阴影偏移

## 6. 组件与交互

| 组件 / 区域 | 说明 |
| --- | --- |
| FilterTabs | 全部/在线/使用中 |
| AppTable | 设备/状态/连接/可见性/分辨率/活跃/操作 |
| DeviceCard | 卡片分组 |
| NetworkConnectDialog | Wi‑Fi ADB |
| DisconnectDialog | 确认断开 |

### 6.1 主流程

1. **刷新**：扫描+拉列表
2. **筛选**：activeFilter
3. **锁定/释放**：actions
4. **局域网**：对话框连接
5. **断开**：确认对话框

## 7. 状态
