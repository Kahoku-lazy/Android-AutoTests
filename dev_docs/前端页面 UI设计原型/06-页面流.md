### 1.1 路由表

| path | name | 组件 | meta.title |
| --- | --- | --- | --- |
| `/workflow` | `workflow-prototypes` | PrototypeList.vue | 页面流 |
| `/workflow/prototypes/:prototypeId` | `workflow-workbench` | index.vue | 原型工作台 |

### 1.2 子页
- 原型列表：SketchCard 网格 + 新建对话框。
- 工作台：目录树资源态 → 点击页面流进入 VueFlow 绘制态；自动保存。

## 2. 目标与范围

### 2.1 做什么

- 按原型组织目录与页面流编排。
- 新建/删除原型；进入工作台维护目录与画布节点。
- 绘制态自动保存；返回列表前 persist。

### 2.2 不做什么

- 不在本原型实现完整 VueFlow 节点库编辑器细节（用画布 Mock）。
- 不改 workflow API 契约。

## 3. 用户与场景

| 角色 | 场景 | 期望 |
| --- | --- | --- |
| 产品 | 新建原型 | 进工作台 |
| 测试 | 点页面流 | 全宽画布 |
| 误删 | 确认删除 | 不可恢复提示 |

## 4. 信息架构与页面布局

列表：Header(+新建) + SketchCard 网格。工作台：Header/面包屑 + 左目录树 / 右画布或资源空态。

> 交付形态为**桌面 Web**。

## 5. 视觉规范

模块色 `var(--c-workflow)` / `var(--c-workflow)`；Doodle Craft 硬阴影。

## 6. 组件与交互

| 组件 / 区域 | 说明 |
| --- | --- |
| SketchCard | 原型卡 |
| WorkflowDirTree | 目录树 |
| PageFlowVueFlow | 画布 |
| 新建对话框 | 名称必填 |

### 6.1 主流程

1. **列表**：loadPrototypes
2. **新建**：dialog → create → workbench
3. **进入流**：hydrate 画布
4. **自动保存**：debounce persist
5. **返回**：persist → /workflow
