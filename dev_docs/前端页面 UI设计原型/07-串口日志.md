## 2. 目标与范围

### 2.1 做什么

- 管理无线串口监听开关与查看原始日志。
- 只读浏览关键词→功能模块/功能点对照表。
- 仅超管可切换监听。

### 2.2 不做什么

- 不在本页编辑关键词表文件。
- 波特率只展示不参与采集。

## 3. 用户与场景

| 角色 | 场景 | 期望 |
| --- | --- | --- |
| 超管 | 关监听 | 开关切换 |
| 测试 | 日志查看 | 抽屉 tail 行 |
| 任意 | 搜关键词 | 过滤表格 |

## 4. 信息架构与页面布局

Header + AppTabs(ports/keywords)。Ports：五列表 + Drawer。Keywords：搜索 + 三列表。

> 交付形态为**桌面 Web**。

## 5. 视觉规范

模块色 `var(--c-device)` / `var(--c-device)`；Doodle Craft 硬阴影。

## 6. 组件与交互

| 组件 / 区域 | 说明 |
| --- | --- |
| WifiPortPanel | 端口表+开关+抽屉 |
| LogKeywordPanel | 关键词只读表 |
| AppTabs | 两 Tab |

### 6.1 主流程

1. **进入**：默认 ports
2. **开关**：toggle API
3. **日志查看**：lines drawer
4. **关键词**：刷新目录+搜索

## 7. 状态

| 状态 | 表现 |
| --- | --- |
| readonly | 非超管禁用开关 |
| empty ports/keywords | 空态 hint |
| autoRefresh | 抽屉自动刷新 |
