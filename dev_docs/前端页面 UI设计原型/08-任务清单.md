# 任务清单 UI 原型需求

## 1. 文档信息

| 项 | 内容 |
| --- | --- |
| 页面名称 | 任务清单 |
| 主路由 | `/tasks` |
| 文档版本 | v1.0 |
| 编写日期 | 2026-10-29（Asia/Shanghai） |
| 关联模块 | `modules/task-list/*`；`MOD_COLORS["/tasks"]={var(--c-ai)}` |
| 关联 HTML | [html-tasks-prototype/](./html-tasks-prototype/) |

### 1.1 路由表

| path | name | 组件 | meta.title |
| --- | --- | --- | --- |
| `/tasks` | `task-list` | index.vue | 任务清单 |
| `/tasks/:id` | `task-detail` | TaskDetailPage.vue | 任务详情 |

### 1.2 子页
- 看板：按状态分组的任务卡 + 新建发布对话框。
- 详情：摘要四格 +（设备执行）用例轮次 /（用例编写）事件流与 CaseImportCard。

## 2. 目标与范围

### 2.1 做什么

- 新建/筛选/重跑/取消 AI 任务。
- 按七态分组展示卡片。
- 详情查看执行、验收、费用与媒体。

### 2.2 不做什么

- 不在清单页改智能体模型配置。
- 详情完整逐步断言 UI 用折叠 Mock。

## 3. 用户与场景

| 角色 | 场景 | 期望 |
| --- | --- | --- |
| 测试 | 新建设备执行任务 | 选设备+智能体发布 |
| 测试 | 点卡片 | 进详情 |
| 失败任务 | 重跑 | 克隆调度 |

## 4. 信息架构与页面布局

列表：Header + TaskBoard（分组折叠卡）。详情：Crumbs + 四事实摘要 + 轮次/事件。

> 交付形态为**桌面 Web**。

## 5. 视觉规范

模块色 `var(--c-ai)` / `var(--c-ai)`。

## 6. 组件与交互

| 组件 / 区域 | 说明 |
| --- | --- |
| TaskBoard | 状态分组看板 |
| 发布对话框 | 标题/智能体/设备/附件 |
| TaskDetailPage | 报告详情 |
| CaseImportCard | 用例编写导入结果 |

### 6.1 主流程

1. **发布**：dialog submit
2. **详情**：/tasks/:id
3. **重跑**：failed → clone
4. **取消**：running → cancel

## 7. 状态

| 状态 | 表现 |
| --- | --- |
| pending/running/success/failed/interrupted/cancelled/paused | 分组色头 |
| 详情 running | case_authoring 轮询 |

## 8. 接口（原型 Mock）

| 接口 | 用途 |
| --- | --- |
| `/tasks/ 相关` | 列表/发布/取消/重跑 |
| `/tasks/:id/report/` | 详情报告 |
