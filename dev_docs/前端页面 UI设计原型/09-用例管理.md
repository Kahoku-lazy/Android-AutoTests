# 用例管理 UI 原型需求

## 1. 文档信息

| 项 | 内容 |
| --- | --- |
| 页面名称 | 用例管理 |
| 主路由 | `/cases` |
| 文档版本 | v1.0 |

| 关联模块 | `modules/case-manager/*`；`MOD_COLORS["/cases"]={var(--c-case)}` |
| 关联 HTML | [html-cases-prototype/](./html-cases-prototype/) |

### 1.1 路由表

| path | name | 组件 | meta.title |
| --- | --- | --- | --- |
| `/cases` | `case-manager-projects` | ProjectList.vue | 用例管理 |
| `/cases/projects/:projectId` | `case-manager-workspace` | ProjectWorkspace.vue | 项目工作台 |
| `/cases/projects/:projectId/files/:fileId` | `case-manager-file-sheet` | CaseFileSheet.vue | 编辑用例表 |

### 1.2 子页
- 项目列表 SketchCard。
- 工作台：左目录树 + 右预览（宽屏≥1280）；窄屏跳文件页。
- CaseFileSheet：用例行编辑 + CaseStepDrawer。

## 2. 目标与范围

### 2.1 做什么

- 按项目组织文档型用例。
- 目录/文件增删改；用例表编辑。
- 宽屏并置预览，窄屏两页流程。

### 2.2 不做什么

- Legacy /cases/ui|web|api 已重定向，不恢复旧编辑器。

| 角色 | 场景 | 期望 |

| 宽屏 | 点文件 | 右侧预览 |
| 编辑 | 进文件页 | 改步骤 |

## 4. 信息架构与页面布局

列表网格 → 工作台 Split(树|预览) → 文件表单页。

## 5. 视觉规范

## 6. 组件与交互

| 组件 / 区域 | 说明 |
| --- | --- |
| SketchCard | 项目卡 |
| ProjectTree | 目录树 |
| CasePagePreview | 只读预览 |
| CaseFileSheet | 用例表 |
| CaseStepDrawer | 步骤抽屉 |

### 6.1 主流程

1. **建项目**：dialog → workspace
2. **选文件**：preview 或跳 sheet
3. **编辑步骤**：drawer
4. **删项目**：确认级联删
