## 2. 目标与范围

### 2.1 做什么

- KPI 概览（总执行/通过/失败/通过率）。
- 通过率趋势与每日通过失败图。
- 执行记录表筛选分页；行点击进任务详情。

### 2.2 不做什么

- 不在本页生成 PDF（下载 API 另述）。
- 不改汇总算法。

## 3. 用户与场景

| 角色 | 场景 | 期望 |
| --- | --- | --- |
| 测试负责人 | 看通过率 | KPI+趋势 |
| 排查 | 筛失败 | 状态 Tab |
| 深挖 | 点行 | /tasks/:run_id |

## 4. 信息架构与页面布局

三节：统计概览（筛选+KPI）→ 数据图表 → 测试报告表（状态 FilterTabs + 分页）。

> 交付形态为**桌面 Web**。

## 5. 视觉规范

模块色 `var(--c-report)` / `var(--c-report)`。

## 6. 组件与交互

| 组件 / 区域 | 说明 |
| --- | --- |
| KpiCard | 四卡 |
| PassRateTrendChart | 趋势 |
| DailyPassFailChart | 柱图 |
| AppTable | 执行记录 |

### 6.1 主流程

1. **加载**：listRuns
2. **筛选**：日期/ID/名称/设备/创建人 debounce
3. **状态 Tab**：本地过滤
4. **点行**：router /tasks/:id
