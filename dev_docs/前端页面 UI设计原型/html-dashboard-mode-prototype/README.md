# 仪表盘模式页 HTML UI 原型（Web 桌面）

纯静态 HTML/CSS/JS，对齐 `../02-仪表盘模式页.md` 与现网 `modules/dashboard`（Doodle Craft / 章节钉板）。

本目录是 **Web 桌面原型**：对照板与交互演示均用**浏览器窗口框**展示侧栏 + 主区工作台（约 1280×800 / 流体视口），**不是手机壳 / 手机产品形态**。

上级目录 `参考-UI对照板风格.png` **仅作板式参考**（紫条分区、黄便签批注、当前/更新后对照、页面跳转流程），不是移动端产品目标。

## 如何打开

任选其一：

1. **直接打开**：用浏览器打开本目录下的 `index.html`（`file://` 即可）。
2. **本地静态服务**（推荐）：

```powershell
cd "D:\GitHub\Android-AutoTests\dev_docs\前端页面 UI设计原型\html-dashboard-mode-prototype"
python -m http.server 8766
```

浏览器访问：<http://127.0.0.1:8766/>

## 可点击流程

- 侧栏「仪表盘」高亮；其它入口 Toast 提示「原型：将跳转 …」
- KPI 卡片点击 → Toast 目标 path（对齐真实 `router.push`）
- 「刷新」→ loading → 更新「最近更新」时间戳
- 一键场景：正常数据 / 无用例空态 / 加载失败 / 运行中 live / 模拟静默刷新
- 对照板便签「高亮跳转流」会切到流程图并标红路径

## Mock 数据说明

- 不调用真实 `/api/dashboard/*`；数字与活动为前端写死样例。
- 静默轮询在演示页用按钮模拟，不挂真实 30s 定时器打扰浏览（状态条可显示「已模拟静默刷新」）。
