# 文档编号对照表

> 版本：v1.3 · 日期：2026-08-21
> 用途：统一管理 `dev_docs/` 下所有编号文档（ARCH / PRD / API / Mermaid / 测试）的编号与文件名，作为编号的**唯一真相源**。改动编号必须先更新本表。

---

## 一、编号规则

1. **模块编号 01~09**，顺序固定为：
   `01 仪表盘 → 02 设备管理 → 03 设备检查器 → 04 元素定位 → 05 用例管理 → 06 执行引擎 → 07 测试报告 → 08 AI 助手 → 09 工作流工作台`
2. **03 设备检查器**：设备快照式页面元素获取工具（dump/OCR 快照落库 → 筛减导入元素定位 → 已保存页面回看），原为预留空号，2026-08-17 由元素定位迁出的实时交互能力独立成模块后占用。
3. **特殊编号**：`ARCH-00`（平台总体架构，总纲）、`API-10`（登录，accounts）、`PRD-11`（评测中心，evaluator，原「无编号」2026-08-21 启用）。
4. **ARCH 与 PRD 编号同步**：同一模块在 ARCH 与 PRD 中使用同一编号。
5. **配套文档跟随模块编号**：`API` / `Mermaid` / `测试` 文档使用其所属模块的编号。
