1基础环境安装

🐍 Python 3.10+

python --version

确认 ≥ 3.10。建议使用 pyenv 或系统包管理器安装。

🟩 Node.js 18+

node --version
npm --version

建议使用 nvm-windows 或 fnm 管理版本。

🗄️ MySQL 8.0+

mysql -u root -p

创建数据库：

CREATE DATABASE android_autotests
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;

📡 Redis

redis-cli ping

期望返回 PONG。

Windows 可从 tporadowski/redis 下载。

📱 ADB（可选）

仅当需要连接真实 Android 设备做自动化测试时才需要。
下载 Android Platform Tools，将 adb 加入 PATH。

adb devices
# 期望: List of devices attached
# (无设备也可以，服务器正常运行)

2项目依赖安装

2.1 克隆项目 & 创建 .env

cd D:\Github\Android-AutoTests
cp .env.example .env

编辑 .env，必须修改以下字段：

变量说明示例值
DJANGO_SECRET_KEY Django 密钥，加密 API Key 的根密钥 django-insecure-随机50字符
DB_PASSWORD MySQL 密码 你的实际密码
DEVICE_SERIAL Android 设备序列号（无设备可留空） RF8N21MSW7A
⚠️ 关键：DJANGO_SECRET_KEY 不能为空字符串。 它是 API Key 加密存储的密钥 —— 为空会导致所有已加密的 Key 无法解密， 且 decrypt_key() 会因无密钥而 fallback 返回原文（安全风险）。

2.2 Python 依赖

pip install -r requirements.txt

核心依赖：

  • Django>=4.2 + daphne>=4.0
  • agentscope>=2.0.0（AI 引擎）
  • uiautomator2>=3.0（设备控制）
  • chromadb>=0.4.0（RAG 知识库）
  • mysqlclient>=2.2（MySQL 驱动）
💡 Windows 提示：mysqlclient 需要 Visual C++ Build Tools。 如果装不上，可切换到 SQLite（见下方"数据库引擎切换"）。

2.3 前端依赖

cd frontend
npm install
cd ..

核心依赖：

  • vue@^3.4 + vite@^5.4
  • element-plus@^2.7
  • animal-island-vue@^0.2（动森主题）
  • animejs@^4.5（动画引擎）

3数据库初始化

3.1 运行数据库迁移

python manage.py makemigrations
python manage.py migrate

这会创建 20+ 张业务表（6 组前缀：dp_ el_ cm_ tr_ rg_ ai_）。

3.2 创建超级用户

python manage.py shell -c ^
"from django.contrib.auth.models import User; ^
 User.objects.create_superuser('admin','admin@local','admin123') ^
 if not User.objects.filter(username='admin').exists() else None"

登录凭据：用户名 admin / 密码 admin123。

3.3 收集静态文件（可选）

python manage.py collectstatic --noinput

为 Django Admin 和 jazzmin 主题准备静态文件。

4知识库初始化（AI 助手 RAG）

python agentscope_service/rag/init_kb.py

从 dev_docs/ 加载 32 篇 Markdown 文档到 ChromaDB 向量数据库（data/chromadb/）。
这是 AI 助手做知识检索的基础，首次运行必须执行，否则 AI 对话缺少上下文。

📝 注意：初始化过程会调用 Embedding API 将文档转为向量， 需要配置好的模型 API Key 才能正常工作。如果只想先跑通基础服务，此步骤可跳过， 后续在 AI 助手中配置好 Agent 后再执行。

5启动服务

5.1 一键启动（推荐）

python run.py start

启动顺序（自动按依赖排列）：

  1. Redis :6379 — 消息总线 + 状态存储
  2. Django :8765 — 后端 API + WebSocket
  3. AgentScope :8000 — AI 对话引擎
  4. Vite :5173 — Vue 前端

5.2 按需启动

python run.py start redis backend          # 只要后端 + Redis
python run.py start agentscope frontend    # 只要 AI + 前端

5.3 验证启动状态

python run.py status

期望输出：

  Redis            (:6379)  ONLINE
  Django backend   (:8765)  ONLINE
  AgentScope AI    (:8000)  ONLINE
  Vue frontend     (:5173)  ONLINE

5.4 各服务手动验证

# Redis — 期望 PONG
redis-cli ping

# Django — 期望 JSON 响应
curl -s http://localhost:8765/api/ | python -m json.tool

# AgentScope — 期望 HTTP 200
curl -s -o /dev/null -w "%{http_code}" http://localhost:8000/docs

# Vite 前端 — 期望 HTTP 200
curl -s -o /dev/null -w "%{http_code}" http://localhost:5173

6登录使用

  1. 浏览器打开 http://localhost:5173
  2. 用户名 admin，密码 admin123
  3. 登录后默认跳转到仪表盘

其他入口：Django Admin → :8765/admin/  |  AgentScope API 文档 → :8000/docs

🔄 数据库引擎切换

使用 SQLite（不依赖 MySQL）

修改 .env：

DB_ENGINE=sqlite

然后重新迁移：

python manage.py migrate

数据库文件：data/app.db

使用 MySQL

.env 中保持：

DB_ENGINE=mysql
DB_NAME=android_autotests
DB_USER=root
DB_PASSWORD=你的密码
DB_HOST=127.0.0.1
DB_PORT=3306

确保 MySQL 服务已启动且数据库已创建。

🩺 常见启动问题

现象原因解决
AgentScope 启动失败 Redis 未运行 redis-server --port 6379
Django 启动失败 / 端口冲突 端口 8765 被占用 netstat -ano | findstr 8765 → taskkill /PID xxx /F
前端白屏 Vite 编译未完成 等待 3-5 秒刷新页面
ModuleNotFoundError: No module named 'xxx' Python 依赖缺失 pip install -r requirements.txt
no such table 未执行数据库迁移 python manage.py migrate
mysqlclient 装不上 (Windows) 缺少 VC++ Build Tools 改用 DB_ENGINE=sqlite
database is locked SQLite 并发写冲突 重启 Django，或迁移到 MySQL
AI 对话无响应 Redis 不可用 / AgentScope 挂了 AI 对话降级到 Django 阻塞模式；检查 logs/agentscope.log
截图流断开 / 空白 设备 ADB 断开 adb devices 确认设备在线；检查截图流 WebSocket 握手

📋 管理命令速查

命令用途
python run.py start启动全部 4 个服务
python run.py stop停止全部服务（Redis 除外）
python run.py restart重启全部服务
python run.py status查看各服务在线状态
python run.py logs backend查看后端最近 20 行日志
python run.py logs agentscope查看 AgentScope 日志
python manage.py createsuperuser创建新的管理员账号
python manage.py makemigrations && python manage.py migrate数据库结构变更后执行
python tools/gen_arch_stats.py统计表/端点/Tool/步骤类型数量
python tools/gen_arch_stats.py --check-md检测文档是否落后代码
