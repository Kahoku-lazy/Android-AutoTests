关键经验
#经验
1ok() 函数要正确处理错误码：400/404/423 等预期错误不能按成功逻辑判定，只需比较 status_code 是否匹配
2每次运行前清理：自动化测试必须幂等，用时间戳前缀 + 前置清理避免数据污染
3所有请求加超时：monkey-patch Session.request 是最小侵入的方式，避免单个请求卡死整个测试套件
4编码问题在 Windows 上优先处理：GBK vs UTF-8 是高频坑，脚本开头就设 PYTHONIOENCODING
5先修环境再修代码：Django 重启 + tester 账号创建解决了 >50% 的失败，不要第一时间怀疑代码
