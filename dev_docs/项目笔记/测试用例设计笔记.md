# AI 助手编写用例的完整逻辑如下：

  ---
## AI 用例生成流程

1. 第一步：识别用例类型

  AI 从用户输入中匹配关键词，映射到 4 种类型：

  用户说                            → 识别为
  "帮我写个 Android UI 自动化用例"     → ui_automation
  "写一个网页登录的测试"              → web_automation
  "写业务功能测试用例"                → storage
  "写 API 接口用例测试登录"           → api_testing

  识别不到时，AI 主动询问 4 选 1。

2. 第二步：创建任务卡片

  create_case_gen_task(title, case_type, total_count)
      ↓
  写入 TestRunRecord（run_id = case-gen-xxxxxxxx）
      ↓
  状态 = PENDING（等待中）
      ↓
  任务看板同步可见

3. 第三步：按类型分发生成

  case_type = ui_automation:
    → search_elements 搜索 XPath
    → save_test_case(case_id, title, steps=[{type, xpath, description}, ...])
    → 17 种步骤类型，可执行
    → 写入 cm_test_definitions

  case_type = storage:
    → save_storage_case(case_id, title, cases=[{title, steps, expected_result, ...}, ...])
    → 批量写入同一个文件，列式表格 rows 格式
    → 写入 cm_storage_testcases

  case_type = web_automation:
    → save_web_case(case_id, title, url, steps, expected_result)
    → 写入 cm_web_testcases

  case_type = api_testing:
    → save_api_case(case_id, title, url, method, headers, body, expected_response)
    → 写入 cm_api_testcases

  第四步：进度同步

  每完成 1 个用例 → update_case_gen_task(run_id, status=RUNNING, case_id, progress_current)
  全部完成       → update_case_gen_task(run_id, status=COMPLETED)

  完整时序

  全部完成       → update_case_gen_task(run_id, status=COMPLETED)

  完整时序

  用户: "帮我写登录功能的业务测试用例"
      │
      ▼
  AI 识别: "功能" → storage
      │
      ├─ create_case_gen_task(title="登录功能业务测试用例", case_type="storage", total_count=2)
      │     └─ 任务卡片: PENDING（等待中），任务看板出现便签
      │
      ├─ update_case_gen_task(status=RUNNING)
      │     └─ 任务卡片: RUNNING（进行中）
      │
      ├─ save_storage_case(case_id="TC-FUNC-login", title="登录功能业务测试用例",
      │     cases=[
      │       {title:"正确账号登录成功", steps:"1.输入账号\n2.输入密码\n3.点击登录", expected_result:"跳转首页"},
      │       {title:"密码错误登录失败", steps:"1.输入账号\n2.输入错误密码\n3.点击登录", expected_result:"提示错误"}
      │     ])
      │     └─ 写入 cm_storage_testcases，一个文件含 2 条用例
      │
      └─ update_case_gen_task(status=COMPLETED, progress_current=2)
            └─ 任务卡片: COMPLETED（已完成）✅

  关键规则

  - storage/web/api 只生成不执行 — 首期只做结构化用例
  - ui_automation 可执行 — 需要先 dump UI 获取 XPath，否则 AI 会提示"请先在元素定位页获取页面元素"
  - storage 批量写一个文件 — cases 数组一次性写入，columner-ele 表格格式
  - 任务卡片同步看板 — 创建/更新都实时反映在 AI 助手首页任务看板
