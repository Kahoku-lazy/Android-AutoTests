关键协作模式

  • Plan Mode 审批门槛：所有多文件改动先出方案等你批，避免方向错误
  • 增量迭代：文档从 v1（基础）→ v2（约束标注）→ v2.1（错误表），逐步完善
  • 代码先行，文档后补：先实现功能并编译通过，再从代码反推文档
  • 验收闭环：文档输出后对照代码和 PRD 逐项检查，确保无遗漏
