### 代码验证
1. npx vue-tsc 验证类型改动,
2. npx vue-tsc --noEmit
    1. 属性/字段不存在（TS2339）
    2. 2. 类型不匹配赋值（TS2322）
    3. 参数个数/签名不符（TS2554）
    4. 模板表达式的类型上下文
    5. 间接暴露的运行时 bug（它只报类型错，但根因是逻辑错）
