# 引擎与平台设备方案
引擎：无状态（每次 new + connect + 操作 + disconnect）
上层：自管连接生命周期
  ├─ 设备管理：adb 实时查询，不连接
  ├─ 执行器：运行前 connect → 独占执行 → 运行后 disconnect
  └─ AI：确认连接 → connect → 独占执行 → 释放 disconnect
互斥：业务锁 DeviceLock（acquire/observe），引擎不碰
