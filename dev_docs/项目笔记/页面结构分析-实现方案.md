# 页面结构分析能力 — 实现方案（纯规则版）

> 日期：2026-08-25 · 决策：前端「结构分析」按钮走**纯规则、无 LLM**；语义命名（LLM）作为后续可选增强，本次不实现。
> 范围：设备检查器快照的结构化分区展示。

### 2.1 `algorithms/layout.py`（新增，核心）

**分区判定规则表**（纯信号，无 rid 硬编码）：

| 分区 | 判定信号（按优先级） |
| --- | --- |
| `system_nav` | `package` 含 systemui 且元素 y 在底部带（`y > screen_h * 0.92`） |
| `status_bar` | `package` 含 systemui 且元素 y 在顶部带（`y < screen_h * 0.06`） |
| `bottom_nav` | App 包内、y 在底部带（`y > screen_h * 0.85`）、含 ≥3 个 clickable ImageView |
| `tab_bar` | App 包内、class 含 `HorizontalScrollView` 或 横向 `RecyclerView`、y 在顶部带 |
| `header` | App 包内、y 在顶部带（status_bar 之下、`y < screen_h * 0.12`）、非 tab_bar |
| `content` | 剩余中间区域 |
| `other` | 未命中以上任何规则 |

> 阈值均为 `screen_h` 的**相对比例**（非绝对像素），横屏/不同分辨率自适应。判定顺序：先 systemui → 再 WebView → 再按 y 带 → 兜底 content。

**`metrics` 聚合**（3 行，直接由已有字段推）：

```python
def _metrics(el: dict) -> list[str]:
    m = []
    if el.get("clickable"): m.append("可点击")
    if el.get("scrollable"): m.append("可滚动")
    if el.get("checkable"): m.append("可勾选")
    return m
```

### 2.2 `service.py`（编排，~60 行）

```python
def analyze_snapshot_payload(snapshot) -> dict:
    """基于已存快照 dump_json 计算结构分区（即时，不落库）。"""
    dump = snapshot.dump_json or {}
    elements = dump.get("elements") or []
    if not elements:
        return {"is_webview": False, "sections": [], "elements": []}

    structure = classify_structure(elements, snapshot.screen_h or 0)

    # 复用已有 XPath（不新写，防漂移）
    for el in structure["elements"]:
        el["xpaths"] = gen_xpath_candidates(el, elements)

    return {
        "package": snapshot.package,
        "activity": snapshot.activity,
        "is_webview": structure["is_webview"],
        "sections": structure["sections"],
        "elements": structure["elements"],
    }
```

> 关键：`gen_xpath_candidates` 用**完整 elements** 算 count（与 capture 时语义一致），`metrics` 直接由字段推，XPath 不另写一套。

### 2.3 `api.py`（白名单，~40 行）

```python
__all__ = [..., "analyze_snapshot"]

def analyze_snapshot(snapshot_id: int) -> dict | None:
    """快照结构分析；不存在返回 None。"""
    from .models import Snapshot
    from .service import analyze_snapshot_payload
    snapshot = Snapshot.objects.filter(id=snapshot_id).first()
    if snapshot is None:
        return None
    return analyze_snapshot_payload(snapshot)
```

### 2.4 `views.py` + `urls.py`（端点）

```python
# views.py
def analyze_snapshot_view(request, snapshot_id):
    data = api.analyze_snapshot(snapshot_id)
    if data is None:
        return JsonResponse({"status": False, "message": "快照不存在"}, status=404)
    return JsonResponse({"status": True, "data": data})

# urls.py
path("snapshots/<int:snapshot_id>/analyze", views.analyze_snapshot_view, name="analyze"),
```

## 7. 风险与边界（重申）

1. **R1 通用性**：`classify_structure` 只用位置/class/package 信号，**禁止 rid 硬编码**；未命中归 `other`，不猜语义。
2. **R2 无精确嵌套**：快照存的是裁剪后扁平 list（`depth`），分区是 **bounds 近似**，不承诺"卡片→子元素"精确父子归属；精确嵌套需另加 `full_hierarchy_json` 字段（本次不做）。
3. **R3 XPath 不重复造**：强制复用 `gen_xpath_candidates`。
4. **R4 即时计算**：analyze 不落库、不加字段，避免 migration 与体积风险。
