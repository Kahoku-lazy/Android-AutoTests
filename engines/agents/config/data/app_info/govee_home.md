# 被测应用短卡 · Govee Home

## 身份与启动
- 显示名：Govee Home
- 包名：`com.govee.home`（**不要**写成 `govee.home.com`，那是反的，启动会报「没有可用入口」）
- 启动：只给包名即可（工具会解析 LAUNCHER 组件后用 `am start` 启动）；无需写 Activity
- 登录态：未知

## 导航与入口
- 底栏五入口（左→右）：设备、生态、社区、购物车、用户
- 设备 / 生态：记住上次 Tab（设备页左上「设备」；生态顶栏「快捷面板」「功能中心」「自动执行」）
- 社区 / 购物车 / 用户：需手动切换

## 交互约定
- 设备页：长按约 1s → 顶部「灵动 / 经典」切换；卡片再长按可缩放
- 灵动放大后：长按可增删功能（最多 4 + 默认 1 = 共 5）
- 详情页：开 → 开关蓝填 + 丰富控制；关 →「设备已关闭」+ 开关黑填
- 模式区（颜色 / 场景 / 音乐 / 用户分享 / DIY / 涂鸦 / AI 等）：选中蓝填，下方内容变；需上下滑看全

## 干扰与禁区
- Loading 转圈：必等加载完成再操作
- 弱网 / 弱蓝牙也会触发 Loading
- 禁区：暂无额外硬禁区

## 验收锚点
| 场景 | 可见文案 / 特征 |
|------|-----------------|
| 设备首页 | 「设备」 |
| 详情关闭 | 「设备已关闭」 |
| 开 / 关态 | 开关蓝填 / 黑填 |
| 模式选中 | 模式键蓝填 |

## 执行红线
- 一步一操作
- 页面非预期 → 回退一步；无法回退则重规划回上一页后再继续
