# H6810 日志关键词（功能点 → 关键词）

> 用途：验收角色判断「这一步的设备动作有没有真的被设备响应」时，从这里选关键词。
> 关键词必须与 `backend/config/device_log_keywords.json`（全量目录）里登记的一致，`test_log_keyword_catalog.py` 会校验。

## 设备开关

- 打开设备成功 → switch_on
- 关闭设备成功 → switch_off

## 亮度

- 成功设置相对亮度 → lumi_set_success

## 灯效与颜色

- 设置颜色成功 → color_configs_set_success
- 成功切换到颜色模式 → color_mode_start
- 分段-渐变开启 → color_gradient_open_success
- 分段-渐变关闭 → color_gradient_close_success
- 分段-相对亮度设置成功 → set_color_segment_lumi_success

## 场景模式

- 成功切换至场景模式 → abstract_mode_start
- 灯效场景设置成功 → scene_configs_set_success

## 音乐模式

- 成功切换到音乐模式 → music_mode_start
- 成功设置灵敏度 → music_mode_agile_sensitivity
- 音乐模式场景设置成功 → music_configs_set_success

## DIY 模式

- 成功切换至DIY模式 → diy_mode_start
- DIY灯效设置成功 → diy_configs_set_success

## 定时功能

- 设置预约定时成功 → timer_configs_set_success
- 设置唤醒定时成功 → awaken_configs_set_success
- 设置睡眠定时成功 → sleep_configs_set_success
