# CLAUDE.md — 前端主题修改

1. **先出原型，再写代码** — 改任何模块主题前，先出 3 个概念原型让用户选。用户选定后再实施方案。直接改的风险：不满意要回滚，反复修改工作量比原型大得多
2. **先 Glob 再动手** — 选定方向后，列出模块下所有文件，逐个 Read 每个组件的 `<style>` 块，确认没有漏掉子组件
3. **改完 grep 残留** — 搜旧令牌/旧色值/旧效果关键词，必须返回 0 行
4. **只改 CSS，不改逻辑** — 不碰 props/emits/API/路由/动画

反面教材：设备管理主题同步时，跳过原型直接改了代码，用户指出流程不对。应先用 HTML 出 3 个方向对比。
