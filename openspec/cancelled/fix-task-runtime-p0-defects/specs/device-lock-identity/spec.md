# device-lock-identity Delta

## Purpose

定义设备锁定 / 公开切换操作的身份来源契约：锁的归属人只能来自服务端鉴权注入的身份，客户端请求体不得伪造或覆盖，保证「是否本人锁定」判定与设备占用归属可信。

## ADDED Requirements

### Requirement: 设备锁身份只取自鉴权注入

设备锁定 / 公开切换 MUST 以服务端鉴权中间件注入的当前用户身份作为 `locked_by`；MUST NOT 从请求体、查询参数或其他客户端可控字段读取或回退身份。鉴权身份缺失时该操作 MUST 被拒绝，MUST NOT 以匿名或客户端自报身份落锁。

#### Scenario: 请求体携带伪造身份被忽略

- **WHEN** 已登录用户 A 调用设备锁定接口，请求体额外携带 `user_id` 为用户 B
- **THEN** 锁的归属人为用户 A，请求体中的身份字段不被采信

#### Scenario: 无鉴权身份时拒绝落锁

- **WHEN** 请求未携带有效鉴权身份（中间件未注入用户）
- **THEN** 锁定操作被拒绝，设备锁状态不变
