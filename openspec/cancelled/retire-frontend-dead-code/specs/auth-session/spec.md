## ADDED Requirements

### Requirement: 令牌续期为被动单飞

前端令牌续期 SHALL 仅由受保护端点返回的 `401` 被动触发，MUST NOT 基于 JWT `exp` 在请求或建连前主动预续期。同一时刻的并发续期 MUST 只产生一次 `POST /api/auth/refresh/`（单飞），并发调用方 SHALL 拿到同一个新访问凭证。本地没有续期凭证时 MUST NOT 发起续期请求，由下游 `401` 走既有失败路径。本要求收敛归档变更 `2026-11-17-fix-auth-refresh` 中未同步进主规格的「过期前主动续期」口径：续期为被动而非主动。

#### Scenario: 并发 401 只刷一次

- **WHEN** 多个受保护请求同时返回 `401` 且本地存在续期凭证
- **THEN** 只产生一次 `POST /api/auth/refresh/`
- **AND** 各请求拿到同一个新访问凭证并各自重试原请求

#### Scenario: 有效凭证不触发预续期

- **WHEN** 本地访问凭证仍在有效期内，前端发起受保护请求
- **THEN** 不基于 `exp` 预先发起续期请求
- **AND** 请求直接携带当前访问凭证（续期只由 `401` 触发）

#### Scenario: 无续期凭证不请求

- **WHEN** 受保护端点返回 `401` 但本地只有访问凭证、没有续期凭证
- **THEN** 不发起续期请求
- **AND** 走既有清会话并跳转登录页的失败路径
