## Purpose

在平台「数据」分组提供知识库只读检索入口：模块（文档路径）可在平台登记与维护，提问前勾选一个或多个模块，返回未经改写的检索原文与相似度，并把嵌入调用的 token 用量写入平台账本。

## ADDED Requirements

### Requirement: 模块登记与路径维护

系统 SHALL 以平台数据库为模块登记的真相源：一个模块 = 唯一库名 + 描述 + 服务器本地资料目录 + 启用状态。库名 MUST 匹配 `^[a-z][a-z0-9_]*$`；资料目录 MUST 是已存在、可读的绝对路径；两个启用模块的资料目录 MUST NOT 相同或互相包含。模块的新增 / 编辑（含改路径）/ 删除 / 启停 SHALL 仅超级管理员可操作；模块列表 SHALL 登录可读。登记变更 MUST 同步更新检索所用的库目录并复用引擎的目录校验；校验失败 MUST 返回可读原因且 MUST NOT 落库。首次部署 SHALL 把引擎自带库目录的既有登记导入为初始模块。

#### Scenario: 超管新增模块成功

- **WHEN** 超级管理员提交合法库名、描述与已存在的资料目录
- **THEN** 模块落库并出现在模块列表
- **AND** 检索库目录同步包含该模块

#### Scenario: 非超管写操作被拒绝

- **WHEN** 普通登录用户调用模块新增 / 编辑 / 删除 / 启停
- **THEN** 返回 403
- **AND** 模块列表与检索库目录不变

#### Scenario: 启用库目录冲突被拒绝

- **WHEN** 新增或启用一个模块，其资料目录与另一启用模块相同或互相包含
- **THEN** 返回 400 并指出冲突的两个库名
- **AND** 不落库、不更新检索库目录

#### Scenario: 改路径后按新目录检索

- **WHEN** 超管把某模块的资料目录改为另一个合法目录
- **THEN** 后续提问只命中新目录下的资料
- **AND** 旧目录中已不在新目录的文件不再命中

#### Scenario: 全新安装带初始模块

- **WHEN** 平台首次部署完成
- **THEN** 模块列表包含引擎自带库目录中的既有登记（含启用与禁用状态）

### Requirement: 勾选模块提问并返回检索原文

`POST /api/knowledge-search/query/` SHALL 登录可用，入参为问题、勾选库名数组（MUST 非空）与可选 top_k；路径 MUST 带尾斜杠，响应 MUST 遵循 `{status, data}` 信封与 snake_case。系统 MUST 只在勾选模块内检索；多选时逐库检索后按相似度降序合并并截断到 top_k。每条命中 MUST 包含库名、来源文件、文档编号、片段序号、相似度与未经改写的原文；MUST NOT 生成总结或改写正文。结果 MUST 区分 ok / no_hit / unavailable 三态，no_hit 与 unavailable 的文案 MUST 不同。单库失败 MUST NOT 拖垮其它库：返回成功库的命中并附逐库错误原因。问题为空或勾选为空 MUST 返回 400。

#### Scenario: 多库命中合并排序

- **WHEN** 用户勾选两个可用模块提问且两库都有过阈值命中
- **THEN** 命中按相似度降序合并返回，条数不超过 top_k
- **AND** 每条命中带库名标签，可区分来源模块

#### Scenario: 命中字段齐全且原文不改写

- **WHEN** 检索返回命中
- **THEN** 每条含库名、来源文件、文档编号、片段序号、相似度与正文
- **AND** 正文与资料文件中的片段逐字一致，无模型生成的总结

#### Scenario: 单库失败部分返回

- **WHEN** 勾选的两个模块中一个索引失败、另一个正常命中
- **THEN** 返回正常库的命中
- **AND** 附失败库的可读错误原因，不整体报错

#### Scenario: 无命中与检索不可用文案不同

- **WHEN** 勾选模块可用但没有过阈值片段
- **THEN** 返回 no_hit 与「资料里没有相关内容」类文案
- **WHEN** 嵌入密钥缺失或全部勾选库索引失败
- **THEN** 返回 unavailable 与可读原因，文案与 no_hit 不同

#### Scenario: 未勾选模块提问被拒绝

- **WHEN** 请求的勾选库名数组为空或问题为空白
- **THEN** 返回 400 与可读原因
- **AND** 不触发任何嵌入调用

### Requirement: 预建索引

`POST /api/knowledge-search/modules/{id}/index/` SHALL 仅超级管理员可用，同步对该模块做增量索引并返回本次重建文件数。索引 SHALL 只覆盖 `.md` 与 `.txt`；修改时间、大小与切块版本均未变化的文件 MUST NOT 重复嵌入。索引失败 MUST 返回可读原因且 MUST NOT 影响其它模块。

#### Scenario: 预建索引返回重建数

- **WHEN** 超管对资料有更新的模块触发预建索引
- **THEN** 返回本次重建的文件数
- **AND** 随后提问不再触发该库的重建

#### Scenario: 增量跳过未变化文件

- **WHEN** 资料未变化时再次触发预建索引
- **THEN** 返回重建数 0
- **AND** 不调用嵌入模型

#### Scenario: 非超管触发被拒绝

- **WHEN** 普通登录用户触发预建索引
- **THEN** 返回 403

### Requirement: 嵌入用量逐调用入账

系统 SHALL 对索引与检索中每次真实发生的嵌入模型调用向 `ai_usage_records` 写入恰好一条记录：category=Embedding、provider=dashscope、模型名取自向量模型配置、input_tokens 为该次调用 token 数、source=knowledge。幂等键 MUST 为「来源:执行 ID:轮次」，同一键重复提交 MUST 更新原行而 MUST NOT 翻倍。token 为 0 或空的调用 SHALL NOT 入账。入账失败 MUST 只记日志，MUST NOT 阻断检索或索引。费用 SHALL 按既有价目表与通用公式计算，MUST NOT 伪造金额。

#### Scenario: 一次提问的嵌入调用逐条入账

- **WHEN** 一次提问触发索引重建与查询嵌入
- **THEN** 每次嵌入调用各有一条 Embedding 记录，source=knowledge
- **AND** token 数与模型返回的用量一致

#### Scenario: 重复提交不翻倍

- **WHEN** 同一调用的用量被提交两次
- **THEN** 账本仍只有一条该键记录

#### Scenario: 入账失败不阻断检索

- **WHEN** 账本暂时不可写
- **THEN** 检索结果照常返回
- **AND** 失败只记日志

### Requirement: 引擎缺失时平台降级不炸

检索桥 SHALL 以局部可选导入使用引擎知识库：`engines/ae_harness/knowledge/` 整目录删除后，模块列表与登记接口 MUST 仍可用，提问 MUST 返回「检索不可用」及可读原因，MUST NOT 返回 500；平台其它功能 MUST NOT 受影响。

#### Scenario: 整目录删除后提问降级

- **WHEN** 引擎知识库目录被整体删除后用户提问
- **THEN** 返回 unavailable 与可读原因
- **AND** 模块列表仍可读取

### Requirement: 前端入口与检索页

侧栏「数据」分组 SHALL 在末尾新增「知识库」入口（路由 `/knowledge-search`），入口级颜色 MUST 与同组其它入口不同，且 SHALL 只用于侧栏图标底色与 active 书签条。页面 SHALL 为单页分栏：左栏模块勾选列表（名称 / 描述 / 路径 / 启用状态），右栏提问与命中原文流。未勾选任何模块时提问动作 MUST 禁用。命中条目 MUST 逐字展示原文，并带库名、来源文件、片段序号与相似度。加载 / 失败 / 空 SHALL 用共享三态组件，加载期间 MUST NOT 渲染空态；no_hit 与 unavailable 文案 SHALL 区分。模块管理与预建索引按钮 SHALL 仅超管可见，非超管只读并显示权限提示。页面 MUST 明示只索引 `.md/.txt`、首次提问可能触发建索引。

#### Scenario: 数据组入口异色出现

- **WHEN** 已登录用户查看侧栏「数据」分组
- **THEN** 末尾出现「知识库」入口
- **AND** 其入口级颜色与设备管理、串口日志不同

#### Scenario: 未勾选时提问禁用

- **WHEN** 用户未勾选任何模块
- **THEN** 提问按钮禁用
- **AND** 勾选至少一个模块后可提问

#### Scenario: 管理按钮按权限显隐

- **WHEN** 普通用户打开检索页
- **THEN** 看不到新增 / 编辑 / 删除 / 预建索引按钮，并见只读权限提示
- **WHEN** 超管打开检索页
- **THEN** 可见模块管理与预建索引入口

#### Scenario: 三态与原文展示

- **WHEN** 提问进行中 / 无命中 / 检索不可用
- **THEN** 分别显示共享加载态 / 空态文案 / 错误态文案，加载期间不出现空态
- **WHEN** 有命中
- **THEN** 每条命中逐字展示原文与来源、相似度
