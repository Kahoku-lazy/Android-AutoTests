# device-log-port-console Delta

## MODIFIED Requirements

### Requirement: 工具箱展示日志端口列表（五列）

串口日志页「无线端口」面板 SHALL 以表格展示平台登记的日志端口，列 MUST 恰为 5 列：端口、SKU名称、波特率、监听开关、日志查看。端口行 MUST 区分来源：**配置端口**（来自 `DEVICE_LOG_SOURCES` 等平台配置）的端口 / SKU名称 / 波特率三列 MUST 为只读展示，页面上 MUST NOT 提供修改它们的入口；**自定义端口**（用户在页面新增）的三列中 SKU名称与波特率 MUST 可编辑、端口号 MUST 不可改，且 MUST 可删除（仅超级管理员）。端口列 MUST 以徽标区分「配置 / 自定义」来源，并 MUST 展示该端口的完整监听地址（本机 IP:端口）。波特率 MUST 表述为该端口无线串口盒的串口参数，MUST NOT 影响采集行为。每行 MUST 同时呈现该端口当前是否正在监听。

#### Scenario: 五列齐备

- **WHEN** 用户打开串口日志页的「无线端口」面板
- **THEN** 表格包含端口、SKU名称、波特率、监听开关、日志查看五列

#### Scenario: 三列只读

- **WHEN** 用户查看配置端口的端口 / SKU名称 / 波特率三列
- **THEN** 三列仅作展示，页面上没有修改它们的入口

#### Scenario: 自定义端口可编辑可删除

- **WHEN** 超级管理员查看自定义端口行
- **THEN** 该行提供编辑（SKU名称 / 波特率）与删除入口，端口号不可修改

#### Scenario: 来源徽标与完整地址

- **WHEN** 用户查看任一端口行
- **THEN** 端口列带「配置」或「自定义」徽标，并展示本机 IP:端口 的完整监听地址

#### Scenario: 展示现场登记值

- **WHEN** 平台登记了现场来源 7005 / H6810 / 921600
- **THEN** 表格对应行显示端口 7005、SKU名称 H6810、波特率 921600，来源徽标为「配置」

#### Scenario: 监听状态如实呈现

- **WHEN** 某端口开关处于关闭状态
- **THEN** 该行状态呈现为未监听，与开关实际状态一致

### Requirement: 端口管理接口契约

平台 SHALL 提供读取端口列表、切换监听开关、读取日志行、新增端口、编辑端口、删除端口六个接口；响应 MUST 遵循平台信封（`{status, data}`）与 snake_case 字段约定。端口列表、日志行 MUST 登录可读；切换开关、新增、编辑、删除 MUST 校验超级管理员身份。端口列表响应 MUST 携带本机监听 IP（`listen_ip`），每行 MUST 携带来源（`origin`）与完整监听地址（`address`）。新增端口 MUST 校验端口号合法（1–65535）且不与任何已登记端口（含配置端口）重复、SKU 必填；校验失败 MUST 返回 400 可读错误。编辑与删除 MUST 只接受自定义端口，对配置端口 MUST 返回可读拒绝。读取日志行 MUST 只接受平台已登记的端口，未登记端口 MUST 返回可读结论而非报错。

#### Scenario: 读取端口列表

- **WHEN** 已登录用户请求端口列表
- **THEN** 返回本机监听 IP，以及每个来源的端口、SKU名称、波特率、来源、完整监听地址、是否正在监听与当前日志文件名

#### Scenario: 切换开关立即生效

- **WHEN** 超级管理员请求打开或关闭某端口
- **THEN** 开关状态落库并立即生效，返回生效后的状态

#### Scenario: 非管理员切换被拒

- **WHEN** 普通登录用户请求切换开关
- **THEN** 请求被拒绝（403）且开关状态保持不变

#### Scenario: 新增端口校验

- **WHEN** 超级管理员新增一个与配置端口重复的端口号，或端口号超出 1–65535，或 SKU 为空
- **THEN** 返回 400 与可读错误原因，不产生任何登记与监听

#### Scenario: 非管理员写操作被拒

- **WHEN** 普通登录用户请求新增、编辑或删除端口
- **THEN** 请求被拒绝（403）且端口登记保持不变

#### Scenario: 配置端口不可编辑删除

- **WHEN** 超级管理员请求编辑或删除一个配置端口
- **THEN** 返回可读拒绝，配置端口登记与监听不受影响

#### Scenario: 未登记端口返回可读结论

- **WHEN** 请求读取一个平台未登记的端口（如 7004）的日志行
- **THEN** 返回可读结论「端口 7004 未配置为日志来源」，MUST NOT 返回服务端错误

## ADDED Requirements

### Requirement: 自定义端口登记

超级管理员 SHALL 能在页面新增自定义端口（端口号 / SKU名称 / 波特率），保存后平台 MUST 立即开始监听该端口并落日志文件；新增 MUST 以单端口增量方式生效，MUST NOT 重启或中断其它端口的监听。自定义端口的登记 MUST 持久化并跨后端重启保留，重启后 MUST 按其开关状态自动恢复监听。编辑自定义端口（SKU名称 / 波特率）MUST 只重启被编辑的那一个端口；删除自定义端口 MUST 先停止监听并释放端口，再移除登记，且 MUST 保留历史日志文件。同时监听的端口达到上限（10 个）时，新增或开启 MUST 返回可读拒绝，MUST NOT 影响已在监听的端口。自定义端口 MUST NOT 与配置端口或已有自定义端口同号。

#### Scenario: 新增即监听

- **WHEN** 超级管理员提交合法的新端口（如 7008 / H717D / 115200）
- **THEN** 该端口登记落库、立即开始监听，设备随后推送的日志写入该端口的日志文件

#### Scenario: 新增不干扰其它端口

- **WHEN** 新增端口时其它端口正在接收设备日志
- **THEN** 其它端口的监听与设备连接保持不中断，日志无空窗

#### Scenario: 重启后恢复自定义端口

- **WHEN** 后端重启完成且自定义端口开关为开启
- **THEN** 该自定义端口自动恢复监听，无需任何人打开页面

#### Scenario: 编辑只重启本端口

- **WHEN** 超级管理员修改某自定义端口的 SKU名称
- **THEN** 只有该端口按新 SKU 重启监听并写入新通道文件，其它端口不受影响

#### Scenario: 删除保留日志文件

- **WHEN** 超级管理员删除某自定义端口
- **THEN** 该端口停止监听、登记移除，历史日志文件仍保留在磁盘

#### Scenario: 超限可读拒绝

- **WHEN** 已有 10 个端口在监听时新增并试图开启第 11 个
- **THEN** 返回可读拒绝「同时监听的端口已达 10 个」，已在监听的端口不受影响

#### Scenario: 端口同号被拒

- **WHEN** 新增的端口号与配置端口或已有自定义端口相同
- **THEN** 返回可读错误，不产生重复登记

### Requirement: 本机监听地址展示

平台 SHALL 探测本机出站局域网 IP 并在端口列表接口返回（`listen_ip`）；无线端口面板 MUST 在头部展示该 IP 并提供一键复制，说明设备侧应填入此地址。平台 MUST 支持以配置项 `DEVICE_LOG_ADVERTISE_HOST` 人工指定对外 IP（多网卡 / 容器部署）；配置存在时 MUST 以配置值为准。监听绑定地址 MUST 保持全网卡（0.0.0.0）不变。IP 探测失败时 MUST 给出可读说明，MUST NOT 使端口列表接口报错。

#### Scenario: 头部展示本机 IP

- **WHEN** 用户打开无线端口面板
- **THEN** 头部展示本机监听 IP 与复制入口，并说明串口盒 / 设备侧填入此 IP

#### Scenario: 一键复制

- **WHEN** 用户点击复制
- **THEN** 本机监听 IP 进入剪贴板并给出已复制提示

#### Scenario: 配置覆盖探测值

- **WHEN** 设置了 `DEVICE_LOG_ADVERTISE_HOST`
- **THEN** 列表接口与页面展示的 IP 为配置值，而非探测值

#### Scenario: 探测失败不拖垮列表

- **WHEN** 本机 IP 探测失败且未配置覆盖值
- **THEN** 端口列表照常返回，IP 字段给出可读的空态说明

### Requirement: 监听失败显式提示

开启监听或新增端口后，端口处于「开关开启但实际未监听」状态时，页面 MUST 以**错误提示**（而非成功提示）告知「端口 X 监听失败」，行内状态 MUST 呈现为区别于「未监听 / 已停止」的**监听失败**态，并 MUST 展示可读失败原因（端口已被其它程序占用 / 端口绑定失败）。失败端口 MUST 保留登记，用户排除占用后 MUST 能直接重试开启，MUST NOT 要求重新新增。「监听中但暂无日志」MUST NOT 被判为监听失败。

#### Scenario: 开启失败给错误提示

- **WHEN** 超级管理员开启一个已被其它程序占用的端口
- **THEN** 页面弹出错误提示「端口 X 监听失败：端口已被其它程序占用」，该行状态为「监听失败」

#### Scenario: 新增失败保留登记

- **WHEN** 新增端口后绑定失败
- **THEN** 该端口保留在列表中（开关开启、状态监听失败、带失败原因），不要求重新新增

#### Scenario: 失败后可重试

- **WHEN** 用户排除端口占用后对失败端口重试开启
- **THEN** 端口开始监听，状态变为「监听中」，错误提示消失

#### Scenario: 无日志不是失败

- **WHEN** 端口监听中但设备尚未推送任何日志
- **THEN** 状态为「监听中」，日志查看给出「暂无日志」可读结论，MUST NOT 提示监听失败
