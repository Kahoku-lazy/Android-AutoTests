## Goals / Non-Goals

**Goals:** 颜色原子 198 → 98 · 序号兜底名归零 · alpha 只留 6 档 · 门禁冻结增长 · 映射 ΔE 可查。
**Non-Goals:** 不改非颜色档（排版 / 基础量 / `--comp-*` 数量）· 不改别名层的名字（消费点零改动）· 不动模块 T1 的场景令牌名。

## Decisions

### D1 · 收敛到「ΔE≤8 + 最小间隔≥4」的调色板
对 161 个唯一 RGB 做**直径上限凝聚聚类**（阈值 8，质心 = 成员加权均值），再做一遍**最小间隔**过滤（任意两基色 ΔE ≥ 4，避免出现明度只差 1 的近邻档）→ **73 个基色**（含锚点）。

### D2 · 13 个锚点不参与合并
`--color-white` / `--color-black` / `--paper`(= `--color-yellow-95-s100-4`) / `--ink`(= `--color-ink-15`) / `--dot`(= `--color-yellow-80-s25`) / 8 个模块色取值（`--color-yellow-65` `--color-green-60-s50` `--color-violet-75-s100` `--color-cyan-55` `--color-red-85-s100` `--color-ink-45-2` `--color-purple-75` `--color-blue-75-s75`）。

理由：它们决定主区**纸面底色**与**模块标识色**，虽然多数与近邻的 ΔE 在预算内（如 `#fffef5` 与纯白 ΔE≈1.5），但被吸收后整页观感会变（暖白纸面变纯白、站点标识色偏移）。锚点仍然**接收**近邻成员（吸收 44 个旧原子），只是自己不被反向吸收。

代价：比无锚点方案多约 10 个原子（88 → 98）。

### D3 · alpha 从 30 档收敛到 6 档
`1 / 0.6 / 0.3 / 0.18 / 0.1 / 0.05`。映射后分布：1×154 · 0.3×11 · 0.18×10 · 0.1×9 · 0.6×7 · 0.05×7。
只剩 **55 个旧原子带 alpha<1**，标准化后 alpha 变体从 45 条降到 25 条。

### D4 · 命名
`--color-<色相>-<明度 2 位>[-s<饱和>][-a<alpha 2 位>]`；12 色相族 + 中性 `ink`；**序号兜底名归零**（同色相同明度若仍需两个饱和度，用 `-s<S>` 区分，实测只有 1 处需要）。

### D5 · 别名层与 `--comp-*` 只重指向
121 条兼容别名 + 44 条 `--comp-*` 的名字**全部保持不变**，只把 `var(旧原子)` 改成 `var(新原子)` → 所有「引用别名」的消费点零改动；只有直接引用 `--color-*` 的消费点需要重命名。

## Risks / Trade-offs

- [色差可见] → 最大 ΔE 7.62、93 行 ΔE>3；「预算曲线」可按需换阈值（ΔE≤5 → 111 原子，ΔE≤12 → 67 原子），阈值一旦调整需重跑映射与门禁上限
- [淡色背景类观感变化最大] → 映射表已标出 top-10，逐页复核时优先看纸面 / 卡片 / 空态
- [低 alpha 叠加色换底色后观感变化] → alpha 标准化会改动 55 个带透明度的原子，阴影 / 遮罩 / hover 底色需目视确认
- [锚点选择带主观性] → 已列出 13 个并写明理由；若还有必须保留的颜色，加入锚点后总数会增加（每多一个锚点最多 +1 基色）
- [无浏览器] → 第 5.2 步必须由人在真机核对，本环境只能做静态核验（门禁 + 类型 + 值等价表）
- [回滚] → 以 `tokens.css` 为单点（其余为名称机械替换），可整文件回退

## Migration Plan

1. 复核 `temps/palette-mapping.md`（198 行）并确认阈值 / alpha 档数 / 锚点
2. 重写 `tokens.css` 颜色原子（198 → 98），别名层与 `--comp-*` 重指向
3. 按映射表重命名全仓 `var(--color-*)`（含注释指引）
4. 门禁加「调色板白名单 + 数量上限 + 禁序号名」并做反例注入
5. 回归：`npm run lint:styles` · `verify-colors.ps1` · `vue-tsc`
6. 逐页浏览器复核；归档
