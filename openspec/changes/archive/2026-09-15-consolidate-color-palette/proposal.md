## Why

T0 主 token 的**颜色原子已膨胀到 198 个**，但这 198 个并不是一套调色板，而是「全站出现过的字面量色值」的登记台账。实测构成：

- **161 个唯一 RGB 色值**（21 个页面 ≈ 每页 7.7 种颜色）
- **30 个不同的 alpha 取值**（0.03 / 0.04 / 0.05 / 0.06 / 0.08 / 0.1 / 0.12 … 0.85），把 161 撑到 198
- **39 个序号兜底名**（`-2`…`-9`）掩盖「同名不同色」，其中 22 组 ΔE>3 肉眼可辨（最大 21.8，如 `--color-blue-65-s50` #6c80d4 与 `--color-blue-65-s50-2` #6f9fd8 本是两种颜色）
- **77 个原子在 tokens.css 之外零引用**、8 个完全零引用；全仓引用仅 **252 次**，平均每个原子被引用 1.27 次

门禁 G1 保证「同值只登记一次」，所以**原子数 = 全站真实用色数**。要把 198 降下来只能改颜色本身：按感知聚类（CIE76 ΔE ≤ 8）合并近邻、把 alpha 标准化到 6 档。

## What Changes

- 颜色原子 **198 → 98**（基色 73 + alpha 变体 25，↓51%）；映射 ΔE **最大 7.62 / 平均 2.64**
- alpha 从 30 档收敛到 **6 档**（1 / 0.6 / 0.3 / 0.18 / 0.1 / 0.05）；序号兜底名 **归零**
- **13 个锚点原子不参与合并**（纸面 `--paper`、墨色 `--ink`、点阵 `--dot`、8 个模块色 `--c-*` 的取值，以及纯白 / 纯黑）——它们决定主区纸面与模块标识，差一点就会整页观感变化
- 兼容别名层（121 条）与 `--comp-*`（44 条）**名字不变**，仅重新指向新原子 → 消费点零改动
- 直接引用颜色原子的消费点按映射表重命名（机械替换）
- 门禁升级：颜色原子 **只降不增 + 调色板白名单 + 数量上限**，新增调色板外的色值即失败
- 完整新旧映射表：`temps/palette-mapping.md`（198 行，含每行 ΔE）
