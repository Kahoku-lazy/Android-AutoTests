## ADDED Requirements

### Requirement: 新建任务必须填写独立标题
系统 SHALL 在任务提交表单中提供独立的「任务标题」字段；标题 MUST 非空。系统 MUST NOT 再用任务目标截断值充当提交标题。

#### Scenario: 标题缺失拒绝提交
- **WHEN** 用户未填写任务标题即提交
- **THEN** 系统拒绝创建任务并提示标题为必填

#### Scenario: 标题与目标分别落库
- **WHEN** 用户填写标题「校准色温」与目标「把滑块拖到最左」后提交成功
- **THEN** 任务记录的标题为「校准色温」，目标为「把滑块拖到最左」

### Requirement: 任务附件为 Word 或 PDF 并解析为 Markdown
系统 SHALL 允许用户在新建任务时上传至多一份附件，类型限于 `.docx` 与 `.pdf`。上传成功后系统 MUST 将文件解析为 Markdown 文本并随任务持久化。解析失败 MUST 拒绝创建任务并返回可读错误。未上传附件时 MUST 将附件文本存为空字符串。系统 MUST NOT 再把「路径/URL 字符串」当作附件语义。

#### Scenario: 上传 PDF 后得到 Markdown
- **WHEN** 用户在新建任务中上传一份可提取文本的 PDF 并提交成功
- **THEN** 任务持久化的附件文本为解析得到的 Markdown，且规划入参中的「附件文本内容」等于该 Markdown

#### Scenario: 不支持的附件类型被拒绝
- **WHEN** 用户上传 `.xlsx` 或其它非 `.docx`/`.pdf` 文件
- **THEN** 系统拒绝创建任务并提示仅支持 Word 与 PDF

#### Scenario: 无附件时附件文本为空
- **WHEN** 用户不上传附件且标题、目标合法并提交成功
- **THEN** 任务创建成功，附件文本为空字符串

## MODIFIED Requirements

### Requirement: 任务卡片提交
系统 SHALL 允许用户通过任务卡片入口提交一条设备控制任务。提交表单 MUST 包含任务标题（必填）、任务目标（必填）、可选附件文件、可选设备。设备留空时系统 MUST 在提交时解析为当时第一台在线设备并写入任务记录；若当时无在线设备 MUST 拒绝创建。

#### Scenario: 提交控制设备任务
- **WHEN** 用户填写任务标题与任务目标并提交
- **THEN** 系统创建任务记录，标题与目标分别保存，并进入按设备调度的执行流程

#### Scenario: 任务目标缺失
- **WHEN** 用户未填写任务目标即提交
- **THEN** 系统拒绝提交并提示任务目标为必填

#### Scenario: 未指定设备且无在线设备
- **WHEN** 用户未选择设备且当前没有在线设备
- **THEN** 系统拒绝创建任务并说明无可用设备

### Requirement: 新建任务设备下拉与设备管理列表同步
系统 SHALL 在「新建任务」弹窗打开时立即拉取当前设备列表。弹窗保持打开期间 MUST 按与设备管理心跳相同的间隔（30 秒）再次拉取 `GET /devices`，使设备管理已检测到的设备出现在下拉选项中。弹窗关闭 MUST 停止轮询。系统 MUST NOT 为此新开 WebSocket。

#### Scenario: 打开弹窗立即刷新设备选项
- **WHEN** 用户打开新建任务弹窗
- **THEN** 设备下拉展示当时 `GET /devices` 返回的设备

#### Scenario: 弹窗打开期间新设备进入下拉
- **WHEN** 新建任务弹窗保持打开，且设备列表在一轮轮询后新增一台设备
- **THEN** 该设备出现在设备下拉选项中

#### Scenario: 关闭弹窗停止轮询
- **WHEN** 用户关闭新建任务弹窗
- **THEN** 系统停止对该弹窗的设备列表轮询

### Requirement: 任务列表与详情
系统 SHALL 提供任务列表与详情。列表卡片 MUST 展示任务标题、状态、创建时间与设备名称（有型号则展示型号，否则展示设备 serial），MUST NOT 把任务目标作为卡片正文。详情页 MUST 仍可查看任务目标、执行状态与执行日志。

#### Scenario: 查看任务详情
- **WHEN** 用户打开某任务详情
- **THEN** 系统展示该任务的标题、目标、设备、执行状态与执行日志

#### Scenario: 列表卡片不展示任务目标正文
- **WHEN** 用户在任务卡片列表查看一条已创建任务
- **THEN** 卡片可见标题、状态、创建时间与设备名称，不可见任务目标全文
