## MODIFIED Requirements

### Requirement: 元素表横向滚动可用与首列冻结

元素表列宽合计超过所在栏宽时，MUST 横向滚动且 MUST NOT 压缩列宽至内容不可读；横向滚动 MUST 由元素表自身的横向滚动容器承载（外层容器只负责定高，MUST NOT 再叠加第二条横向滚动条），该滚动容器 SHALL 支持按住拖拽平移；首列（选择 / 缩略图 / 元素名称）MUST 左侧冻结，横向滚动时保持可见。冻结单元格 MUST 有不透明底色，斑马纹 / 悬停 / 行选中态下 MUST NOT 透出下层内容。

#### Scenario: 拖拽平移

- **WHEN** 用户在元素表空白处按住并左右拖动
- **THEN** 表格随拖动横向平移，松手后停在当前位置

#### Scenario: 首列冻结

- **WHEN** 表格横向滚动到最右
- **THEN** 选择列、缩略图列与元素名称列仍可见（位置不动），其余列正常滚动
- **AND** 该横滚发生在元素表自身的横向滚动容器上，外层容器不出现横向滚动条

#### Scenario: 冻结列底色不透明

- **WHEN** 冻结列所在行处于斑马纹 / 悬停 / 选中任一状态
- **THEN** 冻结单元格底色与该行状态一致且完全不透明（不出现下层列内容透出）

### Requirement: 元素表列宽与间距集中登记

元素表的列宽与面板内间距 MUST 集中登记：列宽与表格最小宽来自模块 `constants.ts`；面板内间距按刻度分层登记——**不在 T0 间距刻度（4 / 8 / 16 / 24 / 32 / 48）上的取值**来自模块 `tokens.css` 的 `--insp-*` 令牌，**落在 T0 刻度上的取值**引用共享 `--app-space-*` 令牌。组件样式与列声明 SHALL NOT 再出现这些值的裸字面量（已登记的硬边几何 `2px`、缩略图边长等固定尺寸除外）。

#### Scenario: 组件内无列宽与间距字面量

- **WHEN** 检索 `StructureAnalysisPanel.vue` 的列声明与样式的间距声明
- **THEN** 列宽引用 `constants.ts` 的宽度常量；非 T0 刻度间距引用 `--insp-*` 令牌，T0 刻度间距引用 `--app-space-*` 令牌
- **AND** 不出现 `gap: 10px` / `padding-bottom: 10px` / `padding: 0 8px` / `min-height: 38px` 一类裸值

#### Scenario: 登记后的视觉与登记前一致

- **WHEN** 对比登记前后元素表面板的计算样式
- **THEN** 分页栏高度、面板列间距、筹码间距与内边距的像素值均未改变
