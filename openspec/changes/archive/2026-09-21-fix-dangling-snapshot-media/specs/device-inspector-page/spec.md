## ADDED Requirements

### Requirement: 失效媒体降级显示

当手机屏幕的截图或元素缩略图的文件已不存在（加载失败）时，界面 MUST 降级为可读的空态 / 占位表达，MUST NOT 留下空白区域或浏览器破图图标；该降级表达 MUST 与「本来就没有媒体」区分开，使用户知道这是资产已失效而非从未抓取。

#### Scenario: 截图失效降级为失效空态

- **WHEN** 用户回看一个已保存页面，其截图文件已不存在
- **THEN** 手机屏幕显示失效空态与说明（MUST NOT 只显示空白）
- **AND** 该提示与「暂无页面快照」的文案不同

#### Scenario: 缩略图失效显示占位符

- **WHEN** 元素表格某行的缩略图文件已不存在
- **THEN** 该格显示占位符（—），MUST NOT 显示破图图标

#### Scenario: 放大预览失效仍有占位

- **WHEN** 用户打开一个缩略图已失效的行的放大预览
- **THEN** 预览区显示占位提示
- **AND** 名称 / Class / ID / Desc / Bounds / 分区 / 指标字段照常显示
