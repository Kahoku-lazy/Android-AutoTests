## Context

见 proposal.md - Why。现行主规格仍要求设备选择天蓝底、元素表每页 8 行。工作区里设备选择皮肤、分页常量与空表高度已经按新外观改过，但行点击仍会选中元素并画红框，且单击「元素名称」也会选中。本设计把实现收到规格的最终手势上。

## Goals / Non-Goals

**Goals:**

- 设备选择触发键与下拉浮层为白底、无阴影
- 元素表每页 7 行，表头全选只覆盖当前这 7 行
- 空表表纸锁在结构栏高度内，空态文案可见
- 单击「元素名称」只重命名；只有双击「标识」才在手机截图上画红框

**Non-Goals:**

- 不改抓取、分区算法或保存接口
- 不取消手机截图上的单击命中（点屏幕上的元素仍可选中并画红框）
- 不改分区筹码的天蓝 / 柠黄，也不改工具条其它按键的天蓝 / 灰键
- 不提供「显示行数」选择器

## Decisions

1. **分页只改模块常量。** `PAGE_SIZE_OPTIONS` 与 `DEFAULT_PAGE_SIZE` 改为 `[7]` / `7`。页面继续把这两个常量交给共享分页，不在页面里写行数字面量。备选「在页面写死 7」会和「选项集必须来自模块常量」冲突，不采纳。

2. **设备选择白底写在页面作用域，浮层用 popper class。** 触发键在检查器页面内覆盖底色与阴影。下拉默认挂到 body，页面作用域够不到，所以选择控件带一个专用 popper class，只把该浮层设为白底、无阴影。备选「改全局下拉皮肤」会波及其它页面，不采纳。

3. **空表高度锁在表体容器里。** 表纸高度取结构栏剩余高度，并盖掉空数据块上那条会随自身滚动高度增长的内联高度，避免表纸被撑出屏幕。备选「空态时去掉表格高度」会让表纸缩成一条，和有数据时的栏高不一致，不采纳。

4. **红框只由双击「标识」触发。** 去掉表格行单击对选中态的写入；「元素名称」的单击保持只进入重命名，不再写入选中态。在「标识」单元格上监听双击，写入当前选中元素。截图按选中元素的坐标画一个红色区域，画在其它框线之上。宽或高为 0 时不画。备选「保留单击整行高亮，仅禁止名称列」仍会让单击「标识」画红框，和「双击才画」冲突，不采纳。

## 模块防火墙自检

- 不新增跨 App import，不写库，不改 API
- 改动只在 `frontend/src/modules/device-inspector` 的页面与两个展示组件，以及本变更的 OpenSpec 文档
- 前端不直连数据库；仪表盘无写操作

## Risks / Trade-offs

- [单击整行不再画红框，和部分用户已经试过的单击行为不同] → 规格与界面提示以双击「标识」为准；手机画面上的单击命中仍可用
- [空数据块的内联高度仍会被组件库写上] → 用更高优先级的高度把它限制在表体里，避免再次撑高表纸
- [主规格里「固定 8 行」与「触发键天蓝底」在归档前仍是旧文] → 本变更用 delta 替换，归档时再写入主规格
