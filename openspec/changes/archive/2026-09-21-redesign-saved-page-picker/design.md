## Context

选择器在 `SavedPagePicker.vue`：`el-dialog` 宽 560px，标题是一整句，内容是 `el-tree`。节点模板把名称和「包名 · 元素 N」放在同一个横向 flex 里，树节点默认只有一行高，所以两者连成一句。外壳已经走全局对话框皮肤，不必另做弹层。快照列表用的是名称一行、说明一行。打开页面仍走现有只读回看，见 specs。

## Goals / Non-Goals

**Goals:**

- 短标题加单独的「只读」标记
- 页面节点两行：名称，其下包名与元素数
- 目录节点加粗并带目录图标，没有第二行元信息
- 目录下的页面与子目录相对父目录缩进，多层再缩进
- 颜色与圆角只用已有令牌

**Non-Goals:**

- 不换掉 `el-dialog` / `el-tree`，不新做一套弹层
- 不改 `apiGetPages`、不改打开页面后的表格与截图
- 不加搜索、删除、重命名，不改快照抽屉和保存弹窗

## Decisions

1. **继续用树，不改成平铺列表。** 数据是目录套页面。树已经会按层级缩进；改节点内容后必须保留 `el-tree` 的缩进，不能把子节点拉回与目录左缘对齐。备选「递归 div」放弃，避免重写展开状态。
2. **节点改成纵向两行，并抬高树行。** 自定义节点用纵向 flex：第一行名称（超出省略），第二行仅页面显示包名与元素数。覆盖树内容行的最小高度和对齐，避免第二行被一行高裁掉。悬停用 `--app-highlight`，边框用 `var(--ink)`，与快照条目同一套纸面，不新发明配色。缩进仍由树的 padding / indent 承担，本弹窗不得把子节点的左缘清零。
3. **标题用对话框 header 插槽。** 文案「已保存页面」，旁边一个「只读」标记。标记用现有标签或令牌色，不写死色值。
4. **点击行为不动。** 页面节点仍打开只读回看并关闭弹窗；目录节点仍只展开或收起。空态文案保持「暂无已保存页面」。

## 模块防火墙自检

- 只改检查器前端这一个弹窗的模板和样式
- 不新增跨 App import，不写库，不改 `api.py`
- 页面列表仍走现有的元素定位读取接口

## Risks / Trade-offs

- [树行高被组件默认一行高裁切] → 只抬高本弹窗内的树内容行，不改全局树样式
- [目录和页面看起来仍一样] → 目录加粗、带图标、不渲染第二行；页面才有包名和元素数
- [改节点内容后子项看起来与目录齐平] → 保留 `el-tree` 层级缩进，不覆盖子节点左 padding
