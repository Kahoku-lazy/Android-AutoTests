## Purpose

定义设备检查器的元素分层查询契约：把一份快照的全量节点按两级分组组织后提供给前端，并支持按分组、交互标志与关键词筛减，使前端只需渲染、不必自带分组与筛选逻辑。

## ADDED Requirements

### Requirement: 分层查询返回两级分组摘要

查询一份快照的分层数据时，系统 MUST 返回两级分组摘要：一级为布局容器、滚动·集合容器、内容控件、其它（不属于以上三类的）；二级 MUST 仅对「内容控件」给出，为文本、图标、其它。每个分组 MUST 携带元素数、被展示裁剪保留数、主定位稳定数、可点击数与可滚动数；「其它」分组在一级与二级中 MUST 如实存在（计数可为 0），MUST NOT 被省略。

#### Scenario: 返回五个有效分组与一个兜底分组
- **WHEN** 查询一份快照的分层数据
- **THEN** 响应含一级四个分组，其中「内容控件」下含文本/图标/其它三个二级分组
- **AND** 每个分组带元素数、保留数、稳定定位数、可点击数、可滚动数

#### Scenario: 兜底分组计数为 0 也如实出现
- **WHEN** 没有任何节点的类名落在三类集合之外
- **THEN** 一级「其它」分组仍然出现在响应中且计数为 0

### Requirement: 分层查询返回元素条目

分层数据中的每个元素条目 MUST 携带：坐标顺序序号、屏幕像素坐标（左上角、宽、高、中心点、原始 bounds 文本）、控件类名、资源标识、文本、内容描述、父内序号、层级深度、七项交互标志、是否被展示裁剪保留、细类，以及主定位（定位表达式、类型、匹配数、是否稳定）。同一分组内条目 MUST 按坐标顺序排列（顶边 y 升序，同 y 再 x 升序，同坐标再按层级深度升序）。被展示裁剪丢弃的元素 MUST 与保留元素一同返回。响应 MUST NOT 携带每个元素的候选定位列表（候选不在列表契约内，需要时另行按元素查询），以免形成第二处「由调用方自行挑选定位」的口径。

#### Scenario: 条目字段完整
- **WHEN** 读取任一元素的条目
- **THEN** 其含坐标、类名、标识、文本、内容描述、七项交互标志、保留标记、细类与主定位

#### Scenario: 分组内按坐标顺序
- **WHEN** 读取任一分组的元素列表
- **THEN** 列表按 (顶边 y, 左边 x, 层级深度) 升序排列

#### Scenario: 被裁元素一并返回并带标记
- **WHEN** 快照中存在被展示裁剪丢弃的元素
- **THEN** 它们在对应分组中返回，且保留标记为假

#### Scenario: 响应只给一条主定位
- **WHEN** 读取任一元素的条目
- **THEN** 它含一条主定位（表达式、类型、匹配数、是否稳定）
- **AND** 不含该元素的候选定位列表

### Requirement: 分层查询支持筛减

分层查询 MUST 支持以下筛减参数，且 MUST 可组合使用：一级分组、二级分组（仅当一级为内容控件时）、交互标志（可点击/可长按/可滚动，可多选）、关键词（对文本、资源标识、内容描述、类名做忽略大小写的子串匹配）、是否仅保留元素、是否仅主定位稳定元素、分页（偏移与条数）。响应 MUST 给出「命中的总条数」与本次返回的区间，使前端分页与计数一致。传入非法参数值（未知的一级或二级分组、非数值的分页参数）时 MUST 返回 400 与可读消息，MUST NOT 静默忽略。

#### Scenario: 按分组筛减
- **WHEN** 指定一级分组为「内容控件」且二级为「图标」
- **THEN** 仅返回该二级分组内的元素，且命中总数为该组元素数

#### Scenario: 按交互标志与关键词组合筛减
- **WHEN** 同时指定「可点击」标志与一个关键词
- **THEN** 仅返回同时满足两个条件的元素

#### Scenario: 分页与总数一致
- **WHEN** 指定偏移与条数
- **THEN** 返回该区间的元素，且命中总数等于筛减后的总条数（与区间无关）

#### Scenario: 非法参数被拒绝
- **WHEN** 传入未知的一级或二级分组，或不可解析的分页参数
- **THEN** 返回 400 与可读消息，且 MUST NOT 返回被静默忽略后的结果

### Requirement: 分层即时计算不落库

分层结果 MUST 在查询时由全量节点索引即时计算得出，MUST NOT 落库为独立表或独立字段，以避免与节点索引形成两处真相源。查询 MUST NOT 触发任何设备交互。

#### Scenario: 同一快照多次查询结果一致
- **WHEN** 对同一份快照连续查询两次相同的筛减条件
- **THEN** 两次返回的分组计数与条目内容一致

#### Scenario: 查询不访问设备
- **WHEN** 执行分层查询
- **THEN** 不建立设备连接，查询在无设备在线时同样成功

### Requirement: 历史快照降级可读

对于在全量节点索引引入之前产生的快照（无索引数据），分层查询 MUST 降级为「仅保留元素集」，MUST NOT 报错，并 MUST 在响应中如实标注数据来源为降级集（前端据此提示条目不完整）。降级集内的元素 MUST 同样带保留标记（真）与分组信息。

#### Scenario: 无索引的历史快照仍可查询
- **WHEN** 查询一份没有全量节点索引的历史快照
- **THEN** 返回该快照展示保留集的分层结果，并在响应中标明数据来源为降级集

#### Scenario: 降级集不伪造被裁元素
- **WHEN** 历史快照降级返回
- **THEN** 响应中 MUST NOT 出现保留标记为假的元素（索引缺失，无法得知被裁元素）

### Requirement: 快照不存在时如实报错

查询不存在的快照或不属于当前调用者的快照时，系统 MUST 返回 404 与可读消息。

#### Scenario: 快照不存在
- **WHEN** 查询一个不存在的快照 ID
- **THEN** 返回 404 与可读消息
