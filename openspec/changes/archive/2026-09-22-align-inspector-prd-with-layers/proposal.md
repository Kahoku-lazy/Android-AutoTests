## What Changes

1. **「结构分析」节重写为「元素分组（分层查询）」**（产品功能一节 + 测试一节）：左栏分组列表与分组徽标、元素表列集合、14 行分页、分组联动、双击/单击缩略图两种写入选中、分层查询的筛减参数与响应字段。
2. **页面骨架节**去掉筛选栏与「页面分区列」，改为左栏分组列表；同步更新骨架常驻清单、响应式折行与样式指针。
3. **快照相关节**：保留上限 100 → 10；删除已不存在的「已显示最近 N 条」提示；补「一键清空」与二次确认；「回看」改为取分层数据。
4. **回看态 / 删除态 / 复位**的口径从「分区」改「分组」，并如实记录回看态调分层端点（当前实现）。
5. **测试一节**刷新为当前资产清单（前端 P0 四个文件 / 灰盒单元 + 集成文件 / 接口 YAML 14 条），并更新「怎么跑这些测试」与「附录：已知缺口」。
