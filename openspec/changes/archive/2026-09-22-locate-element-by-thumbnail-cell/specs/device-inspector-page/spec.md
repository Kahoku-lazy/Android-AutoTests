## MODIFIED Requirements

### Requirement: 手机画面按当前分组圈选并保留选中高亮

手机截图 MUST 常驻显示当前分组的全部元素框：被展示裁剪保留的元素 MUST 用实线描边，被展示裁剪丢弃的元素 MUST 用虚线描边，两者 MUST 使用同一分组色并可在视觉上区分。画面 MUST NOT 画出非当前分组元素的框。单击「元素名称」MUST 只进入该格的重命名，MUST NOT 改动画面上的选中高亮。**左键单击「缩略图」列 MUST 选中该元素并在画面上画出红色描边与淡红色填充**，使不依赖文本即可定位该行对应的框；该格的点击目标 MUST 是**整格**（含该列为空占位的情形），且该格 MUST NOT 因此进入重命名或改动勾选。单击其余单元格（包括单击「标识」）MUST NOT 画出或改动选中高亮。左键双击表格数据格（「标识」「元素」「指标」「XPath」「bounds」，以及该格内文字上下的空白）时，系统 MUST 在该元素坐标处画出红色描边并填入淡红色，以与分组框区分。双击「元素名称」「勾选」或「缩略图」MUST NOT 画出或改动选中高亮。再次双击另一行时红色高亮 MUST 移到新元素，同一时间只保留一个。坐标宽或高为 0 的元素 MUST NOT 画出可见的框或高亮。

#### Scenario: 分组框常驻且线型区分保留与被裁

- **WHEN** 快照截图已显示且已载入分层数据
- **THEN** 当前分组的每个元素都在其坐标处出现分组色框
- **AND** 被展示裁剪保留的元素为实线，被丢弃的元素为虚线

#### Scenario: 切换分组只换框集合

- **WHEN** 用户从分组 A 切到分组 B
- **THEN** 画面上只保留分组 B 的元素框，分组 A 的框全部消失

#### Scenario: 双击标识画出选中的红色高亮

- **WHEN** 快照截图已显示，用户双击某一行的「标识」，且该元素宽和高都大于 0
- **THEN** 手机截图上该元素坐标处出现红色描边与淡红色填充，与分组框并存且可区分

#### Scenario: 单击元素名称只重命名

- **WHEN** 用户单击某一行的「元素名称」
- **THEN** 该格进入重命名
- **AND** 画面上的分组框与红色选中高亮保持点击之前的状态

#### Scenario: 零宽高元素不画框

- **WHEN** 当前分组内存在宽或高为 0 的元素
- **THEN** 画面不为它画出可见的框或高亮

#### Scenario: 单击缩略图列高亮对应矩形框

- **WHEN** 快照截图已显示，用户左键单击某一行的「缩略图」列
- **THEN** 该元素在画面上的坐标处出现红色描边与淡红色填充，与分组框并存且可区分
- **AND** 该行呈选中态，且该格 MUST NOT 进入重命名、MUST NOT 改动勾选

#### Scenario: 缩略图列为空占位时同样可定位

- **WHEN** 该行的缩略图没有数据（该格显示占位）
- **THEN** 单击该格仍按上一 Scenario 高亮该元素对应的矩形框（点击目标是整格，不是图片）
