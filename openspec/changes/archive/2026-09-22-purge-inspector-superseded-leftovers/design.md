## Context

- 排查方式与证据见 `proposal.md` 的 Why 表；三个候选的引用计数均由脚本在 `frontend/src` + `frontend/tests` 全量统计，并用 `grep` 手工复核。
- **列集合现状**：`StructureAnalysisPanel.vue` 的 `COLUMN_SPECS` 15 列与模板 15 个 `#cell-*` / `#header-*` 插槽一一对应（脚本比对：无多余插槽、无缺插槽）；`.sap-label-hit` 是唯一「CSS 定义但模板从不出现」的模块类。
- **令牌登记口径**：`device-inspector/tokens.css` 的注释自称「本模块的间距与固定尺寸唯一登记处」，此前只校验「引用完整」（用到的令牌必须存在），未校验反向（登记的令牌必须被用到）。
- **自检钩子的来历**：`ScreenshotView.vue` 的注释写「自检用：可见层最近一次绘制的矩形数（fillRect + strokeRect），与分组规模无关」；归档变更 `rework-inspector-layers-view` 的 tasks 3.2 记明「浏览器内点击走查未执行」，该走查从未落地。

## Goals / Non-Goals

**Goals:**

- 让「被需求变更替代的代码」不再留在样式 / 令牌 / 测试钩子三处。
- 删除**运行时零变化**，可静态证明（选择器永不匹配、令牌无 `var()`、钩子无读者）。

**Non-Goals:**

- 不做命名重构（`sap-sections` → 分组语义）—— 属重命名，会牵动模板与 CSS，另议。
- 不动冻结链路与其它模块的既有死令牌。
- 不为这三处新建守护门禁（见 Open Questions）。
- 不改规格。

## Decisions

**D1 直接删除，而不是留着或注释掉。** 依据：三者都无任何消费者，且第 1 项的类**从未被挂上元素**、第 2 项无 `var()`、第 3 项无读者 —— 保留它们只会让下一个人以为有对应功能（第 1 项的注释本身就误导：它描述的「标识」列早已不存在）。备选：加 `/* 已废弃 */` 注释保留 → 否决（死代码 + 死注释，比死代码更误导）。

**D2 删 `.sap-label-hit` 时保留紧邻的 `td:has(.sap-thumb-cell)` 规则。** 依据：那条服务于**当前**的缩略图列定位层（本会话刚加的），注释与规则都在用。备选：整块删掉避重就轻 → 否决（会打断缩略图单击定位的定位基准）。

**D3 一并删掉 `rectCalls` 计数，而不是只删 `defineExpose`。** 依据：`let rectCalls = 0` 与两处 `+= 2` 的唯一用途就是喂给那个从没被读过的 ref；留着计数等于保留一个没人看的计量器。备选：只删导出、保留计数 → 否决（无消费者的计量是纯噪声与微小运行时开销）。

**D4 本次不引入「模块令牌必须被引用」的门禁。** 依据：该门禁一旦加，会立刻把 `ai-assistant` 19 个 `--ai-status-*` 与 `workflow` 20 个 `--ac-*` 一起扫成红；要么本次顺带清掉那 39 个（超出用户批准的范围），要么按仓库既有做法登记「存量清单只降不增」——那是门禁变更，属独立一单。备选：现在就加上限清单 → 否决（把一单清理变成一单工具链改动）。**已登记为 Open Question。**

**D5 同步修 `--insp-gap-row` 上方那句消费点枚举。** 依据：那句写「行内间距（工具条 / 筛选栏 / 分页栏）」，而筛选栏已删；本次恰好在同一文件同一区块删它的令牌，留着会让「筛选栏」这个词永久留在令牌文件里。备选：不动 → 否决（同一清理动作的半成品，且该词是本轮已消失的能力）。

## 模块防火墙自检

- **前端 HTTP 出口**：零改动。
- **共享件 / 全局主题 / 其它模块**：零改动。
- **后端 / 规格 / DB**：零改动。

## Risks / Trade-offs

- [删的其实是「隐式依赖」] → 已用三种静态证据互证：`grep` 全仓（含 tests）命中 0、模板/插槽比对无多余类、`git grep HEAD` 与归档变更记录说明来历；另外 `defineExpose` 的消费者只可能是测试或父组件，两者都搜过。
- [`.sap-label-hit` 的 `td:has()` 规则可能被「同名的其它类」命中] → 不会：`:has(.sap-label-hit)` 要求后代带这个类名，而全仓无任何元素挂它。
- [将来要做「标识列整格双击」时需重建这段样式] → 那是新需求，按当时的列集合重写比复活一段与旧列绑定的选择器更干净。
- [删除令牌后 `lint:styles` 的批 3「非样式表载体」统计变化] → 属预期（声明数减少）；执行时逐批核对输出，确认五批仍全过。
