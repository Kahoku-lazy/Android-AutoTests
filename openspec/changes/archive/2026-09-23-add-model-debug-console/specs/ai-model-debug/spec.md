## Purpose

在 AI 工具箱里为平台智能体的规划 / 执行 / 验收三个模型各提供一个只读的调试台：如实展示该角色此刻生效的提示词、模型连接与工具子集，并允许用对话框对单个角色发起一次真实调用，以确认提示词修改是否生效——不改动装配、不触碰真机、不消耗工具。

## ADDED Requirements

### Requirement: 工具箱提供模型调试入口

系统 SHALL 在 AI 工具箱「工具来源」提供「模型调试」入口，且该入口 MUST NOT 绑定「交给助手」总闸。选中后右侧 MUST 展示规划 / 执行 / 验收三个模型入口。点击任一入口 MUST 进入该角色的调试子页，子页正文顶部 MUST 提供回到工具箱的可见回退。

#### Scenario: 选中模型调试来源

- **WHEN** 用户点击工具箱左侧「模型调试」
- **THEN** 右侧出现规划模型 / 执行模型 / 验收模型三个入口

#### Scenario: 进入某角色调试子页

- **WHEN** 用户点击「执行模型」入口
- **THEN** 进入执行模型的调试子页，页内可见角色名与回到工具箱的控件

### Requirement: 调试页展示该角色实际生效的配置

调试子页 MUST 展示该角色的系统提示词（Markdown 渲染）、模型连接（provider、model_name、是否视觉）、以及该角色的工具子集（每个工具名 + 只读/写标记 + 是否被平台停用）。工具清单 MUST 与该角色实际装配一致：规划模型为页面流工具、执行模型为视觉/设备操作工具集、验收模型为截图校验工具。MUST NOT 展示 api_key、base_url 明文等敏感字段。

#### Scenario: 三个角色的工具清单各不相同

- **WHEN** 分别打开规划 / 执行 / 验收三个调试子页
- **THEN** 三页的工具清单按各自子集展示（规划为页面流工具、执行为视觉工具集、验收为截图工具）
- **AND** 执行模型页标注该角色使用视觉模型

#### Scenario: 不泄漏密钥

- **WHEN** 打开任一角色调试子页
- **THEN** 页面与接口响应都不出现 api_key 明文

### Requirement: 技能与知识库展示须标注真实归属

调试子页 MUST 展示当前启用的技能清单，并 MUST 明示这些技能为三模型共用（MUST NOT 让用户以为按角色分配）。MUST 展示智能体启用的知识库来源清单，并 MUST 明示当前设备执行链路未挂载 RAG（MUST NOT 让用户以为该角色正在使用知识库）。

#### Scenario: 技能区块标注共用

- **WHEN** 打开任一角色调试子页
- **THEN** 技能区块可见「三模型共用」这类明确标注

#### Scenario: 知识库区块标注未挂载

- **WHEN** 打开任一角色调试子页
- **THEN** 知识库区块可见「执行链路当前未挂载 RAG」这类明确标注

### Requirement: 单角色调试对话

系统 SHALL 允许超级管理员对单个角色发起一次调试对话，使用该角色的系统提示词与模型连接。该对话 MUST NOT 挂载或调用任何工具，MUST NOT 触发真机操作。对话 MUST NOT 落库到会话 / 消息表。单次请求超时 MUST 为 5 分钟。回复 MUST 展示给用户，失败时 MUST 给出可读错误。

#### Scenario: 改完提示词后对话验证

- **WHEN** 超管把规划提示词改成要求「回答必须以 PLAN-OK 开头」，然后在规划模型调试页发问
- **THEN** 回复体现新提示词的要求（说明该角色的提示词确实生效）

#### Scenario: 对话不产生会话记录

- **WHEN** 超管在任一角色调试页完成一次对话
- **THEN** 会话表与消息表不新增记录

#### Scenario: 对话不触碰真机

- **WHEN** 超管在执行模型调试页发起对话
- **THEN** 不产生任何设备操作（工具未挂载）

### Requirement: 调试能力仅超级管理员可用

模型调试配置读取与调试对话 MUST 仅超级管理员可用；非超级管理员的请求 MUST 返回 403 且 MUST NOT 触发模型调用。模型连接不完整（provider / model_name / api_key 任一为空）时 MUST 返回可读 4xx 错误，MUST NOT 返回空回复。

#### Scenario: 非超管被拒

- **WHEN** 非超级管理员请求角色调试配置或发起调试对话
- **THEN** 返回 403，且不产生任何模型调用

#### Scenario: 模型未配置时给出可读错误

- **WHEN** 超管对某个尚未配置 model_name 的角色发起调试对话
- **THEN** 返回 4xx 与可读错误（指出该角色模型未配置），而不是空回复
