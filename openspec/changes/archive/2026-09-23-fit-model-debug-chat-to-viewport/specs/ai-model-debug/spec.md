## ADDED Requirements

### Requirement: 调试对话栏整体不超出首屏

调试子页的对话栏 MUST 整体落在首屏之内：其高度 MUST NOT 超过「视口高度 − 页头高度 − 面包屑与页面内边距」，使标题、范围说明、消息区与输入区（含清空 / 发送）在页面不滚动的情况下即可看全。消息区 MUST 保留约三分之二屏高作为期望高度，同时 MUST 可被压缩：触到上限时只有消息区收缩，标题、范围说明与输入区 MUST 保持自身高度、MUST NOT 被压扁。窗口高度变化时该约束 MUST 继续成立。

#### Scenario: 常规视口下列表底边在首屏内

- **WHEN** 超管在常规桌面视口（页面不滚动）打开任一角色调试子页
- **THEN** 对话栏的输入框与清空 / 发送按钮在首屏内可见
- **AND** 对话栏底边不低于首屏下沿

#### Scenario: 触到上限时只压缩消息区

- **WHEN** 视口高度不足以容纳「消息区期望高度 + 标题 + 范围说明 + 输入区」
- **THEN** 消息区被压缩并保留内部滚动
- **AND** 标题、范围说明与输入区仍按自身高度完整显示

#### Scenario: 窗口变矮后仍不出首屏

- **WHEN** 超管把浏览器窗口高度调小
- **THEN** 对话栏随可用高度收缩，底边仍在首屏内
- **AND** 消息区继续承担内部滚动

## REMOVED Requirements

### Requirement: 调试消息区高度固定为屏幕三分之二

**Reason**: 固定 2/3 屏只约束了消息区，未约束整块面板：叠加标题、范围说明与输入区后整块高过一屏，输入框落到折线以下，与「首屏看全」的诉求冲突。

**Migration**: 由「调试对话栏整体不超出首屏」取代：`.md-chat` 增加 `max-height: calc(100vh - 页头 - 面包屑与内边距)`；`.md-chat-body` 保留 `height: 66vh` 作为期望高度，并改为可伸缩（`min-height: 0`），面板内其余子项设为 `flex: none` 保持自身高度。
