## Why

模型调试页（规划 / 执行 / 验收三角色共用）两处观感问题：① 对话区虽然加宽了，但竖起只有约 2/3 屏，长回复与工具调用轨迹读起来仍要频繁滚动，需求方要求纵向再高一倍；②「生效装配」的工具清单按分类平铺，一个有十多个工具的角色会把页面拉得很长，需要按分类折叠起来看。

## What Changes

- 对话区的消息区由「上限 66vh（约 2/3 屏），无消息时不占位」改为**固定高度 132vh（约 1.3 屏，即原上限的两倍）**：有无消息都占同样高度，超出在该区域内独立滚动，不把整页撑长。
- 「生效装配」的工具清单按分类加折叠：**默认全部分类收起**，组头保留分类名与「启用数 / 总数」；点组头展开该组工具（仍带只读 / 写、已启用 / 已停用标记），再点收起；各组展开态互相独立，切换角色后重置为全部收起。
- 对话栏内部其余结构不变：思考过程默认展开且逐条可折叠、输入框与清空 / 发送、真机调试二次确认均不动。
- **BREAKING**：无（纯版式与交互展开态调整，接口、数据、权限零改动）
