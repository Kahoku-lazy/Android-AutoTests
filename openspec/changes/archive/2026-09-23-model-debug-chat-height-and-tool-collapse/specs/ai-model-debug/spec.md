## ADDED Requirements

### Requirement: 调试消息区高度固定为原上限的两倍

调试对话栏的消息区 MUST 采用固定高度而非随消息数量伸缩：其高度 MUST 为屏幕高度的约 1.3 倍（`132vh`，即上一版 `66vh` 上限的两倍），使一屏可读的长回复与工具调用轨迹翻倍。消息超出该高度时 MUST 仍在消息区内独立滚动，MUST NOT 把整页撑长。消息为空时该区域 MUST 保持同一高度，MUST NOT 因无消息而塌缩。输入框与清空 / 发送按钮 MUST 仍留在对话栏内、位于消息区之下。

#### Scenario: 高度翻倍且不随消息数量变化

- **WHEN** 超管打开任一角色调试子页（有对话或无对话）
- **THEN** 消息区高度为屏幕高度的约 1.3 倍（约 132vh）
- **AND** 消息条数增减不改变该高度

#### Scenario: 超出部分只在该区内滚动

- **WHEN** 对话内容超过消息区的固定高度
- **THEN** 滚动只发生在消息区内，页面不因消息增多而变长

#### Scenario: 无消息时同样占位

- **WHEN** 超管首次进入某角色调试子页（尚无任何消息）
- **THEN** 消息区仍占据约 1.3 屏高，空态提示与示例问法显示在该区域顶部

### Requirement: 工具分组可折叠

调试子页「生效装配」的工具清单 MUST 按分类分组且每组 MUST 可折叠：默认状态下所有分类 MUST 处于收起态，只显示分类名与该分类的启用数 / 总数，MUST NOT 渲染该分类下的工具条目。点击组头 MUST 展开该组工具，展开后每个工具 MUST 仍带只读 / 写与已启用 / 已停用标记；再次点击 MUST 收起。各分组的展开态 MUST 相互独立。角色切换后展开态 MUST 重置为全部收起。

#### Scenario: 默认全部收起

- **WHEN** 超管打开任一角色调试子页
- **THEN** 每个工具分类只显示分类名与启用数 / 总数
- **AND** 不渲染该分类下的工具条目

#### Scenario: 点击组头展开该组

- **WHEN** 超管点击某个工具分类的组头
- **THEN** 该分类下的工具条目展开可见，且每个工具带只读 / 写与已启用 / 已停用标记
- **AND** 其它分类的展开态不变

#### Scenario: 再次点击收起

- **WHEN** 超管再次点击已展开的分类组头
- **THEN** 该分类的工具条目重新收起，分类名与计数仍可见

#### Scenario: 切换角色后回到全部收起

- **WHEN** 超管在角色 A 展开某分类后切到角色 B
- **THEN** 角色 B 页面的所有分类均为收起态

## REMOVED Requirements

### Requirement: 调试消息区高度占屏幕三分之二

**Reason**: 需求方要求对话区纵向再高一倍：上一版的 `66vh` 上限在长对话下仍显局促，且无消息时消息区不占位，左右两栏高度差很大。

**Migration**: 由「调试消息区高度固定为原上限的两倍」取代：`.md-msgs` 的 `max-height: 66vh` 上限声明从消息区移除，改由消息区容器固定 `132vh` 高度并承担内部滚动（含无消息的空态）。
