## ADDED Requirements

### Requirement: 调试页按三层组织并分组展示

调试子页 MUST 按三层语义组织内容：① 角色带（当前角色 + 模型名 + provider + 模态 + 连接态 + 工具 / Skill / 知识库计数）② 生效装配（该角色工具与 Skill）③ 参考数据（知识库来源）与提示词。调试对话 MUST 独立成栏并与内容并排常驻，用户 MUST NOT 需要滚过提示词才能发问。该角色的工具 MUST 按分类分组展示，每组头部 MUST 显示该分类启用数与总数；每个工具 MUST 保留只读/写与已启用/已停用标记。系统提示词 MUST 默认折叠，折叠头 MUST 显示字数与"库中当前值"的来源标识，展开后 MUST 渲染 Markdown。Skill 区块 MUST 以组头徽标标注「三模型共用」，知识库区块 MUST 以组头徽标标注「执行链路未挂载 RAG」。角色切换 MUST 采用页内分段入口，且 MUST NOT 因此新增浏览历史层级（返回与面包屑行为不变）。

#### Scenario: 三层结构在一屏内可辨

- **WHEN** 超管打开某角色调试页
- **THEN** 可见角色带（角色名 / 模型名 / 模态 / 工具·Skill·知识库计数）
- **AND** 可见「生效装配」与「参考数据」两个分组区，且提示词为折叠态

#### Scenario: 工具按分类分组且组头带计数

- **WHEN** 超管打开执行模型调试页
- **THEN** 工具按分类分组（如设备控制 / 设备信息 / 设备检查器 / 视觉识别）
- **AND** 每组头部显示该分类的启用数与总数
- **AND** 每个工具仍带只读/写与已启用/已停用标记

#### Scenario: 提示词默认折叠

- **WHEN** 超管首次打开调试页
- **THEN** 系统提示词不展开正文，折叠头显示字数与来源标识
- **AND** 展开后才渲染 Markdown 正文

#### Scenario: 对话常驻右栏

- **WHEN** 超管打开调试页（未滚动）
- **THEN** 对话消息区与输入框与配置内容并排可见

#### Scenario: 归属标注可见

- **WHEN** 超管打开任一角色调试页
- **THEN** Skill 组头可见「三模型共用」
- **AND** 知识库组头可见「执行链路未挂载 RAG」

#### Scenario: 角色切换不新增历史层级

- **WHEN** 超管从规划模型切到执行模型
- **THEN** 页面在同一子页内切换角色（路由 role 参数变化），页头返回与面包屑仍指向工具箱
- **AND** 不出现"返回上一角色"这类新增层级的回退
