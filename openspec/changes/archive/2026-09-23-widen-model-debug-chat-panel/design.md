## Context

模型调试页 `ModelDebugPage.vue` 的正文是两栏栅格：左栏 `① 生效装配 / ② 参考数据`（含折叠的系统提示词），右栏 `③ 调试对话`（`aside.md-panel.md-chat`，含消息区 `.md-msgs`、设备下拉、`.md-textarea` 与清空 / 发送）。分栏规则在 `ModelDebugPage.style.css` 的 `.md-split`：`grid-template-columns: minmax(0, 1fr) minmax(320px, 420px)`，即对话栏有 420px 硬上限；`@media (max-width: 960px)` 时退化为单列。三个角色（planner / executor / verifier）共用该页面与同一份样式。

## Goals / Non-Goals

**Goals:**

- 宽屏下对话栏占正文宽度 2/3，长回复与工具轨迹的折行显著减少。
- 窄屏下仍保持两栏各自可读：不足以并排时改为上下单列。

**Non-Goals:**

- 不改对话栏内部结构、消息渲染、思考过程折叠、二次确认与任何接口。
- 不改 `ToolboxPanel` 的提示词编辑区、「提示词历史记录」抽屉与其它页面的分栏。
- 不引入自定义 viewport 断点令牌体系（沿用既有裸 px 媒体查询写法）。

## Decisions

**D1：用栅格比例而非固定宽度。** `.md-split` 的第二轨由 `minmax(320px, 420px)` 改为 `minmax(0, 2fr)`（第一轨保持 `minmax(0, 1fr)`），对话栏即占可用宽度（减栅格间距）的 2/3。备选：`width: 66.67vw` 或 `width: 66.67%`——前者以视口为基准，会被左侧导航挤出正文并产生横向溢出；后者对 `aside` 需脱离栅格，且与第一轨的 1fr 争抢宽度。比例轨随正文自适应，最稳。

**D2：堆叠断点由 960px 上调至 1200px。** 2:1 分栏下，正文宽度 1200px 时左栏约 390px，是工具清单（工具名 + 只读/写 + 已启用/已停用三个徽标一行）仍可读的下限；低于该值继续并排会把左栏压到 300px 以下。上调断点后窄屏走单列，对话栏占满正文宽度，比"两侧都窄"更可用。备选：保持 960px——会在 960–1200px 区间产出不可读的左栏。

**D3：验收口径落在样式声明上。** 栅格比例与高度上限都无法在 jsdom 中通过布局计算断言，测试沿用仓内既有做法（`WorkbenchCrumbs.spec.ts` 读取源文件断言样式规则），读取 `ModelDebugPage.style.css` 断言第二轨为第一轨的两倍、1200px 断点存在、消息区高度上限为 `66vh`。

**D4：消息区高度上限由 `52vh` 改为 `66vh`（屏幕高度的 2/3）。** 宽度到位后，瓶颈转为竖向：`52vh` 上半屏就开始内部滚动，长回复与工具轨迹要频繁滚。备选：`flex: 1` 撑满栏高——需改动 `.md-chat` 与页面骨架的高度分配（`doc-page--fixed` 下栏高由内容决定），波及面大于本次诉求；`100vh` 会把输入框推出视口。`66vh` 与宽度口径同为 2/3，且给标题、范围说明与输入框留出余量。

## 模块防火墙自检

- 跨 App import：无（本次只动一个前端模块内的样式文件与测试文件）。
- 引擎边界：不涉及 `engines/`、不涉及设备句柄。
- 通信通道：不新增 / 不修改任何 HTTP、WebSocket、SSE 调用。
- 前端不直连数据库、不新增写操作；仪表盘不涉及。

## Risks / Trade-offs

- [左栏变窄后工具徽标可能换行] → 断点上调到 1200px，保证左栏 ≥ 约 390px；徽标本身已有 `white-space: nowrap` 与组内换行能力（`.md-tool` 为 flex 行，工具名 `flex: 1` + `overflow-wrap: anywhere`）。
- [2/3 与既有 spec 文字「并排常驻」冲突] → 既有要求保留不动，本次以 ADDED 需求追加占比约束，归档时并入主规范。
- [不同屏幕下"2/3"体感不同] → 占比相对正文而非视口，窗口缩放时比例恒定。
- [66vh 消息区在小屏笔记本（视口高 768px 上下）会把对话栏输入框压到折线以下] → 滚动由 `.doc-body`（工作台壳层策略 ②）承担，内容不被裁切；输入框本就在随内容滚动的正文里，与左栏工具清单更长时的现状一致。若要输入框常驻视口，属"页头 / 输入框改固定栏"的另一次变更。
