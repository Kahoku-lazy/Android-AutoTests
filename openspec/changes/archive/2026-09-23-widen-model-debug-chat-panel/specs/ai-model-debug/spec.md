## ADDED Requirements

### Requirement: 调试对话栏占正文宽度三分之二

调试子页的调试对话栏 MUST 保持独立成栏并与配置内容并排常驻，且其横向占比 MUST 为正文宽度的三分之二（配置区占三分之一），使长回复、思考过程与工具调用轨迹不必频繁折行。当正文可视宽度不足以让两侧同时保持可读时，页面 MUST 改为上下单列堆叠，对话栏此时 MUST 占满正文宽度。该占比约束 MUST NOT 改变对话栏内部结构：消息区独立滚动、输入框与清空 / 发送常驻、思考过程与工具轨迹分区展示 MUST 与既有实现一致。

#### Scenario: 宽屏下对话栏占三分之二

- **WHEN** 超管在宽屏（正文可视宽度 ≥ 1200px）打开任一角色调试子页
- **THEN** 配置区与对话栏并排可见
- **AND** 对话栏与配置区的宽度之比为 2 : 1（即对话栏占正文宽度的三分之二）

#### Scenario: 窄屏下改为上下单列

- **WHEN** 正文可视宽度小于 1200px
- **THEN** 配置区与对话栏改为上下单列堆叠
- **AND** 对话栏占满正文宽度，不出现两侧同时被挤压到不可读的并排布局

#### Scenario: 三个角色占比一致

- **WHEN** 超管分别打开规划 / 执行 / 验收三个角色的调试子页
- **THEN** 三页的对话栏与配置区占比完全相同（2 : 1）

#### Scenario: 对话栏内部结构不受占比调整影响

- **WHEN** 超管打开任一角色调试子页
- **THEN** 消息区仍独立滚动、输入框与清空 / 发送按钮仍常驻可见
- **AND** 助手消息仍分别渲染「回复 / 调用失败」与「思考过程」两个区块

### Requirement: 调试消息区高度占屏幕三分之二

调试对话栏的消息滚动区 MUST 至少可占到屏幕高度的三分之二（长对话一屏可读内容随之增加），超出部分 MUST 仍在该消息区内独立滚动，MUST NOT 把整页撑长或挤走输入框。输入框与清空 / 发送按钮 MUST 始终留在对话栏内可见，不随消息增多被推出视口。

#### Scenario: 消息区高度上限为屏幕三分之二

- **WHEN** 超管打开任一角色调试子页并有较长对话
- **THEN** 消息区高度上限为屏幕高度的三分之二（约 66vh），达到上限后消息区内部滚动

#### Scenario: 输入框不被长对话顶走

- **WHEN** 某角色调试子页已有大量消息
- **THEN** 输入框与清空 / 发送按钮仍在对话栏内可见可点
- **AND** 页面整体高度不随消息条数增长而无限变长
