## Context

`LocatorPagePreview.vue` 在标题行与页脚各放了一个 `<el-button type="primary">进入页面编辑 ›</el-button>`。两个按键文案、目标完全一致，属同一动作的重复呈现。

## Goals / Non-Goals

**Goals:**

- 同一动作在右栏只呈现一次，且位置固定不随翻页变化

**Non-Goals:**

- 不改入口的文案、目标路由与按键皮肤
- 不改分页控件的位置与口径（仍在页脚）

## Decisions

**D1 保留标题行入口，删除页脚入口**
标题行在右栏顶部、不参与表格滚动与翻页，天然满足「常驻可见」；页脚在长列表下会被视口压缩到下方。页脚只留分页控件。

**D2 用「同文案按键数量」作为可机械验证的口径**
验收不靠目视：统计右栏内文案为「进入页面编辑」的按键数必须为 1，可写成浏览器断言，防止再被复制回去。

## 模块防火墙自检

- 跨 App import / 写库 / ORM：无（纯前端一处模板改动）
- 前端 HTTP 出口：不变；右栏仍零写请求
- 引擎边界 / 通信通道：不涉及

## Risks / Trade-offs

- [页脚少一个入口后，用户翻到最后一页可能习惯性找右下角] → 入口在固定的标题行，视线无需移动；且页脚只承载分页，语义更清晰
