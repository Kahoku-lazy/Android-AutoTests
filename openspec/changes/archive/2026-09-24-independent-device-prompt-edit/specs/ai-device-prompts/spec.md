## MODIFIED Requirements

### Requirement: 下拉头入口与历史抽屉

设备提示词三个角色下拉头的右上角 MUST 各提供属于该角色自己的编辑入口：未进入编辑时显示「编辑」，该角色处于编辑态时显示「保存」与「取消」。「查看历史记录」MUST 只在面板页头出现一次，MUST NOT 在每个角色下拉头重复出现。历史抽屉 MUST 列出自动存档与永久存档，每项 MUST 能预览三份正文；永久存档 MUST 提供删除入口且删除前 MUST 二次确认；自动存档 MUST NOT 提供手动删除入口。

#### Scenario: 下拉头可见入口

- **WHEN** 超级管理员打开设备提示词来源
- **THEN** 三个角色下拉头右上角各能看到该角色自己的「编辑」
- **AND** 面板页头能看到唯一的「查看历史记录」

#### Scenario: 编辑态入口切换

- **WHEN** 超管点击某个角色的「编辑」
- **THEN** 该角色下拉头右上角变为「保存」与「取消」
- **AND** 另外两个角色下拉头仍为「编辑」

#### Scenario: 抽屉预览与删除

- **WHEN** 超管打开历史抽屉
- **THEN** 列出自动存档与永久存档并可预览正文
- **AND** 可对永久存档发起删除（删除前有确认），自动存档没有删除入口

## ADDED Requirements

### Requirement: 每份提示词独立编辑与独立保存

系统 SHALL 让规划 / 执行 / 验收三份提示词的编辑态与草稿彼此独立：进入某一份编辑 MUST NOT 改变其余两份的展示与编辑态，也 MUST NOT 强制展开其余两份折叠面板；多份编辑态 MUST 允许并存。每份的「保存」MUST 只把该份草稿写入库，同一请求中其余两份 MUST 取当前已保存值，MUST NOT 携带其余份尚未保存的草稿。每份的「取消」MUST 只退出该份编辑态，MUST NOT 影响其余份的草稿与编辑态。

#### Scenario: 点一份的编辑不牵动其余两份

- **WHEN** 超管在设备提示词来源点击「规划」的「编辑」
- **THEN** 只有规划变为可输入的编辑框并展开
- **AND** 执行与验收仍为只读 Markdown 渲染，且保持各自原有的展开 / 折叠状态

#### Scenario: 同时编辑多份互不干扰

- **WHEN** 超管先后点击「规划」与「执行」的「编辑」
- **THEN** 两份同时处于编辑态，各自草稿互不覆盖
- **AND** 验收仍未进入编辑态

#### Scenario: 保存一份不带入另一份草稿

- **WHEN** 规划与执行同时处于编辑态，超管只点「规划」的「保存」并在确认框中确认
- **THEN** 库中规划为该份草稿正文
- **AND** 库中执行仍为该次编辑前的已保存值，执行未保存的草稿 MUST NOT 被写入

#### Scenario: 取消一份不影响另一份

- **WHEN** 规划与执行同时处于编辑态，超管点「执行」的「取消」
- **THEN** 执行退出编辑态；其草稿有改动时按既有规则自动落库并留一份自动档，无改动时不写库
- **AND** 规划仍在编辑态，其草稿保持用户已输入的内容，且 MUST NOT 被该次写库覆盖

### Requirement: 自动保存只覆盖处于编辑态且有改动的份

系统 SHALL 在退出编辑时按触发点处理：某一份点「取消」时只处理该份（该份有改动才写库）；切换工具来源或离开页面时，把当前仍处于编辑态且有改动的若干份与其余「已保存值」合并提交一次写库。每次写库 MUST 按既有规则留下一份自动存档。未处于编辑态的份、以及未被本次处理的其他编辑中份的草稿，MUST NOT 被写入库。没有任何编辑中改动时 MUST NOT 写库、MUST NOT 新增存档。

#### Scenario: 取消一份只处理该份

- **WHEN** 规划与执行同时处于编辑态且都被改动，超管点「执行」的「取消」
- **THEN** 写库一次，内容为执行的新正文加规划 / 验收的已保存值
- **AND** 规划仍在编辑态且其草稿保持用户已输入的内容（MUST NOT 被写库、MUST NOT 被重置）

#### Scenario: 切换来源只保存有改动的编辑中份

- **WHEN** 规划与执行同时处于编辑态且都被改动，超管切换到其它工具来源
- **THEN** 一次写库提交规划与执行的新正文，验收取已保存值
- **AND** 只新增一份自动存档，永久存档不变

#### Scenario: 无改动退出不写库

- **WHEN** 超管进入某一份编辑态但未修改任何内容就点「取消」
- **THEN** 不写库，也不新增自动存档
