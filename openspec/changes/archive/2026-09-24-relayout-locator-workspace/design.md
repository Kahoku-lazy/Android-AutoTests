## Context

元素定位项目工作台当前是单栏版式：整页只有一棵 el-tree，每个节点渲染为一条通栏墨框。1500×950 视口实测：主区 1192px、树占 1176px、单行 1152px、行高 34px、层级缩进 12px、树高 576px（可用 716px）、名字与行尾「进入」相隔 ≈950–1050px；Android 项目数据为 2 个目录 + 13 个页面（共 73 个元素）。文件详情的呈现逻辑已在 `LocatorFilePanel.vue`，由 `LocatorFileView.vue` 在 `/elements/projects/:code/files/:fileId` 路由下挂载，并自带一套硬边按键皮肤（`element-locator-page-workbench` 在册要求）。

约束：`doc-page--fixed` 下唯一纵向滚动容器是 `.doc-body`；模块只拥有自己页面的 L2–L5；拖拽双通道（桌面原生 DnD / 触摸长按 1s）与批量勾选的判定收敛在 `composables/useLocatorTreeMove.ts`，不得改动；落点只允许目录节点与项目根落点区。

## Goals / Non-Goals

**Goals:**

- 工作台在宽屏下把「目录树」与「选中页面的元素」并置同屏，取消浏览多个页面时的往返跳转
- 让目录树的层级、目录与页面的差异、以及每行的可操作性在默认态就能读出来
- 让项目根落点只在真正需要它的时候出现
- 保持既有端点、信封、拖拽与批量判定、七列表格契约、深链与面包屑口径零变化

**Non-Goals:**

- 不改动拖拽 / 批量勾选 / 右键菜单的任何判定与请求
- 不把 `/files/:fileId` 深链合并进并置态（沿用文件详情页路由；详见 Decisions）
- 不做窄屏的上下叠版式（窄屏直接沿用既有两页流程）
- 不同步改用例管理工作台（该能力在 `openspec/specs/` 下无主 spec，另立一单）
- 不调整工具栏按键皮肤（`--ex-btn` 与共享按钮的规范归属需先决策，另立一单）

## Decisions

**D1 并置采用 L3 分栏容器，元素表沿用既有面板组件**
工作台主体改为左右两栏的 flex/grid 容器，右栏挂载既有 `LocatorFilePanel`。理由：该面板已承载七列表、行内编辑、新增与批量删除的全部逻辑与状态，直接复用可保证「详情页与右栏」呈现完全一致，避免第二套表格。备选（在右栏另写一套精简表格）被否——会立刻产生两套列契约。

**D2 选中态留在工作台本地，不推进路由**
宽屏下点击页面只更新工作台的本地选中态，不 `router.push`。理由：文件详情路由由 `LocatorFileView` 承载，若把并置态也挂到该路由，需同时改写文件详情页的页头 / 面包屑规范与窄屏退化路径，收益（URL 可分享）小于风险。代价：并置态下选中页面不体现在 URL，作为已知缺口登记。

**D3 窄屏直接沿用既有两页流程，不做上下叠**
`<1280px` 时工作台只渲染树，点击页面跳 `/files/:fileId`。理由：`doc-page--fixed` 下唯一滚动在 `.doc-body`，上下叠会让树与元素表争同一个滚动容器；既有整页详情已经提供了等价且已验证的退化路径。

**D4 硬边按键皮肤抽成模块内共享样式文件**
新建 `components/elementDetailSkin.css`，由 `LocatorFileView.vue` 与工作台右栏共同引用，作用域类为 `.element-detail-pane`。理由：皮肤真相源在当前是 `LocatorFileView` 的 scoped 样式，并置后需要两处生效；抽文件避免复制粘贴出两套皮肤。

**D5 层级引导线用原子色令牌，不用字面量**
引导线取 `var(--color-orange-76)`（暖灰，与 `--dot`/表格描边同源）。缩进由 el-tree 的 `indent` 提升到 18px，引导线画在 `.el-tree-node__children` 的左边界上。

## 模块防火墙自检

- 跨 App import：无（纯前端改动，不触碰 `apps/`）
- 跨 App 写库 / ORM：无
- 前端直连数据库：无
- 前端 HTTP 出口：不变（仍只经 `modules/element-locator/api.ts` → `shared/api-client`）
- 引擎边界 / 通信通道：不涉及

## Risks / Trade-offs

- [并置后左栏变窄，长页面名易截断] → 名称单行省略并保留 `title`，行内进入指示紧贴名称，靠 hover 态反馈
- [右栏宽度不足导致七列表横向滚动] → 这是显式取舍（规范要求不删列），并在窄屏阈值以下退化到整页详情
- [隐藏项目根落点区可能影响触摸拖拽] → 落点区在 `touchActive` 与拖拽起手时出现；判定与端点不变，触摸通道复用既有长按逻辑
- [并置态选中页面不体现在 URL] → 登记为已知缺口，后续若需要分享链接再单独立项
