## MODIFIED Requirements

### Requirement: 调试页展示该角色实际生效的配置

调试子页 MUST 展示该角色的系统提示词（Markdown 渲染）、模型连接（provider、model_name、是否视觉）、以及该角色的工具子集（每个工具名 + 只读/写标记 + 是否被平台停用）。工具清单 MUST 与该角色实际装配一致：规划模型为页面流工具、执行模型为视觉/设备操作工具集、验收模型为截图工具与只读日志检查工具。MUST NOT 展示 api_key、base_url 明文等敏感字段。

#### Scenario: 三个角色的工具清单各不相同

- **WHEN** 分别打开规划 / 执行 / 验收三个调试子页
- **THEN** 三页的工具清单按各自子集展示（规划为页面流工具、执行为视觉工具集、验收为截图工具与只读日志检查工具）
- **AND** 执行模型页标注该角色使用视觉模型

#### Scenario: 不泄漏密钥

- **WHEN** 打开任一角色调试子页
- **THEN** 页面与接口响应都不出现 api_key 明文
