# 同步 DeepSeek 模型清单：正式模型名 + 多模态能力标注

## Why

DeepSeek 更新了模型。以**平台自己的密钥**实测其模型接口（`GET https://api.deepseek.com/v1/models`，HTTP 200）现只提供两个模型：

| 模型 ID | 名称 | 图片输入 | 上下文 / 输出 |
| --- | --- | --- | --- |
| `deepseek-flash` | DeepSeek-V4.1-Flash | **支持**（`input_modalities` 含 `image`） | 1M / 384K |
| `deepseek-v4-pro` | DeepSeek-V4-Pro | 不支持 | 1M / 384K |

官方价目页同时写明：**模型名请使用 `deepseek-flash`**；旧名 `deepseek-v4-flash`、`deepseek-v4-flash-vision-exp` 仍可调用，但对应模型已下线，请求由 V4.1-Flash 提供服务、**按 Flash 价计费**；且 Flash 档价格已下调。

平台的清单因此三处漂移：

1. **配置页模型下拉**仍是旧三项（其中两个名字对应的模型已下线），且**没有任何多模态能力标注**——管理员无法分辨哪个模型能读截图，而执行 / 验收角色恰恰依赖截图；
2. **两份价目表**（后端与引擎各一份，约定必须一致）仍是旧价：Flash 档缓存命中 0.05 / 未命中 1.5 / 输出 4.5，官方现价 **0.02 / 1 / 4**；Pro 档 0.15 / 4.5 / 13.5 未变；
3. **默认计费档**与 **`deepseek-chat` 别名**都指向已不存在的 `deepseek-v4-flash`。

根因：模型下拉是前端写死的清单，而平台已有的「探测该密钥可用模型」只用于连通性校验、且只保留模型名（丢弃了接口返回的能力字段），所以 API 一变平台不知道。

## What Changes

- **模型清单**：配置页下拉改为两个正式模型名，并逐项标注能力（多模态 · 支持图片 / 纯文本）；已下线的旧名不再作为选项，但仍可手工输入（厂商仍接受）。
- **多模态提醒**：需要图片的角色（执行 / 验收）区块带固定提示「本角色需要多模态模型（可读截图）」；引擎装配这类角色时若绑定了已知纯文本模型，MUST 记录一条含角色名与模型名的明确告警（任务不中断）。
- **价目与默认档**：两份价目表同步为官方现价；价目键、默认档、别名统一收敛到正式模型名（旧名保留为**别名**指向 `deepseek-flash`，与厂商计费口径一致）。
- **一致性守护**：新增用例断言「前端下拉清单 ≡ 引擎模型目录 ≡ 两份价目表的正式条目」，防止再次漂移；并顺带堵住「清单里出现没有价目、静默按默认档计费」的隐患（旧 `vision-exp` 正是这种处境）。

## 关联文档

- 关联能力：`ai-agent-model-config`（智能体配置页的模型配置与校验）。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `ai-agent-model-config`: 新增两条需求——「模型清单标明多模态能力」与「需要图片的角色绑定纯文本模型时给出提醒」。
  **已知现状（不在本单范围）**：该能力现有三条需求（主推理 / 视觉 / 强模型三类配置、强模型开关、卡片页收敛）描述的是**已退役的意图路由设计**，与当前配置页（规划 / 执行 / 验收三角色）不符；该漂移属既有问题，本单只**新增**不删旧，另行立单校正。

## Impact

- 引擎：`engines/ai/agents/config.py`（新增 DeepSeek 模型目录：模型名 → 是否支持图片）、`engines/ai/agents/base.py`（装配期告警）、`engines/ai/billing/billing.py`（价目 / 别名 / 默认档）。
- 后端：`apps/ai_assistant/deepseek_billing.py`（价目 / 别名 / 默认档，与引擎侧保持一致）。
- 前端：`components/ModelConfigField.vue`（清单 + 多模态标注 + 角色提示）、其调用方 `AgentDetail.vue`（为执行 / 验收两个区块传「需要图片」标记）。
- 测试：新增一致性守护用例；`test_deepseek_billing.py` 的期望值随新价更新；少量以旧模型名作桩数据的用例同步为正式名。
- 文档：接口文档中的计价说明、引擎内的模型名示例注释。
- **可见副作用**：价目表是唯一真相源、按当前价重算，故**历史任务详情/列表显示的 DeepSeek 费用会随新价整体下降**（Flash 档为主）——这是平台既有口径（"调价只改价目表"），非本单新增行为。
- 前端交互 / 接口形状 / 数据库 / 通道：无新增端点、无迁移、无字段变化。
