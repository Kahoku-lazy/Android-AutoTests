## Purpose

从智能体的最终回复和流式模型调用结束事件中，解析出顺序相同的输入、输出与缓存命中 token，供既有费用计算直接使用。

## ADDED Requirements

### Requirement: 最终回复与流式结束事件给出同一用量三元组
解析最终回复，以及解析一条模型调用结束事件，得到的用量 MUST 都是按顺序排列的三项整数：输入 token、输出 token、缓存命中 token。两项来源在数字相同时，三元组 MUST 相同。该三元组 MUST 能原样作为既有费用计算的三项用量。缓存写入 token MUST NOT 出现在这三项里。

#### Scenario: 最终回复带用量
- **WHEN** 最终回复的用量为输入 1000 token、输出 200 token、缓存命中 400 token
- **THEN** 解析结果为输入 1000、输出 200、缓存命中 400

#### Scenario: 流式结束事件带同样的用量
- **WHEN** 一条模型调用结束事件的输入为 1000 token、输出为 200 token、缓存命中为 400 token
- **THEN** 解析结果为输入 1000、输出 200、缓存命中 400，与同等数字的最终回复解析结果相同

#### Scenario: 三元组可直接计费
- **WHEN** 用上述三元组、模型 `deepseek-flash`、处于空闲时段的调用时刻计算费用
- **THEN** 输入费用、输出费用、缓存命中费用与把同样三个整数直接交给既有 DeepSeek 计费得到的结果逐项相等

### Requirement: 缺少用量时不编造
最终回复没有用量时，解析结果 MUST 为输入 0、输出 0、缓存命中 0。不是模型调用结束的流式事件 MUST NOT 产生用量三元组，调用方 MUST NOT 把它计为一次模型调用。

#### Scenario: 最终回复没有用量
- **WHEN** 最终回复不带用量
- **THEN** 解析结果为输入 0、输出 0、缓存命中 0

#### Scenario: 文本增量不是一次调用
- **WHEN** 流式事件是文本增量、思考增量或工具事件
- **THEN** 解析不产生用量三元组

### Requirement: 流式用量按单次调用取值
流式解析 MUST 只反映这一条模型调用结束事件上的三项，MUST NOT 把同一轮里的多次调用加总。最终回复的用量 MUST 取该消息上已经累计好的用量，解析 MUST NOT 再从事件流重算一遍。

#### Scenario: 同一轮两次调用各自成组
- **WHEN** 同一轮回复先后结束两次模型调用，用量分别为输入 10 / 输出 1 / 缓存命中 0，以及输入 20 / 输出 2 / 缓存命中 0
- **THEN** 两次解析分别得到这两组数字，MUST NOT 返回输入 30、输出 3、缓存命中 0

#### Scenario: 最终回复使用消息上的累计用量
- **WHEN** 最终回复消息上的累计用量为输入 30 token、输出 3 token、缓存命中 0
- **THEN** 解析结果为输入 30、输出 3、缓存命中 0
