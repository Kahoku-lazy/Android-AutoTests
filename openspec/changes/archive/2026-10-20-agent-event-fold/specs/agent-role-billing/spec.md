## MODIFIED Requirements

### Requirement: 费用与用量三项对齐
一次计费 MUST 返回输入费用、输出费用、缓存命中费用，顺序与用量的输入 token、输出 token、缓存命中 token 一致。单位 MUST 为元。每一项 MUST 在精确金额算出之后，按小数点后 8 位四舍五入：第 9 位小于 5 则舍去，大于或等于 5 则进位。取位后的金额以普通十进制表示，小数点后固定 8 位，MUST NOT 使用科学计数法。不足 0.000000005 元的一项 MUST 为 0；非零结果的最小刻度是 0.00000001 元。缓存命中 token MUST 先截断到不超过输入 token；输入费用 MUST 只按未命中部分（输入减去缓存命中）乘缓存未命中单价，缓存命中费用 MUST 按命中单价，输出费用 MUST 按输出单价。三项相加 MUST 等于按官方扣费规则计算的该轮总费用（在分别保留 8 位小数之前）。同一次调用 MUST NOT 再按 4 位小数另算一份。

#### Scenario: 小额输入保留四位有效数字
- **WHEN** 模型为 `deepseek-flash`，输入 12345 token、输出 0、缓存命中 0，且处于空闲时段
- **THEN** 输入费用为 0.01234500 元，输出费用与缓存命中费用为 0.00000000 元

#### Scenario: 第五位大于五则进位
- **WHEN** 模型为 `deepseek-flash`，输入 4670 token、输出 0、缓存命中 0，且处于空闲时段
- **THEN** 精确输入费用为 0.00467 元，按 8 位取位后为 0.00467000 元，输出费用与缓存命中费用为 0.00000000 元

#### Scenario: 第五位小于五则舍去
- **WHEN** 模型为 `deepseek-flash`，输入 4630 token、输出 0、缓存命中 0，且处于空闲时段
- **THEN** 精确输入费用为 0.00463 元，按 8 位取位后为 0.00463000 元

#### Scenario: 第五位恰好为五则进位
- **WHEN** 模型为 `deepseek-flash`，输入 4650 token、输出 0、缓存命中 0，且处于空闲时段
- **THEN** 精确输入费用为 0.00465 元，按 8 位取位后为 0.00465000 元

#### Scenario: 很小的缓存命中不再使用科学计数法
- **WHEN** 模型为 `deepseek-flash`，输入 2560 token、输出 972 token、缓存命中 2560 token，且处于空闲时段
- **THEN** 输入费用为 0.00000000 元，输出费用为 0.00388800 元，缓存命中费用为 0.00005120 元，且三项都以普通小数表示

#### Scenario: 不足半分的金额变为零
- **WHEN** 精确的某一项费用小于 0.000000005 元
- **THEN** 该项费用为 0.00000000 元

#### Scenario: 四位小数会变成零的缓存命中仍然保留
- **WHEN** 模型为 `deepseek-flash`，输入 1000 token、输出 0、缓存命中 1000 token，且处于空闲时段
- **THEN** 输入费用与输出费用为 0.00000000 元，缓存命中费用为 0.00002000 元

#### Scenario: 缓存命中不超过输入
- **WHEN** 缓存命中 token 大于输入 token
- **THEN** 缓存命中按输入 token 计，输入费用为 0.00000000 元
