## ADDED Requirements

### Requirement: 用户关闭的任务在报告里标为主动关闭

被用户关闭（`cancelled`）的任务，报告 MUST 把**已开始但没出判决**的步骤结果标为「主动关闭」，MUST NOT 标为「未完成」；从未开始的步骤 MUST 仍为「未执行」。已出判决的步骤 MUST 保持 `PASS` / `FAIL`，关闭 MUST NOT 覆盖已有结论。用例结果按同一口径：全部 `PASS` 为 `PASS`、任一 `FAIL` 为 `FAIL`、其余且任务被关闭为「主动关闭」。

#### Scenario: 当前步骤显示为主动关闭

- **WHEN** 用户在第 1 步执行期间关闭任务，该步已有执行记录但验收没出判决
- **THEN** 报告里该步结果为「主动关闭」，该用例结果也为「主动关闭」
- **AND** 该步不显示为「未完成」

#### Scenario: 未开始的步骤仍显示未执行

- **WHEN** 一条 5 步的用例只跑到第 1 步就被关闭
- **THEN** 第 1 步为「主动关闭」，第 2–5 步仍为「未执行」

#### Scenario: 已判失败不因关闭而改写

- **WHEN** 某步已经被验收判为 `FAIL`，随后用户关闭任务
- **THEN** 该步结果仍为 `FAIL`，该用例结果仍为 `FAIL`
