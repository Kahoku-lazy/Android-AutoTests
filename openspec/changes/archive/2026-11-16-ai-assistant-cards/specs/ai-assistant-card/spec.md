## Purpose

让登录用户把一条运营 Agent 配置收成一张可展示、可入库的助手名片，卡片只露出用户名称、头像和 Agent 配置名称。

## ADDED Requirements

### Requirement: 助手编号在创建当日生成且之后不变

系统 SHALL 在创建助手时生成编号，格式为服务器当地日期 `YYYYMMDD`、一个下划线、以及 3 位由数字与大写字母组成的随机后缀。该编号 MUST 在全部助手中唯一，且创建后 MUST NOT 因改名、换头像、换引用或改工具勾选而变化。生成 MUST 查重；当日可用后缀耗尽时创建 MUST 失败并返回可读错误，MUST NOT 写入重复编号。

#### Scenario: 新建助手得到当日编号

- **WHEN** 已登录用户在 2026-11-16 创建助手
- **THEN** 返回的编号匹配 `^20261116_[0-9A-Z]{3}$`
- **AND** 数据库中不存在另一个相同编号

#### Scenario: 修改名片不改变编号

- **WHEN** 用户修改该助手的显示名或头像
- **THEN** 编号与创建时相同

### Requirement: 名片只保存引用与展示字段

助手记录 MUST 保存显示名、可选头像、笔色、所引用运营 Agent 配置的标识，以及工具勾选。系统 MUST NOT 把该配置的系统提示词或模型连接参数复制进助手记录。显示名 MUST NOT 为空。引用的配置不存在时，创建与更新 MUST 拒绝。删除运营配置 MUST NOT 级联删除助手。

#### Scenario: 创建时不复制提示词

- **WHEN** 用户引用一条已有运营 Agent 配置并创建助手
- **THEN** 助手记录只保存该配置的标识
- **AND** 记录中没有该配置的系统提示词正文与模型密钥

#### Scenario: 引用不存在时拒绝

- **WHEN** 用户提交一个不存在的运营 Agent 配置标识
- **THEN** 创建失败并返回可读错误
- **AND** 不写入助手记录

### Requirement: 头像压缩后以 base64 单独下发

上传的头像 MUST 由服务端压成最长边不超过 128 像素的 JPEG，再以 base64 保存，且保存后的文本 MUST NOT 超过 12KB。超过该上限或无法解码的图片 MUST 拒绝，不得原样入库。未上传时头像为空。助手列表 MUST NOT 返回头像正文，只返回是否有头像；头像正文 MUST 经按编号的单独接口返回。

#### Scenario: 大图被压缩后可在卡片显示

- **WHEN** 用户上传一张长边大于 128 像素的图片
- **THEN** 入库的是压缩后的 base64
- **AND** 其文本长度不超过 12KB

#### Scenario: 列表不带头像正文

- **WHEN** 客户端请求助手列表
- **THEN** 每条记录含编号、显示名、笔色、是否有头像、所引用配置的名称
- **AND** 响应不含头像 base64

### Requirement: 卡片只显示三样信息

助手列表页的每张卡片 MUST 只显示用户定义的名称、头像或笔色圆、以及所引用运营 Agent 配置的名称。卡片 MUST NOT 显示工具清单、模型名、系统提示词或编号以外的运行参数。有头像时中间显示头像；无头像时中间圆使用该助手笔色的深到浅，圆内 MUST NOT 显示文字。

#### Scenario: 无头像卡片显示笔色圆

- **WHEN** 用户打开助手列表，某助手没有头像
- **THEN** 卡片中间是该助手笔色的渐变圆
- **AND** 信息字段只有用户名称、该圆、以及 Agent 配置名称
- **AND** 笔色图钉与「配置 / 对话」按钮可以出现，但不是信息字段

#### Scenario: 有头像卡片不显示笔色圆

- **WHEN** 某助手已有头像
- **THEN** 卡片中间显示该头像
- **AND** 不同时显示笔色圆
