# 助手/工作流卡片动作键：语义渐变底（20% → 5%）

## Why

助手颜料片与工作流便签卡的动作键现在靠「柠黄 85% / 青绿 78%」这类纯色填充区分，颜色重且与页面的浅色渐变语言不一致；助手卡的「配置 / 对话」两枚键更是同色，分不出主次与去向。

## What Changes

- 助手卡：「配置」= 蓝色渐变、「对话」= 绿色渐变。
- 工作流卡：「配置」= 蓝色渐变、「任务」= 紫色渐变。
- 全部渐变统一为**纵向 20% → 5%**（状态色混纸色），描边与几何（1.5px 虚线、2px 近直角）保持不变。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `ai-assistant-card`：新增「动作键底色按语义用 20%→5% 渐变」要求。

## Impact

- 前端 `ai-assistant`：仅 `components/AssistantCard.vue`（两个 class + 样式块）。
- 不动接口、不动卡片结构、不动虚线白名单落点。
