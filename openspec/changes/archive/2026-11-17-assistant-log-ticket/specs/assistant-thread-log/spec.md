## MODIFIED Requirements

### Requirement: 对话栏只打开本栏的 HTML 报告

对话栏 MUST 提供日志入口，列出该栏各轮的时间与一句话结果。点开一轮 MUST 先换一张一次性开门凭证，再在浏览器打开该轮 HTML。打开地址 MUST NOT 携带登录令牌，也 MUST NOT 把磁盘绝对路径返回前端。无凭证直接打开 MUST 拒绝。进行中的一轮 MUST 显示仍在写入，MUST NOT 提供可打开的半份报告。请求路径越出该助手、该对话栏目录时 MUST 拒绝。

#### Scenario: 从对话栏打开完成的一轮

- **WHEN** 已登录用户打开某栏日志并选择一轮已完成的记录
- **THEN** 浏览器经一次性凭证显示该轮 HTML 报告
- **AND** 地址中没有登录令牌，响应中没有磁盘绝对路径

#### Scenario: 无凭证打开被拒绝

- **WHEN** 客户端不带登录头、也不带有效 ticket 直接请求报告
- **THEN** 请求被拒绝
- **AND** 不返回 HTML

#### Scenario: 越权路径被拒绝

- **WHEN** 客户端请求的报告编号不属于该对话栏，或试图跳出该栏目录
- **THEN** 请求被拒绝
- **AND** 不返回其它栏或其它目录的文件
