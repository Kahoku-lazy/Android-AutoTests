## ADDED Requirements

### Requirement: BUG 单详情抽屉的字号两档

BUG 单详情抽屉内的字号 MUST 只取两档：**16px** 与 **14px**。以下元素 MUST 为 16px（`--app-size-md`）：头部行整行（`BUG-0066` 编号、分类标签、状态标签）、单据标题、「错误内容」这类小节标题。以下元素 MUST 为 14px（`--app-size-sm`）：元信息块（关联任务 / 任务状态 / 创建时间 / 解决时间）、错误正文。抽屉标题「BUG 单详情」MUST 保持 16px，处理按键（标记已解决 / 忽略 / 重新打开）的字号 MUST NOT 因本要求改变。抽屉内 MUST NOT 出现 12px 及以下的正文或标签字号，也 MUST NOT 出现大于 16px 的标题字号。

#### Scenario: 头部行整行同字号

- **WHEN** 打开任一 BUG 单详情
- **THEN** `BUG-0066`、分类标签、状态标签的计算字号均为 16px

#### Scenario: 标题与小标题同档

- **WHEN** 比较单据标题与「错误内容」小节标题
- **THEN** 两者计算字号均为 16px
- **AND** 不再出现 24px 的标题

#### Scenario: 其余回到 14px

- **WHEN** 测量元信息块（dt / dd）、任务链接与错误正文
- **THEN** 四者的计算字号均为 14px
- **AND** 错误正文不小于元信息块字号

#### Scenario: 按键字号不受影响

- **WHEN** 测量「标记已解决」「忽略」「重新打开」三个按键
- **THEN** 字号仍为按键自身规格（14px），未被正文档位改写
