## MODIFIED Requirements

### Requirement: 智能体配置由运营统一维护
系统 MUST 仅允许运营或超级管理员创建、更新、删除智能体。普通用户 MUST NOT 执行这三项写操作。写操作 MUST NOT 按智能体归属人再做限制：运营可以修改或删除任何智能体。导入工具箱项与查看完整 API Key 仍仅超级管理员可做。

#### Scenario: 普通用户创建智能体被拒
- **WHEN** 普通用户请求创建智能体
- **THEN** 系统返回 403 且不创建记录

#### Scenario: 普通用户修改或删除智能体被拒
- **WHEN** 普通用户请求更新或删除任意智能体
- **THEN** 系统返回 403 且不修改记录

#### Scenario: 运营创建智能体
- **WHEN** 运营请求创建智能体并给出名称
- **THEN** 系统创建记录并返回 201

#### Scenario: 运营修改或删除任意智能体
- **WHEN** 运营请求更新或删除一条由他人创建的智能体
- **THEN** 系统允许执行该操作

#### Scenario: 超级管理员仍可维护智能体
- **WHEN** 超级管理员请求创建、更新或删除智能体
- **THEN** 系统允许执行该操作

## ADDED Requirements

### Requirement: 智能体对所有登录用户可见
已登录用户请求智能体列表或详情时，系统 MUST 返回全部智能体，MUST NOT 按归属人、是否超级管理员或是否运营过滤。未登录请求 MUST 返回 401。目标不存在时详情 MUST 返回 404，MUST NOT 用 403 表示不存在。

#### Scenario: 普通用户看到运营新建的智能体
- **WHEN** 运营创建一条智能体后，普通用户请求智能体列表
- **THEN** 响应包含该智能体

#### Scenario: 普通用户读取任意详情
- **WHEN** 普通用户请求一条已存在智能体的详情
- **THEN** 系统返回 200 与该智能体

#### Scenario: 详情不存在
- **WHEN** 已登录用户请求一个不存在的智能体详情
- **THEN** 系统返回 404

#### Scenario: 未登录不能读取
- **WHEN** 未登录请求智能体列表
- **THEN** 系统返回 401 且不返回智能体数据

### Requirement: 新建智能体不归属个人
运营或超级管理员创建的智能体 MUST NOT 记到创建者名下。创建之后，其它登录用户 MUST 能在列表中看到它，且 MUST 能用它提交任务。

#### Scenario: 创建后全员可见
- **WHEN** 运营创建一条智能体
- **THEN** 另一个普通用户的列表与任务发布所用的智能体清单都包含它

### Requirement: 运营后台提供智能体维护页
运营栏 MUST 提供「智能体」入口。运营或超级管理员 MUST 能在该页新建、修改、删除智能体。表单 MUST 只收集名称、头像、标签、描述。普通用户 MUST NOT 看到该入口；直接打开该地址时 MUST 回到工作台，且 MUST NOT 展示智能体数据。删除前 MUST 二次确认，并说明会一并删除该智能体下的任务。

#### Scenario: 运营看到入口
- **WHEN** 运营登录后查看侧栏
- **THEN** 「运营」分组内出现「智能体」

#### Scenario: 普通用户看不到入口
- **WHEN** 普通用户登录后查看侧栏或直接打开智能体维护地址
- **THEN** 侧栏没有「智能体」，直接打开时回到工作台且不展示智能体

#### Scenario: 取消删除不发请求
- **WHEN** 运营在删除确认框中取消
- **THEN** 不发出删除请求，该智能体仍在
