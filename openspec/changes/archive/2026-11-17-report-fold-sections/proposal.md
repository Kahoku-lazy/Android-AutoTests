# 执行报告分区折叠：子目标 / 角色块 / 工具卡三层收起

## Why

现有 HTML 执行报告把一次任务的 100 多张工具卡全部平铺：一次 66 次调用、58 张截图的子目标在报告页里要滚动几十屏，长内容反而看不清结构。页面提示写着「点卡片标题可收起」，但实际没有绑定任何交互，提示与行为不一致。

## What Changes

- 报告区三层分区都改成可折叠：**子目标分组**（`启动应用并进入 H6810 详情页`）、**角色块**（`执行者` / `验收者`）、**工具卡**（`1 adb_screenshot …`）。
- 三层**默认全部收起**：打开报告先看到子目标清单，逐层点开；收起时仍显示标题、调用次数与耗时，`1 adb_screenshot 840.3 ms` 这样的标题行照旧可见。
- 折叠状态用 `aria-expanded` 反映，标题行支持鼠标点击与键盘 Enter / Space 切换。
- 子目标标题前加**手绘序号**：`01`、`02` 递增，上限 `99`；序号是内联 SVG 描边画出来的蜡笔质感数字（左位红、右位蓝，各自由 45% 淡到 30%），不依赖字体与位图。
- 修掉轨迹页调用行的两个毛病：详情区默认全部展开（一次 100 条调用的报告直接摊成一面墙），以及点行只切 `hidden`、`aria-expanded` 从不更新——状态与可访问性标记对不上。
- 报告页提示文案与实际交互对齐。

## 关联文档

## Capabilities

### New Capabilities

- `ae-harness-report-render`: 引擎侧 HTML 执行报告（报告 / 轨迹 / 事件三个视图）的可读性契约，本次覆盖报告区三层折叠、折叠状态的语义标记与轨迹列表的展开。

### Modified Capabilities

无。

## Impact

- `engines/ae_harness/event/render.py`：只改视图层（HTML 结构、CSS、内联脚本），不动 `RunRecord` / `StepRecord`、不动 JSONL 与用量口径。
- 新增 `tests/engines/ae_harness/unit/test_report_render.py`：断言三层折叠挂点、默认收起、`aria-expanded` 与轨迹行展开。
- 后端 / 前端 / 数据库零改动；已经落盘的旧报告不重写，重新跑一轮才得到新样式。
