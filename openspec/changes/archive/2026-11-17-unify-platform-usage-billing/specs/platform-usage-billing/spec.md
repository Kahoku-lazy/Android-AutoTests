## Purpose

把平台每一次模型调用收成同一本逐次账，并用一条通用公式折成人民币；之后更换单价、倍率、门槛或汇率只改基数，不改公式，也不让各页面各自计价。

## ADDED Requirements

### Requirement: 每次调用只入账一次

系统 SHALL 在一次模型调用结束时向 `ai_usage_records` 写入或更新恰好一条记录。幂等键 MUST 为「来源:执行 ID:轮次」。同一键重复提交 MUST 更新原行，MUST NOT 新增第二行。入账失败 MUST NOT 阻断任务、语音或对话主流程。

#### Scenario: 同一轮重复提交不翻倍

- **WHEN** 同一来源、同一执行 ID、同一轮次的用量被提交两次
- **THEN** 账本仍只有一条该键记录，token 与费用为后一次提交的值

#### Scenario: 入账失败不阻断任务

- **WHEN** 任务完成时账本暂时不可写
- **THEN** 任务终态仍可写入，本次调用不因此被重复执行

### Requirement: 通用公式只换基数

系统 MUST 按以下公式计算一笔调用的费用：未命中输入 token 乘输入单价，加上缓存命中 token 乘缓存单价，加上输出 token 乘输出单价，加上字符数乘字符单价，再乘该笔调用适用的倍率，再按该模型原币种折成人民币。缓存命中 token MUST 先截断到不超过输入 token；未命中 token MUST 等于输入减去截断后的缓存命中。单价、高峰倍率、长上下文门槛、汇率与模型名映射都是基数。更换任一基数 MUST NOT 改变公式，也 MUST NOT 要求仪表盘或任务清单改计算逻辑。

#### Scenario: 更换单价不改公式

- **WHEN** 同一笔用量先后用两套输入单价计算
- **THEN** 两次都使用同一公式，只有输入费用随单价变化

#### Scenario: 缓存不重复计入输入

- **WHEN** 一笔调用的输入 token 为 1000、缓存命中 token 为 400
- **THEN** 未命中按 600 计，缓存命中按 400 计，两者不相加后再乘输入单价

### Requirement: 基数按模型名选择

系统 MUST 按模型名选择基数，MUST NOT 按厂商名或密钥名把未登记模型归入另一套价目。模型名映射也是基数：映射目标存在时按目标基数计价，映射关系 MUST 记入该行快照。没有基数且没有映射时，token 与字符数 MUST 仍记录，费用 MUST 为 0，计价状态 MUST 为未计价，该行 MUST NOT 计入费用合计。

#### Scenario: 未知模型不冒充已计价

- **WHEN** 一笔非零用量的模型名既无基数也无映射
- **THEN** 该行 token 大于 0，费用为 0，计价状态为未计价，平台费用合计不包含该行

#### Scenario: 映射模型按目标基数计价

- **WHEN** `deepseek-v4.1-flash` 映射到 `deepseek-flash`，且该笔处于空闲时段
- **THEN** 该笔按 `deepseek-flash` 的空闲基数计价，快照记下这一映射

### Requirement: 分档与高峰按单笔选择

长上下文分档 MUST 按该笔调用自己的输入 token 选择。达到门槛时，该笔全部 token MUST 使用高档基数，MUST NOT 只对超出部分使用高档。高峰 MUST 按该笔调用起点的北京时间判断，MUST NOT 按任务结束时刻整段套用。未给出起点时 MUST 按空闲基数。人民币库存金额 MUST 保留小数点后 8 位。

#### Scenario: 达到长上下文门槛后整笔高档

- **WHEN** 一笔 `grok-4.7` 的输入 token 不少于 200000
- **THEN** 该笔输入、缓存与输出全部使用高档基数

#### Scenario: 跨时段任务不整段套用结束时刻

- **WHEN** 同一任务有一笔起点在高峰、另一笔起点在空闲
- **THEN** 两笔分别按各自起点的倍率计价，任务合计等于两笔之和

### Requirement: 库存人民币与展示币种分离

账本费用列的货币 MUST 为人民币。展示层 MUST 提供人民币与美元的一键切换。切换到美元时 MUST 用展示汇率把库存人民币换算后显示，并同时显示该汇率与取值时刻。切换 MUST NOT 回写费用列，MUST NOT 触发历史重算。原币种为美元的基数在入库时按该笔汇率折成人民币，快照 MUST 保留原币种单价与所用汇率。

#### Scenario: 切换美元不改库存

- **WHEN** 用户把已加载的账单从人民币切换到美元，再切换回来
- **THEN** 库存金额不变，美元显示等于库存人民币除以当时展示的汇率

#### Scenario: 美元原价不来回折两次

- **WHEN** 一笔调用的基数原币种为美元
- **THEN** 库存保存按该笔汇率折出的人民币，快照同时保存美元单价与汇率
