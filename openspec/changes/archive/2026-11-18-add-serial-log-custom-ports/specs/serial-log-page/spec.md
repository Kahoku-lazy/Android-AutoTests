# serial-log-page Delta

## MODIFIED Requirements

### Requirement: 页内权限与只读边界

串口日志页 SHALL 对已登录用户开放只读内容：端口表格、本机监听地址、当前日志文件内容与关键词对照表。监听开关与自定义端口的新增 / 编辑 / 删除 MUST 仅超级管理员可操作；非超级管理员打开页面时开关 MUST 呈现为不可操作、新增 / 编辑 / 删除入口 MUST 不可用，并给出只读说明。日志查看窗口 MUST 只提供刷新与调整读取行数，MUST NOT 提供删除、编辑、下载备份或写文件的操作。

#### Scenario: 超管可切开关

- **WHEN** 超级管理员打开无线端口 Tab 并切换某端口开关
- **THEN** 开关在二次确认后生效，页面显示该端口新的监听状态

#### Scenario: 超管可管理自定义端口

- **WHEN** 超级管理员打开无线端口 Tab
- **THEN** 可见「新增端口」入口与自定义端口行的编辑 / 删除入口，配置端口行无编辑 / 删除入口

#### Scenario: 非超管只读

- **WHEN** 普通登录用户打开串口日志页
- **THEN** 可以查看端口列表、本机监听地址、日志内容与关键词表，开关不可操作、新增 / 编辑 / 删除不可用，并显示仅超管可改

#### Scenario: 日志窗口不可写

- **WHEN** 用户在日志查看窗口内操作
- **THEN** 只能刷新与调整读取行数，无法删除、编辑或下载日志文件
