## ADDED Requirements

### Requirement: 运营不能决定模型的使用人

运营保存模型配置 MUST NOT 改变任何用户的使用名单。新建配置保存成功后，系统 MUST 只允许超级管理员主动使用该模型，直到超级管理员另行授予。运营请求修改名单 MUST 返回 403。

#### Scenario: 保存新配置不开放给所有人

- **WHEN** 运营按现有规则保存一条合法的新模型配置
- **THEN** 配置被保存
- **AND** 普通用户的可主动使用名单不包含该模型

#### Scenario: 运营的名单请求被拒绝

- **WHEN** 运营请求把某模型加入某用户名单
- **THEN** 系统返回 403
- **AND** 名单不变
