## MODIFIED Requirements

### Requirement: 设备不是本工作流的必填项

启动本工作流时，系统 MUST 要求一个非空可连接地址。地址为空时 MUST 拒绝本次运行，并且 MUST NOT 创建任务。YAML MUST NOT 被要求携带设备序列号，也 MUST NOT 被用作设备来源。

#### Scenario: 不选设备也可以启动

- **WHEN** 用户启动一条绑定合法、YAML 合法的工作流，且未提供设备序列号
- **THEN** 系统因缺少设备拒绝本次运行
- **AND** 不创建任务

### Requirement: 运行弹窗只提交工作流编号、里程碑 YAML 与可选设备

运行弹窗 MUST 提供一份里程碑 YAML 与一台必选设备。未选择 YAML 或未选择设备时 MUST NOT 提交。设备 MUST 从设备管理的设备列表里下拉选择，MUST NOT 允许手填序列号，MUST NOT 在助手页另建一套设备数据。下拉取值口径 MUST 与设备执行任务一致：USB 设备取序列号，局域网设备取 `IP:端口`，只挂在无线调试别名上的记录 MUST NOT 出现在选项里。下拉 MUST NOT 含「不指定设备」或其它空设备选项。设备列表取不到时 MUST 给出可读提示，并且 MUST NOT 允许提交。提交 MUST 只带工作流编号、YAML 与设备地址，MUST NOT 带提示词、工具清单或角色编号。提交成功后弹窗 MUST 关闭，并 MUST 提示新任务编号。

#### Scenario: 没选 YAML 不能提交

- **WHEN** 用户打开任务弹窗但没有选择 YAML
- **THEN** 提交被拒绝并提示需要一份里程碑 YAML

#### Scenario: 设备从设备管理里选

- **WHEN** 用户打开任务弹窗
- **THEN** 设备字段是下拉框，选项来自设备管理当前列出的设备
- **AND** 没有可手填序列号的输入框
- **AND** 没有「不指定设备」选项

#### Scenario: 局域网设备提交 IP 与端口

- **WHEN** 用户在下拉里选中地址为 `192.168.35.57:39569` 的设备并提交
- **THEN** 请求体的设备字段为 `192.168.35.57:39569`

#### Scenario: 空设备可以提交

- **WHEN** 用户上传合法 YAML，但没有选择设备后点「开始运行」
- **THEN** 提交被拒绝并提示需要选择设备
- **AND** 不创建任务

#### Scenario: 提交成功后关闭弹窗

- **WHEN** 任务提交成功
- **THEN** 弹窗关闭，页面提示新任务编号
