## MODIFIED Requirements

### Requirement: 嵌入模型不进入聊天创建层

聊天模型创建层 MUST NOT 创建嵌入、实时语音或语音合成模型。嵌入模型 MUST 只由知识库按调用方传入的向量模型参数创建，参数限定为厂商、密钥环境变量名、模型名与向量维度。知识库 MUST NOT 从自带配置文件读取这些参数。该参数 MUST NOT 含聊天、实时语音或语音合成字段；出现这些字段或不支持的厂商时 MUST 创建失败。

#### Scenario: 传入合法向量参数

- **WHEN** 调用方传入受支持厂商、成对的密钥环境变量名、模型名与正整数维度
- **THEN** 返回嵌入模型、该密钥环境变量名与维度
- **AND** 返回值不含密钥明文

#### Scenario: 向量配置混入聊天字段

- **WHEN** 传入的向量模型参数出现聊天、实时语音或语音合成字段
- **THEN** 创建失败
- **AND** 错误信息指出违规字段
