## ADDED Requirements

### Requirement: 多轮对话共用一个不关闭的执行循环

同一对话栏的智能体实例与其模型客户端 MUST 在同一个事件循环上创建和使用；该循环 MUST 在会话的多轮之间
存活，MUST NOT 在某一轮结束时被销毁、再由下一轮另建一个新的。

第二轮及之后的消息 MUST NOT 因为「上一轮的循环已关闭」而失败；同一进程内连续多轮 MUST 全部产出助手回复。

#### Scenario: 同一会话连续两轮

- **WHEN** 用户在同一对话栏连续发送两条消息，每条都等到助手回复
- **THEN** 每一轮都产出一条助手回复，且两条回复都不是 `执行异常: Event loop is closed`
- **AND** 第二轮仍进入第一轮创建的同一个智能体实例，多轮上下文继续生效

#### Scenario: 进程重启后的第一轮

- **WHEN** 服务重启（执行循环随之重建）后，用户在同一条会话继续发消息
- **THEN** 新一轮在重建后的循环上正常执行，不要求沿用上一进程的任何循环状态

#### Scenario: 长空闲后继续对话

- **WHEN** 同一会话第一轮结束的时长超过模型客户端的连接保活时长，用户再发一条消息
- **THEN** 新一轮的第一次模型调用成功，不因清理上一轮遗留的保活连接而报错
