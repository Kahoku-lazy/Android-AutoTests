## ADDED Requirements

### Requirement: 交卷轮被模型拒绝时失败原因写明交卷轮

当一次回复在交卷轮（推理轮次用尽后强制交出结构化结果）被模型以「思考模式不支持强制选择工具」拒绝，且按通道重发规则仍未通过时，任务 MUST 以失败结束，并 MUST 在 `result.reason`、`result.summary` 与失败步骤的 `actual` 中写明这是交卷轮被思考模式拒绝，并保留 HTTP 状态码 400。该条失败步骤的 `kind` MUST 仍为 `provider`，步骤名 MUST NOT 沿用「模型拒绝」。其它 provider 400（参数校验、额度、密钥等）的失败文案 MUST NOT 因本条改变。若关思考重发后成功交出结构化结果，任务 MUST NOT 记录这条失败。

#### Scenario: 交卷轮 400 文案写明交卷轮

- **WHEN** 一次回复在强制交卷请求上收到这句 400，且重发后仍是同一句 400
- **THEN** 任务以 `failed` 结束
- **AND** `result.reason` 与 `result.summary` 同时含「交卷轮」与「思考模式」与「400」
- **AND** 失败步骤的 `name` 为「交卷轮被拒绝」，`kind` 仍为 `provider`

#### Scenario: 重发成功后不记失败

- **WHEN** 强制交卷请求第一次被这句 400 拒绝，关闭思考重发后交出了合法结构化结果
- **THEN** 该回复按交出的结论继续推进，任务结果里不出现「交卷轮被拒绝」这条失败步骤

#### Scenario: 其它 provider 失败文案不变

- **WHEN** 模型因密钥无效返回 401，或因参数校验返回与此无关的 400
- **THEN** 失败原因仍按原分类写「模型拒绝（状态码）」或「模型网关不可用」，不出现「交卷轮」
