## Purpose

把聊天角色与 Omni 语音角色的创建收成同一层：调用方传入已经读好的角色表与模型表，按角色键拿到新实例；这一层只创建，不运行。

## ADDED Requirements

### Requirement: 按角色键从传入的表创建智能体

系统 SHALL 提供一个创建入口：调用方传入已读好的角色配置表、已读好的模型表，以及角色键；系统 MUST 返回该键对应的新智能体实例。创建入口 MUST NOT 自己读取配置文件，MUST NOT 自己读取环境变量取密钥。未知角色键 MUST 报错，且错误信息 MUST 包含该键。

#### Scenario: 已知聊天角色键

- **WHEN** 调用方传入含 `UI_EXECUTOR_ROLE_CONFIG` 的角色表、含其模型短名的模型表，并请求该角色键
- **THEN** 系统返回一个新的聊天智能体，其名称与系统提示词来自该角色节，其模型由该节的模型短名经模型创建层得到

#### Scenario: 未知角色键

- **WHEN** 调用方请求角色表中不存在的角色键
- **THEN** 系统拒绝创建，错误信息包含该角色键

### Requirement: 聊天与语音由同一出口按模型族分派

同一创建入口 MUST 同时服务聊天角色与 Omni 实时语音角色。模型表中该短名的族为聊天时，返回值 MUST 是聊天智能体；族为实时语音时，返回值 MUST 是实时语音智能体。创建层 MUST NOT 把实时语音模型交给聊天智能体构造，也 MUST NOT 把聊天模型交给实时语音智能体构造。

#### Scenario: Omni 角色键

- **WHEN** 调用方请求 `OMNI_ROLE_CONFIG`，且其模型短名在模型表中属于实时语音族
- **THEN** 系统返回实时语音智能体，而不是聊天智能体

#### Scenario: 聊天角色键

- **WHEN** 调用方请求 `KNOWLEDGE_CHAT_ROLE_CONFIG`，且其模型短名属于聊天族
- **THEN** 系统返回聊天智能体，而不是实时语音智能体

### Requirement: 只创建不使用

创建入口 MUST NOT 调用智能体的回复、流式回复或观察接口，MUST NOT 启动 SOP、目标流水线或语音会话循环。每次调用 MUST 返回新实例，MUST NOT 跨调用复用同一智能体的对话状态。

#### Scenario: 连续创建两次

- **WHEN** 调用方用同一角色键连续创建两次
- **THEN** 两次返回的是不同实例，且创建过程没有产生回复或会话事件

### Requirement: 运行时工具包由调用方传入

角色配置中的工具节为空时，创建结果 MUST 是空工具包，除非调用方显式传入工具包。创建层 MUST NOT 为了填满空工具节而硬编码设备工具、产物工具或知识检索工具。调用方传入的工具包 MUST 成为该实例的工具包。

#### Scenario: 未传工具包

- **WHEN** 调用方只传角色表、模型表与角色键，不传工具包
- **THEN** 返回实例的工具包为空

#### Scenario: 传入工具包

- **WHEN** 调用方额外传入一份已装配的工具包
- **THEN** 返回实例使用这份工具包，而不是另一份空包
