## MODIFIED Requirements

### Requirement: 打开对话不运行，发送才创建本栏实例

点击对话 MUST 只打开对话页，MUST NOT 调用模型。草稿助手 MUST NOT 允许其他用户打开新的对话。一个对话栏的第一次发送 MUST 按该助手当前已发布版本创建该栏唯一的 Agent 实例，并把输入作为用户消息发送，消息发送者名称 MUST 为 `user`。同一栏之后的发送 MUST 复用该实例，上下文连续。新建另一个对话栏 MUST 使用新的会话，MUST NOT 复用已有栏的实例。

#### Scenario: 首次发送才运行

- **WHEN** 用户打开某已发布助手的对话页但尚未发送
- **THEN** 没有模型调用
- **AND** 该栏没有 Agent 实例

#### Scenario: 同栏第二句续聊

- **WHEN** 用户在同一对话栏发送第二句
- **THEN** 使用该栏第一次发送时创建的同一个实例
- **AND** 不新建第二个实例

#### Scenario: 草稿不能被他人开聊

- **WHEN** 普通用户请求打开一条草稿助手的新对话
- **THEN** 系统返回 404
- **AND** 不创建对话栏

### Requirement: 改名片不改已打开的对话栏

助手发布新版本后，已经发送过的对话栏 MUST 继续使用首次发送时的版本。新建的对话栏 MUST 使用当前已发布版本。系统 MUST NOT 把对话栏中的实例写回名片，也 MUST NOT 把对话栏配置交给工作流。

#### Scenario: 已发送的栏不跟随新配置

- **WHEN** 某栏已经发送过，作者随后发布该助手的新版本
- **THEN** 该栏下一句仍使用首次发送的版本
- **AND** 新建的另一个栏使用新版本
