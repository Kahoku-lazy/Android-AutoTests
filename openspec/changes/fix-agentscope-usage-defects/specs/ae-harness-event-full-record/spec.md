## ADDED Requirements

### Requirement: SOP 角色归属按名字映射

调用方提供「agent 名 → 角色（执行者 / 验收者）」映射时，事件记录器 MUST 按回复开始事件携带的 agent 名归属角色，MUST NOT 依赖回复在步骤内的先后顺序。未提供映射时 SHALL 沿用既有的顺序推断，保持向后兼容。步骤尝试序号 MUST 取自官方 `SOP_STEP_STARTED` 事件的 `attempt` 字段，并写进该步内的工具调用记录；映射与尝试序号 MUST NOT 改变用量按角色密钥归组的既有口径。

#### Scenario: 有映射时按名字归属

- **WHEN** 调用方传入执行者与验收者的名字映射，一步内验收者因故先于执行者产生回复
- **THEN** 两条回复的角色归属仍按 agent 名判定正确，不因顺序颠倒而错配

#### Scenario: 无映射时沿用顺序推断

- **WHEN** 调用方未传入名字映射，一步内先执行者回复、后验收者回复
- **THEN** 角色归属与引入本变更前一致（第一次回复为执行者，第二次为验收者）

#### Scenario: 尝试序号落进工具记录

- **WHEN** 某步第 2 次尝试内发生工具调用
- **THEN** 该工具调用记录带步骤名与尝试序号 2
