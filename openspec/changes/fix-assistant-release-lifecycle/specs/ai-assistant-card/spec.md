## MODIFIED Requirements

### Requirement: 普通用户只看见已发布名片

助手列表对普通用户 MUST 只返回已发布名片。作者 MUST 能在同一列表看见自己的草稿，并且草稿 MUST 有可见标识。超级管理员 MUST 能看见全部草稿。普通用户请求草稿详情 MUST 返回 404。

同一可见性口径 MUST 覆盖所有按编号访问的旁路接口：草稿名片及其头像、对话栏列表与新建、对话栏详情/改名/发送/取消/删除、对话栏日志列表，对非作者 MUST 返回 404，MUST NOT 返回 403，MUST NOT 泄露草稿内容。已发布名片 MUST 对所有登录用户开放头像与对话。

#### Scenario: 列表按身份过滤草稿

- **WHEN** 平台同时有一条草稿助手和一条已发布助手
- **THEN** 普通用户只看到已发布助手
- **AND** 该草稿的作者能看到两条，且草稿有标识

#### Scenario: 草稿头像不外泄

- **WHEN** 普通用户请求草稿助手的头像
- **THEN** 系统返回 404
- **AND** 响应不含头像内容

#### Scenario: 草稿不能开新对话

- **WHEN** 普通用户对草稿助手请求新建对话栏
- **THEN** 系统返回 404
- **AND** 不创建对话栏

#### Scenario: 草稿的对话与日志不可读

- **WHEN** 普通用户用草稿助手的对话栏编号请求消息、日志列表、改名、发送、取消或删除
- **THEN** 系统返回 404
- **AND** 对话栏与其消息保持不变

#### Scenario: 已发布名片对所有人可对话

- **WHEN** 非作者对已发布助手的头像与对话栏发起请求
- **THEN** 请求正常成功

## ADDED Requirements

### Requirement: 发布要求引用的 Agent 配置仍然存在

发布助手或发布工作流时，系统 MUST 校验其引用的 Agent 配置仍然存在。引用缺失时 MUST 拒绝发布并返回可读原因，MUST NOT 冻结一份空提示词或空模型的版本。

#### Scenario: 配置被删后发布被拒

- **WHEN** 名片引用的 Agent 配置已被删除，作者点发布
- **THEN** 系统返回 400 并说明 Agent 配置不存在
- **AND** 不产生新的发布版本
