## MODIFIED Requirements

### Requirement: 浏览器与实时模型之间的音频桥接

系统 SHALL 通过后端 WebSocket 通道在浏览器与实时语音模型之间双向转发音频：上行 MUST 为单声道 PCM16、采样率与模型输入采样率一致；下行 MUST 为单声道 PCM16、采样率与模型输出采样率一致。浏览器 MUST NOT 获得模型服务商的 API Key。通道 MUST 要求有效登录凭证：前端 MUST 在建连前确认访问凭证有效（已过期或即将过期则先续期），MUST NOT 带着已过期凭证建立连接；服务端收到缺失、无效或过期凭证时 MUST 拒绝会话并返回可读提示。前端收到服务端以 4401 拒绝时 MUST 自动续期并重连一次，重连成功 MUST NOT 向用户展示登录过期错误；仅当续期失败或重连仍被拒时 MUST 提示「登录状态已过期」，且 MUST NOT 无限重试。

#### Scenario: 上行音频按模型输入采样率发送

- **WHEN** 会话已建立且模型输入采样率为 16000 Hz
- **THEN** 浏览器发送的上行音频为单声道 PCM16、16000 Hz
- **AND** 后端按原样转发给实时模型，不做二次编码

#### Scenario: 下行音频在浏览器按模型输出采样率播放

- **WHEN** 后端收到模型输出采样率为 24000 Hz 的音频块
- **THEN** 浏览器按 24000 Hz 解码并连续播放，不出现按错误采样率变速

#### Scenario: 未登录不能建立语音通道

- **WHEN** 未携带访问凭证的客户端连接 `/ws/knowledge-assistant/`
- **THEN** 服务端拒绝该会话并返回可读提示
- **AND** 不创建模型会话、不写入对话日志

#### Scenario: 凭证过期的用户仍能开始对话

- **WHEN** 本地访问凭证已过期，用户点击「开始对话」
- **THEN** 前端先续期再建立 WebSocket，会话正常开始
- **AND** 页面 MUST NOT 出现「登录已过期」类错误

#### Scenario: 重连仍被拒才提示过期

- **WHEN** 服务端以 4401 拒绝，且续期后重连仍被 4401 拒绝
- **THEN** 页面提示「登录状态已过期」，不进入重连循环
- **AND** 用户下次点击「开始对话」时重新走一次建连前续期
