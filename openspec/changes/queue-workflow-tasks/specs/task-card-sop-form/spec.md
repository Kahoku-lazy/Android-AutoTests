## REMOVED Requirements

### Requirement: 智能体单选且必选

**Reason**: 任务清单不再提供新建任务弹窗。工作流任务由助手页的工作流卡片提交。
**Migration**: 使用助手页工作流卡片的「任务」弹窗提交工作流编号、里程碑 YAML 与必选设备。

### Requirement: 测试指定用例来自 YAML 标题

**Reason**: 该下拉只存在于已退役的任务清单新建弹窗。
**Migration**: 工作流运行使用里程碑 YAML，不再在任务清单解析用例标题。

### Requirement: 弹窗提交载荷按用例来源区分

**Reason**: 该载荷只由已退役的任务清单新建弹窗发送。
**Migration**: 工作流任务从助手页提交工作流编号、里程碑 YAML 与设备地址。

### Requirement: 平台用例来源由后端物化为执行 YAML

**Reason**: 平台用例物化只服务任务清单新建弹窗，本次不再从任务清单创建该类任务。
**Migration**: 历史任务保留原配置附件；新的工作流任务使用用户提交的里程碑 YAML。

### Requirement: 新建任务弹窗按用例来源提交

**Reason**: 任务清单不再创建任务，平台用例与本地 YAML 两个来源不再从该页进入。
**Migration**: 历史设备执行与用例编写记录保留在各自报告与台账中，不从任务清单新建。
