## MODIFIED Requirements

### Requirement: 主模型用尽后回退备用模型

仅当调用方已经传入备用模型实例时，引擎 SHALL 在主模型重试用尽后改用该实例完成同一次调用，并把备用模型的结果作为本次推理的结果。回退 MUST NOT 改变本轮上下文、工具清单与工具选择策略。未传入备用模型、或备用模型同样失败时，MUST 抛出最后一次的原始错误。回退 MUST 只发生在瞬态故障之后。重试模块 MUST NOT 自行读取备用模型的连接参数或环境变量来构造另一个模型。

#### Scenario: 主模型用尽后由备用模型完成

- **WHEN** 主模型每次都失败于瞬态故障、调用方已传入备用模型，且备用模型返回正常响应
- **THEN** 本轮推理拿到备用模型的响应，日志里出现一条回退警告

#### Scenario: 未配置备用模型

- **WHEN** 主模型每次都失败于瞬态故障，且调用方没有传入备用模型
- **THEN** 引擎不尝试其它模型，也不读取备用模型环境变量，按重试用尽规则抛出原始错误

#### Scenario: 备用模型也失败

- **WHEN** 主模型与备用模型都失败于瞬态故障
- **THEN** 引擎抛出最后一次的原始错误，MUST NOT 编造成功响应
