## REMOVED Requirements

### Requirement: 表格只读且如实说明生效时机

**Reason**: 需求方批准放开关键词维护：超级管理员可在页面新建 / 编辑 / 删除，「任何用户只读、无任何写回接口」的旧口径被取代。
**Migration**: 由新需求「表格维护权限与生效时机」承接；非超管只读、数据库来源如实标注、刷新即取最新、无重启文案的口径保留。

## ADDED Requirements

### Requirement: 表格维护权限与生效时机

关键词表 SHALL 对非超级管理员保持只读：MUST NOT 出现新建 / 编辑 / 删除控件，MUST NOT 发出任何写请求。超级管理员 SHALL 可在页面新建、编辑、删除关键词条目（新建按钮 + 行内操作列 + 表单弹窗），写入 MUST 经串口日志模块的维护接口。条目取自数据库，页面刷新 MUST 取到表内最新条目；页面 MUST 如实说明条目来源为数据库，MUST NOT 呈现「改表后需重启平台」的旧文案。新建 / 编辑 / 删除成功后页面 MUST 刷新目录，计数与行序随最新表呈现；删除 MUST 有二次确认。

#### Scenario: 非超管没有写操作

- **WHEN** 普通登录用户浏览该表格
- **THEN** 页面不出现新建 / 编辑 / 删除控件，不发出任何写请求，表格恰为四个数据列

#### Scenario: 超管新建

- **WHEN** 超级管理员点击「新建关键词」，填写表单并提交成功
- **THEN** 弹窗关闭，目录刷新，新条目按行序出现在表中

#### Scenario: 超管编辑

- **WHEN** 超级管理员点击行内编辑，修改功能点名并保存成功
- **THEN** 该行更新为新名称，其余行不变

#### Scenario: 超管删除

- **WHEN** 超级管理员点击行内删除并在二次确认中确认
- **THEN** 条目移除，目录刷新；在二次确认中取消则不发出写请求

#### Scenario: 如实说明生效时机

- **WHEN** 用户查看表格底部的来源说明
- **THEN** 说明标注取值来自数据库、刷新即取最新条目，不出现「改表后需重启平台」字样

#### Scenario: 刷新即见最新条目

- **WHEN** 关键词表新登记了条目，用户点击刷新
- **THEN** 表格展示最新条目，无需重启平台

## MODIFIED Requirements

### Requirement: 表格列、范围筛选与搜索口径确定

表格 MUST 恰为四个数据列：**关键词 / 功能模块 / 功能点（编号 + 名称）/ 范围**；超级管理员另见**操作列**（编辑 / 删除，不计入数据列），非超管 MUST NOT 出现操作列。范围列 MUST 按口径渲染：通用范围显示「通用」，SKU 专用范围显示「<SKU>专用」（如「H6601专用」）。行序 MUST 与关键词表内登记顺序一致：关键词按登记先后、同一关键词的功能点按登记先后；前端 MUST NOT 重排或合并。搜索 SHALL 以忽略大小写的包含匹配同时作用于关键词、功能模块名与功能点名，命中即保留该行。表格 SHALL 提供范围筛选（全部 / 通用 / 各 SKU 专用），筛选 MUST 只保留所选范围的行；搜索与范围筛选 MUST 可叠加。搜索或筛选时 MUST NOT 改变表格列，也 MUST NOT 让计数缩水（计数恒报全量：关键词按原文去重、功能点按「模块 + 编号 + 名称」去重，范围不影响去重口径）；无命中时 MUST 给出可读空态；清空搜索与范围筛选后 MUST 回到全量。

#### Scenario: 四列固定

- **WHEN** 用户查看该表格
- **THEN** 非超管表头恰为「关键词 / 功能模块 / 功能点 / 范围」四列；超管在四个数据列之外另有操作列

#### Scenario: 行序与登记顺序一致

- **WHEN** 关键词表里关键词与功能点的登记先后顺序固定
- **THEN** 表格行序与之逐行一致，前端不重排

#### Scenario: 按关键词搜索

- **WHEN** 用户输入某个关键词的一部分
- **THEN** 只保留命中该关键词的行，其余不显示

#### Scenario: 按功能点或模块搜索

- **WHEN** 用户输入某个功能点名称或模块名称的一部分
- **THEN** 命中该名称的行被保留

#### Scenario: 搜索时计数不缩水

- **WHEN** 用户输入任一搜索内容
- **THEN** 关键词数与功能点数仍为全量数值

#### Scenario: 无命中给空态

- **WHEN** 用户输入的内容在关键词表里没有任何匹配
- **THEN** 表格区展示可读的「没有匹配的关键词」空态，MUST NOT 呈现空白区域

#### Scenario: 清空搜索回到全量

- **WHEN** 用户清空搜索框
- **THEN** 表格恢复到全量并按既定行序排列

#### Scenario: 通用范围渲染

- **WHEN** 某行范围为通用
- **THEN** 范围列显示「通用」

#### Scenario: SKU 专用范围渲染

- **WHEN** 某行范围为 SKU H6601
- **THEN** 范围列显示「H6601专用」

#### Scenario: 按范围筛选

- **WHEN** 用户选择只看某一范围（如「H6601专用」或「通用」）
- **THEN** 只保留该范围的行，计数仍为全量数值
- **AND** 叠加搜索词时两个条件同时生效

#### Scenario: 清空范围筛选回到全量

- **WHEN** 用户把范围筛选恢复为「全部」
- **THEN** 表格恢复全量行，行序与配色不变
