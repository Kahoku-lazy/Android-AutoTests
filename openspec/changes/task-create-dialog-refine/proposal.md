## Why

「新建任务」弹窗 640px、左标签 120px，横向空间被标签吃掉，用例选择器（项目/用例表/用例列表）整块塞在表单流里，把「设备」和底部按钮顶到滚动区外；字段平铺也没有「基本信息 / 用例」的层级。

## What Changes

- 弹窗 640 → **900px**，两栏：左侧「基本信息（标题 / 智能体 / 用例来源 / 配置 / 设备）」，右侧「平台用例」选择面板。
- 表单标签由左侧 120px 改为**标签在上、输入在下的紧凑字段**。
- 右侧列按用例来源切换：平台用例 → 选择器；本地 YAML → 执行方式说明；需求文档 → 文档解析说明。
- 提交/取消固定在 footer，窄屏（<980px）自动回退单栏。
