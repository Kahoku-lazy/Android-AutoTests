## Context

现状（见 `proposal.md` - Why，需求见 delta spec）：

- 任务详情页是 Doodle 涂鸦风：用例卡 `2.5px dashed` + `4px 4px 0` 硬投影，步骤行只有左侧 4px 色条，结果徽标是 `2px solid ink` 方框。
- 仪表盘的 `TaskResultPanel.vue` 已是卡片风：`28px` 状态方块（`--app-status-*-bg` + 文字色）、`1px` 边框白卡、软底胶囊。两者同页对照会显得割裂。
- `28c51e81` 已上线四层耗时：`.flow-case__duration` / `.flow-step__duration` / `.flow-proc__duration` 都是 `--color-cyan-74` + `2px solid ink`，是页面上最重的元素之一。
- 折叠三级（步骤 → 第 N 次 → 过程）已实现，这次不动逻辑，只换外观。

## Goals / Non-Goals

**Goals:**

- 详情页与仪表盘共用一套卡片语言：白卡、1px 实线、圆角、无硬投影。
- 结果一眼可分：左方块给颜色与图标，右标签给文字，两处一致。
- 耗时保留天蓝身份但降低视觉权重：1px 描边、等宽数字、紧贴结果标签。

**Non-Goals:**

- 不改数据、接口、折叠逻辑与组件边界。
- 不改其它模块的 Doodle 风格（仅任务详情页内实线化）。
- 不新增颜色原子或语义令牌。

## Decisions

### 1. 沿用仪表盘的卡片解剖，不自创

行高与内距、方块 `28×28`、`--app-radius-sm` 取仪表盘同一套。理由：同一个人在两页之间切换时不需要重新学习；且这些数值已在 `TaskResultPanel` 验证过密度。

**备选**：保留现有「左色条 + 行」只换成实线。被否决——那样步骤之间仍没有边界，密集用例依旧糊成一片。

### 2. 结果双通道：方块给图标，标签给文字

方块 `✓/✗/△/○` 用颜色（绿/红/黄/灰）+ 字形；右侧标签只写 `PASS` / `FAIL` / `未完成` / `未执行`。方块与标签 MUST 一致。

**备选**：标签也带 `✓`。被否决——同一行出现两个 ✓ 只会增加噪声；仪表盘的参考图里，行上也只有方块，没有重复图标。

### 3. 实线范围：整页（用例卡 + 摘要 + 步骤 + 过程）

只改步骤区会留下「虚线用例卡里装着卡片步骤」的混搭。整页改 `1px solid` 后，层级由「页面底 → 卡片 → 浅底内嵌 → 白卡」四层背景拉开，不再依赖描边粗细。

### 4. 线条颜色用 ink 混白派生，不加令牌

`color-mix(in srgb, var(--ink) 10~22%, transparent)`：`--app-border-light` 是纯白，在白卡上不可见；新增颜色原子会撞 `lint:styles` 的白名单（上限 98）。P2 若多处复用再抽 `--app-border-muted`。

### 5. 耗时 chip：天蓝填充 + 1px 描边 + 等宽数字

保留 `--color-cyan-74` 填充（用户指定天蓝），描边从 2px 收到 1px，字号 11.5px 粗体，`font-variant-numeric: tabular-nums`——页面 3 秒轮询，数字变宽变窄不能推动右侧标签。进行中时描边加深一档，不换色。

## 模块防火墙自检

- 只改 `frontend/src/modules/task-list/**`，无跨模块 import、无后端改动、无写库。

## Risks / Trade-offs

- [卡片圆角图省事写成 `overflow: hidden`，把超出一屏的内容裁掉] → 用例卡是 `.doc-body` 的 flex 子项，`overflow` 非 `visible` 会让自动最小高度变 0 而被压缩。**实测回归**：超长用例只看得到一屏。改为不带 `overflow`，并显式 `flex-shrink: 0`。
- [整页实线化后与侧栏/页头的涂鸦风不搭] → 页头保持原样，实线仅限内容区（用例卡与以下），侧栏不在本页 DOM 内。
- [卡片间距让长用例变高] → 步骤卡间距 8px、卡片内距 10px；收起态一行约 48px，仍比展开态省。
- [移除 2px 描边后白卡在白底上边界弱] → 保留 1px `ink 10%` 描边，并靠 `--paper` 页面底与白卡区分。
- [测试断言基于旧类名] → 保留 `.flow-step__badge` 等类名，只加 `.flow-step__status` / `.flow-step__duration`，断言按新结构补充。
