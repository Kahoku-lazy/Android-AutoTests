## MODIFIED Requirements

### Requirement: 坐标核对工具

系统 SHALL 在引擎工具层提供一个只读的坐标核对工具：输入设备序列号与坐标，截取当前屏幕并在该坐标处画红色圆点，返回标记后的图片（base64 + media_type）、该帧的标识 `token` 与换算后的像素坐标 `x` / `y`。再给一个终点坐标时，工具 MUST 改画**起点→终点的拖动轨迹**：起点标 1、终点标 2、两点之间画连线并在终点画箭头，返回体 MUST 一并给出终点像素坐标 `x2` / `y2`。工具 MUST 不落盘，且失败时返回可读 error。该工具 MUST 装配给执行角色并保持常驻；验收角色 MUST NOT 获得该工具。

`token` MUST 在核对后的 90 秒内有效，且 MUST 只对同一设备有效。持有效 `token` 的点击类与拖动类工具 MUST 复用该帧上已标记的点定位，MUST NOT 为同一次操作重新截屏；`token` 过期或不匹配时 MUST 返回可读 error 并要求重新核对，MUST NOT 静默改用新截图的坐标。帧缓存 MUST 只存在于进程内，MUST NOT 落盘、写库或进入事件载荷。

#### Scenario: 标记后的图片返回给模型

- **WHEN** 执行模型以归一化坐标调用坐标核对工具
- **THEN** 工具返回一张在原坐标处带红点的截图，media_type 与原截图一致

#### Scenario: 同时给出帧标识与像素坐标

- **WHEN** 执行模型以归一化坐标 `nx=0.5`、`ny=0.5` 调用坐标核对工具，屏幕为 1080×2400
- **THEN** 返回体含 `token`，且 `x=540`、`y=1200`

#### Scenario: 给出终点时画拖动轨迹

- **WHEN** 执行模型以起点 `(0.2, 0.5)`、终点 `(0.8, 0.5)` 调用坐标核对工具
- **THEN** 图上在起点与终点各有一个带序号的标记点、两点之间有连线且终点带箭头，返回体含 `x2` / `y2`，该帧记录两个点

#### Scenario: 像素坐标同样可核对

- **WHEN** 执行模型以 `xpath_action` 返回的像素坐标调用坐标核对工具，并传 `normalized=False`
- **THEN** 工具按原图像素坐标画红点，不做归一化换算

#### Scenario: 有效帧标识不再重新截屏

- **WHEN** 点击或拖动工具收到核对工具刚返回的有效 `token`
- **THEN** 该次操作按 `token` 对应帧上的点执行，不产生新的设备截屏

#### Scenario: 帧标识失效时要求重新核对

- **WHEN** 点击或拖动工具收到的 `token` 已过期，或不属于该设备
- **THEN** 返回可读 error 并提示重新调用坐标核对工具，MUST NOT 用新截图替代该次操作

#### Scenario: 工具只读且常驻

- **WHEN** 检查执行角色的常驻工具表
- **THEN** 其中包含坐标核对工具，且该工具标记为只读

#### Scenario: 验收角色看不到

- **WHEN** 检查验收角色的工具包
- **THEN** 其中不包含坐标核对工具

#### Scenario: 截屏或坐标失败

- **WHEN** 设备截屏失败，或像素坐标越界
- **THEN** 工具返回 {"error": ...}，不抛出未处理异常
