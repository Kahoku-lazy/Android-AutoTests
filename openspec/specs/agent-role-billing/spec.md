# agent-role-billing Specification

## Purpose
让实验角色按 DeepSeek 当前价目，把一轮回复的输入、输出和缓存命中用量分别折成元，并在法定节假日取消高峰。

## Requirements

### Requirement: 只按当前两个 DeepSeek 模型计价
DeepSeek 费用 MUST 只接受 `deepseek-flash` 与 `deepseek-v4-pro`。其它模型名（含已下线旧名）MUST 返回输入、输出、缓存命中费用均为 0。空闲时段单价（元 / 百万 tokens）MUST 为：`deepseek-flash` 缓存命中 0.02、缓存未命中 1、输出 4；`deepseek-v4-pro` 缓存命中 0.15、缓存未命中 4.5、输出 13.5。

#### Scenario: 正式模型按价目计费
- **WHEN** 模型为 `deepseek-flash`，输入 2000000 token、输出 100000 token、缓存命中 500000 token，且调用时刻处于空闲时段
- **THEN** 输入费用为 1.5 元，输出费用为 0.4 元，缓存命中费用为 0.01 元

#### Scenario: 未登记模型不计费
- **WHEN** 模型名为 `deepseek-chat` 或其它未登记名字，且用量不为零
- **THEN** 输入、输出、缓存命中费用均为 0

### Requirement: 费用与用量三项对齐
一次计费 MUST 返回输入费用、输出费用、缓存命中费用，顺序与用量的输入 token、输出 token、缓存命中 token 一致。单位 MUST 为元。每一项 MUST 在精确金额算出之后，按小数点后 4 位四舍五入：第 5 位小于 5 则舍去，大于或等于 5 则进位。取位后的金额以普通十进制表示，MUST NOT 使用科学计数法。不足 0.00005 元的一项 MUST 为 0；非零结果的最小刻度是 0.0001 元。缓存命中 token MUST 先截断到不超过输入 token；输入费用 MUST 只按未命中部分（输入减去缓存命中）乘缓存未命中单价，缓存命中费用 MUST 按命中单价，输出费用 MUST 按输出单价。三项相加 MUST 等于按官方扣费规则计算的该轮总费用（在分别保留 4 位小数之前）。

#### Scenario: 小额输入保留四位有效数字
- **WHEN** 模型为 `deepseek-flash`，输入 12345 token、输出 0、缓存命中 0，且处于空闲时段
- **THEN** 输入费用为 0.0123 元，输出费用与缓存命中费用为 0

#### Scenario: 第五位大于五则进位
- **WHEN** 模型为 `deepseek-flash`，输入 4670 token、输出 0、缓存命中 0，且处于空闲时段
- **THEN** 精确输入费用为 0.00467 元，取位后为 0.0047 元，输出费用与缓存命中费用为 0

#### Scenario: 第五位小于五则舍去
- **WHEN** 模型为 `deepseek-flash`，输入 4630 token、输出 0、缓存命中 0，且处于空闲时段
- **THEN** 精确输入费用为 0.00463 元，取位后为 0.0046 元

#### Scenario: 第五位恰好为五则进位
- **WHEN** 模型为 `deepseek-flash`，输入 4650 token、输出 0、缓存命中 0，且处于空闲时段
- **THEN** 精确输入费用为 0.00465 元，取位后为 0.0047 元

#### Scenario: 很小的缓存命中不再使用科学计数法
- **WHEN** 模型为 `deepseek-flash`，输入 2560 token、输出 972 token、缓存命中 2560 token，且处于空闲时段
- **THEN** 输入费用为 0，输出费用为 0.0039 元，缓存命中费用为 0.0001 元，且三项都以普通小数表示

#### Scenario: 不足半分的金额变为零
- **WHEN** 精确的某一项费用小于 0.00005 元
- **THEN** 该项费用为 0

#### Scenario: 缓存命中不超过输入
- **WHEN** 缓存命中 token 大于输入 token
- **THEN** 缓存命中按输入 token 计，输入费用为 0

### Requirement: 高峰只出现在非假日的工作日钟点
北京时间周一至周五 9:00–12:00 与 14:00–18:00 MUST 按空闲单价的 2 倍计费。周末全天（含调休上班的周六日）MUST 按空闲单价。法定放假日全天 MUST 按空闲单价。未给出调用时刻时 MUST 按空闲单价。带时区的时刻 MUST 先换算到北京时间。节假日数据未收录该年时，MUST 退回「周一至周五的上述钟点为高峰」，MUST NOT 把该年全部当成空闲。

#### Scenario: 法定假日的工作日上午按空闲
- **WHEN** 调用时刻为北京时间 2026-10-01 10:00（周四，国庆放假），模型为 `deepseek-flash`，输入 1000000 token 且无缓存命中、无输出
- **THEN** 输入费用为 1 元

#### Scenario: 普通工作日上午按高峰
- **WHEN** 调用时刻为北京时间 2026-10-08 10:00（周四，非假日），模型与用量同上
- **THEN** 输入费用为 2 元

#### Scenario: 调休周六按空闲
- **WHEN** 调用时刻为北京时间 2026-10-10 10:00（周六，国庆调休上班），模型与用量同上
- **THEN** 输入费用为 1 元

#### Scenario: 未收录年份仍按工作日高峰
- **WHEN** 调用时刻为北京时间 2035-10-08 10:00（周一），节假日数据不含 2035 年，模型与用量同上
- **THEN** 输入费用为 2 元

### Requirement: 角色按模型类型匹配计费
角色对一轮回复计费时，MUST 先取该轮的输入 token、输出 token 与缓存命中 token，再按模型提供商选择费用计算。提供商为 DeepSeek 时 MUST 返回上述三项费用，并用当前北京时间判断高峰。其它提供商 MUST 返回三项均为 0。角色 MUST NOT 对费用再做一次取位。

#### Scenario: DeepSeek 角色返回三项费用
- **WHEN** 角色的提供商为 DeepSeek、模型为 `deepseek-flash`，该轮用量为输入 12345、输出 1000、缓存命中 345，且当前时刻处于空闲时段
- **THEN** 费用为输入 0.012 元、输出 0.004 元、缓存命中 0 元

#### Scenario: 非 DeepSeek 角色不计费
- **WHEN** 角色的提供商不是 DeepSeek，且该轮用量不为零
- **THEN** 输入、输出、缓存命中费用均为 0
