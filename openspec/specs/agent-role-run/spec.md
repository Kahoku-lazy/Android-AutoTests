# agent-role-run Specification

## Purpose
角色基类提供两条同步运行方式：等模型完成本轮任务后返回最终消息，或边把过程打到控制台、边写入对话稿，结束后再返回最终消息。基类自己不解析用量。

## Requirements

### Requirement: 等本轮结束并返回最终消息
角色基类的返回结果入口 MUST 以同步方式等待本轮结束，并返回框架给出的最终消息。该入口 MUST NOT 自行打印这条消息，MUST NOT 解析用量、费用或正文。调用方拿到消息后再做解析。

#### Scenario: 本轮正常结束
- **WHEN** 调用方用一段用户正文请求返回结果，且本轮正常结束
- **THEN** 调用方得到本轮最终消息，基类没有为这条消息向控制台打印正文

#### Scenario: 基类不解析用量
- **WHEN** 调用方拿到上述最终消息
- **THEN** 基类没有从该消息算出输入、输出或缓存命中 token

#### Scenario: 已在运行的事件循环内调用
- **WHEN** 调用方在已经运行的事件循环内请求返回结果
- **THEN** 调用失败，并指出不能在运行中的事件循环内启动这一轮

### Requirement: 上屏并写入对话稿后返回最终消息
角色基类的上屏入口 MUST 以同步方式跑完一轮。每个过程事件 MUST 打到控制台，并写入同一份对话稿。结束后 MUST 返回本轮最终消息，MUST NOT 把可继续迭代的事件流交给调用方。基类 MUST NOT 自己算出用量三元组。

#### Scenario: 上屏、落日志并返回消息
- **WHEN** 调用方用一段用户正文请求上屏运行，且本轮正常结束
- **THEN** 控制台出现本轮过程，对话稿记下本轮用户正文与过程事件，调用方得到本轮最终消息

#### Scenario: 不把事件流交出去
- **WHEN** 上屏运行结束
- **THEN** 调用方得到的是最终消息，不是可继续迭代的事件流

#### Scenario: 已在运行的事件循环内上屏
- **WHEN** 调用方在已经运行的事件循环内请求上屏运行
- **THEN** 调用失败，并指出不能在运行中的事件循环内启动这一轮
