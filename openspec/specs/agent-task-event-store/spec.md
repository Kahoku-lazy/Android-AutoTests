# agent-task-event-store Specification

## Purpose

把一次平台任务里已经折好的智能体事件写入数据库，同时保存缩略图和按小时累计的 8 位费用。任务流程报告读取这些事件。

## Requirements

### Requirement: 平台任务写入结构化事件
有任务号的平台运行 MUST 把交给接收方的结构化记录写入该任务的事件表。同一任务内序号 MUST 从已有最大序号之后连续递增，且任务与序号的组合 MUST 唯一。每条记录 MUST 带上该次运行的用例标题；有当前步骤时 MUST 带上从 1 起的步骤序号和该步的尝试次数，没有当前步骤时这两项 MUST 为空。费用 MUST 保留小数点后 8 位。文本日志 MUST 仍然写出。任务号为 0 或未绑定运行上下文时 MUST NOT 写入事件、图片或小时用量。

#### Scenario: 三条记录按序落在同一任务下
- **WHEN** 一次任务依次交出回复结束、模型调用结束和工具返回结束
- **THEN** 事件表有序号 1、2、3 的三行，且都带该任务的用例标题

#### Scenario: 当前步骤被盖到记录上
- **WHEN** 交出记录时，流程正处于第 2 步的第 1 次尝试
- **THEN** 该行的步骤序号为 2，尝试次数为 1

#### Scenario: 没有任务号时不写库
- **WHEN** 任务号为 0 时交出一条模型调用结束
- **THEN** 事件表、图片表和小时用量表都没有新增行，文本日志仍可写出

### Requirement: 模型调用结束累加小时用量
只有模型调用结束 MUST 累加小时用量。归入的日期和小时 MUST 取该次调用结束时刻的北京时间。同一日期、小时、模型、角色名和智能体编号 MUST 累加到同一行，调用次数、token 和三项 8 位费用都累加。智能体未知时编号 MUST 为 0，且 MUST NOT 通过外键约束智能体是否存在。回复结束或其他事件 MUST NOT 增加小时用量。缓存未命中 token MUST 为输入 token 减去缓存命中 token，且不得小于 0。删除任务 MUST NOT 删除小时用量。

#### Scenario: 一次模型调用写入对应小时
- **WHEN** 一条模型调用结束的时刻是北京时间 2026-10-20 10:00，缓存命中等于输入，缓存费用为 0.00002000
- **THEN** 该日期 10 时、该模型、该角色和该智能体的用量行调用次数为 1，缓存费用为 0.00002000，缓存未命中 token 为 0

#### Scenario: 回复结束不计入小时用量
- **WHEN** 同一任务只交出回复结束，没有模型调用结束
- **THEN** 小时用量表没有新增或增加调用次数

### Requirement: 任务费用只汇总模型调用结束
任务运行收尾时 MUST 把该任务全部模型调用结束行的输入费用、缓存费用、输出费用分别求和，并写回任务上的对应列；合计 MUST 为这三项之和。回复结束行上携带的轮次费用 MUST NOT 计入这次求和。没有模型调用结束时，四项任务费用 MUST 为 0。写入失败 MUST NOT 改写已经完成的任务终态。

#### Scenario: 回复结束的费用不重复计入
- **WHEN** 一条模型调用结束的缓存费用为 0.00002000、输出费用为 0.00004000，同一次运行的回复结束也带有这些金额
- **THEN** 任务的缓存费用为 0.00002000，输出费用为 0.00004000，合计为 0.00006000

#### Scenario: 收尾时刷出尚未写入的记录
- **WHEN** 运行结束时接收方里还有未写入的记录
- **THEN** 这些记录先写入事件表，再按模型调用结束行回写任务费用

### Requirement: 图片只存缩略图并按内容去重
带图片的记录 MUST 把原图压成长边不超过 720 的 JPEG 缩略图后再保存，MUST NOT 保存原图 base64。同一任务内内容相同的原图 MUST 只占一行图片，后续记录 MUST 指向这一行。系统 MUST NOT 按张数设置采集上限：任意数量的不同图片 MUST 都能新增图片行，对应事件 MUST 拿到该图片的引用。无法解码的图片 MUST 跳过图片保存，事件行本身 MUST 仍然写入。删除任务时，该任务的事件和图片 MUST 一并删除。

#### Scenario: 同一张图只存一行
- **WHEN** 同一任务的两条工具返回结束携带同一张原图
- **THEN** 图片表只有一行，两行事件指向同一张缩略图，且媒体类型为 JPEG

#### Scenario: 超过三百张后继续保存
- **WHEN** 某任务已经有 300 张不同图片，又出现第 301 张新的不同图片
- **THEN** 图片表新增一行，该事件的图片引用不为空

#### Scenario: 多用例任务全程都有图
- **WHEN** 一个任务的截图总数达到 785 张（跨 12 条用例）
- **THEN** 每张不同画面都占一行图片，任意一次截图事件都能拿到图片引用

#### Scenario: 删除任务带走事件和图片
- **WHEN** 删除一个已有事件和图片的任务
- **THEN** 该任务的事件和图片都不再存在
