# ai-assistant-test-chat Specification

## Purpose

让用户用多个对话栏测试已创建的助手。同一栏的上下文连续；离开页面不会取消进行中的轮次，只有用户在该栏主动取消才会停止。

## Requirements

### Requirement: 打开对话不运行，发送才创建本栏实例

点击对话 MUST 只打开对话页，MUST NOT 调用模型。一个对话栏的第一次发送 MUST 按发送当时的助手名片创建该栏唯一的 Agent 实例，并把输入作为用户消息发送，消息发送者名称 MUST 为 `user`。同一栏之后的发送 MUST 复用该实例，上下文连续。新建另一个对话栏 MUST 使用新的会话，MUST NOT 复用已有栏的实例。

#### Scenario: 首次发送才运行

- **WHEN** 用户打开某助手的对话页但尚未发送
- **THEN** 没有模型调用
- **AND** 该栏没有 Agent 实例

#### Scenario: 同栏第二句续聊

- **WHEN** 用户在同一对话栏发送第二句
- **THEN** 使用该栏第一次发送时创建的同一个实例
- **AND** 不新建第二个实例

### Requirement: 改名片不改已打开的对话栏

助手名片在某对话栏首次发送之后被修改时，该栏 MUST 继续使用首次发送时的配置。新建的对话栏 MUST 使用修改后的名片。系统 MUST NOT 把对话栏中的实例写回名片，也 MUST NOT 在本期把对话栏配置交给 SOP。

#### Scenario: 已发送的栏不跟随新配置

- **WHEN** 某栏已经发送过，用户随后更换该助手引用的运营配置
- **THEN** 该栏下一句仍使用更换前的配置
- **AND** 新建的另一个栏使用更换后的配置

### Requirement: 离开页面不取消，只有主动取消才停止

进行中的轮次 MUST 在用户刷新、跳转到其它页面或切换对话栏之后继续，直到该轮结束。只有用户在该栏点击取消，系统才 MUST 停止该轮。取消 MUST NOT 影响其它对话栏。服务进程重启后，重启前未结束的轮次 MUST 标为已中断，MUST NOT 自动续跑；这与用户取消区分。每一轮无论完成、取消或失败，只要已经开始记录，MUST 留下可从该对话栏回看的运行日志。

#### Scenario: 刷新后轮次仍在

- **WHEN** 用户发送后刷新页面，该轮尚未结束
- **THEN** 该轮继续运行
- **AND** 回来后能看到该轮仍在进行或已经结束的结果

#### Scenario: 取消只停当前栏

- **WHEN** 用户取消当前对话栏的进行中轮次
- **THEN** 该轮停止并记为用户取消
- **AND** 其它对话栏的轮次不受影响

#### Scenario: 重启后不续跑

- **WHEN** 服务进程在某轮进行中重启
- **THEN** 该轮状态为已中断
- **AND** 不会自动重新调用模型

#### Scenario: 结束后能从该栏回看日志

- **WHEN** 一轮已经结束、取消或失败
- **THEN** 该对话栏的日志入口能列出这一轮
- **AND** 已完成的一轮可以打开对应报告

### Requirement: 对话页以笔色标出身份与当前栏

测试对话页 MUST 有页头，页头 MUST 只显示该助手的图标与显示名，MUST NOT 出现「返回助手」或其它动作按钮。返回入口 MUST 位于正文区域（`.doc-body` 顶部工具条）。助手显示名 MUST 来自进入对话时带上的参数，缺省时回落为「对话」。左栏 MUST 列出全部对话栏并用**浅蓝填充 + 墨色描边**标出当前栏，其余栏用实线分隔。消息流 MUST 左对齐助手气泡并以笔色描边，右对齐用户气泡并保持纸色。发送钮 MUST 使用该助手笔色的深到浅渐变。消息为空时 MUST 给空态提示；轮次进行中 MUST 给状态行与取消入口。

#### Scenario: 返回入口不在页头

- **WHEN** 用户进入某助手的对话页
- **THEN** 页头只有助手图标与名称，没有返回按钮
- **AND** 正文顶部左侧有一个「返回助手」按钮，点击回到助手列表

#### Scenario: 进入对话页看到助手身份

- **WHEN** 用户从名为「小助」的卡片点「对话」
- **THEN** 对话页页头显示「小助」
- **AND** 当前对话栏带该助手的笔色描边

#### Scenario: 进行中可见且可取消

- **WHEN** 某一轮正在跑
- **THEN** 页面显示「这一轮还在跑」与取消入口
- **AND** 发送钮不可用

### Requirement: 对话页左栏是虚线面板卡

左栏 MUST 是一张纸色虚线卡（`1.5px` 浅墨虚线、圆角取令牌、四边闭合），且 MUST NOT 做倾斜或 hover 位移。卡内 MUST 有名称「对话栏」、双波浪线装饰、新建对话入口与对话栏列表。双波浪线 MUST 由两条不同颜色组成：上波为该助手笔色，下波为模块色 `--c-ai`；两条线 MUST NOT 承载信息或响应点击。左栏与对话区之间 MUST 有一条纵向虚线分隔，该分隔 MUST 拉满两栏所在行的高度，且 MUST 落在两栏间距的中部——与面板右边框保留间距，MUST NOT 贴住或压住面板边框。

#### Scenario: 左栏出现彩色双波浪线

- **WHEN** 用户进入某助手的对话页
- **THEN** 左栏卡片外框是浅墨虚线且不倾斜
- **AND** 卡内有一条该助手笔色的波浪线和一条模块色的波浪线
- **AND** 卡片标题是「对话栏」

#### Scenario: 两栏之间有一条虚线

- **WHEN** 对话栏很少、对话区很空
- **THEN** 左栏与对话区之间仍有一条纵向虚线，纵向拉到内容区底部
- **AND** 该线与左栏面板的右边框之间留有空隙，不贴边也不压边

### Requirement: 对话栏支持重命名与删除

每个对话栏 MUST 支持就地重命名与删除。重命名 MUST 只改标题，MUST NOT 影响消息与该栏的进行中轮次；标题清空 MUST 回落为前端默认的「对话 N」。删除 MUST 先二次确认；删除后该栏的消息 MUST 一并删除且不可恢复。删掉的若是当前栏，系统 MUST 自动切到剩余的第一栏；没有剩余栏时必须新建一栏。删除进行中的栏 MUST 先取消该轮的运行。

#### Scenario: 改名后刷新仍在

- **WHEN** 用户把某个对话栏改名为「第一轮排查」并刷新页面
- **THEN** 该栏显示的仍是「第一轮排查」
- **AND** 栏内的消息没有变化

#### Scenario: 删除当前栏后自动切栏

- **WHEN** 用户删除当前选中的对话栏，且还有其它栏
- **THEN** 该栏从列表消失
- **AND** 当前栏切到剩余列表的第一条

#### Scenario: 删掉最后一个栏

- **WHEN** 用户删除最后一个对话栏
- **THEN** 列表自动新建一栏并选中它

### Requirement: 每条消息带时间

对话栏轮询接口返回的每条消息 MUST 带该条消息的创建时间，格式 MUST 是带时区偏移的 ISO 8601 字符串（平台本地时区）。页面 MUST 在每条气泡旁显示该时刻（时:分），用户消息与助手消息的时刻 MUST 各自与自己的气泡同侧对齐。

#### Scenario: 气泡旁边能看到时刻

- **WHEN** 用户打开一个已有消息的对话栏
- **THEN** 每条消息的气泡旁显示 `HH:mm`
- **AND** 时刻与消息来自同一条记录，不按位置推测

#### Scenario: 新发的一句立刻有时间

- **WHEN** 用户发送一句并等到该轮结束
- **THEN** 该句与回复各自显示自己的时刻
