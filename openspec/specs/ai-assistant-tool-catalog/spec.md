# ai-assistant-tool-catalog Specification

## Purpose

把 Harness 工具域暴露成只读目录，让助手按域、预设和函数例外勾选工具，并在运行时只挂选中的工具。

## Requirements

### Requirement: 工具目录只暴露已注册的域与函数名

系统 SHALL 提供只读工具目录。每个域 MUST 列出显示名、预设（至少含全部与只读）以及该域已有函数的名称与一句说明。目录 MUST NOT 返回函数实现、命令或可执行参数。未注册的域或函数名在保存助手时 MUST 拒绝。

#### Scenario: 目录列出 adb 域

- **WHEN** 客户端请求工具目录
- **THEN** 结果包含 `adb` 域
- **AND** 该域含「全部」与「只读」两个预设，以及该域已注册的函数名

#### Scenario: 未知函数被拒绝

- **WHEN** 保存助手时勾选一个目录中不存在的函数名
- **THEN** 保存失败并返回可读错误
- **AND** 已有勾选不被改写

### Requirement: 勾选保存为预设加例外

助手的工具勾选 MUST 保存为域、预设，以及相对该预设的加入或去掉的函数名。空勾选 MUST 允许保存，表示该助手没有工具。运行时 MUST 经该域的装配入口得到工具，再按勾选过滤；调用方 MUST NOT 直接绑定工具实现模块。

#### Scenario: 只读预设去掉一个函数

- **WHEN** 用户为 `adb` 选择只读预设，并去掉其中一个只读函数
- **THEN** 保存的勾选记录该预设与被去掉的函数名
- **AND** 之后装配出的工具集不含该函数，也不含写操作函数

#### Scenario: 不勾选工具仍可创建

- **WHEN** 用户创建助手时不选择任何工具域
- **THEN** 创建成功
- **AND** 该助手的工具勾选为空
