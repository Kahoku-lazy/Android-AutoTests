# ai-device-prompts Specification

## Purpose
让管理员在 AI 工具箱查看并编辑设备控制三角色的系统提示词，以 Markdown 持久化到平台唯一智能体数据表，供后续任务装配读取。

## Requirements

### Requirement: 工具箱展示三角色系统提示词
系统 SHALL 在 AI 工具箱「工具来源」中提供「设备提示词」入口。选中后，右侧 MUST 展示规划、执行、验收三份系统提示词，且 MUST 将库中 Markdown 源码渲染为可读文档。该入口 MUST NOT 使用与业务工具 / Skill 相同的「交给助手」总闸；提示词始终参与设备任务装配，不由总闸关闭。

#### Scenario: 选中设备提示词来源
- **WHEN** 用户在工具箱左侧点击「设备提示词」
- **THEN** 右侧展示规划 / 执行 / 验收三份提示词，并以 Markdown 渲染正文（标题、列表、代码块可见）

#### Scenario: 非管理员只读
- **WHEN** 非超级管理员打开「设备提示词」
- **THEN** 可见渲染后的三份提示词，不可保存修改

### Requirement: 超级管理员可保存提示词
系统 SHALL 仅允许超级管理员更新三份系统提示词。保存成功后 MUST 立即持久化到平台唯一智能体记录。任一份保存内容去空白后为空时 MUST 拒绝写入并返回可读错误，MUST NOT 部分更新其余角色。

#### Scenario: 管理员保存三份提示词
- **WHEN** 超级管理员提交非空的规划 / 执行 / 验收 Markdown 文本
- **THEN** 三份均写入平台智能体记录，再次读取得到相同正文

#### Scenario: 空提示词拒绝保存
- **WHEN** 超级管理员提交的三份中任一份去空白后为空
- **THEN** 系统拒绝保存，数据库保持原值

#### Scenario: 非管理员保存被拒
- **WHEN** 非超级管理员请求更新设备提示词
- **THEN** 系统返回 403 且不修改记录

### Requirement: 登录用户可读取当前提示词
系统 SHALL 允许已登录用户读取平台唯一智能体当前三份系统提示词（Markdown 源码）。平台智能体不存在时 MUST 返回 404。

#### Scenario: 读取当前提示词
- **WHEN** 已登录用户请求设备提示词
- **THEN** 响应包含 planner / executor / verifier 三份正文

#### Scenario: 无平台智能体
- **WHEN** 系统中不存在平台唯一智能体
- **THEN** 读取返回 404
