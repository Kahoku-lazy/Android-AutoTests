# assistant-eval Specification

## Purpose
用固定剧本和五把纯函数尺子判断一条草稿能不能发布，不依赖真模型分数，也不让作者改判定标准。

## Requirements

### Requirement: 发布只校验草稿与编辑权

发布 MUST 只校验：记录是草稿、操作者有权编辑它。任一不成立时 MUST 拒绝发布，且 MUST NOT 生成新版本。

发布 MUST NOT 读取评测结果、评分高低或「是否评测过」；超级管理员 MUST NOT 另有跳过入口（也不需要跳过，因为不再有评测门）。

发布成功后 MUST 生成新版本并记录当时的草稿内容，供已发布版本复现。

#### Scenario: 草稿且有编辑权即可发布

- **WHEN** 作者对一条自己可编辑的草稿请求发布
- **THEN** 发布成功并生成新版本
- **AND** 不看评测结果

#### Scenario: 无编辑权不能发布

- **WHEN** 操作者对一条不属于自己且没有授权的草稿请求发布
- **THEN** 系统拒绝发布
- **AND** 记录保持草稿

#### Scenario: 已发布不重复发布

- **WHEN** 作者对一条已发布的记录再次请求发布
- **THEN** 系统拒绝
- **AND** 不生成第二个同内容版本
