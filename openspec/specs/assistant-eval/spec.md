# assistant-eval Specification

## Purpose
约束一条草稿能不能发布：只在「草稿 + 有编辑权」时放行，不看评测分数、也不留超级管理员后门；评测只作参考。

## Requirements

### Requirement: 发布只认当前内容的空失败清单

系统 MUST 只在以下条件同时成立时允许发布：记录是草稿，操作者有权编辑它，最新一次自测的内容指纹等于当前草稿指纹，该次失败清单为空，且该次使用的是当前启用的样本集。超级管理员也 MUST 满足这些条件，MUST NOT 另有跳过入口。任一条件不成立时 MUST 拒绝发布，且 MUST NOT 生成新版本。

#### Scenario: 未自测不能发布

- **WHEN** 作者保存草稿后直接请求发布
- **THEN** 系统拒绝发布
- **AND** 记录保持草稿

#### Scenario: 改内容后旧通过失效

- **WHEN** 草稿自测通过后，作者又修改一个工具勾选并请求发布
- **THEN** 系统拒绝发布
- **AND** 不生成新版本

#### Scenario: 超级管理员也不能跳过

- **WHEN** 超级管理员对一条没有空失败清单的草稿请求发布
- **THEN** 系统拒绝发布

### Requirement: 自测使用固定剧本且不触达真实设备

一次自测 MUST 用平台样本中的剧本回应替换模型调用，并用只记录调用的假工具替换设备工具。自测 MUST NOT 发起真实模型请求，也 MUST NOT 向真实设备发送动作。自测 MUST 针对草稿当前内容计算指纹。失败清单 MUST 列出样本、尺子、期望和实际，且 MUST NOT 含密钥明文。

#### Scenario: 自测不产生真实调用

- **WHEN** 作者对一条工作流草稿执行自测
- **THEN** 系统返回每条样本的通过或失败
- **AND** 本次没有真实模型请求和真实设备动作

#### Scenario: 超时记为失败

- **WHEN** 一次自测没有在时限内结束
- **THEN** 失败清单含「自测没有在时限内结束」
- **AND** 系统不自动再跑一次

### Requirement: 五把尺子只按期望判定

系统 MUST 用阶段、步骤结论、角色工具、顺序、重复五把尺子读取本次运行结果。期望里没有对应字段时，该尺子 MUST 跳过，MUST NOT 记为失败。空的禁止名单 MUST 表示不允许任何写操作，与字段不存在区分。任一一把尺子失败，整次样本 MUST 失败。系统 MUST NOT 把多把尺子折成一个可抵消失败的综合分。

#### Scenario: 驳回次数不符时发布失败

- **WHEN** 样本期望第一步尝试 2 次，本次运行只记录 1 次
- **THEN** 步骤结论尺失败
- **AND** 原因写明该步骤、期望次数和实际次数

#### Scenario: 没有阶段期望时不制造失败

- **WHEN** 一条助手样本没有阶段期望，其余期望都满足
- **THEN** 阶段尺跳过
- **AND** 该样本可以通过

#### Scenario: 连续重复调用失败

- **WHEN** 同一步中同一角色连续两次使用相同工具和相同入参
- **THEN** 重复尺失败

#### Scenario: 中间隔着验收不算重复

- **WHEN** 执行者两次使用相同工具和入参，但中间有一次验收者调用
- **THEN** 重复尺不因此失败

### Requirement: 作者不能修改判定标准

样本与期望 MUST 只随程序版本变化。页面 MUST NOT 提供修改期望或尺子的入口。作者调用样本修改接口 MUST 返回 403，且样本保持不变。超级管理员 MUST 只能查看样本、启用或停用样本、查看自测清单。停用样本后，新自测 MUST NOT 再跑它。已有自测记录 MUST 仍能打开，并标明当时使用的样本。

#### Scenario: 作者不能改样本

- **WHEN** 作者请求修改一条样本的期望
- **THEN** 系统返回 403
- **AND** 样本内容不变

#### Scenario: 停用样本只影响以后的自测

- **WHEN** 超级管理员停用一条样本后，作者再次自测
- **THEN** 新自测不包含该样本
- **AND** 停用前的自测记录仍可查看

### Requirement: 样本集变化使旧通过失效

启用中的样本集合发生变化后，所有未发布草稿的既有通过结果 MUST 失效。已发布版本 MUST NOT 因样本变化而回退或重新执行。页面自测与提交门禁 MUST 读取同一份样本定义。

#### Scenario: 新增启用样本后需要重测

- **WHEN** 一条草稿已经自测通过，随后启用样本集合新增一条样本
- **THEN** 作者按旧结果发布被拒绝
- **AND** 草稿保持可编辑

#### Scenario: 已发布版本不回退

- **WHEN** 样本集合变化时已经存在已发布工作流
- **THEN** 该工作流保持已发布
- **AND** 已提交任务的版本不变

### Requirement: 第一批样本覆盖通过与故意失败

系统 MUST 提供五条工作流样本和一条助手样本：两步一次通过、驳回一次后再通过、驳回次数用尽、验收者出现写操作、同一步连续重复调用，以及助手同栏第二句仍是同一实例且未勾选工具没有出现。这些样本 MUST 同时用于提交门禁和页面自测。

#### Scenario: 故意失败样本会让自测变红

- **WHEN** 使用「验收者出现写操作」的样本执行自测
- **THEN** 失败清单点名验收者与该工具
- **AND** 发布被拒绝
