# case-manager-workspace-preview Specification

## Purpose
定义用例管理项目工作台的「左目录树 + 右用例预览」版式，以及右栏预览的只读契约：固定五列、分页可达全部、编辑入口唯一且通往文件详情页。

## Requirements

### Requirement: 用例工作台分栏版式

视口宽度不小于 1280px 时，用例管理项目工作台 MUST 以左右两栏呈现：左栏为固定宽度的目录树，右栏为当前选中文件的用例预览；左栏宽度 MUST 取自模块令牌。用户在左栏点击一个文件时 MUST NOT 触发整页跳转，MUST 在同一工作台右栏就地呈现该文件的用例预览。右栏尚未选中文件时 MUST 呈现选择引导（空态），MUST NOT 呈现空白区域。切换选中文件 MUST NOT 重建目录树：树的展开状态与滚动位置 MUST 保持不变。视口宽度小于 1280px 时 MUST NOT 并置，MUST 只呈现目录树，点击文件 MUST 跳转到该文件的详情路由（`/cases/projects/:projectId/files/:fileId`）。工作台页头副标题 MUST 给出内容概况（目录数与文件数）。

#### Scenario: 宽屏点击文件在右栏就地预览

- **WHEN** 视口为 1500px 的用户打开某个用例项目工作台并点击目录树中的一个用例文件
- **THEN** 浏览器地址 MUST NOT 离开该工作台路由
- **AND** 右栏呈现该文件的用例预览，面包屑末项为该文件名

#### Scenario: 未选中文件时给出引导空态

- **WHEN** 用户刚进入工作台、尚未点击任何文件
- **THEN** 右栏呈现选择引导空态
- **AND** MUST NOT 呈现空白右栏

#### Scenario: 窄屏退化为两页流程

- **WHEN** 视口为 1024px 的用户点击目录树中的一个用例文件
- **THEN** 浏览器地址变为该文件的详情路由
- **AND** 工作台 MUST NOT 呈现并置的右栏预览

### Requirement: 右栏用例预览只读且固定五列

工作台右栏的用例预览 MUST 以只读形式呈现，且 MUST 只包含五列：**用例 ID · 测试类型 · 业务类型 · 标题 · 时间**（时间取该用例的更新时间）。「模块 / 前置 / 步骤 / 预期结果 / 操作」等其余列 MUST NOT 出现在右栏，MUST 只在文件详情页呈现。测试类型与业务类型 MUST 以其枚举中文标签呈现，且 MUST NOT 可点击切换。右栏 MUST NOT 提供任何编辑能力：MUST NOT 有行内可编辑单元格、MUST NOT 有新建行 / 删除行按键、MUST NOT 有保存按键。右栏 MUST 通过分页让该文件的**全部**用例都可浏览：每页固定 10 行，MUST 提供「第 X / Y 页 · 共 N 条」与上一页 / 下一页（到边界时对应按键 MUST 禁用）。右栏 MUST 只保留**一个**「进入页面编辑」入口，位置 MUST 在预览标题行并保持可见；点击后 MUST 跳转到该文件的详情路由。预览加载失败时 MUST 展示错误并允许重试，MUST NOT 静默清空后假装成功。

#### Scenario: 预览只呈现五列

- **WHEN** 宽屏用户在工作台右栏打开一个有用例的文件并查看表头
- **THEN** 表头恰好为 用例 ID、测试类型、业务类型、标题、时间 五项
- **AND** MUST NOT 出现模块、前置、步骤、预期结果、操作

#### Scenario: 预览不可编辑

- **WHEN** 用户在右栏预览里双击任一单元格，或尝试切换类型标签
- **THEN** MUST NOT 出现输入框或类型下拉，MUST NOT 进入编辑态
- **AND** MUST NOT 出现新建行 / 删除行 / 保存按键
- **AND** MUST NOT 发出任何写请求

#### Scenario: 分页可达全部用例

- **WHEN** 某文件共有 13 条用例
- **THEN** 右栏首页呈现 10 行并标注「第 1 / 2 页 · 共 13 条」
- **AND** 其余 3 条 MUST 可通过「下一页」到达
- **AND** 到首页 / 末页时对应的翻页按键 MUST 禁用

#### Scenario: 编辑入口唯一且通往详情页

- **WHEN** 统计右栏内文案为「进入页面编辑」的按键并点击它
- **THEN** 数量恰好为 1
- **AND** 浏览器地址变为该文件的详情路由，详情页呈现可编辑的完整用例表

#### Scenario: 加载失败可重试

- **WHEN** 右栏预览的用例数据加载失败
- **THEN** 右栏呈现错误提示与重试入口
- **AND** MUST NOT 呈现为「该文件无用例」的空态

### Requirement: 目录树行不标注节点类型且在窄左栏内不溢出

用例管理工作台目录树的每一行 MUST 通过图标与尾部信息表达节点类型，MUST NOT 再单独渲染「目录」或「文件」文字标签。行内的名称、尾随信息与进入指示 MUST 在左栏宽度（取 T0 分栏档位 `--layout-pane-left`）内**完整容纳且不横向溢出**：名称 MUST 可压缩并在超长时以省略号呈现（完整值 MUST 可经 `title` 获取），尾随信息 MUST NOT 被截断——文件行的时间 MAY 省去年份，完整时间 MUST 可经 `title` 获取；进入指示 MAY 以图标级紧凑形式呈现。目录行 MUST 尾随其直接子项数量。行内交互（拖拽、右键菜单、批量勾选）MUST 保持不变。

#### Scenario: 行内不再出现类型文字标签

- **WHEN** 读取目录树任一行的可见文本
- **THEN** MUST NOT 出现独立的「目录」或「文件」文字标签
- **AND** 该行的图标与尾随信息 MUST 仍在

#### Scenario: 目录与文件仍可区分

- **WHEN** 对比同一棵树中的一个目录行与一个文件行
- **THEN** 目录行的图标为文件夹形态且尾随「N 项」
- **AND** 文件行的图标为文档形态且尾随时间

#### Scenario: 行不横向溢出

- **WHEN** 量测目录树任一行的 `scrollWidth` 与 `clientWidth`
- **THEN** 两者 MUST 相等（MUST NOT 出现被裁剪的内容）
- **AND** 名称超长时 MUST 以省略号呈现，且其 `title` MUST 为完整名称

#### Scenario: 文件行时间可获取完整值

- **WHEN** 文件行的时间以紧凑形式呈现（省去年份）
- **THEN** 该元素的 `title` MUST 为完整时间戳
- **AND** 右栏预览的「时间」列 MUST 仍呈现完整时间戳

#### Scenario: 行交互不回归

- **WHEN** 用户对去掉标签后的行执行拖拽、右键或批量勾选
- **THEN** 移动 / 重命名 / 删除 / 勾选行为与改动前一致

### Requirement: 用例工作台与元素定位工作台共用同一套工作台视觉

用例管理项目工作台的**左栏目录树与工具栏** MUST 与元素定位项目工作台逐项同源，差异 MUST 只限模块色、右栏数据列集与业务动作文案。具体：

1. 树行 MUST 默认不绘制可见描边（用 2px 透明描边占位，避免悬停 / 选中时行高跳动），悬停 MUST 给底色，选中行 MUST 给 2px 墨色实线描边 + `--app-shadow-sm` 硬阴影 + 底色；行圆角与内边距 MUST 取与元素定位同档的圆角 / 间距令牌。
2. 层级 MUST 以不小于 18px 的缩进加子层容器左边界虚线引导线表达；展开箭头 MUST 使用 el-tree 原生箭头，MUST NOT 用行尾自绘符号代替。
3. 文件行的进入指示 MUST 紧贴名称右侧，MUST NOT 推到行尾远端。
4. 目录行 MUST 尾随其直接子项数量，子项为 0 时 MUST 显示「空」。
5. 工具栏 MUST NOT 常驻静态位置面包屑；工具栏按钮 MUST 具备与元素定位一致的 hover 左上位移、disabled 半透明与危险态（红底 + 浅色字）皮肤；内边距 MUST 取间距令牌。

#### Scenario: 行默认态与选中态同源

- **WHEN** 打开用例工作台、指针不在任何行上
- **THEN** 每一行的 `border-color` MUST 为透明值（不绘制可见描边）
- **AND** 选中某文件后，该行 MUST 出现 2px 墨色实线描边与 `--app-shadow-sm` 硬阴影

#### Scenario: 层级引导线与原生箭头

- **WHEN** 观察含子节点的目录行与其子行
- **THEN** 子层容器左边界 MUST 有 `2px dotted` 引导线
- **AND** 目录行 MUST 使用 el-tree 原生展开箭头（MUST NOT 出现自绘的行尾 `▾`）

#### Scenario: 进入指示紧贴名称

- **WHEN** 测量文件行中「进入」指示左边缘与文件名称右边缘的距离
- **THEN** 该距离 MUST 小于 24px

#### Scenario: 空目录表达为空

- **WHEN** 某目录下没有任何文件
- **THEN** 该目录行尾 MUST 显示「空」，MUST NOT 显示「0」或「0 项」

#### Scenario: 工具栏与按钮皮肤同源

- **WHEN** 打开用例工作台并测量工具栏
- **THEN** MUST NOT 出现静态的「项目根 / 全部」面包屑
- **AND** 工具栏按钮 hover 时 MUST 出现左上 1px 位移，disabled 时 MUST 半透明
- **AND** 批量模式下的删除按钮 MUST 为红底 + 浅色字

### Requirement: 树行只表达结构与名称

用例管理工作台目录树的**文件行** MUST 只呈现节点图标、名称与紧贴名称的「进入 ›」指示，MUST NOT 再尾随更新时间等数据列信息；更新时间 MUST 由右栏预览的「时间」列与文件详情页承载。**目录行** MUST 尾随其直接子项数量，为 0 时显示「空」。名称 MUST 获得该行除去图标、进入指示与间距之后的全部剩余宽度，并在超长时以省略号呈现（完整值 MUST 可经 `title` 获取）。行内交互（拖拽、右键菜单、批量勾选）MUST 保持不变。

#### Scenario: 文件行不尾随时间

- **WHEN** 读取任一文件行的可见文本
- **THEN** 文本 MUST 只由「图标 + 名称 + 进入 ›」构成
- **AND** MUST NOT 出现时间戳

#### Scenario: 目录行仍尾随子项数

- **WHEN** 读取一个含 1 个文件的目录行与一个空目录行
- **THEN** 前者行尾为 `1`，后者行尾为「空」

#### Scenario: 名称获得剩余宽度

- **WHEN** 在同一左栏宽度下对比元素定位与用例管理的文件行
- **THEN** 两页名称元素的计算宽度 MUST 处于同一量级（用例不再因行尾时间被额外压缩）
- **AND** 名称超长时 MUST 以省略号呈现且 `title` 为完整名称

#### Scenario: 时间仍可获取

- **WHEN** 用户在用例工作台选中一个文件
- **THEN** 右栏预览的「时间」列 MUST 呈现该行用例的完整更新时间
