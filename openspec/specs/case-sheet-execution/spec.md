# case-sheet-execution Specification

## Purpose

让执行继续只认里程碑 YAML：上传的里程碑直接执行，自动化表中的行先编译成里程碑，功能表不能进入设备任务。

## Requirements

### Requirement: 上传里程碑不入库

用户上传一份里程碑 YAML 执行时，系统 MUST 只把它作为本次任务的配置。系统 MUST NOT 把该文件的步骤写入任何用例项目。文件不是里程碑格式时 MUST 拒绝创建任务，并说明需要里程碑格式。

#### Scenario: 里程碑上传不产生用例行

- **WHEN** 用户上传一份合法里程碑并成功创建任务
- **THEN** 任务保存该配置
- **AND** 任何用例项目的行数不变

#### Scenario: 用例格式不能直接执行

- **WHEN** 用户上传一份顶层为用例列表、步骤含动作与断言的 YAML 来创建任务
- **THEN** 系统拒绝创建任务并说明这不是里程碑格式
- **AND** 不创建任务

### Requirement: 平台来源只编译自动化行

选择平台用例时，系统 MUST 只列出当前用户的自动化项目及其用例行。功能项目 MUST NOT 出现在选择器中。提交时系统 MUST 按选择顺序把这些行编译成一份里程碑配置，并走既有里程碑执行入口。系统 MUST NOT 为平台用例新开执行分支。所选行不存在、不属于当前用户，或编译结果不是合法里程碑时，MUST 拒绝提交且 MUST NOT 创建任务。

#### Scenario: 功能项目不可选

- **WHEN** 用户打开平台用例选择器，且同时拥有自动化项目和功能项目
- **THEN** 选择器只出现自动化项目
- **AND** 功能项目不出现

#### Scenario: 自动化行编译后执行

- **WHEN** 用户从自动化项目选择 2 行并提交
- **THEN** 任务保存一份由这 2 行编译出的里程碑配置
- **AND** 任务按既有里程碑入口启动

#### Scenario: 他人用例被拒绝

- **WHEN** 提交的用例行不属于当前用户
- **THEN** 系统拒绝提交并说明无权限或不存在
- **AND** 不创建任务
