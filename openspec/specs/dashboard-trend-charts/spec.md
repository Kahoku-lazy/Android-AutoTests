# dashboard-trend-charts Specification

## Purpose
约定仪表盘「趋势与动态」章节内图表的横轴口径与卡片形态：三张柱状图只覆盖近一周，另有一张按时间进度绘制的当日用量折线图（token + 费用双轴、逐小时取数、平滑曲线），独占一行放在按日图之后，跨零点自动切到新的一天。

## Requirements

### Requirement: 三张统计图横轴只覆盖近一周

仪表盘「趋势与动态」章节的三张柱状图（助手任务卡、每日 Token 用量、每日 DeepSeek 费用）横轴 MUST 为近 7 个自然日且含当天，标签格式 MUST 为 `MM/DD`。三张图 MUST 共用同一组横轴标签，MUST NOT 出现某张图 7 天、另一张 12 天。当天的最后一个刻度 MUST 是当天日期，MUST NOT 多出未来日期。

#### Scenario: 横轴为近七天

- **WHEN** 用户在某日打开仪表盘
- **THEN** 三张柱状图的横轴各有 7 个刻度，最后一个刻度为当天，且三张图的标签逐一相同

### Requirement: 今日用量折线图按时间进度绘制

「趋势与动态」章节 MUST 在「每日 Token 用量 / 每日 DeepSeek 费用」所在行之后，新增一张整行宽度的「今日 Token 与费用」卡片，图表 MUST 为折线（`line`）且 MUST 用平滑曲线连接（MUST NOT 呈现为由直角折点连成的折线）。横轴 MUST 是 0–24 的时间轴，每隔 4 小时一个刻度，共 7 个（`00:00`、`04:00`、`08:00`、`12:00`、`16:00`、`20:00`、`24:00`），MUST NOT 渲染 24 个逐小时标签。曲线 MUST 逐小时取数（每小时一个点），MUST 只画到最近的已完成小时，MUST NOT 在尚未走完或尚未开始的小时上出点。用户把指针移到曲线上任意位置或点击曲线时 MUST 显示该位置的时间、token 消耗与费用，时间 MUST 精确到分钟刻度（未满整点时标为「进行中」）。图 MUST 含两条曲线：token 消耗与 DeepSeek 费用，其中 token MUST 用左纵轴并以紧凑单位显示，费用 MUST 用右纵轴并以「元」标注，两轴 MUST 分开，MUST NOT 把费用与 token 压在同一数值轴上。图 MUST NOT 包含缓存命中系列。当天没有用量时 MUST 仍渲染卡片与 7 个刻度，页面 MUST NOT 出现错误态、MUST NOT 隐藏该卡片。

#### Scenario: 折线卡位置与形态

- **WHEN** 用户打开仪表盘「趋势与动态」章节
- **THEN** 在按日的 Token 图与费用图下方出现「今日 Token 与费用」卡，占满整行，图表为平滑曲线，横轴为 0–24 且每 4 小时一个刻度，含 token 与费用两条曲线且各用一个纵轴

#### Scenario: 悬停与点击都能读取某一时刻

- **WHEN** 用户把指针移到曲线任意位置，或点击曲线
- **THEN** 显示该位置的时间、token 消耗与费用
- **AND** 未满整点的位置标为「进行中」，整点位置标出所属小时的区间

#### Scenario: 当前小时不出未来数据

- **WHEN** 用户在当天 `11:05` 查看该曲线
- **THEN** 曲线最右端不超过 `11` 点这一小时已产生的数据，`12:00` 及以后没有点

#### Scenario: 不画缓存命中

- **WHEN** 用户查看该折线卡的图例
- **THEN** 只有 token 与费用两项，不存在缓存命中

#### Scenario: 跨零点切到新的一天

- **WHEN** 页面在仪表盘停留到本地日期变化（`00:00` 之后）
- **THEN** 该图与三张按日柱图刷新为新一天的数据，曲线从新一天的 `00:00` 重新开始，无需用户手动刷新

#### Scenario: 当天无用量

- **WHEN** 当天没有任何 token 消耗与费用
- **THEN** 该卡片仍然渲染，横轴 7 个刻度齐全，曲线沿 0 值画到当前时刻，页面不出现错误态
