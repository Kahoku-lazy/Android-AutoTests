# ops-agent-config Specification

## Purpose
运营后台的「Agent配置」页面：用一张表展示每条配置的名称、类型、模型配置与系统提示词，支持新建 / 编辑 / 删除并按每页 10 条在本页分页，让运营只维护「名称 + 一条模型配置 + 系统提示词 + 一个类型」这四件事，不触碰运行时装配。

## Requirements

### Requirement: Agent 配置列表的分页与间距

Agent 配置列表 MUST 按每页固定 **10 条**分页展示，页面上 MUST 常驻显示「第 X / Y 页 · 共 N 条」与「上一页 / 下一页」；只有一页时两键 MUST 同时置灰但仍可见，MUST NOT 因数据量少而隐藏整条翻页栏。页码与翻页键 MUST 置于表格正上方、与「新建配置」同一控制区，并 MUST 与用户管理页同序（页码文案在左、翻页键在右）。

控制区与表格之间 MUST 有不小于 16px 的间距；「新建配置」按键 MUST NOT 紧贴表头。删除最后一条使当前页越界时，页面 MUST 自动回到最后一页，MUST NOT 停在空白页。分页 MUST 在本页前端完成（接口仍一次返回全部），SHALL NOT 为此给 `/api/ai/roles/` 新增分页参数。

#### Scenario: 每页 10 条

- **WHEN** 打开 `/ops/agents` 且接口返回 12 条配置
- **THEN** 表格只显示 10 行，页码文案为「第 1 / 2 页 · 共 12 条」
- **AND** 此时「上一页」置灰、「下一页」可用

#### Scenario: 末页置灰

- **WHEN** 点「下一页」进入第 2 页
- **THEN** 表格显示剩余 2 行，页码文案为「第 2 / 2 页 · 共 12 条」
- **AND** 「下一页」置灰、「上一页」可用

#### Scenario: 只有一页时翻页栏仍可见

- **WHEN** 接口只返回 4 条配置
- **THEN** 页码文案为「第 1 / 1 页 · 共 4 条」，两个翻页键都在且都置灰

#### Scenario: 控制区与表格留白

- **WHEN** 测量「新建配置」所在行底部到表格顶部的距离
- **THEN** 该距离明显大于行内元素间距（不小于 16px，实测约 69px 含翻页行）

### Requirement: Agent 配置列表展示类型列

运营后台「Agent配置」列表 MUST 在「名称」列之后展示「类型」列，顺序为：名称 / 类型 / 模型配置 / 系统提示词 / 操作。

类型列 MUST 以标签（chip）呈现当前配置的类型中文名（执行者 / 验收者 / 规划者）；未分类的配置 MUST 显示「未分类」并以次要色文字呈现，MUST NOT 留空白单元格。类型列 MUST NOT 改变既有的分页口径（仍为本页前端每页 10 条切片），也 MUST NOT 改变提示词与模型参数的传递方式。

#### Scenario: 有类型时显示中文标签

- **WHEN** 列表里有一条类型为「验收者」的配置
- **THEN** 该行类型列显示「验收者」标签
- **AND** 该列位于名称列与模型配置列之间

#### Scenario: 未分类配置显示占位

- **WHEN** 列表里有一条没有类型的存量配置
- **THEN** 该行类型列显示「未分类」
- **AND** 该行其余列与分页行为不受影响

#### Scenario: 类型列不改变分页

- **WHEN** 接口返回 12 条配置且都带类型
- **THEN** 表格仍只显示 10 行，页码文案为「第 1 / 2 页 · 共 12 条」

### Requirement: 类型随配置保存与编辑

新建与编辑抽屉 MUST 提供类型单选（执行者 / 验收者 / 规划者），新建时 MUST 必选一项，未选时 MUST 阻止提交并给出可读提示。

保存时类型 MUST 与名称、模型配置、系统提示词一起提交给 `POST` / `PATCH /api/ai/roles/`；保存成功后列表 MUST 立即反映新类型，失败时 MUST 给出可读错误且 MUST NOT 把本地状态当成已保存。编辑存量未分类配置时，抽屉 MUST 预填为空并要求补齐。

#### Scenario: 新建选类型后列表回带

- **WHEN** 新建配置时选择「验收者」并保存
- **THEN** 保存请求带上该类型
- **AND** 列表该行类型列显示「验收者」

#### Scenario: 未选类型阻止提交

- **WHEN** 新建配置时未选择类型就点保存
- **THEN** 页面给出可读提示并且不发起保存请求

#### Scenario: 编辑可改类型

- **WHEN** 把一条「执行者」配置改为「规划者」并保存
- **THEN** 列表该行类型列变为「规划者」
- **AND** 名称、模型配置与系统提示词保持原值
