# page-flow-node-placement Specification

## Purpose

定义页面流画布新建页面节点时的落点规则：节点跟随鼠标最后停留的画布位置出现，没有鼠标位置时退到画布可视区域中心，同一位置连续新建不被完全压住，使「在这里加一个页面」符合用户的空间预期。

## Requirements

### Requirement: 新建页面节点的中心落在鼠标位置

用户点击「+ 页面」时，新页面节点的**中心** MUST 落在鼠标最后停留在画布内的位置（按画布坐标换算，与当前缩放、平移一致）。节点 MUST NOT 固定落在画布左上角一带的预设阶梯位置。该落点唯一的例外是同一位置连续新建时的最小错位（见「同一位置连续新建保持可见」）。

#### Scenario: 鼠标停在画布中部时新建

- **WHEN** 用户把鼠标移到画布可视区域中部的某一点（该处没有已存在的节点），随后点击「+ 页面」
- **THEN** 新页面节点的中心落在该点对应的画布坐标上（误差不超过 1px）

#### Scenario: 画布缩放或平移后仍落在鼠标处

- **WHEN** 用户先把画布缩放或平移，再把鼠标停在画布内的某一点并点击「+ 页面」
- **THEN** 新页面节点的中心仍落在该点（而非落在缩放前的旧坐标或视口原点）

### Requirement: 无鼠标位置时落到画布可视区域中心

若用户尚未把鼠标移入过画布（例如刚打开文档就直接点工具栏按钮），新页面节点 MUST 落在画布当前可视区域的中心附近，MUST NOT 落在画布坐标系原点附近导致需要大量拖动才能找到。

#### Scenario: 刚打开文档就新建页面

- **WHEN** 打开一篇页面流文档后，用户未把鼠标移入画布即点击「+ 页面」
- **THEN** 新页面节点出现在画布可视区域内（其中心落在可视区域范围内），而不是停留在画布坐标系原点

### Requirement: 同一位置连续新建保持可见

在同一落点连续新建多个页面节点时，后建的节点 MUST 做最小错位，使每个新节点都至少部分可见、可被点选。MUST NOT 让新节点与已存在的节点完全重合（完全压住等于新建失败）。错位比较 MUST 以节点中心为准，避免尺寸不同的两个节点被误判为重合。

#### Scenario: 不动鼠标连点两次新建

- **WHEN** 用户不移动鼠标，连续点击两次「+ 页面」
- **THEN** 画布上出现两个页面节点，两者的位置不相同，任一节点都可见

### Requirement: 落点只影响新节点坐标

本能力的落点规则 MUST NOT 改变已有节点的坐标、节点总数上限、节点命名规则与自动保存行为。

#### Scenario: 新建后已有节点保持原位

- **WHEN** 画布上已有若干页面节点，用户在某点新建一个页面节点
- **THEN** 已有节点的坐标不变，新节点命名沿用既有规则，画布照常自动保存
