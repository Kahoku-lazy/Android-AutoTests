一、结构化输出契约（Pydantic · 两线路共享 · 零新增）

这 4 个契约是「通用能力」，设备控制与平台任务共用，平台任务不新增任何 Pydantic 模型。

class GoalPlan(BaseModel):
    goal: str            # 目标描述（平台任务：内嵌职责①~④的判断结果）
    steps: list[str]     # 执行步骤 = 工具调用序列
    verification: str    # 验收标准

class PlannerOutput(BaseModel):
    plans: list[GoalPlan]    # 拆解后的目标列表（多目标依次执行）

class FailedItem(BaseModel):
    item: str            # 未通过的那一步 / 目标项
    reason: str          # 未通过的原因

class VerificationResult(BaseModel):
    result: Literal["pass", "fail"]
    completed: list[str]
    failed: list[FailedItem]
    summary: str

二、配置数据类型（dataclass）

类归属字段
ModelConfig共享provider / model_name / api_key(已解密) / base_url
DeviceExecutionConfig设备控制planner / executor / verifier（均为 ModelConfig）/ max_loops
PlatformTaskConfig新增planner / executor / verifier（均为 ModelConfig）/ max_loops
 
@dataclass
class PlatformTaskConfig:   # 新增：平台任务专用，与 DeviceExecutionConfig 结构相同但语义隔离
    planner: ModelConfig = field(default_factory=ModelConfig)
    executor: ModelConfig = field(default_factory=ModelConfig)
    verifier: ModelConfig = field(default_factory=ModelConfig)
    max_loops: int = 3

四、输入契约（Serializer，已就绪，零新增）

class TaskSubmitInputSerializer(serializers.Serializer):
    goal = serializers.CharField(required=True, allow_blank=False)
    requirements = serializers.CharField(required=False, allow_blank=True, default="")
    attachment = serializers.CharField(required=False, allow_blank=True, default="")
    route = serializers.ChoiceField(choices=["device_control", "platform_task"], required=True)
    report_name = serializers.CharField(required=False, allow_blank=True, default="")
    checklist = serializers.CharField(required=False, allow_blank=True, default="")
    device_serial = serializers.CharField(required=False, allow_blank=True, default="")

五、工作流 run() 返回契约

# 成功
{"status": "success", "completed": list[str],
 "log": [{"goal": str, "loop": int, "result": str}, ...]}

# 失败（max_loops 用尽 / 规划无产出）
{"status": "fail", "message": "任务失败", "failed_goal": str,
 "failed": [{"item": str, "reason": str}, ...], "log": [...]}
该 dict 直接 JSON 序列化写入 AITask.result，与设备控制完全同构，前端任务卡片零改动。

八、关键结论

✔ 结构化输出契约：4 个 Pydantic 全复用，平台任务零新增

✔ 持久化：route_configs 的 platform_task key + AITask 7 字段均已就绪，零新表
