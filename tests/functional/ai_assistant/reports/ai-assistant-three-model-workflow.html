一、三个智能体

智能体模型职责
planner 规划文本（thinking）拆分多目标 → {goal, steps, verification}
executor 执行视觉完成目标步骤（截图/动作）
verifier 验收视觉二次确认 PASS/FAIL + completed/failed

② model.py（模型层：通用创建 + DeviceExecution 类）

class DeviceExecution:
    """设备执行：读三模型配置 → 通用创建 + 包装 → 持有三个 Agent。"""
    def __init__(self, config: DeviceExecutionConfig, user_id=""):
        self.config = config
        self.user_id = user_id
        # 配置与模型创建分离：通用 create_model，再 build_agent 包装
        self.planner_agent = build_agent(
            create_model(config.planner, stream=False),
            PLANNER_PROMPT, [], user_id)
        self.executor_agent = build_agent(
            create_model(config.executor),
            VISION_PROMPT, VISION_TOOLS, user_id)
        self.verifier_agent = build_agent(
            create_model(config.verifier),
            VERIFIER_PROMPT, VERIFIER_TOOLS, user_id)

③ workflow.py（工作流层：DeviceExecutionWorkflow 类）

class DeviceExecutionWorkflow:
    """设备执行工作流：planner → executor ↔ verifier 循环。"""
    def __init__(self, dev: DeviceExecution):
        self.dev = dev

    async def run(self, user_input: str) -> dict:
        plans = await self.dev.planner_agent.reply(
            UserMsg(user_input), structured_schema=PlannerOutput)
        for plan in plans:
            verdict = None
            for _ in range(self.dev.config.max_loops):
                result = await self.dev.executor_agent.reply(UserMsg(plan.steps))
                verdict = await self.dev.verifier_agent.reply(
                    UserMsg(plan.verification + result),
                    structured_schema=VerificationResult)
                if verdict.result == "pass":
                    break
            if verdict is None or verdict.result != "pass":
                return {"status": "fail", "message": "任务失败", ...}
        return {"status": "success", ...}

三、数据契约

class GoalPlan(BaseModel):
    goal: str            # 目标
    steps: list[str]     # 步骤
    verification: str    # 检验标准

class VerificationResult(BaseModel):
    result: Literal["pass", "fail"]
    completed: list[str]
    failed: list[FailedItem]   # {item, reason}
    summary: str
