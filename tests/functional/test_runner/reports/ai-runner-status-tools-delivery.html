AI 侧使用模式（打通后）

  • run_test 创建 run 后 → 轮询 get_run_status：status=RUNNING 且 result_count=0 表示执行中；completed/COMPLETED 表示结束
  • 结束后调 get_run_results：信封 run_status.summary 给出每用例通过率，results 给每轮明细（pass/fail/时长/详情/步骤详情）
  • 异常 run_id → 400「run 不存在」；AI 可据此校验 run_id 是否拼错

已知边界（登记不修）

  • 登记 执行中实时进度（当前用例/轮次/步骤）仍只走 WebSocket，AI 无法订阅——get_run_status 运行中只能回答"还在跑"
  • 登记 TaskCard（前端任务卡片）无 AI 工具；AI 的 run 与前端卡片体系不互通（run_test 未关联 client_task_id）
  • 登记 tr_test_runs.status 历史值大小写混存（RUNNING/completed/stopped/FAILED），工具如实透传
  • 登记 run_test 的 loop_count 恒 1、仅 UI 用例
